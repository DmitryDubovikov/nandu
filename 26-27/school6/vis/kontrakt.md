# Контракт рисунков HTML-учебников 6 класса

Общий для семи пар. Прецедент — `26-27/school5/vis/` (README school5, абзац «HTML-версии учебников»).

## Как устроено

1. **Сборка.** `python3 tools/md2html.py <учебник.md> <папка сборки>/ <учебник.vis.json>`; учебник `math6_*_uchebnik` собирается
   в одну колонку без сухого остатка (как school5), дроби `a/b` и `½` внутри бэктиков встают столбиком.
   Проверка целиком: `python3 26-27/school6/vis/proverka.py <учебник.md> [--str NN] [--kadry]` — сборка, `--check`
   (потеряно / дописано = 0), рисунки без якоря и не вставшие, повторы id маркеров, вылезание на 400 px.
2. **vis.json** пишется только скриптом `26-27/school6/vis/<пара>.py` целиком, руками не правится. Ключ — якорь: подстрока
   текста блока MD, после которого встанет рисунок. Блок сравнивается без `* \` > # |` и со схлопнутыми пробелами — в якоре
   этих символов быть не должно. Якорь срабатывает один раз, на **первом** блоке документа, где встречается: бери подстроку,
   уникальную для нужного абзаца. Если текст блока целиком входит в более ранний блок (ASCII-сетка из одних точек), якорь
   `=<весь текст блока>` срабатывает только на блоке с точно таким текстом. Якорь в абзаце `**Задача.**`/`**Условие.**` ставит рисунок справа от рамки условия.
3. **Значение** — `fig(svg_body, cap, fx=False, zamena=False)` из `26-27/school6/vis/common.py` (импорт `from common import …`
   из своего скрипта в той же папке). Подпись объясняет «почему так можно», а не пересказывает схему; текст MD подписью не
   дублируется и не пересказывается. Текст рисунка в сверку не входит — но и нового смысла сверх MD в нём быть не должно.
4. **Ширина.** В одноколоночном учебнике `figure>svg` ограничен 460 px. Рисуй viewBox шириной 380–480, шрифт ≥ 14 единиц:
   шире — всё ужмётся и подписи станут мелкими. На телефоне рисунок ужимается ещё (~340 px) — проверь кадр `фиг/*_400.png`.
   Два рисунка рядом (пример | контрпример) — `row(svg1, svg2)` внутри одного `fig`: на узком экране ряд переносится.
5. **Анимация.** `fig(..., fx=True)`; внутри SVG `g('fi', d, …)` проявляется к моменту d секунд, `fo` гаснет, `sl` переезжает
   на `--to` (`g('sl', d, body, ";--to:translate(40px,0px)")`), `dr` прорисовывает линию (`pathLength='100'`). Играет, когда
   рисунок виден наполовину; кнопка «↻ ещё раз» появляется сама. Без `fx=True` классы ничего не делают — рисунок статичен
   в конечном виде. Исходник стоит неподвижно слева, движется копия справа. Длительность всей анимации ≤ 6 с.
6. **ASCII-блоки** (```…``` с рисунком из чёрточек) получают SVG-замену: `fig(..., zamena=True)` с якорем — подстрокой
   **самого блока** (например `A---------C`). Конвертер ставит рисунок на место блока, а ASCII прячет (`hidden`, сверка его
   видит). Все буквы и числа ASCII-рисунка обязаны стоять на SVG — assert в скрипте. Блоки-формулы (```В − Р + Г = 2```)
   и таблицы перевода единиц — не рисунки, их не трогать. Отчёт proverka печатает «ASCII-блоков без замены N» — это
   подсказка, не ошибка.
7. **Цвета** (сквозные): GOLD — на что смотрим, RED — запрет / ошибка / «не подходит», BLUE — выбор / действие,
   GREEN — результат / «подходит», GREY — выбывшее, VIOLET/CYAN/PINK — вторая-третья величина. Подписи — MUTED
   (не тёмно-серый). Фон тёмный — заливки делать полупрозрачными (`fill-opacity` 0.15–0.85).
8. **Примитивы** `common.py`: `NumLine` (числовая прямая: axis/point/seg/jump), `Plane` (координатная плоскость с сеткой),
   `cells` (клетчатое поле), `bar` (полоса-целое из n частей), `sets` (вложенные/пересекающиеся множества-овалы),
   `path`/`dot`/`circle`/`label` (геометрия по координатам), `angle_arc`, `right_angle`, `ticks` (черточки равенства),
   `dim` (размерная линия), `height` (высота пунктиром со знаком прямого угла; вне отрезка — продолжение основания), `brace` (фигурная скобка с подписью), `row`, а также из school5: `svg`, `t`, `g`, `rect`, `line`, `strike`, `frac`, `arrow_defs_p`.
   Одинаковые объекты во всех парах рисуются этими примитивами. Нужен новый общий — пишешь координатору, сам не добавляешь.
9. **Числа из констант.** Геометрия строится из координат в коде; числа и буквы на рисунке — из тех же констант, по которым
   в скрипте стоят assert'ы: длины, углы, площади, точки графика равны числам текста; строка, которую рисунок цитирует,
   действительно есть в MD (`assert s in MD`). Образец приёма — `26-27/school5/vis/drobi.py` (функции `need`, `BLOCKS`).
10. **id маркеров** уникальны на странице: `arrow_defs_p('<пара><глава><№>a', [цвета])` — свой префикс у каждого рисунка.
11. **Кадры** (`--kadry`, папка `26-27/school6/vis/kadry/<учебник>/`, в git не идёт): `стр/<страница>_dK.png` — страница
    на десктопе 1440 px срезами по 1500 px, анимации доиграны; `фиг/<страница>_<n>_400.png` — каждый рисунок на ширине
    телефона; `анм/<страница>_<n>_start.png|_end.png` — анимация в начале и в конце. Смотреть их через Read.
12. **Запреты.** Не править MD-текст, `tools/md2html.py`, шаблоны `tools/md2html_*.html`, `26-27/school6/vis/common.py`,
    `proverka.py`, `kontrakt.md` и чужие файлы. Нужна правка — сообщение координатору; он вносит её один раз для всех.
