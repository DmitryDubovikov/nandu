# План рисунков — `26-27/school6/math6_7_vyrazheniya_koordinaty_uchebnik.md`

Скрипт: `26-27/school6/vis/vyrazheniya_koordinaty.py` → `26-27/school6/math6_7_vyrazheniya_koordinaty_uchebnik.vis.json`.
Цвета по контракту (`26-27/school6/vis/kontrakt.md`, п. 7): GOLD — на что смотрим (исходная точка, исходное выражение,
точки таблицы), BLUE — действие (прыжок, переезд, путь отсчёта), GREEN — результат («подходит», образ), RED — ошибка /
«не подходит», GREY — выбывшее и пунктир-подсказка, VIOLET/CYAN — вторая-третья величина (кучка `b`, кучка чисел,
второй путь). Подписи — MUTED. Префикс id маркеров — `v7` + номер рисунка (`v7_43`).

Сквозные решения:
- **Плоскость и графики — только `Plane`.** Точки графика на рисунке = ровно точки таблицы значений из текста
  (assert на списки `(x; y)` против таблиц MD). Линия графика — отдельно от точек, точек не добавляет.
- **Симметрия, поворот, перенос:** исходная точка / отрезок стоит неподвижно (GOLD), движется копия.
- **Кирпичик буквы** в части A: `x`, `a`, `y` — полоски длины, некратной клетке (общий случай, Ш4: `x` не выглядит
  целым числом клеток, `y` не равен `x`); число — единичный квадрат.
- **Поворот на 180°** (5.1) — `turn(O, deg, body, d)` из `common.py` (положительный `deg` — по часовой на экране;
  против часовой — `deg = −180`).
- **Кирпичики** `a`, `x`, `y` (2.1, 3.1, 3.2, 1.3, 1.4) — `rect`/`bar` с одной шириной кирпичика на всю пару:
  константы `BX` (длина `x` и `a`), `BY` (длина `y`), `BU` (единичный квадрат). Прыжки 1.1, 1.2 — `NumLine.jump`
  (нижний ряд — `below=True`).
- **Плоскость** — `Plane(..., xu, yu)` и `grid(..., xname, yname, xlabels, ylabels)` из `common.py` (правка координатора).
- Ш12 (иерархия схемой): линейной иерархии понятий в учебнике нет; контраст «прямая ≠ прямая пропорциональность» — рисунок 7.6.
- Каждая анимация ≤ 6 с.
