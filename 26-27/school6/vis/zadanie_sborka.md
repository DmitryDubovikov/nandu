# Этап 2 — сборка рисунков одной пары (задание агенту)

Пишешь только свои файлы: `vis/plan_<пара>.md`, `vis/<пара>.py`, `math6_N_*_uchebnik.vis.json` и папку сборки своего
учебника. MD-текст, `tools/`, `common.py`, `proverka.py`, `kontrakt.md` и чужие файлы не трогаешь; нужно что-то общее —
пиши координатору. Не коммить: коммиты делает координатор.

1. Внеси в свой план правки координатора (они в сообщении); план — источник правды для скрипта.
2. Собери учебник без рисунков, `python3 26-27/school6/vis/proverka.py <учебник.md>` — нули в сверке. Посмотри разметку
   (что стало формулой, что карточкой).
3. Напиши `26-27/school6/vis/<пара>.py`, генерирующий `vis.json` целиком (образец приёма — `26-27/school5/vis/drobi.py`):
   геометрия из координат в коде, а не из набранных путей; числа и буквы на рисунке — из тех же констант, на которых
   стоят assert'ы: длины, углы, площади, точки графика равны числам текста; цитируемая строка есть в MD
   (`assert s in MD`); у замены ASCII все буквы и числа блока стоят на SVG. Одинаковые объекты — примитивами
   `common.py` (`NumLine` для любой прямой с числами, `bar` для полосы из частей, `cells` для клеток, `Plane` для
   плоскости, `turn`/`flip` для поворота и перегиба, `height` для высоты, `brace` для скобки).
4. `python3 26-27/school6/vis/proverka.py <учебник.md> --kadry` — сверка 0/0, ни «без якоря», ни «не встал», ни «✗ 400 px».
5. **Смотри кадры** (Read по картинке): каждый срез `стр/*_dK.png` (рисунок на месте, подписи читаются, ничего не
   наложилось), каждый `фиг/*_400.png` (на телефоне подписи не мельче читаемого, ничего не обрезано), у анимаций
   `анм/*_start.png` и `_end.png` (мысль движения понятна по двум кадрам; в начальном кадре нет конечного ответа).
6. Правь и повторяй 4–5, пока все кадры не чистые.

## Отчёт координатору (последнее сообщение, кратко)
- вывод `proverka.py` без `--kadry` дословно (сверка, итого рисунков/анимаций, «ошибок нет»);
- рисунков и анимаций по главам — одной строкой на главу;
- что вычеркнул или изменил сам по ходу и почему;
- чего проверить не смог.
