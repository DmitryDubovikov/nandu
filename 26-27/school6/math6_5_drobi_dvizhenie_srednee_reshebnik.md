## Блок 2. Задачи на движение по реке

**2.1** Собственная скорость катера `14,5` км/ч, скорость течения реки `2,5` км/ч. Найди скорость катера по течению и против течения. За сколько часов катер пройдёт `51` км против течения?

**2.2** Лодка идёт по течению со скоростью `21` км/ч, а против течения — со скоростью `15` км/ч. Найди собственную скорость лодки и скорость течения. На сколько километров больше пройдёт лодка за `3` часа по течению, чем за `3` часа против течения?

**2.3** Теплоход прошёл `120` км по течению реки за `4` часа, а обратно тот же путь — за `6` часов. Найди собственную скорость теплохода и скорость течения. За сколько часов теплоход прошёл бы `120` км по озеру? Объясни, почему скорость течения не равна `10` км/ч.

## Блок 3. Среднее арифметическое

**3.1** Найди среднее арифметическое чисел `3,6`; `4,2`; `5`; `2,8`; `4,9`.

**3.2** В одном ящике `12` яблок, их средняя масса `150` г. В другом ящике `8` яблок, их средняя масса `175` г. Найди среднюю массу яблока в двух ящиках вместе.

**3.3** Турист `3` часа шёл пешком со скоростью `4` км/ч, а потом `1` час ехал на автобусе со скоростью `40` км/ч. Какой путь он проделал и какова его средняя скорость на всём пути? Объясни, почему средняя скорость не равна `22` км/ч.

# Ответы

**Блок 1.** 1.1 `5/12` (в знаменателе `6` есть тройка — считаем в обыкновенных, поэтому `0,8 = 8/10 = 4/5`; дальше `4/5 × 5/6 = 2/3`, затем `2/3 − 1/4 = 8/12 − 3/12 = 5/12`); 1.2 `4,25`, то есть `4 1/4` (дробь `6/15` сокращается до `2/5 = 0,4` — тройка из знаменателя ушла, и десятичная дорога открыта: `2,25 − 0,75 = 1,5`, `1,5 : 0,4 = 3,75`, `3,75 + 0,5 = 4,25`); 1.3 за день отлили `2 11/30` л, осталось `2 5/6` л (в `1 2/3` знаменатель `3` — дробь в десятичную не переводится, поэтому считаем в обыкновенных: `0,7 = 7/10`, `5,2 = 5 1/5`; отлили `1 2/3 + 7/10 = 1 20/30 + 21/30 = 2 11/30` л; осталось `5 1/5 − 2 11/30 = 5 6/30 − 2 11/30 = 2 25/30 = 2 5/6` л; в десятичных считать нельзя: `2/3 = 0,666…` — цифры не кончаются, а округлённое `0,67` даст приблизительный ответ вместо точного).

**Блок 2.** 2.1 по течению `14,5 + 2,5 = 17` км/ч, против течения `14,5 − 2,5 = 12` км/ч, `51 : 12 = 4,25` ч; 2.2 собственная `(21 + 15) : 2 = 18` км/ч (полусумма), течение `(21 − 15) : 2 = 3` км/ч (полуразность, а не вся разность `6`), за `3` часа по течению `21 × 3 = 63` км, против течения `15 × 3 = 45` км, разница `63 − 45 = 18` км; 2.3 по течению `120 : 4 = 30` км/ч, против течения `120 : 6 = 20` км/ч; собственная `(30 + 20) : 2 = 25` км/ч, течение `(30 − 20) : 2 = 5` км/ч; по озеру теплоход идёт с собственной скоростью: `120 : 25 = 4,8` ч; `10` км/ч — это вся разность `30 − 20`, а в ней два течения: одно прибавилось по течению, второе отнялось против, поэтому разность делят пополам.

**Блок 3.** 3.1 `4,1` (сумма `20,5`, чисел `5`, `20,5 : 5 = 4,1`); 3.2 `160` г (сумма масс в первом ящике = `150 × 12 = 1800` г, во втором = `175 × 8 = 1400` г, всего `1800 + 1400 = 3200` г на `12 + 8 = 20` яблок, `3200 : 20 = 160` г; а не `(150 + 175) : 2 = 162,5` г — ящики разного размера, усреднять средние нельзя); 3.3 путь `3 × 4 + 1 × 40 = 52` км, всё время `3 + 1 = 4` ч, средняя скорость `52 : 4 = 13` км/ч; `22` — это среднее арифметическое скоростей, `(4 + 40) : 2`, оно годилось бы при равном времени на каждой скорости, а здесь на медленной скорости турист провёл `3` часа из `4`.
