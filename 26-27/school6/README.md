## Соглашения

- Учебник открывается врезкой «что здесь / как пользоваться / что нужно знать заранее», затем — для новой темы — разделом «Что такое X, читать первым», затем «ритуалы», затем главы. Каждая глава кончается «типичными ошибками».
- **Разборы — итеративные шаги с несгораемыми артефактами:** шаг 1 = план, кончающийся блоком «✅ План готов: Ответ = …», дальше шаг на подзадачу, каждый открывается целью («нужно Б — для этого делаю А») и кончается своим результатом, последний шаг — сборка. Таблица «что делаем | что получается» как скелет разбора не используется (в парах `school5` она ещё есть — это старый формат).
- **Короткий разбор идёт без плана** (12.11.2026, полировка всех пар): блок «✅ План готов» ставится, только если в нём есть операнды — формула, из которой собирается ответ. План, пересказывающий вопрос («Ответ = отрицание + вердикт»), и пустой «Шаг N — сборка» — дефект; такой разбор открывается одной вводной строкой и кончается «Ответ на задачу».
- **Правило стоит под случаями, из которых оно видно** (правило 17 `CLAUDE.md`): над правилом знаков — ряд `3 · 2, 3 · 1, 3 · 0, 3 · (−1)`, над свойством пропорции — три пропорции с произведениями, над формулой площади — счёт на клетках, над графиком — таблица значений по возрастанию. Там, где список ничего не открывает (определения, построения), его нет.
- Наблюдение, на котором держится приём, называется отдельным абзацем **«Заметь главное»**, а не растворяется в механике шагов.
- Блок решебника = 3 задачи с разными ролями: приём в чистом виде · приём с ловушкой или в нестандартной подаче · текстовая задача с двумя вопросами и требованием объяснить ответ. Дубль по скелету выкидывается, а не переписывается с другими числами.
- Примеры учебника и задачи решебника не пересекаются ни числами, ни сюжетом.
- Термины настоящие и вводятся при первом появлении: назвать → показать на числах конкретного примера → дальше использовать свободно.
- Документы самодостаточны: ноль ссылок наружу (кроме имени файла-близнеца), никаких «дней» и номеров занятий.
- Картинок нет — только ASCII-рисунки и словесные инструкции построения.
- Все ответы посчитаны точной арифметикой (`fractions.Fraction` / `decimal.Decimal`, перебор) и перепроверены второй, независимой волной агентов, решавших задачи с нуля по одним условиям.
