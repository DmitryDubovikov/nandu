## 1. Что пишем

- Учебник «по-взрослому»: размещения, перестановки, сочетания, с повторениями и без, с доказательствами формул.
- Строится на четырёх правилах — **сумма, произведение, деление, соответствие**; формулы — теоремы из них.
- Каждая глава повторяет **ход изложения своего образца** (таблица §3); свои числа и сюжеты, текст образца дословно не переносится.
- Закрывает недобор из `26-27/nandu_level2/README.md`: «не усвоено — сочетания/размещения/перестановки с повторами,
  звёзды и палочки, включение-исключение». Ходы корпуса вне образцов — `26-27/nandu_level2/nandu_n2_obraztsy.md`.
- **Только теория, решебника нет** (решение родителя 24.10.2026): практика — корпус и решебники уровня 1.
  Разобранные примеры внутри глав остаются — это и есть изложение образца. В конце главы — **один вопрос «Проверь
  себя»** с ответом под спойлером: понял ли ребёнок главную мысль главы (не тренировка).
- Файлы: учебник `26-27/nandu_level2/kombinatorika/nandu_n2_kombinatorika_uchebnik.md`, карты образцов
  `26-27/nandu_level2/kombinatorika/karty/glava_N.md`.

## 4. Протокол сеанса — одна глава

1. **Прочитать:** `CLAUDE.md` (hard rules — учебник детский, действуют все), этот файл, исследование, разделы образца
   из `26-27/nandu_level2/kombinatorika/istochniki/*.txt` (grep по номеру § или задачи), принятые Т3-решения (§2),
   как тот же ход дан на уровне 1 — `25-26/nandu_level1/regional/nandu_n1_regional_schet_1_atomy_uchebnik.md`,
   `25-26/nandu_level1/regional/nandu_n1_regional_schet_3_tablitsa.md` (продолжаем, не противоречим), уже написанные главы.
2. **Карта образца** → `26-27/nandu_level2/kombinatorika/karty/glava_N.md`: по строке на каждый пример образца —
   **фразы решения образца дословно** (2–4 предложения, цитатой), где автор останавливается и разжёвывает, ловушка,
   обобщение; колонка «В главе» — только свои числа и сюжет, **без своего хода**. Карта — каркас главы: глава
   повторяет цитаты образца со своими числами. Форма — `karty/glava_1.md`.
   - **Что не берём из образца** — так и пишется в карте с причиной: абзацы-мостики к задачам образца, которых в главе
     нет (Шень «нужно вникнуть в формулировку…» перед 2.10); сквозные персонажи образца (Беня Шеня) → наши герои
     (Томас, Лусия, Аня, Боря), заголовок примера называет содержание, не героя.
   - **План рисунков — до текста главы** (решение родителя 24.10.2026: «здесь совсем нет картинок… как Three Blue One
     Brown»): по строке на пример — что рисуем и **какую мысль показывает движение**; не назвал мысль — рисунок
     статичный (правило 15). Анимируется переход: элемент уходит из меню в место, ладья вычёркивает горизонталь,
     одно и то же дописывается в числитель и знаменатель, фильтр гасит лишние слова.
3. **Глава** по карте. Пример = блок «Задача.» (правило 13) + фразы образца со своими числами + формула отдельной
   строкой (правило 10) + «Ответ на задачу». Шаги, план-артефакт, операнды N(…) · N(…) — **только если они есть у
   образца** (⛔-блок и правило 8 `CLAUDE.md` к примерам по образцу не применяются). Термин вводится на числах
   (правило 5), общая формула с n и k — отдельным разделом после примера, типичные ошибки, ритуалы — в главе 1
   (правило 6). Корпус в примерах запрещён (правило 1). Два запрета (решение родителя 24.10.2026, глава 1):
   - **задача — только внутри блока «Задача.», теория — только вне его**; задача и теория в одном абзаце
     («Одинаковое меню. Флаг из четырёх полос…») — дефект;
   - **никаких отсылок и мета-комментариев**: «как в примере 1», «третий выбор в таблицу не помещается», «умножать
     пока нечего», абзац «Идея главы», «что здесь произошло», рассказ о таблице вместо таблицы, метки «(Р1)» в
     тексте примеров. Вне колонки «Разжевать» — только фразы образца.

   Дефекты главы 2 (24.10.2026) — не повторять:
   - **Одна мысль — один абзац.** Фразы образца идут по одной на абзац; перечисление «для первой — n, для второй —
     n − 1, …» — списком; определение в рамке — по утверждению на абзац; «Например, …» после общего правила —
     новым абзацем.
   - **У каждого примера виден вывод.** Если мораль образца общая («важно понимать, что считаем») или её нет —
     вывод рамкой `:::box <вопрос или условие>`: в рамке **только общее** (n, k, «элемент», «набор»), ни одного
     предмета задачи; сразу под рамкой — «В частности, …» на объектах примера (правило 8 `CLAUDE.md`, вставка).
   - **Вопрос и ответ — числом и словами задачи.** Не «изменится ли?» → «а) не изменится» (непонятно, что такое
     а и б), а «сколько слов, в которых…?» → «а) 6 слов; б) 6 слов — те же самые: …».
   - **Условие — по строкам** (правило 13): завязка с «:» + список данных + вопрос отдельной строкой; несколько
     частей данных («Томас считал так:» + список) держатся в рамке.
   - **На рисунке — одна мысль, только существующие объекты.** Сетка «занято / осталось» с красной «4-й строкой»
     для ошибки 8 − 3 = 5 смешала 5, 4, 3 и выбор, которого нет: ошибку объясняет текст, рисунок подписывает
     правильную строку («заняты 2 = 3 − 1», «свободны 8 − 2 = 6»).
   - **Скобки — одни на весь учебник** (решение родителя 25.10.2026, глава 4): круглые — цепочка, порядок важен,
     (Аня, Боря) ≠ (Боря, Аня); фигурные — набор без порядка, {Аня, Боря} = {Боря, Аня}. Неупорядоченную пару или
     тройку в круглых скобках не писать; C(n, k), A(n, k), N(…) — имена чисел, не цепочки.
   - **Один цветовой язык на главу:** у каждого ребёнка, буквы, цифры свой цвет во всех рисунках; выбывшее —
     серое, свободное — подсвечено. Рисунки — скрипт `kombinatorika/vis/glava_N.py` (образец — `vis/glava_2.py`),
     якорь — фраза абзаца, после которого встаёт рисунок.
4. **«Проверь себя»** — один вопрос на главную мысль главы, ответ под спойлером; не дубль примера главы (правило 2).
5. **Проверка:** каждый ответ — отдельный агент вслепую + перебор программой (правило 4); полировка — skill
   `polirovka` отдельным агентом; **сверка с образцом — третьим агентом**: получает цитаты образца из карты и примеры
   главы, помечает каждую фразу, которой у образца нет (кроме мест «Разжевать»), каждую задачу вне блока «Задача.» и
   каждую пропущенную остановку образца. Перед показом —
   `python3 26-27/nandu_level2/kombinatorika/vis/proverka.py N <папка> --kadry` — «ошибок нет»: запретные
   отсылки и персонажи образца, абзацы из нескольких мыслей, рамки «Задача.» не на вопросе, сбитая нумерация
   списков, рисунки без якоря; кадры анимаций (1.5, 3.5, 5.5 с, конец) — посмотреть глазами: подписи не налезают,
   финальный кадр чистый.
6. **Галочки** «написана», «проверена» → коммит. «Принята» ставит родитель после чтения; HTML — skill `md-v-html`
   после принятия. **HTML учебника — одна колонка**, без «сухого остатка» (решение родителя 24.10.2026: «это какие-то
   частные примеры, зачем они нужны»): конвертер узнаёт файл по `_kombinatorika_` в имени (`doc_kind` → `single`).

## 5. Объём и нагрузка

- Текст: 8 глав × 4–6 экранов, по одному вопросу «Проверь себя».
- Ребёнку: 11 сеансов по 25–35 минут ≈ 5,5 часа; при 3 сеансах в неделю — около 4 недель.
- Посильность для сильного 11-летнего (Раскина–Шаповалов дают эти темы в 5–6 классе, сочетания — с 6-го, из-за дробей):
  - главы 1, 2, 6 — лёгкие: результат уже знаком по уровню 1, новое — только доказательство;
  - главы 3, 4, 7 — средние: «каждый ровно m раз» и сокращение факториалов, всё сначала на числах;
  - глава 8 — средняя: новых формул нет, трудность — узнать ситуацию по словам условия;
  - глава 5 — самая трудная (раздача — худшая модель у Батанеро; у Раскиной–Шаповалова это вторая книжка, 6–7 класс):
    на неё 2 сеанса, при затруднении — разбить надвое.
