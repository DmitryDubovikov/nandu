## Т3″ — регионал 2018, №3 — четырёхзначные меньше 2018 с одной 7, кратные 3

**Условие.** Педро выписал список четырёхзначных чисел, которые удовлетворяют всем этим условиям:

- они меньше 2018;
- в них ровно одна цифра 7;
- они кратны 3.

Сколько чисел в списке Педро? Объясни, как ты их считал.

*«четырёхзначных»* и *«меньше 2018»* ⇒ числа от 1000 до 2017: с 1 в начале — от 1000 до 1999, и ещё от 2000 до 2017.

**Идея.** *«ровно одна цифра 7»* ⇒ у чисел с 1 в начале 7 стоит ровно на одном из мест 2, 3, 4.

Место 7 у каждого числа одно, поэтому каждое число попадает ровно в одно слагаемое:

N = N(17bc) + N(1a7c) + N(1ab7) + N(2000–2017)

<small>a, b, c — цифры, отличные от 7</small>

**1. N(17bc).**

*«кратны 3»* ⇒ на 3 делится сумма цифр:

1 + 7 + b + c = 8 + b + c

Ищем, при каких b и c

(8 + b + c) ⋮ 3

:::box Приём — делимость любой суммы на 3
res(x, 3) — остаток от деления x на 3; ⋮ — «делится на».

Делимость любой суммы на 3 решают остатки слагаемых:

(x + y) ⋮ 3 ⇔ (res(x, 3) + res(y, 3)) ⋮ 3

Каждое слагаемое — это несколько троек и остаток. Тройки на делимость не влияют, поэтому сумма делится на 3 ровно тогда, когда на 3 делится сумма остатков.
:::

В частности:

(8 + b + c) ⋮ 3 ⇔ (res(8, 3) + res(b, 3) + res(c, 3)) ⋮ 3

res(8, 3) = 2, а res(b, 3) и res(c, 3) — каждый от 0 до 2.

Значит, сумма трёх остатков — от 2 до 6; из этих чисел ⋮ 3 только 3 и 6:

2 + res(b, 3) + res(c, 3) = 3 или 6

res(b, 3) + res(c, 3) = 1 или 4

(res(b, 3), res(c, 3)) = (0, 1), (1, 0), (2, 2)

```sys
N(17bc) = ⟪N(res(b, 3) = 0, res(c, 3) = 1)⟫
        + ⦃N(res(b, 3) = 1, res(c, 3) = 0)⦄
        + ⦅N(res(b, 3) = 2, res(c, 3) = 2)⦆
```

В каждом мире b — любая цифра с нужным res(b, 3), c — любая цифра с нужным res(c, 3), и выбор b не меняет выбор c.

Сколько цифр с каждым остатком, стоит справа на рисунке выше: с res(·, 3) = 0 — четыре, с res(·, 3) = 1 — две, с res(·, 3) = 2 — три. Числа вариантов для b и c перемножаются:

⟪N(res(b, 3) = 0, res(c, 3) = 1)⟫ = 4 · 2 = ⟪8⟫

<small>1701, 1704, 1731, 1734, 1761, 1764, 1791, 1794</small>

⦃N(res(b, 3) = 1, res(c, 3) = 0)⦄ = 2 · 4 = ⦃8⦄

<small>1710, 1713, 1716, 1719, 1740, 1743, 1746, 1749</small>

⦅N(res(b, 3) = 2, res(c, 3) = 2)⦆ = 3 · 3 = ⦅9⦆

<small>1722, 1725, 1728, 1752, 1755, 1758, 1782, 1785, 1788</small>

N(17bc) = ⟪8⟫ + ⦃8⦄ + ⦅9⦆ = 25

**2. N(1a7c) и N(1ab7).**

В 1a7c и 1ab7 стоят те же 1 и 7, а две свободные цифры — снова любые, кроме 7.

Сумма цифр снова 8 плюс две свободные цифры, поэтому счёт тот же, что для 17bc:

N(1a7c) = N(1ab7) = 25

**3. N(2000–2017).**

У чисел от 2000 до 2017 вторая цифра 0, а третья — 0 или 1 ⇒ 7 может стоять только последней: 2007 и 2017.

2 + 0 + 0 + 7 = 9 ✓

2 + 0 + 1 + 7 = 10 ✗

N(2000–2017) = 1

**Сборка.**

N = 25 + 25 + 25 + 1 = 76

**Ответ на задачу:** в списке Педро **76 чисел**.

**⚠ Ловушки.**

- Взять треть всех пар b, c без 7 — по 27 на случай, выйдет 82: без 7 цифр с res(·, 3) = 1 только две, а не три.
- Прочитать «ровно одна цифра 7» как «хотя бы одна» — в счёт попадут числа вроде 1077, выйдет 88.
- Забыть хвост от 2000 до 2017 — выйдет 75.

*Проверено: N(17bc) по суммам b + c = 1, 4, 7, 10, 13, 16 — 2 + 5 + 6 + 7 + 4 + 1 = 25; перебор программой всех чисел от 1000 до 2017 — 76, по случаям 25, 25, 25 и 1.*
