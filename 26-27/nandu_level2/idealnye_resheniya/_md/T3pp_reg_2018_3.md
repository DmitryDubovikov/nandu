## Т3″ — регионал 2018, №3 — четырёхзначные меньше 2018 с одной семёркой, кратные 3

**Условие.** Педро выписал список четырёхзначных чисел, которые удовлетворяют всем этим условиям:

- они меньше 2018;
- в них ровно одна цифра 7;
- они кратны 3.

Сколько чисел в списке Педро? Объясни, как ты их считал.

**Способ** — выбор цифр по местам числа, кратность 3 — по сумме цифр.

**Идея.** Числа от 1000 до 1999 делим по месту единственной 7, а у двух свободных цифр смотрим только остатки при делении на 3.

*«четырёхзначных»* и *«меньше 2018»* ⇒ числа от 1000 до 2017: блок от 1000 до 1999 и хвост от 2000 до 2017.

У чисел блока на первом месте 1, остальные цифры a, b, c — любые, 0 тоже.

*«ровно одна цифра 7»* ⇒ в блоке 7 стоит на одном из мест a, b, c, а две другие цифры — не 7.

У числа одна 7, поэтому случаи не пересекаются и складываются:

N(список) = N(a = 7) + N(b = 7) + N(c = 7) + N(2000–2017)

**1. N(a = 7), N(b = 7) и N(c = 7).**

При a = 7 свободны b и c.

*«кратны 3»* ⇒ на 3 делится сумма цифр:

1 + 7 + b + c = 8 + b + c

Делимость суммы на 3 решают остатки слагаемых.

У 8 остаток 2, а остатки b и c вместе дают от 0 до 4.

2 + 1 = 3 и 2 + 4 = 6 делятся на 3, поэтому остатки b и c дают в сумме 1 или 4:

(остаток b, остаток c) = (0, 1), (1, 0), (2, 2)

N(a = 7) = N(остатки 0, 1) + N(остатки 1, 0) + N(остатки 2, 2)

b и c берутся из своих столбцов рисунка независимо:

N(остатки 0, 1) = 4 · 2 = 8

<small>1701, 1704, 1731, 1734, 1761, 1764, 1791, 1794</small>

N(остатки 1, 0) = 2 · 4 = 8

<small>1710, 1713, 1716, 1719, 1740, 1743, 1746, 1749</small>

N(остатки 2, 2) = 3 · 3 = 9

<small>1722, 1725, 1728, 1752, 1755, 1758, 1782, 1785, 1788</small>

N(a = 7) = 8 + 8 + 9 = 25

При b = 7 и при c = 7 закреплены те же 1 и 7, а две свободные цифры — снова любые, кроме 7:

N(b = 7) = N(c = 7) = 25

**2. N(2000–2017).**

У чисел от 2000 до 2017 вторая цифра 0, а третья — 0 или 1 ⇒ 7 может стоять только последней: 2007 и 2017.

2 + 0 + 0 + 7 = 9 ✓

2 + 0 + 1 + 7 = 10 ✗

N(2000–2017) = 1

**Сборка.**

N(список) = 25 + 25 + 25 + 1 = 76

**Ответ на задачу:** в списке Педро **76 чисел**.

**⚠ Ловушки.**

- Взять треть всех пар b, c без 7 — по 27 на случай, выйдет 82: без 7 у остатка 1 только две цифры, а не три.
- Прочитать «ровно одна цифра 7» как «хотя бы одна» — в счёт попадут числа вроде 1077, выйдет 88.
- Забыть хвост от 2000 до 2017 — выйдет 75.

*Проверено: N(a = 7) по суммам b + c = 1, 4, 7, 10, 13, 16 — 2 + 5 + 6 + 7 + 4 + 1 = 25; перебор программой всех чисел от 1000 до 2017 — 76, по случаям 25, 25, 25 и 1.*
