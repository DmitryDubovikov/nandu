## Т3‴ — национал 2017, день II, №6 — числа из цифр 4, 5, 6 с суммой цифр 30

**Условие.** Сколько чисел можно составить, используя только цифры 4, 5 и 6, так, чтобы сумма цифр числа была равна 30? В каждом числе можно использовать одну, две или все три цифры. Объясни, как ты их считал.

**Жанр ответа.** «Сколько чисел» плюс «объясни, как считал» — нужно **число** с объяснением.

Порядок цифр важен: 445566 и 654654 — два разных числа.

**Заметь главное — сумма цифр не зависит от их порядка.** У 445566 и 654654 цифры одни и те же: две четвёрки, две пятёрки, две шестёрки, и сумма у обоих 30.

Условие «сумма цифр числа равна 30» проверяет только, **сколько** в числе четвёрок, пятёрок и шестёрок. Где они стоят, для суммы не важно.

*💬 «Сумма цифр не зависит от порядка, поэтому сначала ищу, сколько в числе четвёрок, пятёрок и шестёрок, а потом считаю, сколькими способами можно расставить эти цифры» — мысль для фразы-объяснения.*

**Шаг 1 — план.** Нужно N(чисел) — сколько всего чисел из цифр 4, 5, 6 с суммой цифр 30. Обозначим:

- a — сколько в числе четвёрок;
- b — сколько пятёрок;
- c — сколько шестёрок.

Тройку (a, b, c) назовём **составом** числа: у 445566 состав (2, 2, 2), у 66666 — (0, 0, 5). Любая из букв может быть нулём: условие разрешает обойтись одной или двумя цифрами.

*«сумма цифр числа была равна 30»* ⇒

**4 · a + 5 · b + 6 · c = 30**

У каждого числа ровно один состав ⇒ числа с разными составами не пересекаются ⇒ считаем числа каждого состава отдельно и складываем.

> ✅ **План готов:**
>
> **N(чисел) = сумма N(a, b, c) по всем составам, для которых 4 · a + 5 · b + 6 · c = 30**
>
> - N(a, b, c) — сколько чисел, в которых a четвёрок, b пятёрок и c шестёрок.
>
> Осталось найти: все составы и N(a, b, c) для каждого.

**Шаг 2 — найдём все составы.** Нужны целые a, b, c, не меньше 0, для которых

**4 · a + 5 · b + 6 · c = 30**

**Сколько пятёрок.** Пятёрка — единственная нечётная цифра. Оставим слева одни пятёрки:

**5 · b = 30 − 4 · a − 6 · c**

- 30, 4 · a и 6 · c — чётные ⇒ 5 · b чётное
- 5 · b — сумма b пятёрок, а нечётное число нечётных слагаемых даёт нечётную сумму ⇒ b чётное

И больше шести пятёрок не бывает:

**5 · b ≤ 30 ⇒ b ≤ 6**

→ **b = 0, 2, 4 или 6**

**Лесенка по b.** При каждом b переносим пятёрки вправо:

**4 · a + 6 · c = 30 − 5 · b**

Обе части чётные — делим на 2:

**2 · a + 3 · c = (30 − 5 · b) : 2**

Отсюда:

- 2 · a чётное ⇒ 3 · c той же чётности, что правая часть ⇒ и c той же чётности (3 нечётное);
- c перебираем этой чётности, начиная с 0 (чётные) или с 1 (нечётные), пока 3 · c не больше правой части;
- a = (правая часть − 3 · c) : 2.

b = 0:

**2 · a + 3 · c = 15**

15 нечётное ⇒ c нечётное:

- c = 1 → a = (15 − 3) : 2 = 6
- c = 3 → a = (15 − 9) : 2 = 3
- c = 5 → a = (15 − 15) : 2 = 0
- c = 7 → 3 · 7 = 21 > 15 ✗

b = 2:

**2 · a + 3 · c = 10**

10 чётное ⇒ c чётное:

- c = 0 → a = 10 : 2 = 5
- c = 2 → a = (10 − 6) : 2 = 2
- c = 4 → 3 · 4 = 12 > 10 ✗

b = 4:

**2 · a + 3 · c = 5**

5 нечётное ⇒ c нечётное:

- c = 1 → a = (5 − 3) : 2 = 1
- c = 3 → 3 · 3 = 9 > 5 ✗

b = 6:

**2 · a + 3 · c = 0**

→ a = 0, c = 0

Все составы с их цифрами:

| состав (a, b, c) | цифры | сколько цифр |
|---|---|---|
| (6, 0, 1) | 4 4 4 4 4 4 6 | семь |
| (3, 0, 3) | 4 4 4 6 6 6 | шесть |
| (0, 0, 5) | 6 6 6 6 6 | пять |
| (5, 2, 0) | 4 4 4 4 4 5 5 | семь |
| (2, 2, 2) | 4 4 5 5 6 6 | шесть |
| (1, 4, 1) | 4 5 5 5 5 6 | шесть |
| (0, 6, 0) | 5 5 5 5 5 5 | шесть |

→ **составов семь**

> ✅ **План уточнён:**
>
> **N(чисел) = N(6, 0, 1) + N(3, 0, 3) + N(0, 0, 5) + N(5, 2, 0) + N(2, 2, 2) + N(1, 4, 1) + N(0, 6, 0)**

**Шаг 3 — найдём N(6, 0, 1).** Цифры: шесть четвёрок и одна шестёрка, всего семь мест.

Число задано тем, на каком месте стоит шестёрка: на остальных местах — четвёрки. Мест семь.

→ **N(6, 0, 1) = 7**

**Шаг 4 — найдём N(3, 0, 3).** Цифры 4, 4, 4, 6, 6, 6 на шести местах. Здесь число не задаётся местом одной цифры: и четвёрок, и шестёрок по три.

**Заметь главное — одинаковые цифры можно на время сделать разными.** Пометим их номерами: 4₁, 4₂, 4₃, 6₁, 6₂, 6₃. Порядки шести разных цифр считаются умножением.

Сотрём номера — разные помеченные порядки дадут одно и то же число: 4₁ 6₁ 4₂ 6₂ 4₃ 6₃ и 4₂ 6₁ 4₁ 6₂ 4₃ 6₃ оба становятся 464646.

<!-- иллюстрация: помеченные порядки одного числа (464646) стоят столбиком, номера стираются — столбик сливается в одно число; анимируется именно слияние -->

> ✅ **План состава:**
>
> **N(3, 0, 3) = N(помеченных порядков) : N(помеченных на одно число)**
>
> - N(помеченных порядков) — сколькими порядками можно выписать 4₁, 4₂, 4₃, 6₁, 6₂, 6₃;
> - N(помеченных на одно число) — сколько из них после стирания номеров дают одно и то же число.
>
> Осталось найти оба.

**N(помеченных порядков).** Шесть разных цифр в ряд: на первое место — любая из 6, на второе — любая из 5 оставшихся, и так до последнего места. Это **перестановки**, их число записывают 6! — «шесть факториал»:

**6! = 6 · 5 · 4 · 3 · 2 · 1 = 720**

**N(помеченных на одно число).** Возьмём число 464646. Его помеченные порядки отличаются только тем, где какой номер:

- 4₁ 6₁ 4₂ 6₂ 4₃ 6₃
- 4₂ 6₁ 4₁ 6₂ 4₃ 6₃
- 4₁ 6₂ 4₂ 6₁ 4₃ 6₃
- …

Номера 1, 2, 3 на трёх четвёрках встают 3! способами, на трёх шестёрках — тоже 3! способами, любой с любым:

**3! · 3! = 6 · 6 = 36**

**Заметь главное — у любого числа этого состава таких порядков тоже 36.** В любом из них три четвёрки и три шестёрки, номера на них встают теми же 3! · 3! способами. Поэтому все 720 помеченных порядков делятся на кучки ровно по 36 — по кучке на число.

**Сборка состава:**

**N(3, 0, 3) = 720 : 36 = 20**

**Шаг 5 — найдём N(0, 0, 5), N(5, 2, 0), N(2, 2, 2), N(1, 4, 1), N(0, 6, 0).** Пометки из шага 4 работают при любом составе. Пусть цифр в числе

**n = a + b + c**

Тогда помеченных порядков

**n!**

а на одно число из них приходится

**a! · b! · c!**

— номера переставляются на четвёрках, пятёрках и шестёрках отдельно.

> ✅ **План состава (любого):**
>
> **N(a, b, c) = n! : (a! · b! · c!)**

Это число **перестановок с повторами**. Цифру, которой в составе нет или которая встречается один раз, в делитель не пишем: переставлять на ней нечего.

Нужные факториалы:

- 2! = 2
- 4! = 24
- 5! = 120
- 6! = 720
- 7! = 5040

Составы:

- N(0, 0, 5) = 5! : 5! = 1 — это число 66666
- N(5, 2, 0) = 7! : (5! · 2!) = 5040 : 240 = 21
- N(2, 2, 2) = 6! : (2! · 2! · 2!) = 720 : 8 = 90
- N(1, 4, 1) = 6! : 4! = 720 : 24 = 30
- N(0, 6, 0) = 6! : 6! = 1 — это число 555555

Та же формула для состава из шага 3:

**N(6, 0, 1) = 7! : 6! = 5040 : 720 = 7**

— совпало с прямым счётом.

→ **итоги шага:**

- **N(0, 0, 5) = 1**
- **N(5, 2, 0) = 21**
- **N(2, 2, 2) = 90**
- **N(1, 4, 1) = 30**
- **N(0, 6, 0) = 1**

**Шаг 6 — сборка.** Подставляю в план:

**N(чисел) = 7 + 20 + 1 + 21 + 90 + 30 + 1 = 170**

*💬 «Это все случаи: они не повторяют друг друга и ни один не потерян» — у каждого числа ровно один состав; составы найдены лесенкой по всем b = 0, 2, 4, 6 и всем c нужной чётности; внутри состава каждое число посчитано один раз. Это мысль для фразы про полноту.*

**⚠ Ловушки.**

1. Решить, что цифр всегда шесть («30 : 5 = 6»), — потеряются 66666 и все семизначные, выйдет 141.
2. Не считать 66666 и 555555: условие прямо разрешает числа из одной цифры. Без них — 168.
3. Ответить числом составов (7), а не числом чисел.
4. Считать порядки как у разных цифр: для 4, 4, 5, 5, 6, 6 выйдет 720 вместо 90 — забыто деление на 2! · 2! · 2!.
5. Начать перебор c не с нуля — пропадут составы без шестёрок, (5, 2, 0) и (0, 6, 0), то есть 22 числа.

**Проверка вторым способом.** N(2, 2, 2) — по местам, без пометок. Раздаём места цифрам по очереди; пару мест выбираем по одному месту и делим на 2, потому что каждую пару так выбрали в двух порядках:

- четвёркам — два места из шести: 6 · 5 : 2 = 15
- пятёркам — два места из четырёх оставшихся: 4 · 3 : 2 = 6
- шестёркам — два последних места: 1 способ

**N(2, 2, 2) = 15 · 6 · 1 = 90**

Сошлось с формулой.

Компьютерный перебор всех чисел из цифр 4, 5, 6 длиной от одной до восьми цифр дал 170 чисел с суммой цифр 30, по составам 7, 20, 1, 21, 90, 30, 1. Тот же ответ дал программный счёт по последней цифре: число с суммой 30 — это число с суммой 26, 25 или 24 с приписанной в конце 4, 5 или 6; таких чисел программа насчитала 66, 57 и 47:

**66 + 57 + 47 = 170**

**Ответ на задачу:** **170 чисел**. Как считал: сумма цифр не зависит от порядка, поэтому сначала из уравнения на состав нашёл все семь составов, потом для каждого состава посчитал перестановки с повторами и сложил.

#### Запись

a, b, c — сколько четвёрок, пятёрок, шестёрок.

**n = a + b + c**

**4 · a + 5 · b + 6 · c = 30**

> ✅ **План:**
>
> **N(чисел) = сумма N(a, b, c) по всем составам**
>
> **N(a, b, c) = n! : (a! · b! · c!)**

- 4 · a, 6 · c, 30 — чётные ⇒ 5 · b чётное ⇒ b чётное
- 5 · b ≤ 30 ⇒ b ≤ 6 ⇒ b = 0, 2, 4, 6
- 2 · a + 3 · c = (30 − 5 · b) : 2
- c — той же чётности, что правая часть

Составы:

- b = 0: 2 · a + 3 · c = 15 → (6, 0, 1), (3, 0, 3), (0, 0, 5)
- b = 2: 2 · a + 3 · c = 10 → (5, 2, 0), (2, 2, 2)
- b = 4: 2 · a + 3 · c = 5 → (1, 4, 1)
- b = 6: 2 · a + 3 · c = 0 → (0, 6, 0)

Числа:

- N(6, 0, 1) = 7! : 6! = 7
- N(3, 0, 3) = 6! : (3! · 3!) = 20
- N(0, 0, 5) = 1
- N(5, 2, 0) = 7! : (5! · 2!) = 21
- N(2, 2, 2) = 6! : (2! · 2! · 2!) = 90
- N(1, 4, 1) = 6! : 4! = 30
- N(0, 6, 0) = 1

**N(чисел) = 7 + 20 + 1 + 21 + 90 + 30 + 1 = 170**
