## Т1 — национал 2023, день II, №4 — монеты Лусии

**Условие.** В коробке Лусия хранит монеты по $1, $2, $5 и $10. Всего в коробке 419 монет на общую сумму $2023. Если бы в коробке было вдвое больше монет по $5 и вдвое меньше монет по $10, то всего было бы 416 монет на общую сумму $1668. Сколько в коробке монет каждого достоинства?

### Часть 1 — запись системы

m1, m2, m5, m10 — сколько в коробке монет по $1, $2, $5, $10.

| | $1 | $2 | $5 | $10 |
|---|---|---|---|---|
| настоящая | m1 | m2 | m5 | m10 |
| «если бы» | m1 | m2 | 2 · m5 | m10 : 2 |

*«Всего в коробке 419 монет»* ⇒

**(1) m1 + m2 + m5 + m10 = 419**

*«…на общую сумму $2023»* ⇒

**(2) m1 + 2 · m2 + 5 · m5 + 10 · m10 = 2023**

*«…то всего было бы 416 монет»* — по строке «если бы» ⇒

**(3) m1 + m2 + 2 · m5 + m10 : 2 = 416**

*«…на общую сумму $1668»* — по строке «если бы» ⇒

**m1 + 2 · m2 + 5 · (2 · m5) + 10 · (m10 : 2) = 1668**

**(4) m1 + 2 · m2 + 10 · m5 + 5 · m10 = 1668**

⚠ В (4) количества монет по $5 и по $10 — из строки «если бы», а не настоящие.

### Часть 2 — решение системы

**Система:**

```sys
(1) ⟪m1 + m2⟫ + m5 + m10 = 419
(2) ⦃m1 + 2 · m2⦄ + 5 · m5 + 10 · m10 = 2023
(3) ⟪m1 + m2⟫ + 2 · m5 + m10 : 2 = 416
(4) ⦃m1 + 2 · m2⦄ + 10 · m5 + 5 · m10 = 1668
```

**Ходы:**

```sys
⟪(1) − (3)⟫   m10 : 2 − m5 = 3          | · 2
              (5) m10 − 2 · m5 = 6
⦃(2) − (4)⦄   5 · m10 − 5 · m5 = 355    | : 5
              (6) m10 − m5 = 71
```

**Система:** (5) и (6) встают на место (3) и (4).

```sys
(1) m1 + m2 + m5 + m10 = 419
(2) m1 + 2 · m2 + 5 · m5 + 10 · m10 = 2023
(5) ⦅m10⦆ − 2 · m5 = 6
(6) ⦅m10⦆ − m5 = 71
```

**Ходы:**

```sys
⦅(6) − (5)⦆   m5 = 65
(6)           m10 = 71 + ⟦65⟧ = 136
```

**Система:** m5 и m10 найдены, подставляются в (1) и (2).

```sys
(1) m1 + m2 + ⟦65⟧ + ⟦136⟧ = 419
(2) m1 + 2 · m2 + 5 · ⟦65⟧ + 10 · ⟦136⟧ = 2023
m5 = 65
m10 = 136
```

**Система:**

```sys
(7) ⟬m1⟭ + m2 = 218
(8) ⟬m1⟭ + 2 · m2 = 338
m5 = 65
m10 = 136
```

**Ходы:**

```sys
⟬(8) − (7)⟭   m2 = 120
(7)           m1 = 218 − ⟦120⟧ = 98
```

**Система решена:**

```sys
m1 = 98
m2 = 120
m5 = 65
m10 = 136
```

**Проверка** — подстановка в (3), (4) и целая половина:

- (3): 98 + 120 + 130 + 68 = 416 ✓
- (4): 98 + 240 + 650 + 680 = 1668 ✓
- 136 : 2 = 68 ✓

*Проверено перебором программой: из всех наборов 419 монет на $2023 условию отвечает только 98, 120, 65, 136.*

**Ответ на задачу:** в коробке 98 монет по $1, 120 монет по $2, 65 монет по $5 и 136 монет по $10.

#### 💬 Фраза-объяснение (в начале)

**Las dos situaciones se diferencian solo en las monedas de $5 y de $10, por eso las resto.**

*Две ситуации различаются только монетами по $5 и по $10, поэтому вычитаю одну из другой.*

#### Запись

m1, m2, m5, m10 — монет по $1, $2, $5, $10.

```sys
(1) m1 + m2 + m5 + m10 = 419
(2) m1 + 2 · m2 + 5 · m5 + 10 · m10 = 2023
(3) m1 + m2 + 2 · m5 + m10 : 2 = 416
(4) m1 + 2 · m2 + 10 · m5 + 5 · m10 = 1668
```

- (1) − (3), · 2: (5) m10 − 2 · m5 = 6
- (2) − (4), : 5: (6) m10 − m5 = 71
- (6) − (5): **m5 = 65**
- (6): **m10 = 136**
- (1), (2): (7) m1 + m2 = 218, (8) m1 + 2 · m2 = 338
- (8) − (7): **m2 = 120**
- (7): **m1 = 98**

Проверка: (3) 416 ✓, (4) 1668 ✓, 136 : 2 = 68 ✓

**Ответ: 98 монет по $1, 120 по $2, 65 по $5, 136 по $10.**
