## Т1 — национал 2023, день II, №4 — монеты Лусии

**Условие.** В коробке Лусия хранит монеты по $1, $2, $5 и $10. Всего в коробке 419 монет на общую сумму $2023. Если бы в коробке было вдвое больше монет по $5 и вдвое меньше монет по $10, то всего было бы 416 монет на общую сумму $1668. Сколько в коробке монет каждого достоинства?

**Жанр ответа.** Спрашивают четыре числа: сколько монет по $1, по $2, по $5 и по $10.

**Обозначения.**

- **m1**, **m2**, **m5**, **m10** (*monedas*) — сколько в коробке монет по $1, $2, $5, $10.

В условии две коробки: настоящая и коробка «если бы». Сколько в них монет каждого достоинства:

| | $1 | $2 | $5 | $10 |
|---|---|---|---|---|
| настоящая | m1 | m2 | m5 | m10 |
| «если бы» | m1 | m2 | 2 · m5 | m10 : 2 |

**Перевод в систему.** Каждое данное — равенство:

*«Всего в коробке 419 монет»* ⇒

**(1) m1 + m2 + m5 + m10 = 419**

*«…на общую сумму $2023»* ⇒

**(2) m1 + 2 · m2 + 5 · m5 + 10 · m10 = 2023**

*«…то всего было бы 416 монет»* — считаю по строке «если бы» ⇒

**(3) m1 + m2 + 2 · m5 + m10 : 2 = 416**

*«…на общую сумму $1668»* — по той же строке ⇒

**m1 + 2 · m2 + 5 · (2 · m5) + 10 · (m10 : 2) = 1668**

Раскрываю скобки:

**(4) m1 + 2 · m2 + 10 · m5 + 5 · m10 = 1668**

→ **система:**

```sys
(1) m1 + m2 + m5 + m10 = 419
(2) m1 + 2 · m2 + 5 · m5 + 10 · m10 = 2023
(3) m1 + m2 + 2 · m5 + m10 : 2 = 416
(4) m1 + 2 · m2 + 10 · m5 + 5 · m10 = 1668
```

**Заметь главное — монеты по $1 и по $2 в «если бы» не меняются.** В таблице их столбцы одинаковые в обеих строках.

Поэтому в равенствах про число монет, (1) и (3), стоит одна и та же часть:

**m1 + m2**

А в равенствах про сумму, (2) и (4), — одна и та же часть:

**m1 + 2 · m2**

Вычтешь из равенства для настоящей коробки равенство для коробки «если бы» — эта часть уйдёт целиком, останутся одни m5 и m10.

*💬 «Две ситуации различаются только монетами по $5 и по $10, поэтому вычитаю одну из другой» — это мысль для фразы-объяснения.*

**Шаг 1 — план.**

Спрашивают все четыре числа.

> ✅ **План готов:**
>
> **Ответ = m1, m2, m5, m10**
>
> - m5, m10 — из системы 2×2 двух разностей (1) − (3) и (2) − (4): в них m1 и m2 уходят;
> - m1, m2 — из системы 2×2 (1), (2), когда m5 и m10 уже известны.
>
> Осталось найти: m5 и m10; затем m1 и m2.

**Шаг 2 — найдём m5 и m10.**

**Разность (1) − (3) — по числу монет.**

(1) m1 + m2 + m5 + m10 = 419

(3) m1 + m2 + 2 · m5 + m10 : 2 = 416

Вычитаю, m1 и m2 уходят:

**m5 − 2 · m5 + m10 − m10 : 2 = 419 − 416**

**m10 : 2 − m5 = 3**

Умножаю обе части на 2, чтобы не осталось половины:

→ **(5) m10 − 2 · m5 = 6**

**Разность (2) − (4) — по сумме.**

(2) m1 + 2 · m2 + 5 · m5 + 10 · m10 = 2023

(4) m1 + 2 · m2 + 10 · m5 + 5 · m10 = 1668

Вычитаю, m1 и m2 уходят:

**5 · m5 − 10 · m5 + 10 · m10 − 5 · m10 = 2023 − 1668**

**5 · m10 − 5 · m5 = 355**

Все три числа делятся на 5 — сокращаю:

→ **(6) m10 − m5 = 71**

**Решаем систему из (5) и (6).**

```sys
(5) m10 − 2 · m5 = 6
(6) m10 − m5 = 71
```

В обоих уравнениях m10 стоит без множителя — вычитаю (5) из (6), и m10 уходит (исключение неизвестной):

**−m5 + 2 · m5 = 71 − 6**

→ **m5 = 65**

Подставляю m5 = 65 в (6):

**m10 = 71 + 65**

→ **m10 = 136**

**Шаг 3 — найдём m1 и m2.** Подставляю m5 = 65 и m10 = 136 в (1) и (2).

Из (1):

**m1 + m2 + 65 + 136 = 419**

**(7) m1 + m2 = 218**

Из (2), где 5 · 65 = 325 и 10 · 136 = 1360:

**m1 + 2 · m2 + 325 + 1360 = 2023**

**(8) m1 + 2 · m2 = 338**

В (7) и (8) m1 стоит без множителя — вычитаю (7) из (8):

**2 · m2 − m2 = 338 − 218**

→ **m2 = 120**

Подставляю m2 = 120 в (7):

**m1 = 218 − 120**

→ **m1 = 98**

**Проверка.** Равенства (3) и (4) работали только через разности — подставляю ответ во все четыре:

- (1): 98 + 120 + 65 + 136 = 419 ✓
- (2): 98 + 240 + 325 + 1360 = 2023 ✓
- (3): 98 + 120 + 130 + 68 = 416 ✓
- (4): 98 + 240 + 650 + 680 = 1668 ✓

В коробке «если бы» монет по $10 — половина от m10, и она обязана быть целым числом:

136 : 2 = 68 ✓

*Проверка вторым способом — метод подстановки для (5) и (6). Из (6):*

**m10 = m5 + 71**

*Подставляю в (5):*

**m5 + 71 − 2 · m5 = 6**

*Отсюда m5 = 65 — то же, что в шаге 2. Компьютерный перебор всех наборов из 419 монет на $2023 (половина монет по $10 считалась точно, без предположения о чётности) оставляет ровно один: 98, 120, 65, 136.*

**⚠ Ловушки.**

1. В сумме «если бы» взять старые количества монет по $5 и по $10. Тогда левая часть (4) совпадёт с левой частью (2), а правые части разные, 2023 и 1668, — система противоречива.
2. Остановиться на m5 и m10: спрашивают все четыре числа.

**Ответ на задачу:** в коробке 98 монет по $1, 120 монет по $2, 65 монет по $5 и 136 монет по $10.

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Фраза-объяснение входит в образец наравне с числами.*

#### 💬 Фраза-объяснение (в начале)

**Las dos situaciones se diferencian solo en las monedas de $5 y de $10, por eso las resto.**

*Две ситуации различаются только монетами по $5 и по $10, поэтому вычитаю одну из другой.*

#### Запись

m1, m2, m5, m10 — монет по $1, $2, $5, $10.

```sys
(1) m1 + m2 + m5 + m10 = 419
(2) m1 + 2 · m2 + 5 · m5 + 10 · m10 = 2023
(3) m1 + m2 + 2 · m5 + m10 : 2 = 416
(4) m1 + 2 · m2 + 10 · m5 + 5 · m10 = 1668
```

> ✅ **План:**
>
> **m5, m10 — из (1) − (3) и (2) − (4)**
>
> **m1, m2 — из (1) и (2)**

- (1) − (3): m10 : 2 − m5 = 3
- умножаю на 2: (5) m10 − 2 · m5 = 6
- (2) − (4): 5 · m10 − 5 · m5 = 355
- сокращаю на 5: (6) m10 − m5 = 71
- (6) − (5): **m5 = 65**
- (6): **m10 = 136**
- (1): (7) m1 + m2 = 218
- (2): (8) m1 + 2 · m2 = 338
- (8) − (7): **m2 = 120**
- (7): **m1 = 98**

Проверка:

- (3): 98 + 120 + 130 + 68 = 416 ✓
- (4): 98 + 240 + 650 + 680 = 1668 ✓
- 136 : 2 = 68 — целое ✓

**Ответ: 98 монет по $1, 120 по $2, 65 по $5, 136 по $10.**
