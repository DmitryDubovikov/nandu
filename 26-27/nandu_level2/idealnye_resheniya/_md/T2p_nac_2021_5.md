## Т2′ — национал 2021, день II, №5 — прямоугольник ABCD, площадь ABPR 735 см²

**Условие.** На рисунке:

- ABCD — прямоугольник, 2AB = 3BC;
- M, N, P, R — середины AB, BC, CD, AD;
- точки C, D, E лежат на одной прямой, точки F, B, C — тоже;
- DE = DP, AE = CF;
- площадь ABPR равна 735 см²;
- площадь CAF = 5 · площадь BAF.

Вопросы:

- а) Чему равна площадь ADE?
- б) Чему равен периметр ABCE?
- в) Чему равна площадь AMNE?

*«2AB = 3BC»* ⇒ AB : BC = 3 : 2.

*«M, N, P, R — середины»* ⇒ берём кирпич d = BC : 4: тогда AB = 6d, а половины сторон 3d и 2d целые.

*«C, D, E лежат на одной прямой», «DE = DP»* ⇒ E лежит на прямой CD, и DE = 3d.

Все точки, кроме F, стоят в узлах сетки с шагом d.

**Буквы на рисунке.** BC = 4d, AB = 6d, сетка с шагом d.

> ✅ **а) — прямоугольный треугольник с катетами AD и DE**
>
> **б) — четыре стороны ABCE: три идут по сетке, а наклонная AE равна CF (дано)**
>
> **в) — трапеция ABCE без двух прямоугольных треугольников MBN и NCE**
>
> **Всё, что идёт по сетке, — сколько-то d: осталось найти d и CF**

:::cols
**а) площадь ADE**
:::col
**б) периметр ABCE**
:::

**в) площадь AMNE**

**1. Найдём d.**

*«площадь ABPR равна 735 см²»*

Заметим, что ABPR — это прямоугольник ABCD без двух прямоугольных треугольников BCP и PDR.

> ✅ **S(ABCD) − S(BCP) − S(PDR) = 735**

**Площадь ABCD.** Прямоугольник со сторонами 6d и 4d.

S(ABCD) = 6d · 4d

**Площадь BCP.** Катеты BC = 4d и CP = 3d.

S(BCP) = 4d · 3d : 2

**Площадь PDR.** Катеты PD = 3d и DR = 2d.

S(PDR) = 3d · 2d : 2

**Подставим площади в артефакт.**

**6d · 4d − 4d · 3d : 2 − 3d · 2d : 2 = 735**

```sys
24d² − 6d² − 3d² = 735
15d² = 735       | : 15
d² = 49
d = 7
```

→ **d = 7**

**2. Найдём CF.**

*«площадь CAF = 5 · площадь BAF»*

:::box Приём — общая высота
Основания двух треугольников лежат на одной прямой, а третья вершина общая ⇒ высота у них общая.

S = основание · высота : 2, и высота в обеих площадях одна.

Поэтому площадь одного треугольника во столько раз больше площади другого, во сколько раз больше его основание.
:::

В частности, у CAF и BAF основания CF и BF лежат на прямой BC, а вершина A общая.

> ✅ **CF = 5 · BF**

*«F, B, C лежат на одной прямой»* ⇒ CF = CB + BF = 4d + BF.

**Подставим CF в артефакт.**

**4d + BF = 5 · BF**

```sys
4d = 4 · BF      | : 4
BF = d
```

CF = 5 · BF = 5d

→ **CF = 5d**

**3. Сборка: подставим d = 7.**

а) S(ADE) = 4d · 3d : 2 = 28 · 21 : 2 = 294

б) P(ABCE) = AB + BC + CE + AE = 6d + 4d + 9d + 5d = 24d = 24 · 7 = 168

в) S(AMNE) = (6d + 9d) : 2 · 4d − 3d · 2d : 2 − 2d · 9d : 2 = 18d² = 882

**Ответ на задачу:** а) площадь ADE — **294 см²**; б) периметр ABCE — **168 см**; в) площадь AMNE — **882 см²**.

**⚠ Ловушки.**

- AE не нужно искать через теорему Пифагора: AE = CF, а CF дают площади.
- Основание CAF — весь отрезок CF = CB + BF, а не CB.
- CE = ED + DC = 9d, а не только DC = 6d.

*Проверено программой по координатам вершин (d = 7, BF = 7): S(ABPR) = 735, S(CAF) = 5 · S(BAF), AE = CF = 35, S(ADE) = 294, P(ABCE) = 168, S(AMNE) = 882; слепая проверка вторым агентом дала те же ответы.*
