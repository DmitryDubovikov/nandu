## Т2 — провинциал 2022, №2 — ABDEF и BCD: периметры и площади

**Условие.** На рисунке ABHF и DEGH — прямоугольники, BCD и EFG — прямоугольные треугольники, G — середина FH, BC = DH. Периметр ABDEF равен 144 см, периметр DEFH — 120 см, периметр ABHF — 84 см, периметр DEGH — 102 см, периметр BCD — 144 см. а) Чему равен периметр EFG? б) Чему равен периметр ACDEF? в) Чему равна площадь ABDEF? г) Чему равна площадь BCD?

**1. Буквы.** Одна буква — один цвет: m = FG = GH, a = AF, h = EG.

**2. Склейка.** ABDEF = ABHF + DEFH, приложенные по FH: в обоих обходах FH пройдена, в обходе ABDEF её нет.

P(ABDEF) = P(ABHF) + P(DEFH) − 2 · FH

### Часть 1 — запись системы

*склейка, FH = 2m*

**(1) 144 = 84 + 120 − 2 · 2m**

*P(ABHF) = 84: ширина 2m, высота a*

**(2) 2 · (2m + a) = 84**

*P(DEGH) = 102: ширина m, высота h*

**(3) 2 · (m + h) = 102**

### Часть 2 — решение системы

**Система:**

```sys
(1) 144 = 84 + 120 − 2 · 2⦃m⦄
(2) ⟪2 ·⟫ (2m + a) = 84
(3) ⟪2 ·⟫ (m + h) = 102
```

**Ходы:**

```sys
⦃(1)⦄       4m = 84 + 120 − 144 = 60
            m = 15
⟪(2) : 2⟫   2m + a = 42
⟪(3) : 2⟫   m + h = 51
```

**Система:**

```sys
(2) 2 · ⟦15⟧ + a = 42
(3) ⟦15⟧ + h = 51
m = 15
```

**Ходы:**

```sys
(2)   a = 42 − 30 = 12
(3)   h = 51 − 15 = 36
```

**Система решена:**

```sys
m = 15
a = 12
h = 36
```

### Спрошенное

а) DEFH = EFG + DEGH по EG = h:

P(EFG) = P(DEFH) − P(DEGH) + 2h = 120 − 102 + 72 = 90

б) ACDEF = ABDEF + BCD по BD = a + h:

P(ACDEF) = P(ABDEF) + P(BCD) − 2 · (a + h) = 144 + 144 − 96 = 192

в) ABDEF = ABHF + DEGH + EFG:

площадь ABDEF = 2m · a + m · h + m · h : 2 = 360 + 540 + 270 = 1170

г) BCD — половина прямоугольника h × (a + h):

площадь BCD = h · (a + h) : 2 = 36 · 48 : 2 = 864

**Ответ на задачу:** а) периметр EFG — 90 см; б) периметр ACDEF — 192 см; в) площадь ABDEF — 1170 см²; г) площадь BCD — 864 см².

**⚠ Ловушки.** BD — вся правая стена B–H–D, a + h = 48, а не только DH. Общий отрезок склейки вычитается дважды: он есть в обоих обходах.

*Проверено перебором программой по координатам вершин; наклонные EF = 39 и CD = 60 из периметров совпадают с теоремой Пифагора (тройки 15-36-39 и 36-48-60).*
