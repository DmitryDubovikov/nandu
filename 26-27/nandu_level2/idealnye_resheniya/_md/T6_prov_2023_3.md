## Т6 — провинциал 2023, №3 — восемь кружков, девять отрезков, три цвета

**Условие.** На рисунке восемь кружков, соединённых отрезками:

- у Пабло карандаши трёх цветов: красный, синий и зелёный;
- Пабло хочет закрасить каждый кружок одним из этих цветов;
- два кружка, соединённые отрезком, всегда должны быть разного цвета.

Сколькими различными способами Пабло может закрасить восемь кружков? Объясни, как ты их считал.

**Способ** — цвет для каждого из кружков A, B, …, H.

**Идея.** Кружки A, B, C, D, E, F соединены по кругу в шестиугольник, а G и H приклеены к нему сбоку: G соединён только с B и C, H — только с D.

Красим сначала шестиугольник, потом G и H.

Соседи G — B и C — соединены между собой ⇒ при любой раскраске шестиугольника соседи G разного цвета.

У H один сосед D ⇒ при любой раскраске шестиугольника у соседа H один цвет.

Поэтому число цветов для G и для H не зависит от того, как закрашен шестиугольник, и три хода перемножаются:

> ✅ N = N(раскрасок шестиугольника) · N(цветов для G) · N(цветов для H)

**1. N(раскрасок шестиугольника).**

Перерисуем шестиугольник: A, C, E — углы треугольника, B, D, F — середины его сторон.

Углы A, C, E между собой не соединены ⇒ красим их как угодно, потом середины сторон.

Выпишем два примера для середины F стороны EA:

- концы стороны одного цвета ⇒ для середины два цвета;
- концы стороны разного цвета ⇒ для середины один цвет.

Число цветов для B, D, F задают углы, а у углов A, C, E бывает один, два или три разных цвета:

> ✅ N(раскрасок шестиугольника) = N(один цвет) + N(два цвета) + N(три цвета)

**1.1. N(один цвет).**

Общий цвет углов A, C, E — любой из трёх.

Концы каждой стороны одного цвета ⇒ у B, D, F по два цвета.

N(один цвет) = 3 · 2 · 2 · 2 = 24

**1.2. N(два цвета).**

Два угла одного цвета, третий угол другого цвета.

Угол другого цвета — A, C или E, цвет двух углов — любой из трёх, цвет угла другого цвета — любой из двух оставшихся:

3 · 3 · 2 = 18

<small>угол другого цвета A: C, E красные — A синий или зелёный; C, E синие — A красный или зелёный; C, E зелёные — A красный или синий</small>

Концы одного цвета только у стороны между двумя углами одного цвета: у её середины два цвета.

У середин двух других сторон концы разного цвета, у каждой по одному цвету.

N(два цвета) = 18 · 2 · 1 · 1 = 36

**1.3. N(три цвета).**

Три разных цвета на углы A, C, E, порядок важен:

3 · 2 · 1 = 6

Концы каждой стороны разного цвета ⇒ у B, D, F по одному цвету.

N(три цвета) = 6 · 1 · 1 · 1 = 6

N(раскрасок шестиугольника) = 24 + 36 + 6 = 66

**2. N(цветов для G) и N(цветов для H).**

Соседи G — B и C — разного цвета ⇒ для G остаётся один, третий цвет.

N(цветов для G) = 1

H соединён только с D ⇒ для H годится любой из двух цветов, отличных от цвета D.

N(цветов для H) = 2

**Сборка.**

N = 66 · 1 · 2 = 132

**Ответ на задачу:** Пабло может закрасить кружки **132 способами**.

**⚠ Ловушки.**

- Красить по кругу A, B, …, F и дать F два цвета, забыв отрезок F–A: шестиугольник даст 3 · 2 · 2 · 2 · 2 · 2 = 96, выйдет 192.
- Дать G два цвета, глядя только на B, — выйдет 264.
- Забыть, что углом другого цвета может быть любой из A, C, E: 6 раскрасок углов вместо 18, выйдет 84.

*Проверено: раскрасок углов A, C, E всего 3 + 18 + 6 = 27 = 3 · 3 · 3; перебор программой всех 3⁸ = 6561 раскрасок даёт 132, шестиугольник 66, по мирам 24, 36 и 6; слепое решение отдельного агента тоже 132.*
