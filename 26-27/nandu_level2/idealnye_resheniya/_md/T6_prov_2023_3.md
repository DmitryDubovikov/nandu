## Т6 — провинциал 2023, №3 — восемь кружков, девять отрезков, три цвета

**Условие.** На рисунке восемь кружков, соединённых отрезками:

- у Пабло карандаши трёх цветов: красный, синий и зелёный;
- Пабло хочет закрасить каждый кружок одним из этих цветов;
- два кружка, соединённые отрезком, всегда должны быть разного цвета.

Сколькими различными способами Пабло может закрасить восемь кружков? Объясни, как ты их считал.

**Способ** — цвет для каждого из кружков A, B, …, H.

**Идея.** Кружки A, B, C, D, E, F соединены по кругу в шестиугольник, а G и H приклеены к нему сбоку: G соединён только с B и C, H — только с D.

Красим сначала шестиугольник, потом G и H.

B и C соединены ⇒ при любой раскраске шестиугольника у B и C разные цвета.

Поэтому число цветов для G и для H не зависит от того, как закрашен шестиугольник, и три хода перемножаются:

> ✅ N = N(раскрасок шестиугольника) · N(цветов для G) · N(цветов для H)

**1. N(раскрасок шестиугольника).**

Выпишем две раскраски по кругу A, B, C, D, E и посмотрим на F, который соединён и с E, и с A:

Оба соседа F по кругу уже закрашены:

- соседи одного цвета ⇒ для F два цвета;
- соседи разного цвета ⇒ для F один цвет.

A, C, E между собой не соединены, а у каждого из B, D, F оба соседа по кругу — среди A, C, E.

Поэтому красим сначала A, C, E как угодно, потом каждый из B, D, F так же, как F в примерах.

Число цветов для B, D, F зависит только от того, сколько разных цветов у A, C, E, — это и задаёт мир:

> ✅ N(раскрасок шестиугольника) = N(один цвет) + N(два цвета) + N(три цвета)

**1.1. N(один цвет).**

Общий цвет A, C, E — любой из трёх.

У каждого из B, D, F соседи одного цвета ⇒ по два цвета.

N(один цвет) = 3 · 2 · 2 · 2 = 24

**1.2. N(два цвета).**

Два кружка из A, C, E одного цвета (пара), третий другого цвета (одиночка).

Одиночка — A, C или E, цвет пары — любой из трёх, цвет одиночки — любой из двух оставшихся:

3 · 3 · 2 = 18

<small>одиночка A: пара C, E красная — A синий или зелёный; синяя — A красный или зелёный; зелёная — A красный или синий</small>

Из B, D, F ровно один стоит между кружками пары: у него соседи одного цвета, два цвета.

У двух других соседи разного цвета, у каждого по одному цвету.

N(два цвета) = 18 · 2 · 1 · 1 = 36

**1.3. N(три цвета).**

Три разных цвета на A, C, E, порядок важен:

3 · 2 · 1 = 6

У каждого из B, D, F соседи разного цвета ⇒ по одному цвету.

N(три цвета) = 6 · 1 · 1 · 1 = 6

N(раскрасок шестиугольника) = 24 + 36 + 6 = 66

**2. N(цветов для G) и N(цветов для H).**

G соединён с B и C, а у B и C разные цвета ⇒ для G остаётся один, третий цвет.

N(цветов для G) = 1

H соединён только с D ⇒ для H годится любой из двух цветов, отличных от цвета D.

N(цветов для H) = 2

**Сборка.**

N = 66 · 1 · 2 = 132

**Ответ на задачу:** Пабло может закрасить кружки **132 способами**.

**⚠ Ловушки.**

- Красить по кругу A, B, …, F и дать F два цвета, забыв отрезок F–A: шестиугольник даст 3 · 2 · 2 · 2 · 2 · 2 = 96, выйдет 192.
- Дать G два цвета, глядя только на B, — выйдет 264.
- Забыть, что одиночкой может быть любой из A, C, E: 6 раскрасок вместо 18, выйдет 84.

*Проверено: раскрасок A, C, E всего 3 + 18 + 6 = 27 = 3 · 3 · 3; перебор программой всех 3⁸ = 6561 раскрасок даёт 132, шестиугольник 66, по мирам 24, 36 и 6; слепое решение отдельного агента тоже 132.*
