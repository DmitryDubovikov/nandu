Т3″ — регионал 2018, №3 — четырёхзначные меньше 2018 с одной семёркой, кратные 3

Фаза 1 — Зональ — идеальные решения образцов

Условие

Педро выписал список четырёхзначных чисел, которые удовлетворяют всем этим условиям:

  • они меньше 2018;
  • в них ровно одна цифра 7;
  • они кратны 3.

Сколько чисел в списке Педро? Объясни, как ты их считал.

Жанр ответа (Д6). Спрашивают число и объяснение, как считал. Список не выписываем — считаем, а полноту объясняем словами (Ч5).

Условия по одному:

  • «четырёхзначных» и «меньше 2018» ⇒ числа от 1000 до 2017;
  • «ровно одна цифра 7» ⇒ семёрка стоит ровно в одном разряде, остальные цифры — не 7;
  • «кратны 3» ⇒ число делится на 3 без остатка.
Заметь главное — граница 2018 режет числа по первой цифре

  • Первая цифра 1: числа от 1000 до 1999 — полный блок. После единицы три цифры любые, от 000 до 999, и ноль впереди не встанет: впереди уже 1.
  • Первая цифра 2: только числа от 2000 до 2017 — хвост, его проверяем руками.
Заметь главное — в полном блоке семёрке есть ровно три места

Цифры числа из блока назовём так:

тысячисотнидесяткиединицы
1abc

В тысячах стоит 1, а не 7 ⇒ единственная семёрка стоит ровно в одном из разрядов a, b, c.

  • Число с семёркой в двух местах сразу в список не входит: в нём две семёрки ⇒ случаи «где стоит 7» не пересекаются.
  • У каждого числа списка из блока семёрка где-то стоит ⇒ каждое попадает в один из случаев.
Заметь главное — делимость на 3 решает сумма цифр, а сумму — остатки цифр

«кратны 3» проверяем признаком делимости на 3: число делится на 3 ровно тогда, когда на 3 делится сумма его цифр. Пример — 1734 (a = 7, b = 3, c = 4):

1 + 7 + 3 + 4 = 15 = 3 · 5

1734 = 3 · 578 ✓

Каждая цифра — это кратное 3 плюс её остаток при делении на 3. Кратные 3 делимость суммы не меняют, решают остатки. На том же 1734:

1 = 0 + 1
7 = 6 + 1
3 = 3 + 0
4 = 3 + 1

Кратные 3 (0, 6, 3, 3) откладываю, остатки складываю:

1 + 1 + 0 + 1 = 3

Остатки дали 3 — делится на 3, и вся сумма 15 тоже делится.

Остаток цифры при делении на 3 пишем коротко: res(b : 3) — остаток от деления b на 3. Например:

res(7 : 3) = 1

Кроме единственной семёрки, в разрядах a, b, c стоят цифры не 7. Разложим эти девять цифр по полочкам — по остатку при делении на 3 (взрослое имя полочки — класс остатков). Семёрка зачёркнута:

остаток 0остаток 1остаток 2
012
345
6~~7~~8
9

Полочки неравные: на «остатке 0» четыре цифры, на «остатке 1» — две, на «остатке 2» — три.

Шаг 1 — план.

Нужно число чисел в списке. N(…) — сколько чисел списка, у которых выполнено условие в скобках. Хвост и три случая блока не пересекаются ⇒ складываем.

✅ План готов:

N(список) = N(a = 7) + N(b = 7) + N(c = 7) + N(2000–2017)
  • N(a = 7) — числа списка от 1000 до 1999 с семёркой в сотнях;
  • N(b = 7) — с семёркой в десятках;
  • N(c = 7) — с семёркой в единицах;
  • N(2000–2017) — числа списка от 2000 до 2017.

Осталось найти все четыре слагаемых.

Шаг 2 — найдём N(a = 7).

Числа этого случая:

тысячисотнидесяткиединицы
17bc

«ровно одна цифра 7» ⇒ b и c — не 7, то есть цифры с полочек выше. Сумма цифр:

1 + 7 + b + c = 8 + b + c

У восьмёрки остаток 2:

8 = 3 · 2 + 2

Заменяю восьмёрку, b и c их остатками: сумма цифр делится на 3 ровно тогда, когда на 3 делится

2 + res(b : 3) + res(c : 3)

Каждый остаток — 0, 1 или 2, поэтому эта сумма от 2 до 6, а из чисел от 2 до 6 на 3 делятся только 3 и 6:

2 + res(b : 3) + res(c : 3) = 3 или 6
res(b : 3) + res(c : 3) = 1 или 4

Пары остатков (сначала у b, потом у c):

  • 0 + 1 = 1
  • 1 + 0 = 1
  • 2 + 2 = 4

Других нет: сумму 1 дают только 0 + 1 и 1 + 0 (две единицы — уже 2), сумму 4 из остатков не больше 2 — только 2 + 2.

✅ План случая:

N(a = 7) = N(остатки 0, 1) + N(остатки 1, 0) + N(остатки 2, 2)
  • «остатки 0, 1» — у b остаток 0, у c остаток 1;
  • «остатки 1, 0» — у b остаток 1, у c остаток 0;
  • «остатки 2, 2» — у b и у c остаток 2.

Каждая пара цифр b, c даёт ровно одно число, поэтому считаем пары.

Сколько пар в каждом слагаемом. b берём с полочки своего остатка И c — со своей. Любая цифра с полочки для b сочетается с любой цифрой с полочки для c, и пары не повторяются ⇒ перемножаем длины полочек:

  • N(остатки 0, 1) = 4 · 2 = 8
  • N(остатки 1, 0) = 2 · 4 = 8
  • N(остатки 2, 2) = 3 · 3 = 9

Сборка случая:

→ N(a = 7) = 8 + 8 + 9 = 25

Шаг 3 — найдём N(b = 7) и N(c = 7).

Числа этих случаев:

тысячисотнидесяткиединицы
1a7c
1ab7

Закреплены снова 1 и 7, их сумма 8 ⇒ остатки двух свободных цифр снова должны дать в сумме 1 или 4: 0 + 1, 1 + 0 или 2 + 2. Свободные цифры — снова не 7, с тех же полочек (a = 0 можно: впереди стоит 1).

План случая тот же, только свободные цифры другие. При b = 7 остатки берём у a и c:

N(b = 7) = N(остатки 0, 1) + N(остатки 1, 0) + N(остатки 2, 2)
N(b = 7) = 4 · 2 + 2 · 4 + 3 · 3 = 25

При c = 7 — у a и b:

N(c = 7) = N(остатки 0, 1) + N(остатки 1, 0) + N(остатки 2, 2)
N(c = 7) = 4 · 2 + 2 · 4 + 3 · 3 = 25

→ N(b = 7) = 25

→ N(c = 7) = 25

Шаг 4 — найдём N(2000–2017).

В числах от 2000 до 2017 в сотнях стоит 0, в десятках — 0 или 1 ⇒ семёрка может стоять только в единицах: это 2007 и 2017. Проверяем признаком делимости на 3:

  • 2007: 2 + 0 + 0 + 7 = 9 = 3 · 3 ✓
  • 2017: 2 + 0 + 1 + 7 = 10 = 3 · 3 + 1 ✗

→ N(2000–2017) = 1 (число 2007)

Шаг 5 — сборка.

Подставляем в план:

N(список) = 25 + 25 + 25 + 1 = 76

⚠ Ловушки.

  1. 1. Взять треть всех пар: пар b, c без семёрки 9 · 9 = 81, «каждая третья подходит» — 27, и в ответе 82. Неверно: семёрка ушла с полочки «остаток 1», полочки стали неравными (четыре, две, три цифры), и подходящих пар 25, а не 27.
  2. 2. Прочитать «ровно одна 7» как «хотя бы одна»: в счёт попадут 12 чисел с двумя и тремя семёрками (1077, 1707, 1770 и ещё девять), выйдет 88.
  3. 3. Запретить ноль в сотнях: «ноль впереди нельзя» относится к первой цифре, а она здесь 1. С запретом a = 0 случаи b = 7 и c = 7 дают по 23, и выйдет 72.
  4. 4. Забыть хвост — выйдет 75. Засчитать 2017, не проверив сумму цифр (10), — выйдет 77.

Проверка вторым способом. Пересчитаю N(a = 7) без полочек — прямо по сумме двух свободных цифр. Сумма цифр должна делиться на 3, а две свободные цифры вместе дают не больше 9 + 9 = 18:

8 + b + c = 9, 12, 15, 18, 21 или 24
b + c = 1, 4, 7, 10, 13 или 16

Пары по суммам, семёрку вычёркиваю:

  • b + c = 1: 0 + 1, 1 + 0 → 2
  • b + c = 4: 0 + 4, 1 + 3, 2 + 2, 3 + 1, 4 + 0 → 5
  • b + c = 7: 1 + 6, 2 + 5, 3 + 4, 4 + 3, 5 + 2, 6 + 1 (0 + 7 и 7 + 0 ✗) → 6
  • b + c = 10: 1 + 9, 2 + 8, 4 + 6, 5 + 5, 6 + 4, 8 + 2, 9 + 1 (3 + 7 и 7 + 3 ✗) → 7
  • b + c = 13: 4 + 9, 5 + 8, 8 + 5, 9 + 4 (6 + 7 и 7 + 6 ✗) → 4
  • b + c = 16: 8 + 8 (7 + 9 и 9 + 7 ✗) → 1

2 + 5 + 6 + 7 + 4 + 1 = 25 ✓

Компьютерный перебор всех чисел от 1000 до 2017 даёт 76: по 25 с семёркой в сотнях, в десятках и в единицах и одно число 2007 из хвоста.

Ответ на задачу: в списке Педро 76 чисел. Как считал:

  • числа от 1000 до 1999 разрезал по месту единственной семёрки — сотни, десятки или единицы;
  • в каждом случае две свободные цифры без семёрки, и признак делимости на 3 требует от их остатков 0 + 1, 1 + 0 или 2 + 2 — это 25 чисел на случай;
  • из чисел от 2000 до 2017 подходит одно — 2007.
