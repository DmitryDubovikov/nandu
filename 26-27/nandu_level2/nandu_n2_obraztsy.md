# Образцы — Segundo Nivel

## 17 задач корпуса, по одной на подтип, в три фазы по турам · с них начинается курс второго уровня

> **Зачем этот файл.** Курс второго уровня строится от решений, а не от учебников (hard rule 7 в `CLAUDE.md`).
> На каждый подтип типологии берётся одна реальная задача корпуса — образец. Родитель и Claude решают её, родитель
> доводит решение до вида, который считает оптимальным. Из принятых решений выписываются ходы (раздел 5), и учебники
> пишутся ровно под эти ходы — в той же записи и под теми же именами.
>
> **Фазы.** Работа идёт не «все 17 решений, потом все учебники», а фазами по турам сезона: внутри фазы — образцы →
> идеальные решения → ходы → учебники, потом следующая фаза. Фаза определяется туром, к которому она готовит; по времени
> фазы могут перекрываться.
>
> Образцы — рабочий материал для учебников, а не тренировка ребёнка. Задача, решённая здесь, остаётся в корпусе
> на общих основаниях. Решения всего корпуса — последний этап, после учебников.
>
> **Выбор образца** (окт 2026): задача, чьё решение требует «первого хода» подтипа из
> `26-27/nandu_level2/nandu_n2_tipologia_svodnaya.md` и как можно больше его стандартных вариантов; типичная, а не
> одиночка; на верхнем краю сложности подтипа; по возможности свежая. Запасной — если образец по ходу работы окажется
> неудачным. Решение трудного образца покрывает и простые задачи подтипа; реальный уровень тура калибруется
> боевыми задачами в конце фазы (раздел 1).

### Уровень образца и уровень тура

**Каждый образец — на максимальной сложности своего подтипа, один проход на тему** (решение родителя, 23.10.2026):
одно идеальное решение и один учебник под его ходы, без отдельного «зонального» разбора той же темы. Трудное решение
покрывает простые задачи подтипа как частные случаи. Учебник сразу на этом уровне: трудность держит порядок глав
(hard rule 3), а не возраст. **Реальный уровень тура калибруется боевыми задачами этого тура** в конце фазы — для этого
в календаре у каждой фазы есть боевое окно.

## 6. Где лежат решения и как идёт работа над образцом

- Исходники: `26-27/nandu_level2/idealnye_resheniya/_md/<подтип>_<этап>_<год>_<№>.md` (например `T1_nac_2023_4.md`;
  штрихи латиницей: Т3′ → `T3p`, Т3″ → `T3pp`, Т3‴ → `T3ppp`, Т1⁗ → `T1pppp`; этапы `inter`, `zon`, `prov`, `reg`, `nac`);
  HTML фазы собирается командой `python3 26-27/nandu_level2/idealnye_resheniya/_md/sobrat.py <фаза>` → `idealnye_resheniya/faza<N>/`.
- Площадь пишется словом: «площадь ABDEF = …». Отдельного знака нет — `S(…)` в словаре обозначений занято суммой (23.10.2026).
- Формат — hard rules 8–15 `CLAUDE.md` (план-артефакт, шаги-операнды, «Заметь главное», «Условие» отдельным блоком,
  боевая запись с 💬-фразой). Эталон отточенного решения — разборы первого уровня
  `25-26/nandu_level1/national/boevye_resheniya/_md/parts/{2021_6,2023_3,2024_1}.md`.
- Порядок по одной задаче:
  1. Claude пишет черновик, ответ проверяется независимо (второй агент по одному условию + перебор программой) → галочка «черновик» в роадмапе;
  2. родитель и Claude шлифуют решение, пока родитель не примет его как оптимальное → галочка «идеально»;
  3. ходы решения вносятся в раздел 5.
- Задачи идут по таблицам фаз сверху вниз, если родитель не скажет иначе. Учебники фазы пишутся, когда все её образцы приняты. Галочки — `26-27/nandu_level2/nandu_n2_roadmap.md`.
