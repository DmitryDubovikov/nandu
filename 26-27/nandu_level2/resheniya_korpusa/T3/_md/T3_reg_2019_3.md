## Т3 — регионал 2019, №3 — неделя Хуаны: гимнастика не два дня подряд

**Условие.** На прошлой неделе, с понедельника по субботу, Хуана занималась гимнастикой, ходила на английский и ходила в художественную мастерскую:

- занятия были в 5 из 6 дней;
- в один день — не больше одного занятия;
- в мастерской она была только один день;
- гимнастикой она не занималась в дни подряд.

Сколькими разными способами Хуана могла распределить свои занятия? Объясни, как ты их считала.

**Способ** — расписание недели: каждому из дней Пн, Вт, Ср, Чт, Пт, Сб — гимнастика, английский, мастерская или день без занятий.

<!-- отступление от образца: «Идея» — какое правило ставить первым, а не «правила, выполненные сами»: здесь единственное правило о расположении дней касается только гимнастики -->
**Идея.** Правило «не в дни подряд» говорит только о гимнастике ⇒ первыми ставим дни гимнастики, остальные занятия — в оставшиеся дни.

**Дано:** *«занятия были в 5 из 6 дней»* ⇒ ровно один день без занятий, назовём его выходным.

**Дано:** *«в мастерской она была только один день»* ⇒ на гимнастику и английский остаются четыре дня.

**Дано:** *«занималась гимнастикой»* и *«ходила на английский»* ⇒ гимнастика и английский — каждое хотя бы один день.

**Значит:** из четырёх дней гимнастике достаётся один, два или три.

Неделя собирается в три хода: дни гимнастики, день мастерской среди оставшихся, выходной среди оставшихся, остальные дни — английский.

<!-- отступление от образца: формула верхнего уровня — сумма миров по числу дней гимнастики, а не произведение ходов: число вариантов первого хода (дней гимнастики) зависит от того, сколько их, и от правила «не подряд», поэтому произведение — внутри каждого мира -->
Число дней гимнастики задаёт, сколько дней остаётся мастерской и выходному, поэтому миры — по числу дней гимнастики:

N(расписаний) = N(один день гимнастики) + N(два дня гимнастики) + N(три дня гимнастики)

**1. N(один день гимнастики).**

Ни один ход не меняет число вариантов следующего, поэтому три хода перемножаются:

N(один день гимнастики) = N(дней для гимнастики) · N(дней для мастерской) · N(дней для выходного)

Один день гимнастики — любой из шести дней.

**Заметим:** при одном дне гимнастики правило «не в дни подряд» выполнено само.

N(дней для гимнастики) = 6

Мастерская — один из пяти дней, оставшихся после гимнастики.

N(дней для мастерской) = 5

Выходной — один из четырёх дней, оставшихся после мастерской.

N(дней для выходного) = 4

N(один день гимнастики) = 6 · 5 · 4 = 120

**2. N(два дня гимнастики).**

N(два дня гимнастики) = N(пар дней для гимнастики) · N(дней для мастерской) · N(дней для выходного)

**Дано:** *«не занималась в дни подряд»* ⇒ между двумя днями гимнастики хотя бы один другой день недели, выходной тоже подходит.

N(пар дней для гимнастики) = 4 + 3 + 2 + 1 = 10

<small>первый день Пн: второй Ср, Чт, Пт, Сб   Вт: Чт, Пт, Сб   Ср: Пт, Сб   Чт: Сб</small>

Мастерская — один из четырёх дней, оставшихся после гимнастики.

N(дней для мастерской) = 4

Выходной — один из трёх дней, оставшихся после мастерской.

N(дней для выходного) = 3

N(два дня гимнастики) = 10 · 4 · 3 = 120

**3. N(три дня гимнастики).**

N(три дня гимнастики) = N(троек дней для гимнастики) · N(дней для мастерской) · N(дней для выходного)

**Значит:** между любыми двумя из трёх дней гимнастики хотя бы один другой день.

N(троек дней для гимнастики) = 4

<small>Пн, Ср, Пт   Пн, Ср, Сб   Пн, Чт, Сб   Вт, Чт, Сб</small>

Мастерская — один из трёх дней, оставшихся после гимнастики.

N(дней для мастерской) = 3

Выходной — один из двух дней, оставшихся после мастерской.

N(дней для выходного) = 2

N(три дня гимнастики) = 4 · 3 · 2 = 24

**Сборка.**

N(расписаний) = 120 + 120 + 24 = 264

**Ответ на задачу:** Хуана могла распределить занятия **264** способами.

**⚠ Ловушки.**

- Забыть правило «не в дни подряд»: пар дней гимнастики 15, троек 20, выйдет 420.
- Считать гимнастику во Вт и Чт при выходном в Ср днями подряд: выйдет 240.
- Выбрать два дня для мастерской и выходного, не различая, где мастерская, а где выходной: выйдет вдвое меньше, 132.

*Проверено: «всё минус плохие» 420 − (5 · 12 + 16 · 6) = 264; перебор программой всех 4096 расписаний недели даёт 264.*
