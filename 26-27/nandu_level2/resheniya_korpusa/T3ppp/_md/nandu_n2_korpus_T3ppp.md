## Т3‴ — национал 2026, день II, №6 — ряд из 18 красных и 18 синих фишек блоками

**Условие.** У Мартина 36 фишек: 18 красных и 18 синих. Он хочет выложить их в ряд так, чтобы:

- в ряду было четыре блока красных фишек и четыре блока синих, цвета чередуются, первый блок красный;
- в блоках одного цвета было разное число фишек;
- число фишек в блоках одного цвета всё время росло.

Вопросы:

- а) Сколькими способами он может это сделать? Объясни, как ты их считал.
- б) В скольких случаях во всех восьми блоках разное число фишек?

**Способ** — ряд фишек, который задают длины восьми блоков слева направо (длина блока — сколько в нём фишек).

**Дано:** *«18 красных и 18 синих»* ⇒ фишки различаются только цветом.

r₁, r₂, r₃, r₄ — длины красных блоков слева направо.

b₁, b₂, b₃, b₄ — длины синих блоков слева направо.

*🆕 Приём: число = сумма k разных растущих слагаемых; два независимых цвета → произведение — условия на красные блоки не касаются синих ⇒ N = N(длин красных) · N(длин синих); первое из растущих слагаемых ограничено наименьшей суммой x + (x + 1) + …, по этой границе — миры по первому слагаемому, внутри них по второму, последние два — пара с данной суммой*

**Идея.** Каждое условие говорит о блоках одного цвета ⇒ длины красных и синих блоков выбираем отдельно.

**Дано:** *«18 красных»*, *«разное число фишек»*, *«всё время росло»* (по ходу ряда, слева направо) ⇒

r₁ < r₂ < r₃ < r₄

r₁ + r₂ + r₃ + r₄ = 18

**Дано:** *«18 синих»* и те же условия ⇒ b₁, b₂, b₃, b₄ так же растут, и их сумма так же 18.

**Заметим:** в условиях на r нет ни одного b, а в условиях на b нет ни одного r ⇒ к любым длинам красных блоков годятся любые длины синих, выборы перемножаются:

> ✅ N(рядов) = ⟪N(длин красных)⟫ · ⦃N(длин синих)⦄

**1. N(длин красных).**

**Заметим:** r₁ — самый короткий красный блок, за ним идут три блока длиннее ⇒ r₁ не может быть большим.

:::box Приём — первое из растущих слагаемых
Слагаемые растут: каждое хотя бы на 1 больше предыдущего.

Если первое слагаемое равно x, то следующие слагаемые не меньше:

x + 1, x + 2, x + 3, …

Значит, сумма всех слагаемых не меньше наименьшей суммы, где каждое слагаемое наименьшее:

x + (x + 1) + (x + 2) + …

Если наименьшая сумма больше заданной, то первое слагаемое меньше x.

Пример на числах, не из задачи: три растущих слагаемых с суммой 12.

x = 4 ⇒ сумма ≥ 4 + 5 + 6 = 15 > 12 ⇒ первое слагаемое равно 1, 2 или 3.
:::

В частности, при r₁ = 4:

r₁ + r₂ + r₃ + r₄ ≥ 4 + 5 + 6 + 7 = 22 > 18 ⇒ r₁ = 1, 2 или 3

Мир задаёт r₁:

> ✅ ⟪N(длин красных)⟫ = N(r₁ = 1) + N(r₁ = 2) + N(r₁ = 3)

**1.1. N(r₁ = 1).**

r₁ = 1 ⇒ r₂ + r₃ + r₄ = 18 − 1 = 17, а r₂ ≥ 2

**Способ** — состав пакетика: пакетики различаются только числом монет каждого веса, порядок монет не важен.

## Т3‴ — регионал 2017, №3 — зачёркнутые числа от 1 до 9, сумма оставшихся вдвое больше

**Условие.** Написаны числа 1, 2, 3, 4, 5, 6, 7, 8, 9:

- Бето зачёркивает некоторые из этих чисел;
- Андрес складывает числа, которые остались незачёркнутыми;
- сумма Андреса вдвое больше суммы чисел, которые зачеркнул Бето.

Какие числа мог зачеркнуть Бето? Дай все возможности.

**Идея.** Сумма всех чисел от 1 до 9 известна ⇒ из «вдвое больше» найдём сумму зачёркнутых чисел.

**Дано:** *«написаны числа 1, 2, 3, 4, 5, 6, 7, 8, 9»*, и каждое число либо зачёркнуто, либо осталось ⇒

S_{оставшихся} + S_{зачёркнутых} = 1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 + 9 = 45

**Дано:** *«сумма Андреса вдвое больше суммы чисел, которые зачеркнул Бето»* ⇒ подставим в сумму 45:

```sys
S_{ост} = 2 · S_{зач}
(2 · S_{зач}) + (1 · S_{зач}) = 45
3 · S_{зач} = 45        | : 3
S_{зач} = 15
```

**Значит:** Бето зачеркнул разные числа от 1 до 9 с суммой 15.

Каждое число не больше 9, а 9 < 15 ⇒ зачёркнутых чисел не меньше двух.

Шесть разных чисел дают сумму не меньше 1 + 2 + 3 + 4 + 5 + 6 = 21, а 21 > 15 ⇒ зачёркнутых чисел не больше пяти.


> ✅ N(наборов) = ⟪N(2 числа)⟫ + ⦃N(3 числа)⦄ + ⦅N(4 числа)⦆ + ⟬N(5 чисел)⟭

**1. N(2 числа).**

**Заметим:** зачёркнутые числа разные ⇒ выпишем зачёркнутые числа по возрастанию:

x₁ < x₂ < x₃ < …

**Заметим:** x₁ — самое маленькое зачёркнутое число, за ним идут только числа больше ⇒ x₁ не может быть большим.

*🆕 Приём: число = сумма k разных растущих слагаемых — зачёркнутые числа по возрастанию; первое ограничено наименьшей суммой m + (m + 1) + …, по этой границе — миры по первому числу, последние два числа — пара с известной суммой; здесь у пары есть ещё граница сверху: числа не больше 9*


:::box Приём — первое из растущих слагаемых
Слагаемые растут: каждое хотя бы на 1 больше предыдущего.

Если первое слагаемое равно m, то следующие слагаемые не меньше:

m + 1, m + 2, m + 3, …

Значит, сумма всех слагаемых не меньше наименьшей суммы, где каждое слагаемое наименьшее:

m + (m + 1) + (m + 2) + …

Если наименьшая сумма больше заданной, то первое слагаемое меньше m.

Пример на числах, не из задачи: три растущих слагаемых с суммой 12.

m = 4 ⇒ сумма ≥ 4 + 5 + 6 = 15 > 12 ⇒ первое слагаемое равно 1, 2 или 3.
:::

x₁ = 6 или 7, x₂ = 15 − x₁

## Т3‴ — национал 2013, день I, №3 — числа меньше 99999 без цифры 1 с произведением цифр 168

**Условие.** Диего пишет числа, у которых:

- число меньше 99999;
- ни одна цифра не равна 1;
- произведение всех цифр равно 168.

Сколько разных чисел может написать Диего? Объясни, как ты их считал.

**Способ** — расстановка цифр по местам числа: 378 и 873 — разные числа.

**Идея.** Длина числа почти задана, а внутри длины всё решает, на какие цифры раскладывается 168.

Каждая цифра не больше 9, а 9 · 9 = 81 < 168 ⇒ цифр не меньше трёх.

*«меньше 99999»* ⇒ цифр не больше пяти.

> ✅ N = ⟪N(3 цифры)⟫ + ⦃N(4 цифры)⦄ + ⦅N(5 цифр)⦆

*🆕 Приём вне реестра: цифры из простых множителей — простые множители произведения цифр делятся на группы, каждая цифра равна произведению своей группы*

:::box Приём — цифры из простых множителей
Цифры 2, 3, 5, 7 сами простые, а остальные цифры от 4 до 9 раскладываются на простые множители:

4 = 2 · 2,      6 = 2 · 3,      8 = 2 · 2 · 2,      9 = 3 · 3

Значит, простые множители произведения цифр делятся между цифрами: каждая цифра равна произведению своей группы множителей.

Пример на числах, не из задачи: число 326.

произведение цифр 326 = 3 · 2 · 6 = 36 = 2 · 2 · 3 · 3

Цифра 3 забрала множитель 3, цифра 2 забрала 2, цифра 6 забрала 2 · 3.
:::

В частности, *«произведение всех цифр равно 168»* ⇒

произведение цифр = 168 = 2 · 2 · 2 · 3 · 7

С 0 произведение равно 0, а не 168 ⇒ 0 в числе нет.

*«ни одна цифра не равна 1»* ⇒ каждая цифра забирает хотя бы один множитель.

```sys

407 · A = 2013 − 333 · B − 2 · C − D
```
