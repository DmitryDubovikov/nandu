## Т3‴ — национал 2013, день I, №3 — числа меньше 99999 без цифры 1 с произведением цифр 168

**Условие.** Диего пишет числа, у которых:

- число меньше 99999;
- ни одна цифра не равна 1;
- произведение всех цифр равно 168.

Сколько разных чисел может написать Диего? Объясни, как ты их считал.

**Способ** — расстановка цифр по местам числа: 378 и 873 — разные числа.

<!-- отступление от образца: идея говорит не об отклонении от 5, а о разложении 168 на цифры — условие задаёт произведение цифр, а не сумму -->
**Идея.** Длина числа почти задана, а внутри длины всё решает, на какие цифры раскладывается 168.

Каждая цифра не больше 9, а 9 · 9 = 81 < 168 ⇒ цифр не меньше трёх.

<!-- отступление от образца: граница сверху — из цитаты «меньше 99999», а не из наименьшей цифры: условие ограничивает длину прямо -->
*«меньше 99999»* ⇒ цифр не больше пяти.

> ✅ N = ⟪N(3 цифры)⟫ + ⦃N(4 цифры)⦄ + ⦅N(5 цифр)⦆

<!-- отступление от образца: врезка не «отклонение от 5», а цифры из простых множителей — задано произведение цифр, и состав ищется разложением на простые -->
<!-- 🆕 приём вне реестра: цифры из простых множителей — простые множители произведения цифр делятся на группы, каждая цифра равна произведению своей группы -->

:::box Приём — цифры из простых множителей
Цифры 2, 3, 5, 7 сами простые, а остальные цифры от 4 до 9 раскладываются на простые множители:

4 = 2 · 2,      6 = 2 · 3,      8 = 2 · 2 · 2,      9 = 3 · 3

Значит, простые множители произведения цифр делятся между цифрами: каждая цифра равна произведению своей группы множителей.

Пример на числах, не из задачи: число 326.

произведение цифр 326 = 3 · 2 · 6 = 36 = 2 · 2 · 3 · 3

Цифра 3 забрала множитель 3, цифра 2 забрала 2, цифра 6 забрала 2 · 3.
:::

В частности, *«произведение всех цифр равно 168»* ⇒

произведение цифр = 168 = 2 · 2 · 2 · 3 · 7

С 0 произведение равно 0, а не 168 ⇒ 0 в числе нет.

*«ни одна цифра не равна 1»* ⇒ каждая цифра забирает хотя бы один множитель.

7 · 2 = 14 больше 9 ⇒ множитель 7 забирает цифра 7 и больше ничего ⇒ 7 встречается ровно один раз.

Остальные цифры делят множители 2, 2, 2, 3.

Множитель 3 забирает цифра 3 или 6: 2 · 2 · 3 = 12 уже не цифра.

**1. N(3 цифры).**

Множители 2, 2, 2, 3 делят две цифры кроме 7.

<!-- отступление от образца: мир задаёт не число шестёрок, а цифра, которая забирает множитель 3 (3 или 6) — состав здесь решает разложение, а не разность -->

Мир задаёт, какая цифра забирает множитель 3:

> ✅ ⟪N(3 цифры)⟫ = N(с 3) + N(с 6)

**1.1. N(с 3).**

Цифра кроме 3 и 7 забирает 2 · 2 · 2 = 8 ⇒ цифры 3, 7, 8.

При любом месте 7 для 8 остаются два места, а 3 встаёт на последнее, поэтому выборы перемножаются:

> ✅ N(с 3) = N(мест для 7) · N(мест для 8)

N(мест для 7) = 3

N(мест для 8) = 2

N(с 3) = 3 · 2 = 6

<small>378    387    738    783    837    873</small>

**1.2. N(с 6).**

Цифра кроме 6 и 7 забирает 2 · 2 = 4 ⇒ цифры 4, 6, 7.

При любом месте 7 для 6 остаются два места, а 4 встаёт на последнее, поэтому выборы перемножаются:

> ✅ N(с 6) = N(мест для 7) · N(мест для 6)

N(мест для 7) = 3

N(мест для 6) = 2

N(с 6) = 3 · 2 = 6

<small>467    476    647    674    746    764</small>

⟪N(3 цифры)⟫ = 6 + 6 = ⟪12⟫

**2. N(4 цифры).**

Множители 2, 2, 2, 3 делят три цифры кроме 7.

Мир задаёт, какая цифра забирает множитель 3:

> ✅ ⦃N(4 цифры)⦄ = N(с 3) + N(с 6)

**2.1. N(с 3).**

Две цифры кроме 3 и 7 делят 2, 2, 2: одна забирает 2, другая 2 · 2 = 4 ⇒ цифры 2, 3, 4, 7.

При любых местах 7 и 4 для 3 остаются два места, а 2 встаёт на последнее, поэтому выборы перемножаются:

> ✅ N(с 3) = N(мест для 7) · N(мест для 4) · N(мест для 3)

N(мест для 7) = 4

N(мест для 4) = 3

N(мест для 3) = 2

<small>при 7 на месте 1: 7234    7243    7324    7342    7423    7432</small>

N(с 3) = 4 · 3 · 2 = 24

**2.2. N(с 6).**

Две цифры кроме 6 и 7 делят 2, 2: каждая забирает 2 ⇒ цифры 2, 2, 6, 7.

**Дано:** *«ни одна цифра не равна 1»* ⇒ запрещена только 1, а одинаковые цифры можно.

При любом месте 7 для 6 остаются три места, на остальных двух местах стоит 2, поэтому выборы перемножаются:

> ✅ N(с 6) = N(мест для 7) · N(мест для 6)

N(мест для 7) = 4

N(мест для 6) = 3

<small>при 7 на месте 1: 7622    7262    7226</small>

N(с 6) = 4 · 3 = 12

⦃N(4 цифры)⦄ = 24 + 12 = ⦃36⦄

**3. N(5 цифр).**

Множители 2, 2, 2, 3 делят четыре цифры кроме 7 ⇒ каждая цифра забирает ровно один множитель.

Цифры числа: 2, 2, 2, 3, 7.

При любом месте 7 для 3 остаются четыре места, на остальных трёх местах стоит 2, поэтому выборы перемножаются:

> ✅ ⦅N(5 цифр)⦆ = N(мест для 7) · N(мест для 3)

N(мест для 7) = 5

N(мест для 3) = 4

<small>при 7 на месте 1: 73222    72322    72232    72223</small>

⦅N(5 цифр)⦆ = 5 · 4 = ⦅20⦆

**Сборка.**

N = ⟪12⟫ + ⦃36⦄ + ⦅20⦆ = 68

**Ответ на задачу:** Диего может написать **68 чисел**.

**⚠ Ловушки.**

- Прочитать «ни одна цифра не равна 1» как «все цифры разные»: потеряются числа из цифр 2, 2, 6, 7 и 2, 2, 2, 3, 7, выйдет 36.
- Переставлять одинаковые 2 как разные: для 2, 2, 6, 7 выйдет 24 вместо 12, для 2, 2, 2, 3, 7 выйдет 120 вместо 20, всего 180.
- Не заметить, что множитель 3 может забрать цифра 6 при четырёх цифрах: потеряются числа из цифр 2, 2, 6, 7, выйдет 56.

*Проверено перебором программой всех чисел от 1 до 99998: 68, по длинам 12, 36, 20.*
