## Т3‴ — провинциал 2013, №3 — карточка A, B, C, D с 407 · A + 333 · B + 2 · C + D = 2013

**Условие.** Хуан заполнил карточку целыми положительными числами A, B, C и D:

- все четыре числа отличны от нуля;
- Хуан без ошибок посчитал 407 · A + 333 · B + 2 · C + D;
- получилось 2013.

Сколькими разными способами Хуан мог заполнить карточку? Объясни, как ты их считал.

<!-- отступление от образца: «Способ» — четвёрка чисел в клетках, а не расстановка цифр по местам: места букв заданы карточкой -->
**Способ** — четвёрка чисел A, B, C, D: карточки с разным числом хотя бы в одной клетке — разные.

<!-- отступление от образца: «Идея» — большие множители 407 и 333, а не отклонение от 5: значения букв не соседние числа, а сумма с разными множителями -->
**Идея.** При A и B стоят большие множители 407 и 333 ⇒ у A и B мало значений, а при выбранных A и B каждое C даёт ровно одно D.

<!-- отступление от образца: вместо врезки «отклонение от 5» перед разбиением — уравнение из условия и оценка A из него; врезка с подсчётом пар C, D стоит в разделе 1, где она впервые нужна -->
*«посчитал 407 · A + 333 · B + 2 · C + D»* и *«получилось 2013»* ⇒

```sys
407 · A + 333 · B + 2 · C + D = 2013        | − 333 · B − 2 · C − D
407 · A = 2013 − 333 · B − 2 · C − D
```

**Дано:** *«целыми положительными»*, *«отличны от нуля»* ⇒ A, B, C, D не меньше 1, равные числа в разных клетках разрешены.

**Значит:** в правой части из 2013 вычитается положительное число ⇒ 407 · A < 2013.

407 · 5 = 2035 > 2013 ⇒ A от 1 до 4.

> ✅ N = ⟪N(A = 1)⟫ + ⦃N(A = 2)⦄ + ⦅N(A = 3)⦆ + ⟬N(A = 4)⟭

**1. N(A = 1).**

A = 1 ⇒ 333 · B + 2 · C + D = 2013 − 407 = 1606

C и D не меньше 1 ⇒ 333 · B < 1606

333 · 5 = 1665 > 1606 ⇒ B от 1 до 4.

Мир задаёт B (2 · C + D равно остальному):

> ✅ ⟪N(A = 1)⟫ = N(B = 1) + N(B = 2) + N(B = 3) + N(B = 4)

**1.1. N(B = 1).**

B = 1 ⇒ 2 · C + D = 1606 − 333 = 1273

**Заметим:** при выбранном C число D находится однозначно ⇒ считаем подходящие C.

<!-- 🆕 приём вне реестра: «сколько пар C, D с 2 · C + D = x» — каждое C даёт одно D, условие D ≥ 1 ограничивает C сверху, граница зависит от чётности x -->

:::box Приём — сколько пар C, D с 2 · C + D = x
C и D — целые, не меньше 1.

Каждое C даёт ровно одно D:

D = x − 2 · C

D ≥ 1 ⇒ 2 · C ≤ x − 1

x нечётное ⇒ C от 1 до (x − 1) : 2

x чётное ⇒ x − 1 нечётное, а 2 · C чётное ⇒ 2 · C ≤ x − 2 ⇒ C от 1 до (x − 2) : 2

Пример на числах, не из задачи: 2 · C + D = 9 ⇒ N(пар C, D) = (9 − 1) : 2 = 4

<small>(C, D) = (1, 7)    (2, 5)    (3, 3)    (4, 1)</small>

2 · C + D = 8 ⇒ N(пар C, D) = (8 − 2) : 2 = 3

<small>(C, D) = (1, 6)    (2, 4)    (3, 2)</small>
:::

В частности, 1273 нечётное ⇒

N(B = 1) = (1273 − 1) : 2 = 636

<small>от C = 1, D = 1271 до C = 636, D = 1</small>

**1.2. N(B = 2).**

B = 2 ⇒ 2 · C + D = 1606 − 333 · 2 = 940

940 чётное ⇒ N(B = 2) = (940 − 2) : 2 = 469

<small>от C = 1, D = 938 до C = 469, D = 2</small>

**1.3. N(B = 3).**

B = 3 ⇒ 2 · C + D = 1606 − 333 · 3 = 607

607 нечётное ⇒ N(B = 3) = (607 − 1) : 2 = 303

<small>от C = 1, D = 605 до C = 303, D = 1</small>

**1.4. N(B = 4).**

B = 4 ⇒ 2 · C + D = 1606 − 333 · 4 = 274

274 чётное ⇒ N(B = 4) = (274 − 2) : 2 = 136

<small>от C = 1, D = 272 до C = 136, D = 2</small>

⟪N(A = 1)⟫ = 636 + 469 + 303 + 136 = ⟪1544⟫

**2. N(A = 2).**

A = 2 ⇒ 333 · B + 2 · C + D = 2013 − 407 · 2 = 1199

C и D не меньше 1 ⇒ 333 · B < 1199

333 · 4 = 1332 > 1199 ⇒ B от 1 до 3.

Мир задаёт B (2 · C + D равно остальному):

> ✅ ⦃N(A = 2)⦄ = N(B = 1) + N(B = 2) + N(B = 3)

**2.1. N(B = 1).**

B = 1 ⇒ 2 · C + D = 1199 − 333 = 866

866 чётное ⇒ N(B = 1) = (866 − 2) : 2 = 432

<small>от C = 1, D = 864 до C = 432, D = 2</small>

**2.2. N(B = 2).**

B = 2 ⇒ 2 · C + D = 1199 − 333 · 2 = 533

533 нечётное ⇒ N(B = 2) = (533 − 1) : 2 = 266

<small>от C = 1, D = 531 до C = 266, D = 1</small>

**2.3. N(B = 3).**

B = 3 ⇒ 2 · C + D = 1199 − 333 · 3 = 200

200 чётное ⇒ N(B = 3) = (200 − 2) : 2 = 99

<small>от C = 1, D = 198 до C = 99, D = 2</small>

⦃N(A = 2)⦄ = 432 + 266 + 99 = ⦃797⦄

**3. N(A = 3).**

A = 3 ⇒ 333 · B + 2 · C + D = 2013 − 407 · 3 = 792

C и D не меньше 1 ⇒ 333 · B < 792

333 · 3 = 999 > 792 ⇒ B от 1 до 2.

Мир задаёт B (2 · C + D равно остальному):

> ✅ ⦅N(A = 3)⦆ = N(B = 1) + N(B = 2)

**3.1. N(B = 1).**

B = 1 ⇒ 2 · C + D = 792 − 333 = 459

459 нечётное ⇒ N(B = 1) = (459 − 1) : 2 = 229

<small>от C = 1, D = 457 до C = 229, D = 1</small>

**3.2. N(B = 2).**

B = 2 ⇒ 2 · C + D = 792 − 333 · 2 = 126

126 чётное ⇒ N(B = 2) = (126 − 2) : 2 = 62

<small>от C = 1, D = 124 до C = 62, D = 2</small>

⦅N(A = 3)⦆ = 229 + 62 = ⦅291⦆

**4. N(A = 4).**

A = 4 ⇒ 333 · B + 2 · C + D = 2013 − 407 · 4 = 385

C и D не меньше 1 ⇒ 333 · B < 385

333 · 2 = 666 > 385 ⇒ B = 1

B = 1 ⇒ 2 · C + D = 385 − 333 = 52

52 чётное ⇒ ⟬N(A = 4)⟭ = (52 − 2) : 2 = ⟬25⟭

<small>от C = 1, D = 50 до C = 25, D = 2</small>

**Сборка.**

N = ⟪1544⟫ + ⦃797⦄ + ⦅291⦆ + ⟬25⟭ = 2657

**Ответ на задачу:** Хуан мог заполнить карточку **2657 способами**.

**⚠ Ловушки.**

- Забыть, что D не меньше 1, и при чётном x брать C до половины x: в шесть миров с чётным x добавится по карточке с D = 0, выйдет 2663.
- Прочитать «все отличны от нуля» как «все разные»: выйдет 1727.

*Проверено перебором программой всех A, B, C от 1 до 2013 при D = 2013 − 407 · A − 333 · B − 2 · C не меньше 1: 2657, по мирам A = 1, 2, 3, 4: 1544, 797, 291, 25.*
