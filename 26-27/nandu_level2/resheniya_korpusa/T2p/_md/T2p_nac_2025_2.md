## Т2′ — национал 2025, день I, №2 — прямоугольник ABDG, периметр AMNH 112 см, площадь FOP 84 см²

<!-- отступление от образца: в оригинале вопросы без меток; метки а)–г) поставлены в условии, ответ на каждый — своим абзацем -->
**Условие.** На рисунке:

- CDEJ и FGHI — равные квадраты;
- ABCH и CDGH — равные прямоугольники;
- M — середина AB;
- PM перпендикулярна AB;
- периметр IJEF = 2 · периметр CDEJ;
- периметр AMNH равен 112 см;
- периметр EFP равен 98 см;
- площадь FOP равна 84 см².

Вопросы:

- а) Чему равна площадь MJEPFI?
- б) Чему равна площадь BEPF?
- в) Чему равна площадь ACDE?
- г) Чему равна площадь BPI?

<!-- отступление от образца: отношение сторон не дано числом, а выводится из «периметр IJEF = 2 · периметр CDEJ» — две строки до выбора кирпича -->
**Дано:** *«ABCH и CDGH — равные прямоугольники»* ⇒ BC = CD, а AB = HC = GD.

**Дано:** *«CDEJ и FGHI — равные квадраты»* ⇒ CD = DE = EJ = JC = GF = FI = IH = HG.

**С чертежа:** IJEF — прямоугольник со сторонами FI = JE = CD.

**Дано:** *«периметр IJEF = 2 · периметр CDEJ»* ⇒

2 · (IJ + CD) = 2 · 4 · CD ⇒ IJ = 3 · CD

**Значит:** HC = HI + IJ + JC = CD + 3 · CD + CD = 5 · CD.

**Дано:** *«M — середина AB»* ⇒ AM = MB = HC : 2 = 5 · CD : 2.

**Значит:** чтобы CD, AM и MB были целыми кирпичами, берём маленький кирпич x = CD : 2.

**В кирпичах:** CD = BC = AH = HG = GF = HI = DE = JC = 2x, IJ = FE = 6x, AB = HC = GD = 10x, AM = MB = 5x.

**С чертежа:** N и O лежат на PM.

**Дано:** *«PM перпендикулярна AB»*, а M — середина AB ⇒ N и O — середины HC и GD.

**С чертежа:** IN = NJ = FO = OE = 5x − 2x = 3x, GE = 10x − 2x = 8x, BD = AG = 4x.

**Значит:** все точки, кроме P, стоят в узлах сетки с шагом x.

**Значит:** P стоит над O на неизвестной высоте OP.

**Буквы на рисунке.** CD = 2x, AB = 10x, сетка с шагом x.

**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** площадь MJEPFI.

**Заметим:** MJEPFI не прямоугольник и не трапеция, готовой формулы нет ⇒ MJEPFI складывается из прямоугольника IJEF и треугольников FPE и IMJ.

**Заметим:** FPE — два одинаковых прямоугольных треугольника FOP и EOP, площадь FOP дана.

<small>IMJ: основание IJ, высота MN.</small>
:::col
**б) Спросили:** площадь BEPF.

**Заметим:** BEPF не прямоугольник и не трапеция ⇒ отрезок FE разрезает BEPF на треугольники FPE и FEB.

<small>FEB: основание FE, высота BD.</small>
:::

:::cols
**в) Спросили:** площадь ACDE.

**Заметим:** ACDE не прямоугольник и не трапеция ⇒ ACDE — это прямоугольник ABDG без прямоугольных треугольников ABC и AGE.
:::col
**г) Спросили:** площадь BPI.

**Заметим:** N лежит внутри BPI ⇒ отрезки NP, NI и NB разрезают BPI на треугольники PIN, INB и BNP.

<small>I и N на одной прямой HC, а IB идёт от I вниз к B ⇒ N выше IB.</small>

<small>PIN: катеты IN и NP = NO + OP = 2x + OP.</small>

<small>INB: основание IN, высота BC.</small>

<small>BNP: основание NP, высота BM.</small>
:::

> ✅ **Значит, осталось найти x и OP.**

**1. Найдём x.**

*«периметр AMNH равен 112 см»*

**Заметим:** AMNH — прямоугольник со сторонами AM = 5x и AH = 2x.

> ✅ **2 · (5x + 2x) = 112**

```sys
14x = 112       | : 14
x = 8
```

**2. Найдём OP.**

*«площадь FOP равна 84 см²»*

**Заметим:** FOP — прямоугольный треугольник с катетами FO = 3x и OP.

<small>PM перпендикулярна AB, а GD параллельна AB ⇒ PO перпендикулярна FE.</small>

> ✅ **3x · OP : 2 = 84**

**Подставим x = 8 в уравнение.**

```sys
24 · OP : 2 = 84
12 · OP = 84      | : 12
OP = 7
```

**3. Сборка: подставим x = 8, OP = 7 и S(FOP) = 84.**

а) S(MJEPFI) = S(IJEF) + S(FPE) + S(IMJ) = 6x · 2x + 2 · 84 + 6x · 2x : 2 = 768 + 168 + 384 = 1320

б) S(BEPF) = S(FPE) + S(FEB) = 2 · 84 + 6x · 4x : 2 = 168 + 768 = 936

в) S(ACDE) = S(ABDG) − S(ABC) − S(AGE) = 10x · 4x − 10x · 2x : 2 − 4x · 8x : 2 = 2560 − 640 − 1024 = 896

г) S(BPI) = S(PIN) + S(INB) + S(BNP) = 3x · (2x + OP) : 2 + 3x · 2x : 2 + (2x + OP) · 5x : 2 = 276 + 192 + 460 = 928

**Ответ на задачу:**

а) площадь MJEPFI равна **1320 см²**;

б) площадь BEPF равна **936 см²**;

в) площадь ACDE равна **896 см²**;

г) площадь BPI равна **928 см²**.

**⚠ Ловушки.**

- Из «периметр IJEF = 2 · периметр CDEJ» следует IJ = 3 · CD, а не IJ = 2 · CD: в периметр IJEF входят и стороны JE = CD.
- Высота INB и BNP падает на продолжение основания: у INB высота BC = 2x, у BNP высота BM = 5x.
- Периметр EFP для площадей не нужен: OP находится из площади FOP, без теоремы Пифагора.

*Проверено перебором программой по координатам вершин (CD и AB с шагом 1/4 см, OP с шагом 1/4 см): все данные выполняются только при x = 8, OP = 7; S(MJEPFI) = 1320, S(BEPF) = 936, S(ACDE) = 896, S(BPI) = 928; PF = 25, периметр EFP = 48 + 25 + 25 = 98 сходится; слепая проверка вторым агентом дала те же ответы.*
