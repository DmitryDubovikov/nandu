## Т2′ — национал 2016, день I, №2 — BD ⊥ AC, площадь DFH 525 см²

<!-- отступление от образца: четыре вопроса без меток в оригинале — метки а), б), в), г) в условии, ответ на каждый отдельным абзацем -->

**Условие.** На рисунке:

- BD параллельна AE, AC параллельна FG;
- BD перпендикулярна AC;
- GF = 3EF, AH = 2AF, BG = 4EF;
- площадь ABD = 6 · площадь EFG;
- площадь DFH равна 525 см²;
- площадь DEFG = площадь BCH.

Вопросы:

- а) Чему равен периметр AHGF?
- б) Чему равна площадь ABCD?
- в) Чему равна площадь ABE?
- г) Чему равна площадь ABCDF?

<!-- отступление от образца: рисунок условия встаёт под первой строкой решения, а не под последним вопросом: так он идёт крупно, а не узкой колонкой рядом с условием -->
**Дано:** *«BD параллельна AE», «AC параллельна FG», «BD перпендикулярна AC»* ⇒ AC и FG перпендикулярны обеим прямым BD и AE.

**С чертежа:** D, G, H, B лежат на BD; E, F, A — на AE; A, H, C — на AC.

**Значит:** AHGF — прямоугольник, AH = GF и GH = AF.

<!-- отступление от образца: кирпич не из середин, а из «AH = 2AF»: AF = 1,5 EF, поэтому кирпич — половина EF -->
**Дано:** *«GF = 3EF», «AH = 2AF»* ⇒ AF = AH : 2 = GF : 2 = 1,5 EF.

**Значит:** чтобы EF, AF и GF были целыми кирпичами, берём кирпич x = EF : 2.

Тогда EF = 2x, AF = GH = 3x, AH = GF = 6x.

**Дано:** *«BG = 4EF»* ⇒ BG = 8x и HB = BG − GH = 8x − 3x = 5x.

<!-- отступление от образца: в узлах сетки не все точки — места D и C на прямых BD и AC неизвестны, их дают данные про площади -->
**Значит:** E, F, A, G, H, B стоят в узлах сетки с шагом x, а места D и C на прямых BD и AC пока неизвестны.

**Буквы на рисунке.** EF = 2x, сетка с шагом x.

<!-- отступление от образца: строки артефакта стоят рядом со своими рисунками («Спросили / Заметим» в колонках) — по CHECKLIST, п. 3 (3.11.2026, №15) -->
**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** периметр AHGF.

**Заметим:** AHGF — прямоугольник со сторонами AH = GF = 6x и AF = GH = 3x.
:::col
**б) Спросили:** площадь ABCD.

**Заметим:** диагональ DB режет ABCD на треугольники ABD и CBD с общим основанием DB.

**С чертежа:** AH и HC лежат на AC, а AC ⊥ DB ⇒ высота ABD — AH, высота CBD — HC.
:::

:::cols
**в) Спросили:** площадь ABE.

**Заметим:** сторона AE лежит на прямой AE, а вершина B — на параллельной прямой BD ⇒ высота ABE — расстояние между BD и AE, то есть GF = 6x.

**С чертежа:** AE = EF + FA = 2x + 3x = 5x.
:::col
**г) Спросили:** площадь ABCDF.

<!-- отступление от образца: отрезка DF на чертеже нет — прочтение ABCDF названо строкой «Дано» -->
**Дано:** *«площадь ABCDF»*, а отрезка DF на чертеже нет ⇒ ABCDF — пятиугольник с вершинами A, B, C, D, F по порядку.

**Заметим:** ABCDF не треугольник и не трапеция, готовой формулы нет ⇒ это ABCD плюс треугольник DFA с основанием FA = 3x и высотой GF = 6x.
:::

<!-- отступление от образца: неизвестных три — x, DB и HC; DB находится первым, потому что без него не записать площадь DFH, которая даёт x -->
> ✅ **Значит, осталось найти x, DB и HC.**

<!-- отступление от образца: EFG — не часть ABD, кратность площадей связывает две отдельные фигуры; отрезок DB выходит в x до того, как найден x -->
**1. Найдём DB.**

*«площадь ABD = 6 · площадь EFG»*

> ✅ **S(ABD) = 6 · S(EFG)**

**Площадь ABD.** Основание DB, высота AH = 6x.

<small>AH лежит на AC, а AC ⊥ BD.</small>

S(ABD) = DB · 6x : 2

**Площадь EFG.** Катеты EF = 2x и FG = 6x.

S(EFG) = 2x · 6x : 2

**Подставим площади в уравнение.**

**DB · 6x : 2 = 6 · (2x · 6x : 2)**

```sys
3x · DB = 36x²      | : 3x
DB = 12x
```

<!-- отступление от образца: площадь, дающая x, — один треугольник, а не прямоугольник без углов -->
**2. Найдём x.**

*«площадь DFH равна 525 см²»*

> ✅ **S(DFH) = 525**

**Площадь DFH.** Основание DH, высота FG = 6x.

<small>DH лежит на BD, а F — на AE ⇒ высота DFH — расстояние между BD и AE, то есть FG.</small>

DH = DB − HB = 12x − 5x = 7x

S(DFH) = 7x · 6x : 2

**Подставим площадь в уравнение.**

**7x · 6x : 2 = 525**

```sys
21x² = 525      | : 21
x² = 25
x = 5
```

<!-- отступление от образца: C не в узле сетки — HC = 36x : 5, не целое число кирпичей -->
**3. Найдём HC.**

*«площадь DEFG = площадь BCH»*

> ✅ **S(DEFG) = S(BCH)**

**Площадь DEFG.** Основания DG и EF = 2x, высота FG = 6x.

<small>DG лежит на BD, а EF — на AE, BD ∥ AE ⇒ DEFG — трапеция.</small>

DG = DB − BG = 12x − 8x = 4x

S(DEFG) = (4x + 2x) : 2 · 6x

**Площадь BCH.** Катеты HB = 5x и HC.

<small>BD ⊥ AC ⇒ угол BHC прямой.</small>

S(BCH) = 5x · HC : 2

**Подставим площади в уравнение.**

**(4x + 2x) : 2 · 6x = 5x · HC : 2**

```sys
18x² = 5x · HC : 2      | · 2
36x² = 5x · HC          | : 5x
HC = 36x : 5
```

**4. Сборка: подставим x = 5.**

а) P(AHGF) = 2 · (AH + AF) = 2 · (6x + 3x) = 18x = 18 · 5 = 90

б) S(ABCD) = S(ABD) + S(CBD) = DB · AH : 2 + DB · HC : 2 = 12x · 6x : 2 + 12x · (36x : 5) : 2 = 60 · 30 : 2 + 60 · 36 : 2 = 900 + 1080 = 1980

в) S(ABE) = AE · GF : 2 = 5x · 6x : 2 = 25 · 30 : 2 = 375

г) S(ABCDF) = S(ABCD) + S(DFA) = 1980 + FA · GF : 2 = 1980 + 3x · 6x : 2 = 1980 + 15 · 30 : 2 = 1980 + 225 = 2205

**Ответ на задачу:**

а) периметр AHGF равен **90 см**;

б) площадь ABCD равна **1980 см²**;

в) площадь ABE равна **375 см²**;

г) площадь ABCDF равна **2205 см²**.

**⚠ Ловушки.**

- AH = 2AF, а не AF = 2AH: AH = GF = 3EF, значит AF = 1,5 EF.
- BG = 8x — весь отрезок от G до B через H, поэтому HB = BG − GH = 5x, а DG = DB − BG = 4x.
- HC не равна AH: C не в узле сетки, HC = 36 даёт только «площадь DEFG = площадь BCH».

*Проверено перебором программой по координатам вершин (EF с шагом 1/2 до 100 см, DB с шагом 1/2 до 400 см, HC с шагом 1/10 до 400 см): все данные выполняются только при EF = 10, DB = 60, HC = 36; P(AHGF) = 90, S(ABCD) = 1980, S(ABE) = 375, S(ABCDF) = 2205.*
