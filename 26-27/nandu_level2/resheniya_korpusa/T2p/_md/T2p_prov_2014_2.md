## Т2′ — провинциал 2014, №2 — прямоугольник ABCF и трапеция CDEF, два периметра

<!-- отступление от образца: в оригинале вопросы без меток; метки а)–г) поставлены в условии, ответ на каждый — своим абзацем -->
**Условие.** На рисунке:

- ABCF — прямоугольник, CDEF — трапеция;
- DP — высота трапеции CDEF;
- BC = CD = EF;
- DE = 3/4 AB, DP = 1/6 AB;
- периметр ABCF равен 174 см;
- периметр CDEF равен 156 см.

Вопросы:

- а) Чему равен периметр ABCDEF?
- б) Чему равна площадь ABCF?
- в) Чему равна площадь CDEF?
- г) Чему равна площадь ABCDF?

<!-- отступление от образца: рисунок условия встаёт под первой строкой решения, а не под последним вопросом: так он идёт крупно, а не узкой колонкой рядом с условием -->
**Дано:** *«ABCF — прямоугольник»* ⇒ FC = AB и FA = BC.

**Дано:** *«DE = 3/4 AB», «DP = 1/6 AB»* ⇒ чтобы AB, DE и DP были целыми кирпичами, берём кирпич x = AB : 12.

**В кирпичах:** AB = FC = 12x, DE = 9x, DP = 2x.

<!-- отступление от образца: кроме кирпича x есть вторая неизвестная длина — BC с AB в условии не связана; буква h, как у высоты прямоугольника -->
**Дано:** *«BC = CD = EF»* ⇒ BC = CD = EF = FA.

**Заметим:** BC не дан через AB ⇒ вторая буква h = BC.

**Буквы на рисунке.** x = AB : 12, h = BC = CD = EF = FA.

<!-- отступление от образца: строки артефакта стоят рядом со своими рисунками («Спросили / Заметим» в колонках) — по CHECKLIST, Геометрия п. 3 (3.11.2026, №15) -->

**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** периметр ABCDEF.

**Заметим:** шесть сторон ABCDEF: AB = 12x, DE = 9x и четыре отрезка BC, CD, EF и FA, равные h.
:::col
**б) Спросили:** площадь ABCF.

**Заметим:** ABCF — прямоугольник со сторонами AB = 12x и BC = h.
:::

:::cols
**в) Спросили:** площадь CDEF.

**Заметим:** CDEF — трапеция с основаниями FC = 12x и DE = 9x и высотой DP = 2x.
:::col
**г) Спросили:** площадь ABCDF.

**Дано:** *«площадь ABCDF»* ⇒ в имени нет E: ABCDF — пятиугольник с вершинами A, B, C, D, F и стороной DF.

**Заметим:** ABCDF не прямоугольник и не трапеция, готовой формулы нет ⇒ FC режет ABCDF на прямоугольник ABCF из б) и треугольник FCD.

**Заметим:** *«DP — высота»* ⇒ DP режет FCD на прямоугольные треугольники FPD и DPC с общим катетом DP = 2x.

**Значит:** FP + PC = FC = 12x.
:::

> ✅ **Значит, осталось найти x и h**

**1. Найдём x и h.**

<!-- отступление от образца: две неизвестные длины и два данных периметра — вместо одного уравнения площадей запись системы и механика, как в задачах с несколькими длинами -->

### Часть 1 — запись системы

*«периметр ABCF равен 174 см»* ⇒ стороны AB = FC = 12x и BC = FA = h.

**(1) 2 · (12x + h) = 174**

*«периметр CDEF равен 156 см»* ⇒ стороны CD = h, DE = 9x, EF = h и FC = 12x.

**(2) h + 9x + h + 12x = 156**

### Часть 2 — решение системы

**Система:**

```sys
(1) 2 · (12x + h) = 174       | : 2
(2) h + 9x + h + 12x = 156
```

**Причёсанная система:**

```sys
(1) 12x ⟪+ h⟫ = 87
(2) 21x ⟪+ 2h⟫ = 156
```

**Ходы:**

```sys
⟪2 · (1) − (2)⟫   3x = 18     | : 3
                  x = 6
```

**Система:** x найдено, подставляется в (1).

```sys
(1) 12 · ⟦6⟧ + h = 87
x = 6
```

**Ходы:**

```sys
(1)   h = 87 − 72 = 15
```

**Система решена:**

```sys
x = 6
h = 15
```

**2. Сборка: подставим x = 6 и h = 15.**

а) P(ABCDEF) = AB + BC + CD + DE + EF + FA = 12x + h + h + 9x + h + h = 21x + 4h = 126 + 60 = 186

б) S(ABCF) = AB · BC = 12x · h = 72 · 15 = 1080

в) S(CDEF) = (FC + DE) : 2 · DP = (12x + 9x) : 2 · 2x = 21x² = 756

г) S(ABCDF) = S(ABCF) + S(FPD) + S(DPC) = 12x · h + FP · 2x : 2 + PC · 2x : 2 = 12x · h + (FP + PC) · 2x : 2 = 12x · h + 12x² = 1080 + 432 = 1512

**Ответ на задачу:**

а) периметр ABCDEF равен **186 см**;

б) площадь ABCF равна **1080 см²**;

в) площадь CDEF равна **756 см²**;

г) площадь ABCDF равна **1512 см²**.

**⚠ Ловушки.**

- FC входит в периметр CDEF, но не в периметр ABCDEF: у ABCDEF отрезок FC лежит внутри.
- Высота трапеции — DP = 2x = 12, а не боковая сторона CD = h = 15: CD наклонная.
- FP и PC по отдельности не нужны (и без теоремы Пифагора не находятся): в г) площади FPD и DPC складываются в FC · DP : 2.

*Проверено перебором программой: из всех AB и BC от 0,5 до 200 см с шагом 0,5 см условию (DE = 3/4 AB, DP = 1/6 AB, CD = EF = BC и два периметра по координатам вершин) отвечают только AB = 72, BC = 15; по координатам вершин P(ABCDEF) = 186, S(ABCF) = 1080, S(CDEF) = 756, S(ABCDF) = 1512; слепая проверка вторым агентом дала те же ответы.*
