## Т2′ — регионал 2022, №2 — прямоугольники ABCF и DEGH, равные треугольники CDH и EFG

<!-- отступление от образца: четыре вопроса без меток в оригинале — метки а)–г) поставлены в условии, ответ на каждый отдельным абзацем -->

**Условие.** На рисунке:

- ABCF и DEGH — прямоугольники;
- CDH и EFG — равные треугольники;
- CF = 2GH;
- периметр CDH равен 90 см;
- периметр DEGH равен 132 см;
- периметр CDEG равен 150 см;
- периметр ABCF равен 174 см.

Вопросы:

- а) Чему равен периметр CDEF?
- б) Чему равен периметр ABCDEF?
- в) Чему равна площадь DEFH?
- г) Чему равна площадь BDE?

<!-- отступление от образца: рисунок условия встаёт под первой строкой решения, а не под последним вопросом: так он идёт крупно, а не узкой колонкой рядом с условием -->

**С чертежа:** F, G, H и C лежат на одной прямой.

**Дано:** *«DEGH — прямоугольник»* ⇒ EG = DH, DE = GH, углы при G и H прямые.

**Дано:** *«CDH и EFG — равные треугольники»* и EG = DH ⇒ вторые катеты FG = HC, гипотенузы EF = CD.

**Дано:** *«CF = 2GH»* ⇒ FG + HC = CF − GH = 2GH − GH = GH ⇒ FG = HC = GH : 2.

Чтобы FG, HC, GH и CF были целыми кирпичами, берём кирпич x = FG.

**В кирпичах:** FG = HC = x, GH = DE = 2x, CF = 4x.

**Дано:** *«ABCF — прямоугольник»* ⇒ AB = CF = 4x, BC = AF.

<!-- отступление от образца: сетки нет — высота EG, наклонная CD и сторона AF не кратны x и через x не выражаются; неизвестных четыре: x, h, CD и AF -->

**Буквы на рисунке.** x = FG, h = EG = DH, наклонная CD = EF и AF = BC.

<!-- отступление от образца: строки артефакта стоят рядом со своими рисунками («Спросили / Заметим» в колонках) — по CHECKLIST, п. 3 (3.11.2026, №15) -->

**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** периметр CDEF.

**Заметим:** стороны CDEF — FC = 4x, DE = 2x и две наклонные CD = EF.
:::col
**б) Спросили:** периметр ABCDEF.

**Заметим:** стороны ABCDEF — AB = 4x, DE = 2x, две наклонные CD = EF и две стороны BC = AF прямоугольника ABCF.
:::

<!-- отступление от образца: в строке г) треугольник BDE не прямоугольный — площадь по основанию DE и высоте (S = a · h : 2), а не по двум катетам -->

:::cols
**в) Спросили:** площадь DEFH.

**Заметим:** DE ∥ FH ⇒ DEFH — трапеция с основаниями DE = 2x и FH = FG + GH = 3x и высотой EG = h.
:::col
**г) Спросили:** площадь BDE.

**Заметим:** BDE не прямоугольный ⇒ площадь BDE считаем по основанию DE и высоте от B до прямой ED.

**С чертежа:** высота идёт от B вверх через C и равна BC + DH = AF + h.
:::

> ✅ **Значит, осталось найти x, h, CD и AF**

**1. Найдём x, h, CD и AF.**

<!-- отступление от образца: четыре неизвестные длины и четыре данных периметра — вместо одного уравнения площадей запись системы и механика, как в задачах с несколькими длинами -->

*«периметр CDH равен 90 см»* ⇒ стороны HC = x, DH = h и CD.

**(1) x + h + CD = 90**

*«периметр DEGH равен 132 см»* ⇒ стороны DE = 2x и EG = h.

**(2) 2 · (2x + h) = 132**

*«периметр CDEG равен 150 см»* ⇒ DEGH (132) и CDH (90), склеенные по DH = h, дают CDEG (150).

**(3) 132 + 90 − 2h = 150**

*«периметр ABCF равен 174 см»* ⇒ стороны CF = 4x и AF.

**(4) 2 · (4x + AF) = 174**

**Система:**

```sys
(1) x + h + CD = 90
(2) 2 · (2x + h) = 132       | : 2
(3) 132 + 90 − 2h = 150      | : 2
(4) 2 · (4x + AF) = 174      | : 2
```

**Причёсанная система:**

```sys
(1) x + h + CD = 90
(2) 2x + h = 66
(3) h = 66 + 45 − 75 = 36
(4) 4x + AF = 87
```

**Система:** h найдено, подставляется в (1) и (2).

```sys
(1) x + ⟦36⟧ + CD = 90
(2) 2x + ⟦36⟧ = 66
(4) 4x + AF = 87
h = 36
```

**Ходы:**

```sys
(1)   x + CD = 54
(2)   2x = 30        | : 2
      x = 15
```

**Система:** x найдено, подставляется в (1) и (4).

```sys
(1) ⟦15⟧ + CD = 54
(4) 4 · ⟦15⟧ + AF = 87
h = 36
x = 15
```

**Ходы:**

```sys
(1)   CD = 54 − 15 = 39
(4)   AF = 87 − 60 = 27
```

**Система решена:**

```sys
x = 15
h = 36
CD = 39
AF = 27
```

**2. Сборка: подставим x = 15, h = 36, CD = 39 и AF = 27.**

а) P(CDEF) = CD + DE + EF + FC = CD + 2x + CD + 4x = 39 + 30 + 39 + 60 = 168

б) P(ABCDEF) = AB + BC + CD + DE + EF + FA = 4x + AF + CD + 2x + CD + AF = 60 + 27 + 39 + 30 + 39 + 27 = 222

в) S(DEFH) = (DE + FH) : 2 · EG = (2x + 3x) : 2 · h = 75 : 2 · 36 = 1350

г) S(BDE) = DE · (BC + DH) : 2 = 2x · (AF + h) : 2 = 30 · 63 : 2 = 945

**Ответ на задачу:**

а) периметр CDEF равен **168 см**;

б) периметр ABCDEF равен **222 см**;

в) площадь DEFH равна **1350 см²**;

г) площадь BDE равна **945 см²**.

**⚠ Ловушки.**

- FG = HC = GH : 2, а не FG = GH: «CF = 2GH» значит, что FG и HC вместе равны одному GH.
- CD не нужно искать через теорему Пифагора: CD = 39 даёт периметр CDH (и сходится: 15² + 36² = 39²).
- Высота BDE — BC + DH = AF + h = 63, а не DH = h: B лежит ниже прямой FC ещё на BC.

*Проверено перебором программой: из всех FG, HC и EG от 0,5 до 90 см с шагом 0,5 см (GH — из CF = 2GH, AF — из периметра ABCF) условию — равенство CDH и EFG по сторонам и три периметра по координатам вершин — отвечает только FG = HC = 15, GH = 30, EG = 36, AF = 27; по координатам вершин P(CDEF) = 168, P(ABCDEF) = 222, S(DEFH) = 1350, S(BDE) = 945; слепая проверка вторым агентом дала те же ответы.*
