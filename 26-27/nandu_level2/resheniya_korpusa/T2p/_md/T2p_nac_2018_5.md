## Т2′ — национал 2018, день II, №5 — фигура ADEFG, площадь GMP 1152 см², периметр BCEG 270 см

<!-- отступление от образца: в оригинале вопросы без меток; метки а)–г) поставлены в условии, ответ на каждый — своим абзацем -->
**Условие.** На рисунке:

- GMPS — квадрат;
- BCRM и PRES — прямоугольники;
- треугольники ABG и CDE равны;
- FS перпендикулярна GE;
- площадь BCRM = площадь GPE;
- площадь GMP равна 1152 см²;
- периметр BCEG равен 270 см;
- площадь GEF = 3/4 площади GPE;
- площадь GMRE = 4 · площадь CDE.

Вопросы:

- а) Чему равна площадь GPEF?
- б) Чему равна площадь BDG?
- в) Чему равна площадь AEFG?
- г) Чему равна площадь всей фигуры?

**С чертежа:** точки A, B, C, D лежат на одной прямой.

<!-- отступление от образца: отношения сторон в условии нет — кирпич x даёт квадрат, все четыре стороны которого равны -->
**Дано:** *«GMPS — квадрат»* ⇒ чтобы все стороны квадрата были целыми кирпичами, берём кирпич x = GM.

Тогда GM = MP = PS = SG = x.

**Дано:** *«BCRM и PRES — прямоугольники»* ⇒ BCRM, PRES и квадрат GMPS вместе складываются в прямоугольник BCEG.

**Значит:** противоположные стороны прямоугольников равны ⇒

GE = MR = BC = x + SE

BG = CE = x + BM

<!-- отступление от образца: сетки нет — SE и CD не кратны x (SE = 15, CD = 21 при x = 48); кроме кирпича x остаются три неизвестных отрезка BM, SE, CD, каждый находится своим разделом из одного данного, системы нет -->
**Буквы на рисунке.** GM = MP = PS = SG = x, а BM, SE и CD — неизвестные отрезки.

<!-- отступление от образца: артефакт — колонки «Спросили / Заметим» с рисунком под каждой строкой и рамка «Значит, осталось найти …» (CHECKLIST, Геометрия п. 3, 3.11.2026), а не строки в рамке и отдельные колонки с рисунками -->
**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** площадь GPEF.

**Заметим:** отрезок GE разрезает GPEF на треугольники GPE и GEF.

**Дано:** *«площадь GEF = 3/4 площади GPE»*.

**Заметим:** у GPE основание GE = x + SE, высота PS = x.

<small>PS перпендикулярна GE как сторона квадрата GMPS.</small>
:::col
**б) Спросили:** площадь BDG.

**Заметим:** BDG — прямоугольный треугольник с катетами BD и BG = x + BM.

<small>BG перпендикулярна BC как сторона прямоугольника BCEG, а BC лежит на AD.</small>

BD = BC + CD = x + SE + CD
:::

<!-- отступление от образца: AEFG и всю фигуру не «вычитаем углы», а складываем из двух кусков; у AEG высота из A — расстояние между параллельными AD и GE -->
:::cols
**в) Спросили:** площадь AEFG.

**Заметим:** AEFG не прямоугольник и не трапеция, готовой формулы нет ⇒ разрежем AEFG отрезком GE на треугольники AEG и GEF.

**Заметим:** у AEG основание GE = x + SE, высота из A равна BG = x + BM.

<small>A лежит на AD, а расстояние между параллельными прямыми AD и GE равно BG.</small>

**Дано:** площадь GEF равна 3/4 площади GPE.
:::col
**г) Спросили:** площадь всей фигуры.

**Дано:** *«площадь всей фигуры»* ⇒ площадь пятиугольника ADEFG, обведённого внешним контуром.

**Заметим:** отрезок GE разрезает ADEFG на трапецию ADEG и треугольник GEF.

**Заметим:** у трапеции ADEG основания AD и GE = x + SE, высота BG = x + BM.

<small>Треугольники ABG и CDE равны, а катеты BG и CE равны ⇒ AB = CD.</small>

AD = AB + BC + CD = 2 · CD + x + SE
:::

> ✅ **Значит, осталось найти x, BM, SE и CD.**

**1. Найдём x.**

*«площадь GMP равна 1152 см²»*

**Заметим:** GMP — прямоугольный треугольник с катетами GM = x и MP = x.

> ✅ **S(GMP) = 1152**

S(GMP) = x² : 2

**Подставим площадь в уравнение.**

```sys
x² : 2 = 1152       | · 2
x² = 2304
x = 48
```

**2. Найдём BM.**

*«площадь BCRM = площадь GPE»*

**Заметим:** BCRM — прямоугольник со сторонами MR и BM, а основание GE треугольника GPE равно MR.

> ✅ **S(BCRM) = S(GPE)**

**Площадь BCRM.** Стороны MR = x + SE и BM.

S(BCRM) = (x + SE) · BM

**Площадь GPE.** Основание GE = x + SE, высота PS = x.

S(GPE) = (x + SE) · x : 2

**Подставим площади в уравнение.**

**(x + SE) · BM = (x + SE) · x : 2**

```sys
(x + SE) · BM = (x + SE) · x : 2       | : (x + SE)
BM = x : 2
```

**Подставим x = 48.**

BM = 48 : 2 = 24

**3. Найдём SE.**

*«периметр BCEG равен 270 см»*

**Заметим:** BCEG — прямоугольник со сторонами GE = x + SE и BG = x + BM.

> ✅ **2 · (x + SE) + 2 · (x + BM) = 270**

**Подставим x = 48 и BM = 24 в уравнение.**

```sys
2 · (48 + SE) + 2 · (48 + 24) = 270       | : 2
48 + SE + 72 = 135
SE + 120 = 135       | − 120
SE = 15
```

**4. Найдём CD.**

*«площадь GMRE = 4 · площадь CDE»*

**Заметим:** GMRE — прямоугольник со сторонами GE и GM, а CDE — прямоугольный треугольник с катетами CD и CE.

> ✅ **S(GMRE) = 4 · S(CDE)**

**Площадь GMRE.** Стороны GE = x + SE и GM = x.

S(GMRE) = (x + SE) · x

**Площадь CDE.** Катеты CD и CE = x + BM.

S(CDE) = CD · (x + BM) : 2

**Подставим площади и x = 48, BM = 24, SE = 15 в уравнение.**

**(48 + 15) · 48 = 4 · (CD · (48 + 24) : 2)**

```sys
63 · 48 = 2 · CD · 72
3024 = 144 · CD       | : 144
CD = 21
```

**5. Сборка: подставим x = 48, BM = 24, SE = 15, CD = 21.**

а) S(GPEF) = S(GPE) + S(GPE) · 3/4 = (x + SE) · x : 2 + (x + SE) · x : 2 · 3/4 = 63 · 48 : 2 + 1512 · 3/4 = 1512 + 1134 = 2646

б) S(BDG) = BD · BG : 2 = (x + SE + CD) · (x + BM) : 2 = 84 · 72 : 2 = 3024

в) S(AEFG) = S(AEG) + S(GEF) = (x + SE) · (x + BM) : 2 + S(GPE) · 3/4 = 63 · 72 : 2 + 1134 = 2268 + 1134 = 3402

г) S(ADEFG) = S(ADEG) + S(GEF) = (2 · CD + x + SE + x + SE) : 2 · (x + BM) + S(GPE) · 3/4 = (105 + 63) : 2 · 72 + 1134 = 6048 + 1134 = 7182

**Ответ на задачу:**

а) площадь GPEF равна **2646 см²**;

б) площадь BDG равна **3024 см²**;

в) площадь AEFG равна **3402 см²**;

г) площадь всей фигуры равна **7182 см²**.

**⚠ Ловушки.**

- FS искать не нужно: площадь GEF дана долей площади GPE.
- BC = MR = x + SE, а катет CE треугольника CDE — CR + RE = x + BM, а не одна сторона квадрата x.
- Высота AEG из A — BG = x + BM, а не GM: A лежит на AD, а не на MR.

*Проверено перебором программой по координатам вершин (GM, BM, SE и AB, CD — целые от 1 до 199 см, площади по координатам): все данные выполняются только при x = 48, BM = 24, SE = 15, AB = CD = 21 (FS = 36); S(GPEF) = 2646, S(BDG) = 3024, S(AEFG) = 3402, S(ADEFG) = 7182; слепая проверка вторым агентом дала те же ответы.*
