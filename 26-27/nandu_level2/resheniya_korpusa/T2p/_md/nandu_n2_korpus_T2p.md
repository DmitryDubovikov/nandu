## Т2′ — национал 2026, день I, №2 — квадрат ABCD из четырёх прямоугольников и квадрата IJKL, AELH 48 см², JFCG 133 см²


**Условие.** На рисунке:

- ABCD — квадрат, разрезанный на четыре прямоугольника и квадрат IJKL в середине;
- площадь прямоугольника AELH равна 48 см²;
- площадь прямоугольника JFCG равна 133 см²;
- у прямоугольников AELH и JFCG все стороны — целые числа сантиметров, больше 1;
- AE длиннее AH, CF длиннее GC.

Вопросы:

- а) Чему равна площадь IJKL?
- б) Чему равна площадь ABCD?
- в) Чему равен периметр HKGD?
- г) Единственный ли ответ?


**С чертежа:** E, I, L лежат на одной прямой, G, K, J — тоже.

**С чертежа:** H, L, K лежат на одной прямой, I, J, F — тоже.

**Дано:** *«разрезанный на четыре прямоугольника и квадрат»* ⇒ у каждой части противоположные стороны равны: HL = AE, EL = AH, JF = GC, JG = CF.

**Буквы на рисунке.** x — сторона квадрата IJKL.


**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** площадь IJKL.

**Заметим:** IJKL — квадрат со стороной x.
:::col
**б) Спросили:** площадь ABCD.

**Заметим:** ABCD — квадрат со стороной AB.

**С чертежа:** AB складывается из AE и EB, а EB = IF — из IJ = x и JF = GC.
:::

:::cols
**в) Спросили:** периметр HKGD.

**Заметим:** HKGD — прямоугольник со сторонами HK и HD.

**С чертежа:** HK складывается из HL = AE и LK = x, а HD = KG, то есть JG = CF без JK = x.
:::col
**г) Спросили:** единственный ли ответ.

**Заметим:** у AE и AH, у GC и CF дано только произведение ⇒ пар целых сторон может быть несколько.

**Значит:** ответов столько, сколько подходит наборов AE, AH, GC, CF, x.
:::

> ✅ **Значит, осталось найти все наборы AE, AH, GC, CF и x**

**1. Найдём GC и CF.**

**Дано:** *«площадь JFCG равна 133 см²»*, *«все стороны — целые числа сантиметров, больше 1»* ⇒ GC и CF — целые делители 133, больше 1:

GC · CF = 133

**Заметим:** 133 = 7 · 19, а 7 и 19 — простые ⇒ 133 раскладывается на два множителя только как 1 · 133 и 7 · 19.

**Значит:** стороны больше 1 ⇒ GC и CF равны 7 и 19.

**Дано:** *«CF длиннее GC»* ⇒ CF — больший множитель.

→ **GC = 7, CF = 19**

**2. Найдём все пары AE и AH.**

**Дано:** *«площадь AELH равна 48 см²»*, *«все стороны — целые числа сантиметров, больше 1»* ⇒ AE и AH — целые делители 48, больше 1:

AE · AH = 48

**Дано:** *«AE длиннее AH»* ⇒ AE — больший множитель.

Выпишем все разложения 48 на два множителя больше 1:

48 = 24 · 2 = 16 · 3 = 12 · 4 = 8 · 6

→ **(AE, AH) = (24, 2), (16, 3), (12, 4) или (8, 6)**

**3. Найдём x.**

**Заметим:** x есть в AB и в HD, а из условия ещё не работало только *«ABCD — квадрат»* ⇒ AB = AD.

**Заметим:** AB складывается из AE, IJ = x и JF = GC, а AD — из AH и HD = CF − x.

> ✅ **AE + x + GC = AH + CF − x**

Подставим GC = 7 и CF = 19:

```sys
AE + x + 7 = AH + 19 − x       | + x − AE − 7
```

| AE | AH | AE − AH | 2x = 12 − (AE − AH) | x |

<small>Стороны EBFI и HKGD при этом тоже положительны:</small>

<small>BF = EI = AH − x: 4 − 2 = 2 и 6 − 5 = 1</small>

<small>HD = CF − x: 19 − 2 = 17 и 19 − 5 = 14</small>

**Дано:** *«у прямоугольников AELH и JFCG все стороны … больше 1»* ⇒ про стороны EBFI условие ничего не требует, и BF = 1 допустима.

> ◆ Подходят два набора: AE = 12, AH = 4, x = 2 и AE = 8, AH = 6, x = 5.


**4. Сборка: подставим GC = 7, CF = 19 и каждый набор.**

:::cols
**AE = 12, AH = 4, x = 2**

а) S(IJKL) = x² = 2² = 4

б) S(ABCD) = (AE + x + GC)² = (12 + 2 + 7)² = 21² = 441

в) P(HKGD) = 2 · ((AE + x) + (CF − x)) = 2 · (14 + 17) = 62
:::col
**AE = 8, AH = 6, x = 5**

а) S(IJKL) = x² = 5² = 25

б) S(ABCD) = (AE + x + GC)² = (8 + 5 + 7)² = 20² = 400

в) P(HKGD) = 2 · ((AE + x) + (CF − x)) = 2 · (13 + 14) = 54
:::

**Ответ на задачу:**

б) площадь ABCD равна **441 см²** или **400 см²** соответственно;

в) периметр HKGD равен **62 см** или **54 см** соответственно;

## Т2′ — национал 2025, день I, №2 — прямоугольник ABDG, периметр AMNH 112 см, площадь FOP 84 см²

**Условие.** На рисунке:

- CDEJ и FGHI — равные квадраты;
- ABCH и CDGH — равные прямоугольники;
- M — середина AB;
- PM перпендикулярна AB;
- периметр IJEF = 2 · периметр CDEJ;
- периметр AMNH равен 112 см;
- периметр EFP равен 98 см;
- площадь FOP равна 84 см².

Вопросы:

- а) Чему равна площадь MJEPFI?
- б) Чему равна площадь BEPF?
- в) Чему равна площадь ACDE?
- г) Чему равна площадь BPI?

**Дано:** *«ABCH и CDGH — равные прямоугольники»* ⇒ BC = CD, а AB = HC = GD.

**Дано:** *«CDEJ и FGHI — равные квадраты»* ⇒ CD = DE = EJ = JC = GF = FI = IH = HG.

**С чертежа:** IJEF — прямоугольник со сторонами FI = JE = CD.

**Дано:** *«периметр IJEF = 2 · периметр CDEJ»* ⇒

2 · (IJ + CD) = 2 · 4 · CD ⇒ IJ = 3 · CD

**Значит:** HC = HI + IJ + JC = CD + 3 · CD + CD = 5 · CD.

**Дано:** *«M — середина AB»* ⇒ AM = MB = HC : 2 = 5 · CD : 2.

**Значит:** чтобы CD, AM и MB были целыми кирпичами, берём маленький кирпич x = CD : 2.

**В кирпичах:** CD = BC = AH = HG = GF = HI = DE = JC = 2x, IJ = FE = 6x, AB = HC = GD = 10x, AM = MB = 5x.

**С чертежа:** N и O лежат на PM.

**Дано:** *«PM перпендикулярна AB»*, а M — середина AB ⇒ N и O — середины HC и GD.

**С чертежа:** IN = NJ = FO = OE = 5x − 2x = 3x, GE = 10x − 2x = 8x, BD = AG = 4x.

**Значит:** все точки, кроме P, стоят в узлах сетки с шагом x.

**Значит:** P стоит над O на неизвестной высоте OP.

**Буквы на рисунке.** CD = 2x, AB = 10x, сетка с шагом x.

**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** площадь MJEPFI.

**Заметим:** MJEPFI не прямоугольник и не трапеция, готовой формулы нет ⇒ MJEPFI складывается из прямоугольника IJEF и треугольников FPE и IMJ.

**Заметим:** FPE — два одинаковых прямоугольных треугольника FOP и EOP, площадь FOP дана.

<small>IMJ: основание IJ, высота MN.</small>
:::col
**б) Спросили:** площадь BEPF.

**Заметим:** BEPF не прямоугольник и не трапеция ⇒ отрезок FE разрезает BEPF на треугольники FPE и FEB.

<small>FEB: основание FE, высота BD.</small>
:::

:::cols
**в) Спросили:** площадь ACDE.

**Заметим:** ACDE не прямоугольник и не трапеция ⇒ ACDE — это прямоугольник ABDG без прямоугольных треугольников ABC и AGE.
:::col
**г) Спросили:** площадь BPI.

**Заметим:** N лежит внутри BPI ⇒ отрезки NP, NI и NB разрезают BPI на треугольники PIN, INB и BNP.

<small>I и N на одной прямой HC, а IB идёт от I вниз к B ⇒ N выше IB.</small>

<small>PIN: катеты IN и NP = NO + OP = 2x + OP.</small>

<small>INB: основание IN, высота BC.</small>

<small>BNP: основание NP, высота BM.</small>
:::

> ✅ **Значит, осталось найти x и OP.**

**1. Найдём x.**

*«периметр AMNH равен 112 см»*

**Заметим:** AMNH — прямоугольник со сторонами AM = 5x и AH = 2x.

> ✅ **2 · (5x + 2x) = 112**

```sys
14x = 112       | : 14
x = 8
```

**2. Найдём OP.**

*«площадь FOP равна 84 см²»*

**Заметим:** FOP — прямоугольный треугольник с катетами FO = 3x и OP.

<small>PM перпендикулярна AB, а GD параллельна AB ⇒ PO перпендикулярна FE.</small>

**Ответ на задачу:**

- AB = 5AD;
- площадь треугольника ABM равна 405 см²;
- площадь треугольника AND равна 135 см².

Вопросы:

- а) Чему равна AB?
- б) Чему равна DN?
- в) Чему равна площадь треугольника AMN?

**Дано:** *«AB = 5AD», «M — середина стороны BC»* ⇒ чтобы стороны AD, AB и половины BM, MC были целыми кирпичами, берём кирпич x = BC : 2.

Тогда BM = MC = x, AD = BC = 2x, AB = DC = 5 · 2x = 10x.

Все точки, кроме N, стоят в узлах сетки с шагом x.

**Буквы на рисунке.** AD = 2x, AB = 10x, сетка с шагом x.

**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** длина AB.

**Заметим:** вся сторона AB идёт по сетке.
:::col
**б) Спросили:** длина DN.

**Заметим:** DN — катет прямоугольного треугольника AND, второй катет AD идёт по сетке, а площадь AND дана.
:::

**в) Спросили:** площадь AMN.

**Заметим:** у треугольника AMN ни одна сторона не идёт по сетке, основание и высоту с сетки не взять ⇒ AMN — это прямоугольник ABCD без трёх прямоугольных треугольников ABM, MCN и AND.

> ✅ **Значит, осталось найти x и DN.**

**1. Найдём x.**

*«площадь треугольника ABM равна 405 см²»*

**Заметим:** ABM — прямоугольный треугольник с катетами AB = 10x и BM = x.

> ✅ **10x · x : 2 = 405**

```sys
10x² : 2 = 405
5x² = 405      | : 5
x² = 81
x = 9
```

**2. Найдём DN.**

*«площадь треугольника AND равна 135 см²»*

**Заметим:** AND — прямоугольный треугольник с катетами AD = 2x и DN.

> ✅ **2x · DN : 2 = 135**

**Подставим x = 9 в уравнение.**

```sys
18 · DN : 2 = 135
9 · DN = 135      | : 9
DN = 15
```

**3. Сборка: подставим x = 9 и DN = 15.**

а) AB = 10x = 10 · 9 = 90

б) DN = 15

в) S(AMN) = S(ABCD) − S(ABM) − S(MCN) − S(AND) = 10x · 2x − 405 − x · (10x − DN) : 2 − 135 = 1620 − 405 − 9 · 75 : 2 − 135 = 1620 − 405 − 337,5 − 135 = 742,5

**Ответ на задачу:**

а) AB = **90 см**;

б) DN = **15 см**;

в) площадь AMN равна **742,5 см²**.

**⚠ Ловушки.**

- BM — половина BC, а BC = AD: катеты ABM равны 10x и x, а не 10x и 2x.
- Катет MCN на стороне DC равен NC = DC − DN = 90 − 15 = 75, а не DN = 15.
- Площадь AMN нецелая, и это не ошибка в счёте: S(MCN) = 9 · 75 : 2 = 337,5.

*Проверено перебором программой по координатам вершин (AD от 0,5 до 200 см с шагом 0,5 см, AB = 5AD; DN от 0 до AB с шагом 0,25 см): все данные выполняются только при AD = 18, AB = 90, DN = 15; S(AMN) = 742,5; слепая проверка вторым агентом дала те же ответы.*
## Т2′ — провинциал 2014, №2 — прямоугольник ABCF и трапеция CDEF, два периметра

**Условие.** На рисунке:

- ABCF — прямоугольник, CDEF — трапеция;
- DP — высота трапеции CDEF;
- BC = CD = EF;
- DE = 3/4 AB, DP = 1/6 AB;
- периметр ABCF равен 174 см;
- периметр CDEF равен 156 см.

Вопросы:

- а) Чему равен периметр ABCDEF?
- б) Чему равна площадь ABCF?
- в) Чему равна площадь CDEF?
- г) Чему равна площадь ABCDF?

**Дано:** *«ABCF — прямоугольник»* ⇒ FC = AB и FA = BC.

**Дано:** *«DE = 3/4 AB», «DP = 1/6 AB»* ⇒ чтобы AB, DE и DP были целыми кирпичами, берём кирпич x = AB : 12.

**В кирпичах:** AB = FC = 12x, DE = 9x, DP = 2x.

**Дано:** *«BC = CD = EF»* ⇒ BC = CD = EF = FA.

**Заметим:** BC не дан через AB ⇒ вторая буква h = BC.

**Буквы на рисунке.** x = AB : 12, h = BC = CD = EF = FA.


**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** периметр ABCDEF.

**Заметим:** шесть сторон ABCDEF: AB = 12x, DE = 9x и четыре отрезка BC, CD, EF и FA, равные h.
:::col
**б) Спросили:** площадь ABCF.

**Заметим:** ABCF — прямоугольник со сторонами AB = 12x и BC = h.
:::

:::cols
**в) Спросили:** площадь CDEF.

**Заметим:** CDEF — трапеция с основаниями FC = 12x и DE = 9x и высотой DP = 2x.
:::col
**г) Спросили:** площадь ABCDF.

**Дано:** *«площадь ABCDF»* ⇒ в имени нет E: ABCDF — пятиугольник с вершинами A, B, C, D, F и стороной DF.

**Заметим:** ABCDF не прямоугольник и не трапеция, готовой формулы нет ⇒ FC режет ABCDF на прямоугольник ABCF из б) и треугольник FCD.

**Заметим:** *«DP — высота»* ⇒ DP режет FCD на прямоугольные треугольники FPD и DPC с общим катетом DP = 2x.

**Значит:** FP + PC = FC = 12x.
:::

> ✅ **Значит, осталось найти x и h**

**1. Найдём x и h.**


### Часть 1 — запись системы

*«периметр ABCF равен 174 см»* ⇒ стороны AB = FC = 12x и BC = FA = h.

**(1) 2 · (12x + h) = 174**

*«периметр CDEF равен 156 см»* ⇒ стороны CD = h, DE = 9x, EF = h и FC = 12x.

**(2) h + 9x + h + 12x = 156**

### Часть 2 — решение системы

**Система:**

```sys
(1) 2 · (12x + h) = 174       | : 2
(2) h + 9x + h + 12x = 156
```

**Причёсанная система:**

```sys
(1) 12x ⟪+ h⟫ = 87
(2) 21x ⟪+ 2h⟫ = 156
```

**Ходы:**

```sys
⟪2 · (1) − (2)⟫   3x = 18     | : 3
                  x = 6
```

**Система:** x найдено, подставляется в (1).

```sys
(1) 12 · ⟦6⟧ + h = 87
x = 6
```

**Ходы:**

```sys
(1)   h = 87 − 72 = 15
```

**Система решена:**

```sys
x = 6
h = 15
```

**2. Сборка: подставим x = 6 и h = 15.**

а) P(ABCDEF) = AB + BC + CD + DE + EF + FA = 12x + h + h + 9x + h + h = 21x + 4h = 126 + 60 = 186

б) S(ABCF) = AB · BC = 12x · h = 72 · 15 = 1080

в) S(CDEF) = (FC + DE) : 2 · DP = (12x + 9x) : 2 · 2x = 21x² = 756

г) S(ABCDF) = S(ABCF) + S(FPD) + S(DPC) = 12x · h + FP · 2x : 2 + PC · 2x : 2 = 12x · h + (FP + PC) · 2x : 2 = 12x · h + 12x² = 1080 + 432 = 1512

**Ответ на задачу:**

а) периметр ABCDEF равен **186 см**;

б) площадь ABCF равна **1080 см²**;

в) площадь CDEF равна **756 см²**;

г) площадь ABCDF равна **1512 см²**.

**⚠ Ловушки.**

- FC входит в периметр CDEF, но не в периметр ABCDEF: у ABCDEF отрезок FC лежит внутри.
- Высота трапеции — DP = 2x = 12, а не боковая сторона CD = h = 15: CD наклонная.
- FP и PC по отдельности не нужны (и без теоремы Пифагора не находятся): в г) площади FPD и DPC складываются в FC · DP : 2.

*Проверено перебором программой: из всех AB и BC от 0,5 до 200 см с шагом 0,5 см условию (DE = 3/4 AB, DP = 1/6 AB, CD = EF = BC и два периметра по координатам вершин) отвечают только AB = 72, BC = 15; по координатам вершин P(ABCDEF) = 186, S(ABCF) = 1080, S(CDEF) = 756, S(ABCDF) = 1512; слепая проверка вторым агентом дала те же ответы.*
