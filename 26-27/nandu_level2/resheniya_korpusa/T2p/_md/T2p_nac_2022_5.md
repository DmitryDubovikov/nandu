## Т2′ — национал 2022, день II, №5 — трапеция ADEF, периметр ADEF 270 см, площадь BEF 540 см²

<!-- отступление от образца: в оригинале вопросы без меток; метки а)–г) поставлены в условии, ответ на каждый — своим абзацем -->
**Условие.** На рисунке:

- AD параллельна EF;
- BCEF — прямоугольник;
- AD = AF;
- AD = 6EF;
- AF = DE + EF;
- треугольники ABF и AGF равны;
- периметр ADEF равен 270 см;
- площадь BEF равна 540 см²;
- периметр CDE равен 168 см.

Вопросы:

- а) Чему равен периметр ACEF?
- б) Чему равна площадь CDEF?
- в) Чему равна площадь ADEFG?
- г) Чему равна площадь ABE?

**С чертежа:** точки A, B, C, D лежат на одной прямой AD.

**Дано:** *«AD = 6EF»* ⇒ чтобы AD и EF были целыми кирпичами, берём кирпич x = EF.

Тогда AD = 6x.

**Дано:** *«AD = AF»* ⇒ AF = 6x.

**Дано:** *«AF = DE + EF»* ⇒

DE = AF − EF = 6x − x = 5x

**Дано:** *«BCEF — прямоугольник»* ⇒ BC = EF = x и CE = FB.

<!-- отступление от образца: сетки нет — FB и CD не кратны x (FB = 72, CD = 21 при x = 15); кроме кирпича x остаются две неизвестные длины FB и CD, каждая находится своим разделом из одного данного, системы нет -->
**Буквы на рисунке.** EF = BC = x, AD = AF = 6x, DE = 5x; FB и CD — неизвестные отрезки.

<!-- отступление от образца: артефакт — колонки «Спросили / Заметим» с рисунком под каждой строкой и рамка «Значит, осталось найти …» (CHECKLIST, Геометрия п. 3, 3.11.2026), а не строки в рамке и отдельные колонки с рисунками -->
**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** периметр ACEF.

**Заметим:** стороны ACEF — это AC, CE = FB, EF = x и FA = 6x.

**Заметим:** AC — это AD без CD.

AC = 6x − CD
:::col
**б) Спросили:** площадь CDEF.

**Заметим:** отрезок CF разрезает CDEF на прямоугольный треугольник CDE и треугольник CEF.

<small>CE перпендикулярна BC, а BC лежит на AD ⇒ угол DCE прямой.</small>

**Заметим:** CEF и BEF — две половины прямоугольника BCEF, площадь BEF дана.
:::

<!-- отступление от образца: треугольник ABE не прямоугольный — его площадь «основание · высота : 2», высота EC падает на продолжение основания AB (так же решено в нац 2025 I №2) -->
:::cols
**в) Спросили:** площадь ADEFG.

**Заметим:** ADEFG не прямоугольник и не трапеция, готовой формулы нет ⇒ ADEFG — это трапеция ADEF и треугольник AGF.

<small>С чертежа: G лежит вне трапеции ADEF, по другую сторону AF.</small>

**Заметим:** у трапеции ADEF основания AD = 6x и EF = x, высота FB.

<small>FB перпендикулярна BC, а BC лежит на AD.</small>

**Дано:** *«треугольники ABF и AGF равны»* ⇒ S(AGF) = S(ABF), какие бы вершины ни соответствовали друг другу.

**Заметим:** ABF — прямоугольный треугольник с катетами AB и FB.

AB = AD − BC − CD = 5x − CD
:::col
**г) Спросили:** площадь ABE.

**Заметим:** ABE — треугольник с основанием AB, высота ABE из E — отрезок EC.

<small>EC перпендикулярна прямой AD и падает на продолжение AB за точку B.</small>

AB = 5x − CD
:::

> ✅ **Значит, осталось найти x, FB и CD.**

**1. Найдём x.**

*«периметр ADEF равен 270 см»*

**Заметим:** стороны ADEF — это AD, DE, EF и FA.

> ✅ **AD + DE + EF + FA = 270**

**Подставим AD = 6x, DE = 5x, EF = x и FA = 6x в уравнение.**

```sys
6x + 5x + x + 6x = 270
18x = 270       | : 18
x = 15
```

**2. Найдём FB.**

*«площадь BEF равна 540 см²»*

**Заметим:** BEF — прямоугольный треугольник с катетами EF и FB.

> ✅ **EF · FB : 2 = 540**

**Подставим EF = x = 15 в уравнение.**

```sys
15 · FB : 2 = 540     | · 2
15 · FB = 1080        | : 15
FB = 72
```

**3. Найдём CD.**

*«периметр CDE равен 168 см»*

**Заметим:** стороны CDE — это CD, DE и EC.

> ✅ **CD + DE + EC = 168**

**Подставим DE = 5x = 75 и EC = FB = 72 в уравнение.**

```sys
CD + 75 + 72 = 168
CD + 147 = 168     | − 147
CD = 21
```

**4. Сборка: подставим x = 15, FB = 72, CD = 21 и S(BEF) = 540.**

а) P(ACEF) = AC + CE + EF + FA = (6x − CD) + FB + x + 6x = 69 + 72 + 15 + 90 = 246

б) S(CDEF) = S(CDE) + S(CEF) = CD · FB : 2 + 540 = 756 + 540 = 1296

в) S(ADEFG) = S(ADEF) + S(AGF) = (6x + x) : 2 · FB + (5x − CD) · FB : 2 = 3780 + 1944 = 5724

г) S(ABE) = AB · EC : 2 = (5x − CD) · FB : 2 = 54 · 72 : 2 = 1944

**Ответ на задачу:**

а) периметр ACEF равен **246 см**;

б) площадь CDEF равна **1296 см²**;

в) площадь ADEFG равна **5724 см²**;

г) площадь ABE равна **1944 см²**.

**⚠ Ловушки.**

- AB не нужно искать через теорему Пифагора из AF и FB: AB = AD − BC − CD = 5x − CD.
- В AC входит и BC: AC = AD − CD = 69, а не AB = 54.
- Высота ABE из E — EC = FB, она падает на продолжение AB, а не на сам отрезок AB.

*Проверено перебором программой по координатам вершин (EF, FB и CD с шагом 1/2 см): все данные выполняются только при x = 15, FB = 72, CD = 21; P(ACEF) = 246, S(CDEF) = 1296, S(ADEFG) = 5724, S(ABE) = 1944; наклонные сходятся с теоремой Пифагора: AF = 90 (тройка 54-72-90), DE = 75 (тройка 21-72-75); слепая проверка вторым агентом дала те же ответы.*
