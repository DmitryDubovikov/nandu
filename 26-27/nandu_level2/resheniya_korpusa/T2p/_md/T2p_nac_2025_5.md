## Т2′ — национал 2025, день II, №5 — равные прямоугольники крест-накрест, площадь KMN 100 см²

<!-- отступление от образца: в оригинале вопросы без меток; метки а)–г) поставлены в условии, ответ на каждый — своим абзацем -->
**Условие.** На рисунке:

- ABCD и EFGH — равные прямоугольники;
- IJKL — квадрат;
- M — середина HG, N — середина AD;
- HI = ID = ML = NJ;
- AJ = 2/3 AB;
- площадь KMN равна 100 см².

Вопросы:

- а) Чему равна площадь IJKL?
- б) Чему равен периметр ABCD?
- в) Чему равна площадь HNKG?
- г) Чему равна площадь AMLF?

<!-- отступление от образца: кирпич даёт не отношение сторон, а доля AJ = 2/3 AB; равные отрезки HI = ID = ML = NJ выражаются через x цепочкой через середину N, а не сразу -->
**С чертежа:** I и J лежат на AD, K и L — на BC, J и K — на EF, I и L — на HG.

**Дано:** *«IJKL — квадрат»* ⇒ AB = JK = IJ.

**Дано:** *«AJ = 2/3 AB»* ⇒ чтобы AB и AJ были целыми кирпичами, берём кирпич x = AB : 3.

**В кирпичах:** AB = JK = IJ = 3x, AJ = 2x.

**Дано:** *«ID = NJ»* ⇒ ND складывается из NI и ID, то есть из NI и NJ:

ND = NI + NJ = IJ = 3x

**Дано:** *«N — середина AD»* ⇒ AN = ND = 3x:

NJ = AN − AJ = 3x − 2x = x

**Дано:** *«HI = ID = ML = NJ»* ⇒ HI = ID = ML = NJ = x.

NI = ND − ID = 3x − x = 2x

AD = AN + ND = 3x + 3x = 6x

**Дано:** *«ABCD и EFGH — равные прямоугольники»* ⇒ HG = AD = 6x, HE = AB = 3x.

**Дано:** *«M — середина HG»* ⇒ HM = MG = 3x:

IM = HM − HI = 3x − x = 2x

LG = MG − ML = 3x − x = 2x

**Значит:** все точки стоят в узлах сетки с шагом x.

**Буквы на рисунке.** AB = 3x, AD = HG = 6x, сетка с шагом x.

<!-- отступление от образца: артефакт — колонки «Спросили / Заметим» с рисунком под каждой строкой и рамка «Значит, осталось найти …» (CHECKLIST, Геометрия п. 3, 3.11.2026), а не строки в рамке и отдельные колонки с рисунками; вопросов четыре — два блока колонок -->
**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** площадь IJKL.

**Заметим:** IJKL — квадрат со стороной JK = 3x.
:::col
**б) Спросили:** периметр ABCD.

**Заметим:** ABCD — прямоугольник со сторонами AB = 3x и AD = 6x.
:::

<!-- отступление от образца: HNKG — сумма кусков, на которые её режут отрезки IN и LK чертежа, а не одна большая фигура без углов: у EFGH без углов один из углов — трапеция HEJN, кусков больше -->
<!-- 🆕 приём вне реестра: достроить до прямоугольника — продолжить AB и GF до новой точки P, чтобы AMLF стала прямоугольником AIGP без трёх прямоугольных углов; на чертеже такого прямоугольника нет -->
:::cols
**в) Спросили:** площадь HNKG.

**Заметим:** HNKG не прямоугольник и не трапеция, готовой формулы нет ⇒ отрезки IN и LK режут HNKG на прямоугольные треугольники HIN, LKG и четырёхугольник INKL.

**Заметим:** INKL — квадрат IJKL без прямоугольного треугольника KJN.
:::col
**г) Спросили:** площадь AMLF.

**Заметим:** AMLF не прямоугольник и не трапеция, готовой формулы нет ⇒ продолжим AB и GF до встречи в точке P.

**В кирпичах:** AI = AJ + JI = 5x, IG = IL + LG = 5x, GF = HE = 3x, FP = AJ = 2x, PA = IG = 5x.

**Заметим:** AMLF — прямоугольник AIGP без прямоугольных треугольников AIM, LGF и FPA.
:::

> ✅ **Значит, осталось найти x.**

<!-- отступление от образца: раздел-операнд один — вторую неизвестную (CF у образца) здесь искать не нужно, все отрезки идут по сетке -->
**1. Найдём x.**

*«площадь KMN равна 100 см²»*

<!-- отступление от образца: KMN — квадрат без трёх прямоугольных треугольников, а не прямоугольник без двух -->
Заметим, что KMN — это квадрат IJKL без трёх прямоугольных треугольников NIM, MLK и KJN.

> ✅ **S(IJKL) − S(NIM) − S(MLK) − S(KJN) = 100**

**Площадь IJKL.** Сторона JK = 3x.

S(IJKL) = 3x · 3x

**Площадь NIM.** Катеты NI = 2x и IM = 2x.

S(NIM) = 2x · 2x : 2

**Площадь MLK.** Катеты ML = x и LK = 3x.

S(MLK) = x · 3x : 2

**Площадь KJN.** Катеты KJ = 3x и JN = x.

S(KJN) = 3x · x : 2

**Подставим площади в уравнение.**

**3x · 3x − 2x · 2x : 2 − x · 3x : 2 − 3x · x : 2 = 100**

```sys
9x² − 2x² − 1,5x² − 1,5x² = 100
4x² = 100       | : 4
x² = 25
x = 5
```

**2. Сборка: подставим x = 5.**

а) S(IJKL) = 3x · 3x = 9x² = 9 · 25 = 225

б) P(ABCD) = 2 · (AB + AD) = 2 · (3x + 6x) = 18x = 18 · 5 = 90

в) S(HNKG) = S(HIN) + S(IJKL) − S(KJN) + S(LKG) = x · 2x : 2 + 3x · 3x − 3x · x : 2 + 3x · 2x : 2 = 11,5x² = 11,5 · 25 = 287,5

г) S(AMLF) = S(AIGP) − S(AIM) − S(LGF) − S(FPA) = 5x · 5x − 5x · 2x : 2 − 2x · 3x : 2 − 2x · 5x : 2 = 12x² = 12 · 25 = 300

**Ответ на задачу:**

а) площадь IJKL равна **225 см²**;

б) периметр ABCD равен **90 см**;

в) площадь HNKG равна **287,5 см²**;

г) площадь AMLF равна **300 см²**.

**⚠ Ловушки.**

- У KMN нет прямого угла: площадь KMN не «катет · катет : 2», а квадрат IJKL без трёх прямоугольных треугольников.
- ND = IJ = 3x, потому что ID = NJ: отрезок ND — это NI и NJ, сложенные вместе.
- LG = 2x, а не x: M — середина всего HG, а не стороны IL квадрата.

*Проверено перебором программой: сторона квадрата и HI перебраны с шагом 0,05 см до 50 см; все условия и площадь KMN = 100 выполнены только при стороне 15 и HI = 5 (x = 5); по координатам вершин S(IJKL) = 225, P(ABCD) = 90, S(HNKG) = 287,5, S(AMLF) = 300; слепая проверка вторым агентом дала те же ответы.*
