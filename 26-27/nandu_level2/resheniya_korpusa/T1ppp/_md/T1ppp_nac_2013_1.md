## Т1‴ — национал 2013, день I, №1 — коробки с фишками для Дани, Матиаса и Пабло

<!-- отступление от образца: в условии четыре вопроса — метки а)–г) поставлены в условии, ответ на каждый — отдельным абзацем -->
**Условие.** У Хуана 13 коробок, в них 266 фишек для подарков:

- в коробках 9, 13, 15, 16, 18, 19, 21, 22, 23, 24, 25, 28 и 33 фишки;
- одну коробку Хуан дарит Дани, несколько коробок — Матиасу, остальные коробки — Пабло;
- Пабло получает вдвое больше фишек, чем Матиас.

Вопросы:

- а) Сколько фишек Хуан дарит Дани?
- б) Сколько фишек Хуан дарит Матиасу?
- в) Сколько фишек Хуан дарит Пабло?
- г) Какое наименьшее число коробок мог получить Пабло? Покажи способ.

N_{Дани}, N_{Матиаса}, N_{Пабло} — сколько фишек получили Дани, Матиас и Пабло.

**Идея.** *«Пабло получает вдвое больше фишек, чем Матиас»* ⇒ Матиас и Пабло вместе получают втрое больше, чем Матиас ⇒ сведём *«266 фишек»* и «вдвое» в одно уравнение. *«Одну коробку Хуан дарит Дани»* ⇒ у N_{Дани} всего тринадцать возможных значений ⇒ начнём с N_{Дани}.

**Уравнение.**

<!-- отступление от образца: нет врезки «сколько сверх 2» — фишки в коробках не соседние числа, уравнение записывается прямо из данных -->
**Дано:** *«13 коробок, в них 266 фишек»* и коробки делятся между Дани, Матиасом и Пабло ⇒

N_{Дани} + N_{Матиаса} + N_{Пабло} = 266

**Дано:** *«Пабло получает вдвое больше фишек, чем Матиас»* ⇒

N_{Пабло} = 2 · N_{Матиаса}

Подставим N_{Пабло} в уравнение:

```sys
N_{Дани} + N_{Матиаса} + (2 · N_{Матиаса}) = 266   | приведём подобные
```

> ◆ N_{Дани} + 3 · N_{Матиаса} = 266      (*)

<!-- отступление от образца: нет этапа «Наименьшие значения» — в условии нет фильтров «хотя бы один», «кратно», «чётное»; значения N_{Дани} задаёт список коробок -->
**Все возможные значения N_{Дани}: одна коробка, потом делимость на 3.**

**Дано:** *«одну коробку Хуан дарит Дани»* ⇒ N_{Дани} — одно из тринадцати чисел 9, 13, 15, …, 33.

Выразим из (*) 3 · N_{Матиаса}:

```sys
N_{Дани} + 3 · N_{Матиаса} = 266   | − N_{Дани}
3 · N_{Матиаса} = 266 − N_{Дани}
```

<!-- отступление от образца: значения N_{Дани} отсекает делимость на 3 (как «3 · S делится на 3» у общей клетки), а не граница сверху из уравнения; таблица стоит столбцами: 13 значений не помещаются в строку -->
**Заметим:** 3 · N_{Матиаса} делится на 3 ⇒ 266 − N_{Дани} тоже делится на 3:

| N_{Дани} | 266 − N_{Дани} | делится на 3 |
|:-:|:-:|:-:|
| 9 | 257 | |
| 13 | 253 | |
| 15 | 251 | |
| 16 | 250 | |
| 18 | 248 | |
| 19 | 247 | |
| 21 | 245 | |
| 22 | 244 | |
| 23 | 243 | ✓ |
| 24 | 242 | |
| 25 | 241 | |
| 28 | 238 | |
| 33 | 233 | |

> ◆ N_{Дани} = 23

<!-- отступление от образца: у N_{Дани} одно значение, поэтому миров нет — разделы идут по вопросам б), в), г) -->
**У N_{Дани} одно значение ⇒ миров нет.**

Ответы на б) и в) находим из (*).

<!-- 🆕 приём вне реестра: оценка плюс пример — наименьшее число коробок доказывается оценкой «меньше нельзя» и раздачей, на которой оно достигается -->

**Заметим:** г) — наименьшее число коробок Пабло ⇒ нужны оценка «меньше нельзя» и раздача, где у Пабло ровно столько коробок.

> ✅ а) N_{Дани} = 23
>
> б) N_{Матиаса} — из (*) при N_{Дани} = 23
>
> в) N_{Пабло} = 2 · N_{Матиаса}
>
> г) наименьшее число коробок Пабло — оценка снизу и раздача, где у Пабло ровно столько коробок

**1. б) Найдём N_{Матиаса}.**

Подставим N_{Дани} = 23 в (*):

```sys
23 + 3 · N_{Матиаса} = 266   | − 23
3 · N_{Матиаса} = 243        | : 3
```

> ◆ N_{Матиаса} = 81

**2. в) Найдём N_{Пабло}.**

N_{Пабло} = 2 · N_{Матиаса} = 2 · 81 = 162

**3. г) Найдём наименьшее число коробок Пабло: оценка, потом раздача.**

**Обозначим:** x — сколько коробок получил Пабло.

**Значит:** коробка с 23 фишками у Дани ⇒ коробки Пабло — из остальных двенадцати:

9, 13, 15, 16, 18, 19, 21, 22, 24, 25, 28, 33

**Оценка снизу.**

**Заметим:** чем больше коробки, тем меньше коробок нужно для 162 фишек ⇒ возьмём шесть самых больших коробок из двенадцати:

S_{шести} = 33 + 28 + 25 + 24 + 22 + 21 = 153

**Значит:** любые шесть коробок или меньше дают не больше 153 фишек, а 153 < 162 ⇒ шести коробок Пабло не хватит.

> ◆ x ≥ 7

**Раздача с x = 7.**

Шести самых больших коробок не хватает до 162:

N_{недостающих} = 162 − 153 = 9

**Заметим:** коробка с 9 фишками есть и не входит в шесть самых больших ⇒ седьмая коробка Пабло — коробка с 9 фишками:

N_{Пабло} = 33 + 28 + 25 + 24 + 22 + 21 + 9 = 162 ✓

Матиасу — остальные пять коробок:

N_{Матиаса} = 13 + 15 + 16 + 18 + 19 = 81 ✓

**Дано:** *«несколько коробок — Матиасу»* ⇒ у Матиаса больше одной коробки ✓

> ◆ x_{наим} = 7

**Сборка.**

а) N_{Дани} = 23

б) N_{Матиаса} = (266 − 23) : 3 = 81

в) N_{Пабло} = 2 · N_{Матиаса} = 2 · 81 = 162

г) x ≥ 7 и раздача с x = 7 есть ⇒ x_{наим} = 7

**Ответ на задачу:**

а) Хуан дарит Дани 23 фишки;

б) Хуан дарит Матиасу 81 фишку;

в) Хуан дарит Пабло 162 фишки;

г) наименьшее число коробок у Пабло — семь, например: Пабло получает коробки с 9, 21, 22, 24, 25, 28 и 33 фишками, Матиас — с 13, 15, 16, 18 и 19 фишками, Дани — с 23 фишками.

**⚠ Ловушки.**

- Делить 266 на 3, забыв про Дани: 266 на 3 не делится, и кажется, что раздачи нет.
- Взять в коробки Пабло коробку с 23 фишками: она у Дани.
- Ответить в г) только раздачей с семью коробками или только оценкой «не меньше семи»: нужны и оценка, и раздача: оценка показывает, что шести коробок не хватит, раздача — что семи хватает.

*Проверено перебором программой всех раздач 13 коробок: одна Дани, остальные между Матиасом и Пабло; Пабло вдвое больше Матиаса только при N_{Дани} = 23, N_{Матиаса} = 81, N_{Пабло} = 162; у Пабло всегда не меньше семи коробок, раздач с семью коробками восемь.*
