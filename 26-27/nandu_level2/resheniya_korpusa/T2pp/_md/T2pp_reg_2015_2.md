## Т2″ — регионал 2015, №2 — прямоугольники ABCF и DEFG, площадь ABCF 448 см²

<!-- отступление от образца: в оригинале вопросы без меток; метки а)–в) поставлены в условии, ответ на каждый — своим абзацем -->

**Условие.** На рисунке:

- ABCF и DEFG — прямоугольники;
- AF = FG;
- площадь CDG = 3 · площадь DEFG;
- площадь ABCF равна 448 см²;
- периметр DEFG равен 88 см;
- периметр CDG равен 144 см.

Вопросы:

- а) Чему равен периметр ABCF?
- б) Чему равна площадь CDEF?
- в) Чему равен периметр ABCDE?

<!-- отступление от образца: рисунок условия встаёт под первой строкой решения, а не под последним вопросом: так он идёт крупно, а не узкой колонкой рядом с условием -->

**Заметим:** отрезки разрезают чертёж на прямоугольники ABCF, DEFG и треугольник CDG.

<!-- отступление от образца: спрошены два периметра ⇒ нужны длины сторон, а не только площади кусков; поэтому до разбора спрошенного стоят буквы на рисунке (кирпич x из «AF = FG»), как в геометрии с длинами -->

**Буквы на рисунке.**

**Дано:** *«AF = FG»* ⇒ обозначим AF = FG = x.

<small>Противоположные стороны прямоугольников равны: BC = AF = x, DE = FG = x, AB = FC, EF = DG.</small>

**Из каких фигур состоит каждое спрошенное.**

:::cols
**а) Спросили:** периметр ABCF.

**Заметим:** ABCF — прямоугольник со сторонами AF = x и FC.
:::col
**б) Спросили:** площадь CDEF.

**Заметим:** CDEF состоит из DEFG и CDG.

**Дано:** *«площадь CDG = 3 · площадь DEFG»* ⇒ площадь CDEF равна четырём площадям DEFG.

**Заметим:** DEFG — прямоугольник со сторонами FG = x и DG.
:::

**в) Спросили:** периметр ABCDE.

**Заметим:** обход ABCDE — это стороны AB = FC, BC = x, CD, DE = x и EA.

**Заметим:** EA состоит из EF = DG и FA = x.

> ✅ **Цель: найти длины x, FC, DG и CD.**

<!-- отступление от образца: цепочка идёт по длинам, а не по площадям: данные числом — площадь ABCF и два периметра, а доля площадей «CDG = 3 · DEFG» нужна только для связи FC с x -->

**Идея.** Площадь ABCF дана числом, но у ABCF две неизвестные стороны x и FC ⇒ сначала выразим FC через x из данного «площадь CDG = 3 · площадь DEFG».

**Значит, длины найдём по цепочке** (стрелка: из этой длины найдём следующую):

**FC через x → x → DG → CD**

**1. Найдём FC через x.**

**Дано:** *«площадь CDG = 3 · площадь DEFG»*.

**Заметим:** у CDG и DEFG общая сторона DG: у CDG отрезок DG — катет, у DEFG — сторона прямоугольника.

> ✅ **S(CDG) = 3 · S(DEFG)**

<!-- отступление от образца: врезки «Приём — треугольники с одной высотой» нет: сравниваются треугольник и прямоугольник, общая сторона DG сокращается прямо в уравнении площадей, записанном по школьным формулам -->

**Площадь CDG.** CDG — прямоугольный треугольник с катетами DG и GC.

<small>С чертежа: F, G и C лежат на одной прямой, а угол DGF — угол прямоугольника DEFG ⇒ угол DGC тоже прямой.</small>

S(CDG) = DG · GC : 2

**Площадь DEFG.** DEFG — прямоугольник со сторонами FG = x и DG.

S(DEFG) = x · DG

**Подставим площади в уравнение.**

```sys
DG · GC : 2 = 3 · x · DG     | · 2
DG · GC = 6 · x · DG         | : DG
GC = 6x
```

**С чертежа:** F, G и C лежат на одной прямой ⇒ FC складывается из FG и GC.

FC = FG + GC = x + 6x = 7x

→ **FC = 7x**

**2. Найдём x.**

**Дано:** *«площадь ABCF равна 448 см²»*.

**Заметим:** ABCF — прямоугольник со сторонами AF = x и FC = 7x.

**x · 7x = 448**

```sys
7x² = 448       | : 7
x² = 64
x = 8
```

→ **x = 8**

**3. Найдём DG.**

**Дано:** *«периметр DEFG равен 88 см»*.

**Заметим:** DEFG — прямоугольник со сторонами FG = x = 8 и DG.

```sys
2 · (8 + DG) = 88     | : 2
8 + DG = 44           | − 8
DG = 36
```

→ **DG = 36**

**4. Найдём CD.**

**Дано:** *«периметр CDG равен 144 см»*.

**Заметим:** обход CDG — это стороны CD, DG = 36 и GC = 6x = 48.

**CD + 36 + 48 = 144**

```sys
CD + 84 = 144     | − 84
CD = 60
```

→ **CD = 60**

**5. Сборка: подставим x = 8, DG = 36, CD = 60.**

а) P(ABCF) = 2 · (AF + FC) = 2 · (x + 7x) = 2 · (8 + 56) = 128

б) S(CDEF) = 4 · S(DEFG) = 4 · x · DG = 4 · 8 · 36 = 1152

в) P(ABCDE) = AB + BC + CD + DE + EA = 7x + x + CD + x + (DG + x) = 56 + 8 + 60 + 8 + 44 = 176

**Ответ на задачу:**

а) P(ABCF) = **128 см**;

б) S(CDEF) = **1152 см²**;

в) P(ABCDE) = **176 см**.

**⚠ Ловушки.**

- GC = 6x, а не 3x: треугольник CDG — половина прямоугольника со сторонами DG и GC.
- EA = EF + FA = 36 + 8 = 44, а не только EF = 36: сторона EA идёт через F.
- Для CD не нужна теорема Пифагора: CD даёт периметр CDG.

*Проверено перебором программой: целые AF = FG и DG до 300, FC до 600, вершины по условию, площади и периметры по координатам вершин — единственное решение x = 8, FC = 56, DG = 36; а) 128, б) 1152, в) 176; CD = 60 из периметра совпадает с теоремой Пифагора (тройка 36, 48, 60); слепая проверка вторым агентом дала те же ответы.*
