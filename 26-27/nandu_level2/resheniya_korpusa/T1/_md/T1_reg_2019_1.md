## Т1 — регионал 2019, №1 — шарики Педро

**Условие.** У Педро мешок с шариками четырёх цветов: красными, синими, зелёными и белыми. Известно:

- всего в мешке 2150 шариков;
- если он вынет все зелёные шарики, в мешке останется 1806 шариков;
- если он вынет половину синих шариков, в мешке останется 1992 шарика;
- если он вынет все белые шарики, то в мешке останется 2/3 того, что осталось бы, если бы он вынул все красные.

Сколько у Педро шариков каждого цвета?

### Часть 1 — запись системы

r, b, g, w — сколько в мешке красных, синих, зелёных и белых шариков (red, blue, green, white).

<!-- отступление от образца: вместо одной строки «если бы» четыре, и каждая названа своим действием — в условии четыре воображаемых мешка; вынутые цвета стоят нулём -->
| | красные | синие | зелёные | белые |
|---|---|---|---|---|
| настоящий мешок | r | b | g | w |
| вынет все зелёные | r | b | 0 | w |
| вынет половину синих | r | b : 2 | g | w |
| вынет все белые | r | b | g | 0 |
| вынет все красные | 0 | b | g | w |

*«Всего в мешке 2150 шариков»* ⇒

**(1) r + b + g + w = 2150**

*«…если он вынет все зелёные шарики, в мешке останется 1806 шариков»* — по строке «вынет все зелёные» ⇒

**(2) r + b + w = 1806**

*«…если он вынет половину синих шариков, в мешке останется 1992 шарика»* — по строке «вынет половину синих» ⇒

**(3) r + (b : 2) + g + w = 1992**

*«…если он вынет все белые шарики, то в мешке останется 2/3 того, что осталось бы, если бы он вынул все красные»* — по строкам «вынет все белые» и «вынет все красные» ⇒

**(4) r + b + g = (b + g + w) · 2/3**

⚠ В (4) доля 2/3 взята от того, что осталось бы без красных, то есть от b + g + w, а не от 2150.

### Часть 2 — решение системы

**Система:**

```sys
(1) r + b + g + w = 2150
(2) r + b + w = 1806
(3) r + b : 2 + g + w = 1992
(4) r + b + g = (b + g + w) · 2/3      | · 3
```

**Причёсанная система:**

```sys
(1) ⟪r + b⟫ + g + ⟪w⟫ = 2150
(2) ⟪r + b + w⟫ = 1806
(3) r + b : 2 + g + w = 1992
(4) 2 · w − 3 · r − b − g = 0
```

**Ходы:**

```sys
⟪(1) − (2)⟫   g = 344
```

**Система:** g = 344 встаёт на место (1) и подставляется в (3) и (4).

```sys
(2) r + b + w = 1806
(3) r + b : 2 + ⟦344⟧ + w = 1992
(4) 2 · w − 3 · r − b − ⟦344⟧ = 0
g = 344
```

**Система:**

```sys
(2) ⦃r⦄ + b + ⦃w⦄ = 1806
(5) ⦃r⦄ + b : 2 + ⦃w⦄ = 1648
(6) 2 · w − 3 · r − b = 344
g = 344
```

**Ходы:**

```sys
⦃(2) − (5)⦄   b : 2 = 158    | · 2
              b = 316
```

**Система:** b найдено, подставляется в (2) и (6).

```sys
(2) r + ⟦316⟧ + w = 1806
(6) 2 · w − 3 · r − ⟦316⟧ = 344
b = 316
g = 344
```

**Система:**

```sys
(7) ⟬r⟭ + w = 1490
(8) 2 · w ⟬− 3 · r⟭ = 660
b = 316
g = 344
```

**Ходы:**

<!-- отступление от образца: у r в (7) и (8) разные множители и разные знаки, поэтому к (8) прибавляется утроенное (7) -->
```sys
⟬3 · (7) + (8)⟭   5 · w = 5130    | : 5
                  w = 1026
(7)               r = 1490 − ⟦1026⟧ = 464
```

**Система решена:**

```sys
r = 464
b = 316
g = 344
w = 1026
```

**Проверка** — подстановка в (1), (3), (4) и целая половина:

- (1): 464 + 316 + 344 + 1026 = 2150 ✓
- (3): 464 + 158 + 344 + 1026 = 1992 ✓
- (4): 464 + 316 + 344 = 1124 и (316 + 344 + 1026) · 2/3 = 1686 · 2/3 = 1124 ✓
- 316 : 2 = 158 ✓

*Проверено перебором программой: из всех наборов 2150 шариков четырёх цветов условию отвечает только 464, 316, 344, 1026.*

**Ответ на задачу:** у Педро 464 красных шарика, 316 синих, 344 зелёных и 1026 белых.
