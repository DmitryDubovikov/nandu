## Т1 — национал 2021, день I, №1 — цены орехов

**Условие.** Эмилия хочет купить орехи четырёх видов: миндаль, каштаны, грецкие орехи и фисташки. Известно:

- если она купит по четверти килограмма каждого вида, то всего заплатит $730;
- если она купит полкило фисташек и по четверти килограмма каждого из остальных видов, то всего заплатит $860;
- если она купит 100 граммов миндаля, 100 граммов грецких орехов, 200 граммов каштанов и 200 граммов фисташек, то всего заплатит $412;
- если она купит четверть килограмма миндаля и килограмм грецких орехов, то заплатит столько же, сколько за полкило миндаля и килограмм фисташек.

Сколько стоит килограмм каждого вида?

### Часть 1 — запись системы

<!-- отступление от образца: буквы x_{м}, x_{к}, x_{г}, x_{ф} вместо букв по английскому слову (almond → a, chestnut → c запрещены CHECKLIST «Сомневаешься, как обозначить»); по правилу «сомневаешься — x» одна буква x, индекс — вид ореха -->
x_{м}, x_{к}, x_{г}, x_{ф} — сколько долларов стоит килограмм миндаля, каштанов, грецких орехов, фисташек.

<!-- отступление от образца: нет таблицы «настоящая / «если бы»» — воображаемого набора в условии нет, каждое данное говорит о своей покупке -->
*«…по четверти килограмма каждого вида, то всего заплатит $730»* ⇒

**(1) (x_{м} · 1/4) + (x_{к} · 1/4) + (x_{г} · 1/4) + (x_{ф} · 1/4) = 730**

*«…полкило фисташек и по четверти килограмма каждого из остальных видов, то всего заплатит $860»* ⇒

**(2) (x_{м} · 1/4) + (x_{к} · 1/4) + (x_{г} · 1/4) + (x_{ф} · 1/2) = 860**

*«…100 граммов миндаля, 100 граммов грецких орехов, 200 граммов каштанов и 200 граммов фисташек, то всего заплатит $412»* ⇒ граммы переводим в килограммы:

100 г = 1/10 кг

200 г = 2/10 кг

**(3) (x_{м} · 1/10) + (x_{к} · 2/10) + (x_{г} · 1/10) + (x_{ф} · 2/10) = 412**

⚠ В (3) буквы — цены килограмма, а куплено 100 и 200 граммов: цену умножаем на 1/10 и на 2/10, а не берём целиком.

*«…четверть килограмма миндаля и килограмм грецких орехов, то заплатит столько же, сколько за полкило миндаля и килограмм фисташек»* ⇒ две покупки стоят одинаково ⇒ приравняем стоимости двух покупок:

<!-- 🆕 приём: приравнять два выражения одной суммы -->
**(4) (x_{м} · 1/4) + (x_{г} · 1) = (x_{м} · 1/2) + (x_{ф} · 1)**

### Часть 2 — решение системы

**Система:**

```sys
(1) x_{м} · 1/4 + x_{к} · 1/4 + x_{г} · 1/4 + x_{ф} · 1/4 = 730          | · 4
(2) x_{м} · 1/4 + x_{к} · 1/4 + x_{г} · 1/4 + x_{ф} · 1/2 = 860          | · 4
(3) x_{м} · 1/10 + x_{к} · 2/10 + x_{г} · 1/10 + x_{ф} · 2/10 = 412      | · 10
(4) x_{м} · 1/4 + x_{г} = x_{м} · 1/2 + x_{ф}                             | · 4   | − 2 · x_{м} − 4 · x_{ф}
```

**Причёсанная система:**

```sys
(1) ⟪x_{м} + x_{к} + x_{г}⟫ + x_{ф} = 2920
(2) ⟪x_{м} + x_{к} + x_{г}⟫ + 2 · x_{ф} = 3440
(3) x_{м} + 2 · x_{к} + x_{г} + 2 · x_{ф} = 4120
(4) −x_{м} + 4 · x_{г} − 4 · x_{ф} = 0
```

**Ходы:**

```sys
⟪(2) − (1)⟫   x_{ф} = 520
```

**Система:** x_{ф} найдено, подставляется в (1), (3) и (4).

```sys
(1) x_{м} + x_{к} + x_{г} + ⟦520⟧ = 2920
(3) x_{м} + 2 · x_{к} + x_{г} + 2 · ⟦520⟧ = 4120
(4) −x_{м} + 4 · x_{г} − 4 · ⟦520⟧ = 0
x_{ф} = 520
```

**Система:**

```sys
(5) ⦅x_{м}⦆ + x_{к} + ⦅x_{г}⦆ = 2400
(6) ⦅x_{м}⦆ + 2 · x_{к} + ⦅x_{г}⦆ = 3080
(7) −x_{м} + 4 · x_{г} = 2080
x_{ф} = 520
```

**Ходы:**

```sys
⦅(6) − (5)⦆   x_{к} = 680
```

**Система:** x_{к} найдено, подставляется в (5).

```sys
(5) x_{м} + ⟦680⟧ + x_{г} = 2400
(7) −x_{м} + 4 · x_{г} = 2080
x_{к} = 680
x_{ф} = 520
```

**Система:**

```sys
(8) ⟬x_{м}⟭ + x_{г} = 1720
(7) ⟬−x_{м}⟭ + 4 · x_{г} = 2080
x_{к} = 680
x_{ф} = 520
```

**Ходы:**

```sys
⟬(8) + (7)⟭   5 · x_{г} = 3800          | : 5
              x_{г} = 760
(8)           x_{м} = 1720 − ⟦760⟧ = 960
```

**Система решена:**

```sys
x_{м} = 960
x_{к} = 680
x_{г} = 760
x_{ф} = 520
```

**Проверка** — подстановка в (1), (2), (3) и (4):

- (1): 240 + 170 + 190 + 130 = 730 ✓
- (2): 240 + 170 + 190 + 260 = 860 ✓
- (3): 96 + 136 + 76 + 104 = 412 ✓
- (4): 240 + 760 = 1000 и 480 + 520 = 1000 ✓

*Проверено перебором программой: из всех целых цен четверти килограмма (от $0 до $730) условию отвечает только 240, 170, 190, 130, то есть 960, 680, 760, 520 за килограмм.*

**Ответ на задачу:** килограмм миндаля стоит $960, килограмм каштанов стоит $680, килограмм грецких орехов стоит $760, килограмм фисташек стоит $520.
