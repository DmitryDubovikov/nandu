## Т1 — регионал 2023, №1 — чупетины и альфахоры

**Условие.** В оптовом киоске продают чупетины, белые альфахоры и чёрные альфахоры. Известно:

- каждый чупетин стоит $100;
- каждый альфахор стоит $300;
- Алехандро купил 130 сладостей;
- за покупку Алехандро заплатил $34200;
- если бы Алехандро купил на 10 чупетинов больше, вдвое больше белых альфахоров и вдвое меньше чёрных альфахоров, то заплатил бы $40900.

Вопросы:

<!-- отступление от образца: в оригинале три вопроса без меток; метки а), б), в) поставлены, чтобы ответ на каждый стоял отдельным абзацем -->
- а) Сколько чупетинов купил Алехандро?
- б) Сколько белых альфахоров купил Алехандро?
- в) Сколько чёрных альфахоров купил Алехандро?

### Часть 1 — запись системы

<!-- отступление от образца: буквы не по одному слову с индексом, а x, w, b — у чупетина английская буква l читается как 1, поэтому x; у альфахоров w (white) и b (black) -->
x, w, b — сколько Алехандро купил чупетинов, белых альфахоров и чёрных альфахоров.

<!-- отступление от образца: в шапке таблицы рядом с видом сладости её цена — у образца цена и есть имя столбца ($1, $2…), здесь вид назван словом -->
| | чупетины, $100 | белые альфахоры, $300 | чёрные альфахоры, $300 |
|---|---|---|---|
| настоящая | x | w | b |
| «если бы» | x + 10 | 2 · w | b : 2 |

*«Алехандро купил 130 сладостей»* ⇒

**(1) x + w + b = 130**

*«…Алехандро заплатил $34200»* ⇒

**(2) (100 · x) + (300 · w) + (300 · b) = 34200**

<!-- отступление от образца: у «если бы» дано одно число (сумма), а не два — уравнений три, а не четыре -->
*«…то заплатил бы $40900»* — по строке «если бы» ⇒

**(100 · (x + 10)) + (300 · (2 · w)) + (300 · (b : 2)) = 40900**

**(3) 100 · x + 1000 + 600 · w + 150 · b = 40900**

⚠ В (3) количества сладостей — из строки «если бы», а не настоящие.

⚠ 10 добавочных чупетинов стоят 100 · 10 = 1000, а не 10.

### Часть 2 — решение системы

**Система:**

```sys
(1) x + w + b = 130
(2) 100 · x + 300 · w + 300 · b = 34200            | : 100
(3) 100 · x + 1000 + 600 · w + 150 · b = 40900     | − 1000   | : 50
```

**Причёсанная система:**

```sys
(1) ⟪x⟫ + w + b = 130
(2) ⟪x⟫ + 3 · w + 3 · b = 342
(3) 2 · x + 12 · w + 3 · b = 798
```

**Ходы:**

```sys
⟪(2) − (1)⟫   2 · w + 2 · b = 212    | : 2
              (4) w + b = 106
```

**Система:** (4) встаёт на место (2).

```sys
(1) x + ⦃w + b⦄ = 130
(3) 2 · x + 12 · w + 3 · b = 798
(4) ⦃w + b⦄ = 106
```

**Ходы:**

```sys
⦃(1) − (4)⦄   x = 24
```

**Система:** x найдено, подставляется в (3).

```sys
(3) 2 · ⟦24⟧ + 12 · w + 3 · b = 798
(4) w + b = 106
x = 24
```

<!-- отступление от образца: после подстановки в (3) появился общий множитель 3 — он делится здесь же, по шаблону «Система:» с отметкой → «Причёсанная система:» -->
**Система:**

```sys
(4) w + b = 106
(5) 12 · w + 3 · b = 750    | : 3
x = 24
```

**Причёсанная система:**

```sys
(4) w + ⦅b⦆ = 106
(5) 4 · w + ⦅b⦆ = 250
x = 24
```

**Ходы:**

```sys
⦅(5) − (4)⦆   3 · w = 144    | : 3
              w = 48
(4)           b = 106 − ⟦48⟧ = 58
```

**Система решена:**

```sys
x = 24
w = 48
b = 58
```

**Проверка** — подстановка в (2), (3) и целая половина:

- (2): 2400 + 14400 + 17400 = 34200 ✓
- (3): 2400 + 1000 + 28800 + 8700 = 40900 ✓
- 58 : 2 = 29 ✓

*Проверено перебором программой: из всех наборов 130 сладостей на $34200 условию «если бы» отвечает только 24, 48, 58.*

**Ответ на задачу:**

а) Алехандро купил 24 чупетина;

б) Алехандро купил 48 белых альфахоров;

в) Алехандро купил 58 чёрных альфахоров.
