## Т1 — регионал 2021, №1 — конфеты трёх вкусов

**Условие.** В пакете лежат конфеты трёх вкусов: яблочные, банановые и клубничные. Известно:

- всего в пакете 863 конфеты;
- если не считать клубничные, то конфет 718;
- если не считать яблочные, то конфет втрое больше, чем если не считать банановые.

Сколько в пакете конфет каждого вкуса?

### Часть 1 — запись системы

<!-- отступление от образца: буквы по испанским словам условия (manzana, banana, frutilla), а не по английским — у яблока английская буква a, а латинская a запрещена (читается как русская «а») -->

m, b, f — сколько в пакете яблочных, банановых и клубничных конфет (manzana, banana, frutilla).

<!-- отступление от образца: таблицы «настоящая / «если бы»» нет — в условии нет воображаемого набора, «если не считать» только убирает один вкус -->

*«Всего в пакете 863 конфеты»* ⇒

**(1) m + b + f = 863**

*«Если не считать клубничные, то конфет 718»* ⇒

**(2) m + b = 718**

*«Если не считать яблочные, то конфет втрое больше, чем если не считать банановые»* ⇒

**(3) b + f = 3 · (m + f)**

⚠ Без яблочных остаются банановые и клубничные: в (3) слева b + f, а не m.

### Часть 2 — решение системы

**Система:**

```sys
(1) m + b + f = 863
(2) m + b = 718
(3) b + f = 3 · (m + f)    | − 3 · (m + f)
```

**Причёсанная система:**

```sys
(1) ⟪m + b⟫ + f = 863
(2) ⟪m + b⟫ = 718
(3) b − 3 · m − 2 · f = 0
```

**Ходы:**

```sys
⟪(1) − (2)⟫   f = 145
```

**Система:** f найдено, подставляется в (3).

```sys
(2) m + b = 718
(3) b − 3 · m − 2 · ⟦145⟧ = 0
f = 145
```

**Система:**

```sys
(2) m + ⦅b⦆ = 718
(4) ⦅b⦆ − 3 · m = 290
f = 145
```

**Ходы:**

```sys
⦅(2) − (4)⦆   4 · m = 428    | : 4
              m = 107
(2)           b = 718 − ⟦107⟧ = 611
```

**Система решена:**

```sys
m = 107
b = 611
f = 145
```

**Проверка** — подстановка в (1) и (3):

- (1): 107 + 611 + 145 = 863 ✓
- (3): 611 + 145 = 756 и 3 · (107 + 145) = 3 · 252 = 756 ✓

*Проверено перебором программой: из всех наборов 863 конфет условию отвечает только 107, 611, 145.*

**Ответ на задачу:** в пакете 107 яблочных конфет, 611 банановых и 145 клубничных.
