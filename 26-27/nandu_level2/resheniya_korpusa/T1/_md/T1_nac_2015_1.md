## Т1 — национал 2015, №1 — сосуды с фигурками

<!-- отступление от образца: данные задачи — на рисунке, в тексте условия их нет; завязка и пункты списка описывают, что показывает рисунок, сам рисунок стоит рядом с условием -->
**Условие.** В четырёх сосудах лежат фигурки (рисунок):

- для каждого из первых трёх сосудов известен общий вес (в граммах) фигурок, которые в нём лежат;
- общий вес записан под сосудом.

Каков общий вес фигурок сосуда 4?

### Часть 1 — запись системы

<!-- отступление от образца: буква w (weight) с фигуркой в индексе — неизвестные здесь веса, индекс — вид фигурки, как у образца достоинство монеты -->
w■, w★, w⅄, w● — сколько граммов весит одна фигурка ■, ★, ⅄, ●.

<!-- отступление от образца: спрошен не набор букв, а сумма — она получает свою букву x и своё уравнение (4) -->
x — сколько граммов весят вместе фигурки сосуда 4.

<!-- отступление от образца: данные — с рисунка, а не цитатой из текста -->
**С рисунка:** в сосуде 1 три ■, одна ★ и один ⅄, под сосудом 211 ⇒

**(1) (3 · w■) + (1 · w★) + (1 · w⅄) = 211**

**С рисунка:** в сосуде 2 три ■, одна ★ и один ●, под сосудом 178 ⇒

**(2) (3 · w■) + (1 · w★) + (1 · w●) = 178**

**С рисунка:** в сосуде 3 один ■, три ★, два ⅄ и три ●, под сосудом 292 ⇒

**(3) (1 · w■) + (3 · w★) + (2 · w⅄) + (3 · w●) = 292**

**С рисунка:** в сосуде 4 два ■, две ★, два ⅄ и один ● ⇒

**(4) (2 · w■) + (2 · w★) + (2 · w⅄) + (1 · w●) = x**

⚠ Вес каждой фигурки по отдельности найти нельзя: неизвестных четыре, а данных уравнений три.

### Часть 2 — решение системы

<!-- 🆕 приём вне реестра: спрошенная сумма — уравнением с x: спрошенная сумма записывается своим уравнением с буквой x, и сложением и вычитанием уравнений получается уравнение, где кроме x ничего не осталось; отдельные буквы не находятся -->
**Система:**

```sys
(1) ⟪3 · w■ + w★⟫ + w⅄ = 211
(2) ⟪3 · w■ + w★⟫ + w● = 178
(3) w■ + 3 · w★ + 2 · w⅄ + 3 · w● = 292
(4) 2 · w■ + 2 · w★ + 2 · w⅄ + w● = x
```

**Ходы:**

```sys
⟪(1) − (2)⟫   (5) w⅄ − w● = 33
```

<!-- отступление от образца: золотая ручка отмечает не одинаковые группы, а группы ■ и ★, которые в сумме дают группу (4): 3 · w■ + w★ из (2) и w■ + 3 · w★ из (3) вместе дают 4 · w■ + 4 · w★, вдвое больше 2 · w■ + 2 · w★ из (4); поэтому ход — (2) + (3) с делением на 2, а потом (4) − (6) гасит группу -->
**Система:** (5) встаёт на место (1).

```sys
(2) ⦃3 · w■ + w★⦄ + w● = 178
(3) ⦃w■ + 3 · w★⦄ + 2 · w⅄ + 3 · w● = 292
(4) ⦃2 · w■ + 2 · w★⦄ + 2 · w⅄ + w● = x
(5) w⅄ − w● = 33
```

**Ходы:**

```sys
⦃(2) + (3)⦄   4 · w■ + 4 · w★ + 2 · w⅄ + 4 · w● = 470    | : 2
              (6) ⦃2 · w■ + 2 · w★⦄ + w⅄ + 2 · w● = 235
⦃(4) − (6)⦄   (7) w⅄ − w● = x − 235
```

**Система:** (6) встаёт на место (2) и (3), (7) — на место (4).

```sys
(5) ⦅w⅄ − w●⦆ = 33
(7) ⦅w⅄ − w●⦆ = x − 235
```

**Ходы:**

```sys
⦅(7) − (5)⦆   0 = x − 235 − 33
              x = 235 + 33 = 268
```

<!-- отступление от образца: блока «Система решена» нет — неизвестных четыре, уравнений три, каждая буква по отдельности не находится, а найденная сумма x уже стоит в последней строке хода -->
<!-- отступление от образца: система не имеет единственного решения, поэтому проверка — два разных набора весов: каждый подставлен в (1), (2), (3) и в (4) -->
**Проверка** — подстановка двух разных наборов весов.

**Набор 1:** w■ = 39, w★ = 59, w⅄ = 35, w● = 2.

- (1): 117 + 59 + 35 = 211 ✓
- (2): 117 + 59 + 2 = 178 ✓
- (3): 39 + 177 + 70 + 6 = 292 ✓
- (4): 78 + 118 + 70 + 2 = 268 ✓

**Набор 2:** w■ = 47, w★ = 3, w⅄ = 67, w● = 34.

- (1): 141 + 3 + 67 = 211 ✓
- (2): 141 + 3 + 34 = 178 ✓
- (3): 47 + 9 + 134 + 102 = 292 ✓
- (4): 94 + 6 + 134 + 34 = 268 ✓

*Проверено перебором программой: у (1), (2) и (3) девять решений в целых положительных граммах, и у всех девяти вес сосуда 4 равен 268.*

**Ответ на задачу:** общий вес фигурок сосуда 4 равен **268** граммам.
