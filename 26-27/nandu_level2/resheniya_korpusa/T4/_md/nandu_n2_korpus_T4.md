## Т4 — провинциал 2024, №1 — шесть кружков, разные цифры, три суммы

**Условие.** Лола хочет заполнить рисунок из шести кружков A, B, C, D, E, F:

- в каждый кружок она пишет цифру;
- все шесть цифр разные;
- первое условие: A + B = D;
- второе условие: B + C = E;
- третье условие: D + E = F.

Как Лола может заполнить рисунок? Приведи все возможности.

A, B, C, D, E, F — кружки рисунка и цифры в них.

**Идея.** Кружок B входит и в D, и в E, а D и E вместе дают F ⇒ выразим F через A, B, C и вспомним, что F — цифра.

Подставим первые два условия в третье: числа A и C войдут по одному разу, а B войдёт два раза.

F = D + E = (A + B) + (B + C) = A + 2 · B + C

<small>*«цифру»* ⇒ F не больше 9</small>

> ◆ A + 2 · B + C ≤ 9      (*)

**Дано:** *«в каждый кружок она пишет цифру»* ⇒ 0 тоже можно писать.

Но ни одна из цифр A, B, C не равна 0.

<small>A = 0 даёт D = B, B = 0 даёт D = A, C = 0 даёт E = B, а *«все шесть цифр разные»*</small>

A и C — разные цифры, не 0 и не B ⇒ A + C не меньше суммы двух самых маленьких цифр, отличных от 0 и от B:

| B | 1 | 2 | 3 | 4 и больше |
|---|:-:|:-:|:-:|:-:|
| A + C | ≥ 2 + 3 = 5 | ≥ 1 + 3 = 4 | ≥ 1 + 2 = 3 | ≥ 1 + 2 = 3 |
| A + 2 · B + C | ≥ 7 | ≥ 8 | ≥ 9 | ≥ 11 |
| (*) | ✓ | ✓ | ✓ | ✗ |

> ◆ B = 1, 2 или 3

> ✅ N = ⟪N(B = 1)⟫ + ⦃N(B = 2)⦄ + ⦅N(B = 3)⦆

**1. N(B = 1).**

Подставим B = 1 в (*):

```sys
A + 2 · 1 + C ≤ 9
A + 2 + C ≤ 9           | − 2
```

> ◆ A + C ≤ 7

Если поменять местами цифры в A и C, а вместе с ними в D и E, все три условия останутся верными ⇒ сначала выбираем пару цифр для A и C, потом расставляем пару по кружкам A и C:

> ✅ N(B = 1) = N(пар для A и C) · N(порядков в паре)

*Пары:* разные цифры, не 0 и не 1, с суммой не больше 7, меньшая в A.

D и E — по первым двум условиям, F — по третьему:

| A, C | 2, 3 | 2, 4 | 2, 5 | 3, 4 |
|---|:-:|:-:|:-:|:-:|
| D = A + 1 | 3 | 3 | 3 | 4 |
| E = C + 1 | 4 | 5 | 6 | 5 |
| F = D + E | 7 | 8 | 9 | 9 |
| все цифры разные | ✗ D = C | ✓ | ✓ | ✗ D = C |

N(пар для A и C) = 2

*Порядки:* пары 2, 4 и 2, 5 встают в A и C двумя способами каждая.

**Дано:** *«Приведи все возможности»* ⇒ два порядка одной пары — два разных заполнения: цифры стоят в разных кружках.

N(порядков в паре) = 2

⟪N(B = 1)⟫ = 2 · 2 = ⟪4⟫

**2. N(B = 2).**

Подставим B = 2 в (*):

```sys
A + 2 · 2 + C ≤ 9
A + 4 + C ≤ 9           | − 4
```

> ◆ A + C ≤ 5

Пару для A и C выбираем так же, как при B = 1:

> ✅ N(B = 2) = N(пар для A и C) · N(порядков в паре)

*Пары:* разные цифры, не 0 и не 2, с суммой не больше 5, меньшая в A.

| A, C | 1, 3 | 1, 4 |
|---|:-:|:-:|
| D = A + 2 | 3 | 3 |
| E = C + 2 | 5 | 6 |
| F = D + E | 8 | 9 |
| все цифры разные | ✗ D = C | ✓ |

N(пар для A и C) = 1

*Порядки:* 1 и 4 встают в A и C двумя способами.

N(порядков в паре) = 2

⦃N(B = 2)⦄ = 1 · 2 = ⦃2⦄

**3. N(B = 3).**

Подставим B = 3 в (*):

```sys
A + 2 · 3 + C ≤ 9
A + 6 + C ≤ 9           | − 6
```

> ◆ A + C ≤ 3

Пару для A и C выбираем так же, как при B = 1:

> ✅ N(B = 3) = N(пар для A и C) · N(порядков в паре)

*Пары:* сумму не больше 3 дают только 1 и 2.

| A, C | 1, 2 |
|---|:-:|
| D = A + 3 | 4 |
| E = C + 3 | 5 |
| F = D + E | 9 |
| все цифры разные | ✓ |

N(пар для A и C) = 1

*Порядки:* 1 и 2 встают в A и C двумя способами.

N(порядков в паре) = 2

⦅N(B = 3)⦆ = 1 · 2 = ⦅2⦆

**Сборка.**

N = ⟪4⟫ + ⦃2⦄ + ⦅2⦆ = 8

**Ответ на задачу:** Лола может заполнить рисунок **8 способами**.

В каждой строке два заполнения: второе получается из первого обменом A ↔ C и D ↔ E.

- B = 1, A = 2, C = 4, D = 3, E = 5, F = 8 и зеркальное A = 4, C = 2, D = 5, E = 3;
- B = 1, A = 2, C = 5, D = 3, E = 6, F = 9 и зеркальное A = 5, C = 2, D = 6, E = 3;
- B = 2, A = 1, C = 4, D = 3, E = 6, F = 9 и зеркальное A = 4, C = 1, D = 6, E = 3;
- B = 3, A = 1, C = 2, D = 4, E = 5, F = 9 и зеркальное A = 2, C = 1, D = 5, E = 4.

**⚠ Ловушки.**

- Забыть, что B входит и в D, и в E: из A + B + C ≤ 9 выйдут лишние B = 4, 5, 6.
- Не проверить повторы: пары 2, 3 и 3, 4 при B = 1 и пара 1, 3 при B = 2 дают D = C.
- Привести только одно заполнение из каждой зеркальной пары: выйдет 4 вместо 8.

*Проверено перебором программой всех 10⁶ расстановок цифр 0, 1, …, 9 по шести кружкам: 8, по мирам 4, 2 и 2; слепое решение отдельного агента тоже 8.*
## Т4 — национал 2017, день II, №4 — доска 3 × 4, втрое вниз, вдвое вправо, сумма 2730

**Условие.** В каждую клетку доски 3 × 4 (три строки, четыре столбца) нужно вписать число так, чтобы:

- каждое число было втрое больше своего соседа сверху;
- каждое число было вдвое меньше своего соседа слева;
- сумма всех 12 чисел равнялась 2730.

Как вписать числа? Покажи.

*🆕 Приём вне реестра: все клетки через одну букву — соседи связаны «в k раз» ⇒ x в клетку с наименьшим числом, остальные числа — целые кратные x, известная сумма даёт x (перенос «кирпич-сетка», №7, с длин на числа доски)*

**Идея.** Каждое число задано через своего соседа ⇒ впишем x в одну клетку, выразим через x все 12 чисел, и *«сумма 2730»* даст x.

**Дано:** *«втрое больше своего соседа сверху»* ⇒ вниз по столбцу числа растут втрое.

**Дано:** *«вдвое меньше своего соседа слева»* ⇒ влево по строке числа растут вдвое.

**Значит:** самое маленькое число стоит в правом верхнем углу.

Чтобы все 12 чисел были целыми кратными x, берём x — число в правом верхнем углу.

**Тогда:** в строке 1 от x влево каждое число вдвое больше соседа справа, а каждое число строки ниже втрое больше числа над ним:

> ✅ Все 12 чисел доски выражены через x ⇒ осталось найти x.

**1. Найдём x.**

*«Сумма всех 12 чисел равна 2730»* ⇒ сложим числа доски по строкам.

**Обозначим:** S₁, S₂, S₃ — суммы строк 1, 2 и 3.

S₁ = 8x + 4x + 2x + x = 15x

**Заметим:** каждое число строк 2 и 3 втрое больше числа над ним ⇒ сумма строки 2 втрое больше S₁, а сумма строки 3 втрое больше S₂.

S₂ = 3 · 15x = 45x

S₃ = 3 · 45x = 135x

S_{доски} = S₁ + S₂ + S₃ = 15x + 45x + 135x = 195x

```sys
195x = 2730            | : 195
```

> ◆ x = 14

**2. Сборка: подставим x = 14.**

Строка 1: 8 · 14 = 112, 4 · 14 = 56, 2 · 14 = 28, 14.

Строка 2: 3 · 112 = 336, 3 · 56 = 168, 3 · 28 = 84, 3 · 14 = 42.

Строка 3: 3 · 336 = 1008, 3 · 168 = 504, 3 · 84 = 252, 3 · 42 = 126.

S_{доски} = S₁ + S₂ + S₃ = 210 + 630 + 1890 = 2730 ✓

**Ответ на задачу:** доску заполняем так:

- строка 1: 112, 56, 28, 14;
- строка 2: 336, 168, 84, 42;
- строка 3: 1008, 504, 252, 126.

Другого заполнения нет: сумма доски задаёт x однозначно.

**⚠ Ловушки.**

- Перевернуть доску: *«втрое больше соседа сверху»* ⇒ большие числа внизу, а не вверху; доска со строкой 1008, 504, 252, 126 наверху условию не отвечает.
- Отразить доску слева направо: *«вдвое меньше соседа слева»* ⇒ вправо числа уменьшаются, и 14 стоит в правом верхнем углу, а не в левом.
- Взять x в левом верхнем углу: справа от него встанут половина, четверть и восьмая часть x, и уравнение выйдет с дробями (тот же ответ, но дольше).

*Проверено перебором программой: система из 17 условий на соседей и суммы 2730 имеет ровно одно решение (ранг 12); перебор целых x от 1 до 2730 в правом верхнем углу тоже даёт только x = 14.*
