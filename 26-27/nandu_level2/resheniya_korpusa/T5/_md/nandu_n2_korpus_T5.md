## Т5 — провинциал 2022, №1 — квадрат из палочек от 1 до 11 см

**Условие.** У Адрианы есть палочки, и она складывает из них квадрат:

- 11 палочек длиной 1 см, 2 см, 3 см, …, 11 см;
- в квадрат идут все палочки или только некоторые;
- каждая сторона квадрата состоит из одной палочки или из нескольких.

Вопросы:

- а) Какие периметры могут быть у квадратов, которые может сложить Адриана? Дай все возможности.
- б) Для каждого периметра укажи, из каких палочек сложены стороны квадрата.

x — сторона квадрата в сантиметрах.

**Идея.** *«каждая сторона квадрата состоит из одной палочки или из нескольких»* ⇒ палочки каждой стороны вместе дают x ⇒ выпишем несколько квадратов и посмотрим, какой бывает x.

Сторона из самой длинной палочки 11, остальные три стороны — пары с суммой 11:

x = 11: (11), (1 + 10), (2 + 9), (3 + 8)

Так же со стороной из палочки 10:

x = 10: (10), (1 + 9), (2 + 8), (3 + 7)

**Заметим:** чем меньше x, тем меньше палочек короче x, из которых складываются пары ⇒ у x есть наименьшее значение.

**Заметим:** чем больше x, тем длиннее четыре стороны вместе, а длина всех палочек ограничена ⇒ у x есть наибольшее значение.

*🆕 Приём вне реестра: оценка плюс пример — каждая граница искомой величины доказывается оценкой и квадратом на самой границе, каждое значение между границами — своим квадратом*

**Значит:** ищем наименьшую и наибольшую сторону и квадрат для каждой стороны между ними:

> ✅ Возможные P = 4 · x, где x_{наим} ≤ x ≤ x_{наиб} и для x есть квадрат

**Дано:** *«для каждого периметра укажи, из каких палочек сложены стороны квадрата»* ⇒ на каждый периметр достаточно одного квадрата.

**1. x_{наиб}: оценка из длины всех палочек, потом квадрат.**

S_{палочек} = 1 + 2 + 3 + … + 11 = 66

**Заметим:** палочки квадрата и лишние палочки вместе составляют все 11 палочек:

```sys
(4 · x) + S_{лишних} = 66      | − S_{лишних}
4 · x = 66 − S_{лишних}
```

Вычитаемое S_{лишних} не меньше 0, а чем больше вычитаем, тем меньше остаётся:

4 · x ≤ 66 ⇒ x ≤ 16,5

<small>x — сумма целых длин ⇒ x целое</small>

> ◆ x ≤ 16

**Квадрат с x = 16.**

S_{лишних} = 66 − 4 · 16 = 2 ⇒ лишняя только палочка 2.

<small>сумму 2 даёт только сама палочка 2: второй палочки 1 нет</small>

Остаются палочки 1, 3, 4, …, 11.

Пары с суммой 16 ищем через напарника: напарник 11 равен 5, напарник 10 равен 6, напарник 9 равен 7.

(11 + 5), (10 + 6), (9 + 7)

Напарник 8 равен 8, а палочка 8 одна ⇒ к палочке 8 добавляем оставшиеся палочки 1, 3 и 4:

8 + 1 + 3 + 4 = 16 ✓

x_{наиб} = 16

**2. x_{наим}: оценка через палочки короче x, потом квадрат.**

*🆕 Приём вне реестра: сторона из одной палочки — не больше одной, поэтому остальные три стороны требуют не меньше шести палочек короче x*

**Заметим:** палочек длиной x не больше одной ⇒ из одной палочки состоит не больше одной стороны.

**Значит:** остальные три стороны — из двух палочек или больше, и каждая палочка этих трёх сторон короче x:

N(палочек короче x) ≥ 3 · 2 = 6

Палочки короче x — это палочки 1, 2, …, x − 1:

N(палочек короче x) ≤ x − 1

x − 1 ≥ 6 ⇒ x ≥ 7

> ◆ x ≥ 7

**Квадрат с x = 7.**

Сторона из палочки 7, остальные три — пары через напарника: напарники 1, 2 и 3 равны 6, 5 и 4.

x = 7: (7), (1 + 6), (2 + 5), (3 + 4)

x_{наим} = 7

**3. Квадраты для каждого x от 8 до 15.**

**x от 8 до 11.**

Палочка x есть ⇒ сторона из палочки x и три пары с напарниками 1, 2 и 3:

(x), (1 + (x − 1)), (2 + (x − 2)), (3 + (x − 3))

<small>все семь палочек разные:</small>

<small>x − 3 ≥ 5 > 3 и x − 1 < x</small>

<small>x = 8: (8), (1 + 7), (2 + 6), (3 + 5)</small>

<small>x = 9: (9), (1 + 8), (2 + 7), (3 + 6)</small>

<small>x = 10: (10), (1 + 9), (2 + 8), (3 + 7)</small>

<small>x = 11: (11), (1 + 10), (2 + 9), (3 + 8)</small>

**x от 12 до 15.**

Палочки x нет ⇒ берём самые длинные палочки 8, 9, 10, 11, каждую с напарником:

(8 + (x − 8)), (9 + (x − 9)), (10 + (x − 10)), (11 + (x − 11))

<small>напарники x − 11, x − 10, x − 9, x − 8 разные и короче 8:</small>

<small>x − 11 ≥ 1 и x − 8 ≤ 7</small>

<small>x = 12: (8 + 4), (9 + 3), (10 + 2), (11 + 1)</small>

<small>x = 13: (8 + 5), (9 + 4), (10 + 3), (11 + 2)</small>

<small>x = 14: (8 + 6), (9 + 5), (10 + 4), (11 + 3)</small>

<small>x = 15: (8 + 7), (9 + 6), (10 + 5), (11 + 4)</small>

Квадрат есть для каждого x от 8 до 15.

**Сборка.**

Из разделов 1, 2 и 3: квадрат есть для каждого x от 7 до 16.

P = 4 · 7, 4 · 8, …, 4 · 16 = 28, 32, 36, 40, 44, 48, 52, 56, 60, 64

**Ответ на задачу:**

а) периметры 28, 32, 36, 40, 44, 48, 52, 56, 60 и 64 см, всего десять возможностей;

б) стороны квадратов:

| P, см | x, см | стороны квадрата |
|:-:|:-:|---|
| 28 | 7 | (7), (1 + 6), (2 + 5), (3 + 4) |
| 32 | 8 | (8), (1 + 7), (2 + 6), (3 + 5) |
| 36 | 9 | (9), (1 + 8), (2 + 7), (3 + 6) |
| 40 | 10 | (10), (1 + 9), (2 + 8), (3 + 7) |
| 44 | 11 | (11), (1 + 10), (2 + 9), (3 + 8) |
| 48 | 12 | (8 + 4), (9 + 3), (10 + 2), (11 + 1) |
| 52 | 13 | (8 + 5), (9 + 4), (10 + 3), (11 + 2) |
| 56 | 14 | (8 + 6), (9 + 5), (10 + 4), (11 + 3) |
| 60 | 15 | (8 + 7), (9 + 6), (10 + 5), (11 + 4) |
| 64 | 16 | (11 + 5), (10 + 6), (9 + 7), (8 + 1 + 3 + 4); палочка 2 лишняя |

**⚠ Ловушки.**

- Решить, что в квадрат идут все палочки: 66 не делится на 4, и выйдет «квадрата нет».
- Строить только квадраты «одна палочка и три пары» — пропадут x от 12 до 16, где палочки x нет.
- Решить, что годится любая сторона до 16: при x = 6 пар с суммой 6 только две, (1 + 5) и (2 + 4), и сторон набирается три.

*Проверено перебором программой всех раскладок 11 палочек по четырём сторонам и в лишние: квадрат есть ровно при x = 7, 8, …, 16, то есть P = 28, 32, …, 64; при x = 16 лишняя всегда палочка 2; все квадраты из ответа проверены той же программой.*
## Т5 — национал 2021, день I, №3 — красная кнопка ×2, синяя ×5

**Условие.** Игра начинается с числа на экране, у игры две кнопки:

- красная кнопка умножает число на экране на 2;
- синяя кнопка умножает число на экране на 5;
- Алан выигрывает, если, нажимая кнопки одну за другой, он может перейти от начального числа к целевому.

Вопросы:

- а) начальное число 21, целевое 840000: может ли Алан выиграть?
- б) начальное число 17, целевое 1434375: может ли Алан выиграть?
- в) целевое число 284750: может ли Алан выбрать начальное число меньше 1000 и выиграть?

Если ответ «да», покажи как; если «нет», объясни почему.

**Идея.** *«умножает число на экране на 2»*, *«на 5»* ⇒ выпишем несколько нажатий и посмотрим, что стоит на экране.

Нажмём с 21 красную, синюю и красную кнопки:

21 → 42 → 210 → 420

Число на экране = 21 · 2 · 5 · 2 = 420

**Заметим:** на экране всегда начальное число, умноженное на несколько двоек и несколько пятёрок.

**Заметим:** двоек столько, сколько раз нажата красная кнопка, пятёрок — сколько раз нажата синяя.

**Значит:** порядок множителей не важен ⇒ важно только, сколько раз нажата каждая кнопка.

> ✅ Алан выигрывает ⇔ целевое число = начальное число · 2 · … · 2 · 5 · … · 5

**а) Найдём, из каких простых множителей состоит 840000 : 21.**

*«начальное число 21, целевое 840000»* ⇒ по условию выигрыша нужно, чтобы 840000 : 21 состояло из одних двоек и пятёрок.

Целевое : начальное = 840000 : 21 = 40000

Целевое : начальное = 4 · 10 · 10 · 10 · 10

<small>4 = 2 · 2, 10 = 2 · 5</small>

Целевое : начальное = 40000 = 2 · 2 · 2 · 2 · 2 · 2 · 5 · 5 · 5 · 5

**Значит:** 840000 = 21 · 2 · 2 · 2 · 2 · 2 · 2 · 5 · 5 · 5 · 5 ⇒ Алан выигрывает.

Шесть раз красная, потом четыре раза синяя:

21 → 42 → 84 → 168 → 336 → 672 → 1344 → 6720 → 33600 → 168000 → 840000

**б) Найдём, из каких простых множителей состоит 1434375 : 17.**

*«начальное число 17, целевое 1434375»* ⇒ по условию выигрыша нужно, чтобы 1434375 : 17 состояло из одних двоек и пятёрок.

Целевое : начальное = 1434375 : 17 = 84375

**Заметим:** 84375 нечётное ⇒ в 84375 нет множителя 2.

**Заметим:** 84375 оканчивается на 5 ⇒ делим 84375 на 5, пока делится.

| число | 84375 | 16875 | 3375 | 675 | 135 | 27 | 9 | 3 | 1 |
|---|---|---|---|---|---|---|---|---|---|
| делим на | 5 | 5 | 5 | 5 | 5 | 3 | 3 | 3 | |

Целевое : начальное = 84375 = 3 · 3 · 3 · 5 · 5 · 5 · 5 · 5

**Заметим:** в 84375 есть множитель 3, а кнопки дают только 2 и 5.

*🆕 Приём: «докажи, что невозможно» по пунктам — у частного «целевое : начальное» есть простой множитель, которого кнопки не дают*

:::box Приём — делимость произведения через разложение
⋮ — «делится на».

Если произведение ⋮ b, то все простые множители b должны найтись среди простых множителей сомножителей.

Пример на числах, не из задачи: в 2 · 2 · 5 · 5 нет множителя 3 ⇒ 2 · 2 · 5 · 5 не делится на 3.

2 · 2 · 5 · 5 = 100, а 100 : 3 = 33, остаток 1
:::

В частности:

84375 ⋮ 3, а среди множителей 2 · … · 2 · 5 · … · 5 нет 3 ⇒ 2 · … · 2 · 5 · … · 5 не делится на 3 ⇒ 84375 ≠ 2 · … · 2 · 5 · … · 5

**Значит:** 1434375 ≠ 17 · 2 · … · 2 · 5 · … · 5 ⇒ Алан не выигрывает при любом числе и порядке нажатий.

**в) Найдём наименьшее начальное число для 284750.**

*«целевое число 284750»* ⇒ по условию выигрыша:

начальное число = 284750 : (2 · … · 2 · 5 · … · 5)

**Дано:** *«выбрать начальное число»* ⇒ прочтение: начальное число натуральное.

**Значит:** в делителе только двойки и пятёрки, которые есть в разложении 284750.

**Заметим:** чем больше двоек и пятёрок в делителе, тем меньше начальное число ⇒ наименьшее начальное число равно 284750, из которого убраны все двойки и пятёрки.

| число | 284750 | 142375 | 28475 | 5695 | 1139 |
|---|---|---|---|---|---|
| делим на | 2 | 5 | 5 | 5 | |

<small>1139 нечётное и не оканчивается на 0 или 5 ⇒ 1139 не делится ни на 2, ни на 5</small>

Целевое = 284750 = 2 · 5 · 5 · 5 · 1139

Наименьшее начальное число = 284750 : (2 · 5 · 5 · 5) = 1139

<small>все начальные числа, с которых Алан доходит до 284750 хотя бы одним нажатием: 1139, 2278, 5695, 11390, 28475, 56950, 142375</small>

1139 > 1000 ⇒ начальное число меньше 1000 Алан выбрать не может.

**Ответ на задачу:**

а) да: 21 → 42 → 84 → 168 → 336 → 672 → 1344 → 6720 → 33600 → 168000 → 840000 (шесть раз красная кнопка, потом четыре раза синяя);

б) нет: 1434375 : 17 = 84375 = 3 · 3 · 3 · 5 · 5 · 5 · 5 · 5, а множителя 3 кнопки не дают;

в) нет: 284750 = 2 · 5 · 5 · 5 · 1139, и наименьшее начальное число равно 1139 > 1000.

**⚠ Ловушки.**

- В а) ответить «да» только потому, что 840000 делится на 21: нужно ещё, чтобы в 840000 : 21 были одни двойки и пятёрки.
- В б) увидеть, что 1434375 оканчивается на 5, и решить, что синей кнопкой дойти можно, — выйдет «да».
- В в) взять начальным числом любой делитель 284750 меньше 1000, например 17, — выйдет «да», хотя 284750 : 17 = 16750 = 2 · 5 · 5 · 5 · 67.

*Проверено перебором программой всех последовательностей нажатий: из 21 до 840000 Алан доходит (шесть красных, четыре синих), из 17 до 1434375 не доходит; среди начальных чисел от 1 до 999 до 284750 не доходит ни одно, наименьшее подходящее начальное число равно 1139; слепое решение отдельного агента — тоже да, нет, нет.*
