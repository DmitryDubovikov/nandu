## Т1 — система уравнений

**Т1 — задачи, где неизвестных несколько и про них дано несколько чисел.**

Каждое число говорит про все неизвестные сразу: «всего 120 предметов», «вместе стоят $630», «если бы предметов по $5 было вдвое больше, то стоили бы $730».

Спрошены сами неизвестные: сколько предметов каждого вида, сколько стоит каждый товар.

Решение всегда из двух частей: **запись системы** (каждое число условия ⇒ своё уравнение) и **решение системы** (ходы над уравнениями, без смысла букв).

**Образец решения:** [национал 2023, день II, №4 — монеты Лусии](../../idealnye_resheniya/faza1/01-t1-nacional-2023-den-ii-4-monety-lusii.html)

### Приёмы записи системы

#### 1. Данное → уравнение

Видно: числа про все предметы сразу — «всего …», «вместе стоят …», «понадобилось …».

→ буквы — то, что спрошено; каждое число ⇒ своё уравнение, слагаемое со смыслом — в скобках:

```sys
(1) m2 + m5 + m10 = 120
(2) (2 · m2) + (5 · m5) + (10 · m10) = 630
```

#### 2. Строка «если бы»

Видно: рядом с настоящим набором воображаемый — «если бы … было вдвое больше / на 10 больше / вынуть все …, то …».

→ таблица «настоящая / «если бы»», уравнение — по строке «если бы»:

| | $2 | $5 | $10 |
|---|---|---|---|
| настоящая | m2 | m5 | m10 |
| «если бы» | m2 | 2 · m5 | m10 : 2 |

```sys
(3) (2 · m2) + (5 · (2 · m5)) + (10 · (m10 : 2)) = 730
```

<small>Меняются количества: воображаемых строк бывает несколько, по строке на действие; убранный вид стоит нулём.</small>

<small>Меняется цена, а количества те же: скидка, акция, другой день, «за полцены» ⇒ таблица цен по ситуациям.</small>

#### 3. Приравнять два выражения одной суммы · новый

Видно: данное без числа — «столько же, сколько …», «заплатит столько же, сколько за …», «втрое больше, чем …», «2/3 того, что …».

→ уравнение «выражение = выражение», справа не число:

```sys
(4) x1 + x3 = x2
(5) x1 + x2 = 3 · (x2 + x3)
```

#### 4. Доля · N = число одним ходом

Видно: «треть … — …», «две трети всех …», «2/3 того, что осталось бы, если …» — доля от буквы или от суммы букв.

→ доля пишется после целого:

```sys
(x1 · 1/3) + (x2 · 1/4) = 60
r + b + g = (b + g + w) · 2/3
```

<small>Одна неизвестная и одно уравнение — решается одним ходом: x · 90/100 = 540 | · 100/90.</small>

#### 5. Таблица параметров · новый

Видно: у каждого вида свой множитель — «в пакете 8 штук», «в каждом 2 ракушки», «по 1/2 литра в день, 4 дня»; цена за килограмм, а куплено в граммах.

→ таблица «вид | буква | параметры»; слагаемое = (параметр · буква), единицы переведены в единицы буквы:

```sys
300 г = 3/10 кг   ⇒   (x1 · 3/10)
(8 · p8) + (4 · p4) = 1200
```

#### 6. Доля другой части = 1 − данная

Видно: «скидка 20 %», «60 % потратил» — дана одна часть, а работает другая.

→ платят 100 − 20 = 80 % цены:

```sys
p · 80/100
```

#### 7. Покупка парами · новый

Видно: «скидка на вторую единицу», количество каждого товара чётное.

→ покупка делится на пары; цена пары = полная + со скидкой; в день без скидки — две полные:

```sys
(3 · (p + p · 30/100)) + (2 · (2 · q)) = 1060
```

#### 8. Спрошенная сумма — уравнением с x · новый

Видно: спрошена сумма набора («сколько весит пакет 4»), неизвестных больше, чем данных уравнений.

→ спрошенная сумма — своё уравнение с x; сложением и вычитанием данных получается уравнение, где кроме x ничего нет:

```sys
(4) (2 · w1) + (2 · w2) + w3 = x
```

#### 9. Одна неизвестная — запись уравнения · новый

Видно: одна неизвестная, части берутся долями «от остатка», «от потраченного».

→ x — целое; каждая часть через x своей строкой; сумма частей = данное:

```sys
S_{остатка} = x · 70/100
S_{остатка} + S_{остатка} · 10/100 = 770
```

### Приёмы решения системы

Цикл: «Система:» → «Причёсанная система:» → ручкой то, что бросается в глаза → «Ходы:» → снова «Система:» … → «Система решена».

#### 10. Причесать систему

Видно: скобки, общие множители, дроби.

→ скобки раскрыты, общие множители поделены до конца, дроби сняты:

```sys
(2) 50 · b1 + 75 · b2 + 100 · b3 = 7500     | : 25
(3) x · 1/3 = y · 1/5 + z · 1/6              | · 30
```

#### 11. Сложение или вычитание, гасящее общую группу букв

Видно: в двух уравнениях одна и та же группа букв.

→ с теми же множителями — вычитаем, с противоположными знаками — складываем, с множителями 1 и 3 — утроенное уравнение:

```sys
(1) ⟪m2 + m5⟫ + m10 = 120
(3) ⟪m2 + m5⟫ + m10 : 2 = 105
⟪(1) − (3)⟫   m10 : 2 = 15
```

```sys
(4) ⦃3 · x⦄ + y = 50
(5) ⦃x⦄ + 3 · y = 70
⦃3 · (5) − (4)⦄   8 · y = 160
```

#### 12. Найденное — в остальные уравнения

Видно: одна-две буквы найдены и стоят в других уравнениях.

→ «m10 = 30 найдено, подставляется в (1) и (2)»:

```sys
(1) m2 + m5 + ⟦30⟧ = 120
```

#### 13. Метод подстановки · новый

Видно: одно уравнение уже выражает букву или группу — «x = y : 2», «группа = группа».

→ выражение встаёт на место буквы в другом уравнении:

```sys
(1) x = y : 2
(2) y + 3 · x = 750
⟪(1) в (2)⟫   y + 3 · (y : 2) = 750
```

## T1-30-1 — лодочная станция

**Условие.** На лодочной станции у озера есть лодки трёх видов: 2-местные, 4-местные и 6-местные. Известно:

- всего на станции 38 лодок;
- во всех лодках вместе 138 мест;
- если бы 2-местных лодок было вдвое больше, а 4-местных и 6-местных столько же, то мест было бы 170.

Сколько на станции лодок каждого вида?

### Часть 1 — запись системы

b2, b4, b6 — сколько на станции 2-местных, 4-местных, 6-местных лодок.

| | 2-местные | 4-местные | 6-местные |
|---|---|---|---|
| настоящая | b2 | b4 | b6 |
| «если бы» | 2 · b2 | b4 | b6 |

*«Всего на станции 38 лодок»* ⇒

**(1) b2 + b4 + b6 = 38**

*«…во всех лодках вместе 138 мест»* ⇒

**(2) (2 · b2) + (4 · b4) + (6 · b6) = 138**

*«…то мест было бы 170»* — по строке «если бы» ⇒

**(2 · (2 · b2)) + (4 · b4) + (6 · b6) = 170**

**(3) 4 · b2 + 4 · b4 + 6 · b6 = 170**

⚠ В (3) количество 2-местных лодок — из строки «если бы», а не настоящее.

### Часть 2 — решение системы

**Система:**

```sys
(1) b2 + b4 + b6 = 38
(2) 2 · b2 + 4 · b4 + 6 · b6 = 138     | : 2
(3) 4 · b2 + 4 · b4 + 6 · b6 = 170     | : 2
```

**Причёсанная система:**

```sys
(1) b2 + b4 + b6 = 38
(2) b2 + ⟪2 · b4 + 3 · b6⟫ = 69
(3) 2 · b2 + ⟪2 · b4 + 3 · b6⟫ = 85
```

**Ходы:**

```sys
⟪(3) − (2)⟫   b2 = 16
```

**Система:** b2 найдено, подставляется в (1) и (2).

```sys
(1) ⟦16⟧ + b4 + b6 = 38
(2) ⟦16⟧ + 2 · b4 + 3 · b6 = 69
b2 = 16
```

**Система:**

```sys
(4) ⦃b4⦄ + b6 = 22
(5) ⦃2 · b4⦄ + 3 · b6 = 53
b2 = 16
```

**Ходы:**

```sys
⦃(5) − 2 · (4)⦄   b6 = 9
(4)               b4 = 22 − ⟦9⟧ = 13
```

**Система решена:**

```sys
b2 = 16
b4 = 13
b6 = 9
```

**Проверка** — подстановка в (2) и (3):

- (2): 32 + 52 + 54 = 138 ✓
- (3): 64 + 52 + 54 = 170 ✓

*Проверено перебором программой: из всех наборов 38 лодок на 138 мест (их 16) условию «если бы» отвечает только 16, 13, 9.*

**Ответ на задачу:** на станции 2-местных лодок 16, 4-местных 13, 6-местных 9.

## T1-30-2 — аквариум

**Условие.** В аквариуме у Мартины живут рыбки трёх видов: гуппи, неоны и сомики. Известно:

- всего в аквариуме 56 рыбок;
- гуппи столько же, сколько неонов и сомиков вместе;
- неонов втрое больше, чем сомиков.

Сколько в аквариуме рыбок каждого вида?

### Часть 1 — запись системы

N_{гуп}, N_{неон}, N_{сом} — сколько в аквариуме гуппи, неонов, сомиков.

*«Всего в аквариуме 56 рыбок»* ⇒

**(1) N_{гуп} + N_{неон} + N_{сом} = 56**

*«…гуппи столько же, сколько неонов и сомиков вместе»* ⇒

**(2) N_{гуп} = N_{неон} + N_{сом}**

*«…неонов втрое больше, чем сомиков»* ⇒

**(3) N_{неон} = 3 · N_{сом}**

⚠ В (2) справа неоны и сомики вместе, а не один вид.

⚠ В (3) множитель 3 стоит у сомиков: неонов больше, поэтому N_{сом} = 3 · N_{неон} неверно.

### Часть 2 — решение системы

**Система:**

```sys
(1) N_{гуп} + ⟪N_{неон} + N_{сом}⟫ = 56
(2) N_{гуп} = ⟪N_{неон} + N_{сом}⟫
(3) N_{неон} = 3 · N_{сом}
```

**Ходы:**


```sys
⟪(2) в (1)⟫   N_{гуп} + N_{гуп} = 56
              2 · N_{гуп} = 56    | : 2
              N_{гуп} = 28
(2)           (4) N_{неон} + N_{сом} = ⟦28⟧
```

**Система:** N_{гуп} и (4) встают на место (1) и (2).

```sys
(4) ⦃N_{неон}⦄ + N_{сом} = 28
(3) ⦃N_{неон}⦄ = 3 · N_{сом}
N_{гуп} = 28
```

**Ходы:**

```sys
⦃(3) в (4)⦄   3 · N_{сом} + N_{сом} = 28
              4 · N_{сом} = 28    | : 4
              N_{сом} = 7
(3)           N_{неон} = 3 · ⟦7⟧ = 21
```

**Система решена:**

```sys
N_{гуп} = 28
N_{неон} = 21
N_{сом} = 7
```

**Проверка** — подстановка во все три уравнения:

- (1): 28 + 21 + 7 = 56 ✓
- (2): 21 + 7 = 28 ✓
- (3): 3 · 7 = 21 ✓

*Проверено перебором программой: из всех наборов от 0 до 200 рыбок каждого вида условию отвечает только 28, 21, 7.*

**Ответ на задачу:** в аквариуме 28 гуппи, 21 неон и 7 сомиков.

## T1-50-1 — спортивный магазин

**Условие.** Тренер собрал в спортивном магазине заказ из мячей, ракеток и скакалок. Известно:

- всего в заказе 40 предметов;
- мяч стоит $120;
- ракетка стоит $40;
- скакалка стоит $10;
- если на мячи скидка 25 %, то за весь заказ надо заплатить $1320;
- если на ракетки скидка 50 %, то за весь заказ надо заплатить $1290.

Сколько в заказе мячей, ракеток и скакалок?

### Часть 1 — запись системы

b, r, j — сколько в заказе мячей, ракеток и скакалок.

**Дано:** *«скидка 25 %»* ⇒ за мяч со скидкой платят 100 − 25 = 75 % его цены.

**Дано:** *«скидка 50 %»* ⇒ за ракетку со скидкой платят 100 − 50 = 50 % её цены.

| цена предмета | мяч | ракетка | скакалка |
|---|---|---|---|
| скидка на мячи | 120 · 75/100 | 40 | 10 |
| скидка на ракетки | 120 | 40 · 50/100 | 10 |

*«Всего в заказе 40 предметов»* ⇒

**(1) b + r + j = 40**

*«…на мячи скидка 25 %, то за весь заказ надо заплатить $1320»* — по строке «скидка на мячи» ⇒

**((120 · 75/100) · b) + (40 · r) + (10 · j) = 1320**

**(2) 90 · b + 40 · r + 10 · j = 1320**

*«…на ракетки скидка 50 %, то за весь заказ надо заплатить $1290»* — по строке «скидка на ракетки» ⇒

**(120 · b) + ((40 · 50/100) · r) + (10 · j) = 1290**

**(3) 120 · b + 20 · r + 10 · j = 1290**

⚠ Скидка в каждом случае только на один вид: в (2) ракетка стоит полные $40, в (3) полные $120 стоит мяч.

⚠ Мяч со скидкой 25 % стоит 75 % цены, то есть $90, а не $30.

### Часть 2 — решение системы

**Система:**

```sys
(1) b + r + j = 40
(2) 90 · b + 40 · r + 10 · j = 1320    | : 10
(3) 120 · b + 20 · r + 10 · j = 1290   | : 10
```

**Причёсанная система:**

```sys
(1) b + r + ⟪j⟫ = 40
(2) 9 · b + 4 · r + ⟪j⟫ = 132
(3) 12 · b + 2 · r + ⟪j⟫ = 129
```

**Ходы:**

```sys
⟪(2) − (1)⟫   (4) 8 · b + 3 · r = 92
⟪(3) − (1)⟫   (5) 11 · b + r = 89
```

**Система:** (4) и (5) встают на место (2) и (3).

```sys
(1) b + r + j = 40
(4) 8 · b + ⦃3 · r⦄ = 92
(5) 11 · b + ⦃r⦄ = 89
```

**Ходы:**

```sys
⦃3 · (5) − (4)⦄   25 · b = 175    | : 25
                  b = 7
(5)               r = 89 − 11 · ⟦7⟧ = 12
```

**Система:** b и r найдены, подставляются в (1).

```sys
(1) ⟦7⟧ + ⟦12⟧ + j = 40
b = 7
r = 12
```

**Ходы:**

```sys
(1)   j = 40 − 7 − 12 = 21
```

**Система решена:**

```sys
b = 7
r = 12
j = 21
```

**Проверка** — подстановка в (2) и (3):

- (2): 90 · 7 + 40 · 12 + 10 · 21 = 630 + 480 + 210 = 1320 ✓
- (3): 120 · 7 + 20 · 12 + 10 · 21 = 840 + 240 + 210 = 1290 ✓

*Проверено перебором программой: из всех наборов 40 предметов условию отвечает только 7, 12, 21.*

**Ответ на задачу:** в заказе 7 мячей, 12 ракеток и 21 скакалка.

## T1-70-1 — бакалея

**Условие.** Пабло покупает в бакалее крупы четырёх видов: рис, гречку, нут и фасоль. Известно:

- если он купит по 250 граммов каждой крупы, то всего заплатит $1075;
- если он купит по 100 граммов риса, гречки и нута и 300 граммов фасоли, то всего заплатит $530;
- если он купит 250 граммов риса, 500 граммов гречки и 250 граммов нута, то всего заплатит $1250;
- если он купит 100 граммов риса и 300 граммов нута, то заплатит столько же, сколько за 200 граммов гречки и 400 граммов фасоли.

Сколько стоит килограмм каждой крупы?

### Часть 1 — запись системы

x_{р}, x_{г}, x_{н}, x_{ф} — сколько долларов стоит килограмм риса, гречки, нута, фасоли.

*«…по 250 граммов каждой крупы, то всего заплатит $1075»* ⇒ граммы переводим в килограммы:

250 г = 1/4 кг

**(1) (x_{р} · 1/4) + (x_{г} · 1/4) + (x_{н} · 1/4) + (x_{ф} · 1/4) = 1075**

⚠ В (1) буквы — цены килограмма, а куплено по 250 граммов: цену умножаем на 1/4, а не берём целиком.

*«…по 100 граммов риса, гречки и нута и 300 граммов фасоли, то всего заплатит $530»* ⇒ граммы переводим в килограммы:

100 г = 1/10 кг

300 г = 3/10 кг

**(2) (x_{р} · 1/10) + (x_{г} · 1/10) + (x_{н} · 1/10) + (x_{ф} · 3/10) = 530**

*«…250 граммов риса, 500 граммов гречки и 250 граммов нута, то всего заплатит $1250»* ⇒ граммы переводим в килограммы:

500 г = 1/2 кг

**(3) (x_{р} · 1/4) + (x_{г} · 1/2) + (x_{н} · 1/4) = 1250**

*«…100 граммов риса и 300 граммов нута, то заплатит столько же, сколько за 200 граммов гречки и 400 граммов фасоли»* ⇒ граммы переводим в килограммы:

200 г = 2/10 кг

400 г = 4/10 кг

Две покупки стоят одинаково ⇒ приравняем стоимости двух покупок:

**(4) (x_{р} · 1/10) + (x_{н} · 3/10) = (x_{г} · 2/10) + (x_{ф} · 4/10)**

### Часть 2 — решение системы

**Система:**

```sys
(1) x_{р} · 1/4 + x_{г} · 1/4 + x_{н} · 1/4 + x_{ф} · 1/4 = 1075          | · 4
(2) x_{р} · 1/10 + x_{г} · 1/10 + x_{н} · 1/10 + x_{ф} · 3/10 = 530      | · 10
(3) x_{р} · 1/4 + x_{г} · 1/2 + x_{н} · 1/4 = 1250                       | · 4
```

## T1-70-2 — птицы на пруду

**Условие.** На пруду живут птицы четырёх видов: утки, гуси, лебеди и цапли. Известно:

- всего на пруду 336 птиц;
- если улетят все лебеди, на пруду останется 286 птиц;
- если улетит половина гусей, на пруду останется 291 птица;
- если улетят все цапли, то на пруду останется 3/4 того, что осталось бы, если бы улетели все утки.

Сколько на пруду птиц каждого вида?

### Часть 1 — запись системы

d, g, s, h — сколько на пруду уток, гусей, лебедей и цапель (duck, goose, swan, heron).

| | утки | гуси | лебеди | цапли |
|---|---|---|---|---|
| настоящий пруд | d | g | s | h |
| улетят все лебеди | d | g | 0 | h |
| улетит половина гусей | d | g : 2 | s | h |
| улетят все цапли | d | g | s | 0 |
| улетят все утки | 0 | g | s | h |

*«Всего на пруду 336 птиц»* ⇒

**(1) d + g + s + h = 336**

*«…если улетят все лебеди, на пруду останется 286 птиц»* — по строке «улетят все лебеди» ⇒

**(2) d + g + h = 286**

*«…если улетит половина гусей, на пруду останется 291 птица»* — по строке «улетит половина гусей» ⇒

**(3) d + (g : 2) + s + h = 291**

*«…если улетят все цапли, то на пруду останется 3/4 того, что осталось бы, если бы улетели все утки»* — по строкам «улетят все цапли» и «улетят все утки» ⇒

**(4) d + g + s = (g + s + h) · 3/4**

⚠ В (4) доля 3/4 взята от того, что осталось бы без уток, то есть от g + s + h, а не от 336.

### Часть 2 — решение системы

**Система:**

```sys
(1) d + g + s + h = 336
(2) d + g + h = 286
(3) d + g : 2 + s + h = 291
(4) d + g + s = (g + s + h) · 3/4      | · 4
```

**Причёсанная система:**

```sys
(1) ⟪d + g⟫ + s + ⟪h⟫ = 336
(2) ⟪d + g + h⟫ = 286
(3) d + g : 2 + s + h = 291
(4) 3 · h − 4 · d − g − s = 0
```

**Ходы:**

```sys
⟪(1) − (2)⟫   s = 50
```

**Система:** s = 50 встаёт на место (1) и подставляется в (3) и (4).

```sys
(2) d + g + h = 286
(3) d + g : 2 + ⟦50⟧ + h = 291
(4) 3 · h − 4 · d − g − ⟦50⟧ = 0
s = 50
```

**Система:**

```sys
(2) ⦃d⦄ + g + ⦃h⦄ = 286
(5) ⦃d⦄ + g : 2 + ⦃h⦄ = 241
(6) 3 · h − 4 · d − g = 50
s = 50
```

**Ходы:**

```sys
⦃(2) − (5)⦄   g : 2 = 45    | · 2
              g = 90
```

**Система:** g найдено, подставляется в (2) и (6).

```sys
(2) d + ⟦90⟧ + h = 286
(6) 3 · h − 4 · d − ⟦90⟧ = 50
g = 90
s = 50
```

**Система:**

```sys
(7) ⟬d⟭ + h = 196
(8) 3 · h ⟬− 4 · d⟭ = 140
g = 90
s = 50
```

**Ходы:**

```sys
⟬4 · (7) + (8)⟭   7 · h = 924    | : 7
                  h = 132
(7)               d = 196 − ⟦132⟧ = 64
```

**Система решена:**

```sys
d = 64
g = 90
s = 50
h = 132
```

**Проверка** — подстановка в (1), (3), (4) и целая половина:

- (1): 64 + 90 + 50 + 132 = 336 ✓
- (3): 64 + 45 + 50 + 132 = 291 ✓
- (4): 64 + 90 + 50 = 204 и (90 + 50 + 132) · 3/4 = 272 · 3/4 = 204 ✓
- 90 : 2 = 45 ✓

*Проверено перебором программой: из всех наборов 336 птиц четырёх видов условию отвечает только 64, 90, 50, 132.*

**Ответ на задачу:** на пруду 64 утки, 90 гусей, 50 лебедей и 132 цапли.

## T1-O-1 — магазин игрушек

**Условие.** По субботам в магазине игрушек действуют три акции:

- скидка 50 % на каждую вторую машинку в покупке;
- скидка 25 % на каждый второй мяч в покупке;
- скидка 40 % на каждый второй пазл в покупке;
- по воскресеньям действует только акция на машинки;
- по понедельникам действуют акции на мячи и на пазлы;
- игрушка без акции стоит полную цену, и полные цены во все дни одни и те же;
- Лукас хочет купить 4 машинки, 2 мяча и 6 пазлов;
- если он сделает эту покупку в субботу, то заплатит $670;
- если он сделает эту покупку в воскресенье, то заплатит $740;
- если он сделает эту покупку в понедельник, то заплатит $790.

Сколько стоит без скидки одна машинка, один мяч и один пазл?

**Приём:** покупка парами.

**Первая запись:** x, b, p — сколько стоит без скидки одна машинка, один мяч и один пазл.

Покупка делится на 2 пары машинок, 1 пару мячей и 3 пары пазлов.

*«…в субботу, то заплатит $670»* ⇒

(1) (2 · (x + x · 50/100)) + (1 · (b + b · 75/100)) + (3 · (p + p · 60/100)) = 670

Условие даёт три уравнения, по одному на день.

В день без акции на товар пара стоит две его полные цены: в воскресенье 2 · b и 2 · p, в понедельник 2 · x.

**Ответ:** машинка $120, мяч $40, пазл $50.

## T1-O-2 — садовый магазин

**Условие.** Садовый магазин продаёт наборы семян в пакетах:

- пакетики одного вида стоят одинаково;

- пакет 1 стоит $310;

Сколько стоит пакет 4?

**Приём:** спрошенная сумма — уравнением с x.

(4) (2 · b) + (1 · p) + (2 · d) + (2 · r) = x

Неизвестных четыре, данных уравнений три: по отдельности b, p, d, r не находятся.

x = (1) + (2) − (3)

**Ответ:** $240.
