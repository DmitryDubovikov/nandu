## T1-70-2 — птицы на пруду

**Условие.** На пруду живут птицы четырёх видов: утки, гуси, лебеди и цапли. Известно:

- всего на пруду 336 птиц;
- если улетят все лебеди, на пруду останется 286 птиц;
- если улетит половина гусей, на пруду останется 291 птица;
- если улетят все цапли, то на пруду останется 3/4 того, что осталось бы, если бы улетели все утки.

Сколько на пруду птиц каждого вида?

### Часть 1 — запись системы

<!-- отступление от образца: буквы d, g, s, h — первые буквы английских duck, goose, swan, heron, а не m1, m2… образца -->
d, g, s, h — сколько на пруду уток, гусей, лебедей и цапель (duck, goose, swan, heron).

<!-- отступление от образца: вместо одной строки «если бы» четыре, и каждая названа своим действием — в условии четыре воображаемых пруда; улетевшие виды стоят нулём -->
| | утки | гуси | лебеди | цапли |
|---|---|---|---|---|
| настоящий пруд | d | g | s | h |
| улетят все лебеди | d | g | 0 | h |
| улетит половина гусей | d | g : 2 | s | h |
| улетят все цапли | d | g | s | 0 |
| улетят все утки | 0 | g | s | h |

*«Всего на пруду 336 птиц»* ⇒

**(1) d + g + s + h = 336**

*«…если улетят все лебеди, на пруду останется 286 птиц»* — по строке «улетят все лебеди» ⇒

**(2) d + g + h = 286**

*«…если улетит половина гусей, на пруду останется 291 птица»* — по строке «улетит половина гусей» ⇒

**(3) d + (g : 2) + s + h = 291**

*«…если улетят все цапли, то на пруду останется 3/4 того, что осталось бы, если бы улетели все утки»* — по строкам «улетят все цапли» и «улетят все утки» ⇒

**(4) d + g + s = (g + s + h) · 3/4**

⚠ В (4) доля 3/4 взята от того, что осталось бы без уток, то есть от g + s + h, а не от 336.

### Часть 2 — решение системы

**Система:**

```sys
(1) d + g + s + h = 336
(2) d + g + h = 286
(3) d + g : 2 + s + h = 291
(4) d + g + s = (g + s + h) · 3/4      | · 4
```

**Причёсанная система:**

```sys
(1) ⟪d + g⟫ + s + ⟪h⟫ = 336
(2) ⟪d + g + h⟫ = 286
(3) d + g : 2 + s + h = 291
(4) 3 · h − 4 · d − g − s = 0
```

**Ходы:**

```sys
⟪(1) − (2)⟫   s = 50
```

**Система:** s = 50 встаёт на место (1) и подставляется в (3) и (4).

```sys
(2) d + g + h = 286
(3) d + g : 2 + ⟦50⟧ + h = 291
(4) 3 · h − 4 · d − g − ⟦50⟧ = 0
s = 50
```

**Система:**

```sys
(2) ⦃d⦄ + g + ⦃h⦄ = 286
(5) ⦃d⦄ + g : 2 + ⦃h⦄ = 241
(6) 3 · h − 4 · d − g = 50
s = 50
```

**Ходы:**

```sys
⦃(2) − (5)⦄   g : 2 = 45    | · 2
              g = 90
```

**Система:** g найдено, подставляется в (2) и (6).

```sys
(2) d + ⟦90⟧ + h = 286
(6) 3 · h − 4 · d − ⟦90⟧ = 50
g = 90
s = 50
```

**Система:**

```sys
(7) ⟬d⟭ + h = 196
(8) 3 · h ⟬− 4 · d⟭ = 140
g = 90
s = 50
```

**Ходы:**

<!-- отступление от образца: у d в (7) и (8) разные множители и разные знаки, поэтому к (8) прибавляется учетверённое (7) -->
```sys
⟬4 · (7) + (8)⟭   7 · h = 924    | : 7
                  h = 132
(7)               d = 196 − ⟦132⟧ = 64
```

**Система решена:**

```sys
d = 64
g = 90
s = 50
h = 132
```

**Проверка** — подстановка в (1), (3), (4) и целая половина:

- (1): 64 + 90 + 50 + 132 = 336 ✓
- (3): 64 + 45 + 50 + 132 = 291 ✓
- (4): 64 + 90 + 50 = 204 и (90 + 50 + 132) · 3/4 = 272 · 3/4 = 204 ✓
- 90 : 2 = 45 ✓

*Проверено перебором программой: из всех наборов 336 птиц четырёх видов условию отвечает только 64, 90, 50, 132.*

**Ответ на задачу:** на пруду 64 утки, 90 гусей, 50 лебедей и 132 цапли.
