## T1-30-2 — аквариум

**Условие.** В аквариуме у Мартины живут рыбки трёх видов: гуппи, неоны и сомики. Известно:

- всего в аквариуме 56 рыбок;
- гуппи столько же, сколько неонов и сомиков вместе;
- неонов втрое больше, чем сомиков.

Сколько в аквариуме рыбок каждого вида?

### Часть 1 — запись системы

<!-- отступление от образца: вместо букв m1, m2… — N с индексом-словом (N_{гуп}, N_{неон}, N_{сом}): английская буква сомика (catfish) — c, а латинская c читается как русская «с» -->
N_{гуп}, N_{неон}, N_{сом} — сколько в аквариуме гуппи, неонов, сомиков.

<!-- отступление от образца: таблицы нет — нет ни строки «если бы», ни цен; все три данных говорят об одних и тех же количествах рыбок -->
*«Всего в аквариуме 56 рыбок»* ⇒

**(1) N_{гуп} + N_{неон} + N_{сом} = 56**

<!-- отступление от образца: данное без числа — равенство двух выражений; уравнение без числа справа -->
*«…гуппи столько же, сколько неонов и сомиков вместе»* ⇒

**(2) N_{гуп} = N_{неон} + N_{сом}**

<!-- отступление от образца: данное без числа — «во сколько раз больше»; уравнение без числа справа -->
*«…неонов втрое больше, чем сомиков»* ⇒

**(3) N_{неон} = 3 · N_{сом}**

⚠ В (2) справа неоны и сомики вместе, а не один вид.

⚠ В (3) множитель 3 стоит у сомиков: неонов больше, поэтому N_{сом} = 3 · N_{неон} неверно.

### Часть 2 — решение системы

**Система:**

```sys
(1) N_{гуп} + ⟪N_{неон} + N_{сом}⟫ = 56
(2) N_{гуп} = ⟪N_{неон} + N_{сом}⟫
(3) N_{неон} = 3 · N_{сом}
```

**Ходы:**

<!-- 🆕 приём вне реестра: метод подстановки — буква или группа букв, выраженная одним уравнением, заменяется своим выражением в другом уравнении (здесь вычитать нечего: (2) говорит «буква = группа», (3) говорит «буква = 3 · буква») -->

```sys
⟪(2) в (1)⟫   N_{гуп} + N_{гуп} = 56
              2 · N_{гуп} = 56    | : 2
              N_{гуп} = 28
(2)           (4) N_{неон} + N_{сом} = ⟦28⟧
```

**Система:** N_{гуп} и (4) встают на место (1) и (2).

```sys
(4) ⦃N_{неон}⦄ + N_{сом} = 28
(3) ⦃N_{неон}⦄ = 3 · N_{сом}
N_{гуп} = 28
```

**Ходы:**

```sys
⦃(3) в (4)⦄   3 · N_{сом} + N_{сом} = 28
              4 · N_{сом} = 28    | : 4
              N_{сом} = 7
(3)           N_{неон} = 3 · ⟦7⟧ = 21
```

**Система решена:**

```sys
N_{гуп} = 28
N_{неон} = 21
N_{сом} = 7
```

**Проверка** — подстановка во все три уравнения:

- (1): 28 + 21 + 7 = 56 ✓
- (2): 21 + 7 = 28 ✓
- (3): 3 · 7 = 21 ✓

*Проверено перебором программой: из всех наборов от 0 до 200 рыбок каждого вида условию отвечает только 28, 21, 7.*

**Ответ на задачу:** в аквариуме 28 гуппи, 21 неон и 7 сомиков.
