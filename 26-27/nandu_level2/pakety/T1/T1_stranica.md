# Т1 — система уравнений

**Т1 — задачи, где неизвестных несколько и про них дано несколько чисел.**

Каждое число говорит про все неизвестные сразу: «всего 120 предметов», «вместе стоят $630», «если бы предметов по $5 было вдвое больше, то стоили бы $730».

Спрошены сами неизвестные: сколько предметов каждого вида, сколько стоит каждый товар.

Решение всегда из двух частей: **запись системы** (каждое число условия ⇒ своё уравнение) и **решение системы** (ходы над уравнениями, без смысла букв).

**Образец решения:** [национал 2023, день II, №4 — монеты Лусии](../../idealnye_resheniya/faza1/01-t1-nacional-2023-den-ii-4-monety-lusii.html)

## Приёмы записи системы

### 1. Данное → уравнение

Видно: числа про все предметы сразу — «всего …», «вместе стоят …», «понадобилось …».

→ буквы — то, что спрошено; каждое число ⇒ своё уравнение, слагаемое со смыслом — в скобках:

```sys
(1) m2 + m5 + m10 = 120
(2) (2 · m2) + (5 · m5) + (10 · m10) = 630
```

### 2. Строка «если бы»

Видно: рядом с настоящим набором воображаемый — «если бы … было вдвое больше / на 10 больше / вынуть все …, то …».

→ таблица «настоящая / «если бы»», уравнение — по строке «если бы»:

| | $2 | $5 | $10 |
|---|---|---|---|
| настоящая | m2 | m5 | m10 |
| «если бы» | m2 | 2 · m5 | m10 : 2 |

```sys
(3) (2 · m2) + (5 · (2 · m5)) + (10 · (m10 : 2)) = 730
```

<small>Меняются количества: воображаемых строк бывает несколько, по строке на действие; убранный вид стоит нулём.</small>

<small>Меняется цена, а количества те же: скидка, акция, другой день, «за полцены» ⇒ таблица цен по ситуациям.</small>

### 3. Приравнять два выражения одной суммы · новый

Видно: данное без числа — «столько же, сколько …», «заплатит столько же, сколько за …», «втрое больше, чем …», «2/3 того, что …».

→ уравнение «выражение = выражение», справа не число:

```sys
(4) x1 + x3 = x2
(5) x1 + x2 = 3 · (x2 + x3)
```

### 4. Доля · N = число одним ходом

Видно: «треть … — …», «две трети всех …», «2/3 того, что осталось бы, если …» — доля от буквы или от суммы букв.

→ доля пишется после целого:

```sys
(x1 · 1/3) + (x2 · 1/4) = 60
r + b + g = (b + g + w) · 2/3
```

<small>Одна неизвестная и одно уравнение — решается одним ходом: x · 90/100 = 540 | · 100/90.</small>

### 5. Таблица параметров · новый

Видно: у каждого вида свой множитель — «в пакете 8 штук», «в каждом 2 ракушки», «по 1/2 литра в день, 4 дня»; цена за килограмм, а куплено в граммах.

→ таблица «вид | буква | параметры»; слагаемое = (параметр · буква), единицы переведены в единицы буквы:

```sys
300 г = 3/10 кг   ⇒   (x1 · 3/10)
(8 · p8) + (4 · p4) = 1200
```

### 6. Доля другой части = 1 − данная

Видно: «скидка 20 %», «60 % потратил» — дана одна часть, а работает другая.

→ платят 100 − 20 = 80 % цены:

```sys
p · 80/100
```

### 7. Покупка парами · новый

Видно: «скидка на вторую единицу», количество каждого товара чётное.

→ покупка делится на пары; цена пары = полная + со скидкой; в день без скидки — две полные:

```sys
(3 · (p + p · 30/100)) + (2 · (2 · q)) = 1060
```

### 8. Спрошенная сумма — уравнением с x · новый

Видно: спрошена сумма набора («сколько весит пакет 4»), неизвестных больше, чем данных уравнений.

→ спрошенная сумма — своё уравнение с x; сложением и вычитанием данных получается уравнение, где кроме x ничего нет:

```sys
(4) (2 · w1) + (2 · w2) + w3 = x
```

### 9. Одна неизвестная — запись уравнения · новый

Видно: одна неизвестная, части берутся долями «от остатка», «от потраченного».

→ x — целое; каждая часть через x своей строкой; сумма частей = данное:

```sys
S_{остатка} = x · 70/100
S_{остатка} + S_{остатка} · 10/100 = 770
```

## Приёмы решения системы

Цикл: «Система:» → «Причёсанная система:» → ручкой то, что бросается в глаза → «Ходы:» → снова «Система:» … → «Система решена».

### 10. Причесать систему

Видно: скобки, общие множители, дроби.

→ скобки раскрыты, общие множители поделены до конца, дроби сняты:

```sys
(2) 50 · b1 + 75 · b2 + 100 · b3 = 7500     | : 25
(3) x · 1/3 = y · 1/5 + z · 1/6              | · 30
```

### 11. Сложение или вычитание, гасящее общую группу букв

Видно: в двух уравнениях одна и та же группа букв.

→ с теми же множителями — вычитаем, с противоположными знаками — складываем, с множителями 1 и 3 — утроенное уравнение:

```sys
(1) ⟪m2 + m5⟫ + m10 = 120
(3) ⟪m2 + m5⟫ + m10 : 2 = 105
⟪(1) − (3)⟫   m10 : 2 = 15
```

```sys
(4) ⦃3 · x⦄ + y = 50
(5) ⦃x⦄ + 3 · y = 70
⦃3 · (5) − (4)⦄   8 · y = 160
```

### 12. Найденное — в остальные уравнения

Видно: одна-две буквы найдены и стоят в других уравнениях.

→ «m10 = 30 найдено, подставляется в (1) и (2)»:

```sys
(1) m2 + m5 + ⟦30⟧ = 120
```

### 13. Метод подстановки · новый

Видно: одно уравнение уже выражает букву или группу — «x = y : 2», «группа = группа».

→ выражение встаёт на место буквы в другом уравнении:

```sys
(1) x = y : 2
(2) y + 3 · x = 750
⟪(1) в (2)⟫   y + 3 · (y : 2) = 750
```
