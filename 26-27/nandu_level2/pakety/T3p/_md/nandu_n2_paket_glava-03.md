## 3. Места по очереди: последним — место, где вариантов всегда поровну (новый)

[← оглавление учебника](index.html)

Если условие стоит на всю доску сразу (сумма делится на 3, сумма чётная), то клетки заполняются по очереди так, чтобы у последней клетки число вариантов не зависело от остальных.

**Условие.** У чемодана кодовый замок из четырёх колёсиков в ряд, и код на нём набирают так:

- на каждом колёсике выставляют одну из цифр 1, 2, 3, 4, 5, 6;
- цифры на разных колёсиках могут повторяться;
- сумма четырёх цифр кода делится на 3;
- чётных цифр в коде не больше одной.

Сколько различных кодов можно набрать? Объясни, как ты их считал.

**Способ** — код: цифры на колёсиках c₁, c₂, c₃, c₄ слева направо, цифры могут повторяться.

**Дано:** *«сколько различных кодов»* ⇒ одни и те же цифры в другом порядке дают другой код.

**Идея.** *«чётных цифр в коде не больше одной»* ⇒ в коде ни одной чётной цифры или ровно одна.

N = N(нет чётных) + N(одна чётная)

**1. N(нет чётных).**

На каждом колёсике стоит одна из цифр 1, 3, 5.

**Последним — место, где вариантов всегда поровну:** *«сумма делится на 3»* связывает все четыре колёсика сразу, а у 1, 3, 5 разные остатки при делении на 3 ⇒ c₁, c₂, c₃ ставим любыми, а в c₄ при любых c₁, c₂, c₃ годится ровно одна цифра:

<small>остатки при делении на 3: у 1 остаток 1, у 3 остаток 0, у 5 остаток 2</small>

<small>остаток c₁ + c₂ + c₃ равен 0 ⇒ у c₄ нужен остаток 0 ⇒ годится только 3</small>

<small>остаток c₁ + c₂ + c₃ равен 1 ⇒ у c₄ нужен остаток 2 ⇒ годится только 5</small>

<small>остаток c₁ + c₂ + c₃ равен 2 ⇒ у c₄ нужен остаток 1 ⇒ годится только 1</small>

<small>c₁, c₂, c₃ = 1, 1, 5 ⇒ сумма 7, остаток 1 ⇒ c₄ = 5, сумма кода 12</small>

N(нет чётных) = 3 · 3 · 3 · 1 = 27

**2. N(одна чётная).**

**Заметим:** где бы ни стояла чётная цифра, на её колёсике стоит одна из 2, 4, 6, а на трёх других колёсиках одна из 1, 3, 5 ⇒ от места чётной цифры число заполнений колёсиков не зависит ⇒ перемножаем:

N(одна чётная) = N(мест для чётной цифры) · N(заполнений колёсиков)

**2.1. N(мест для чётной цифры).**

Чётная цифра стоит на одном из четырёх колёсиков:

N(мест для чётной цифры) = 4

**2.2. N(заполнений колёсиков).**

**Последним — место, где вариантов всегда поровну:** c₄ берёт цифру из своей тройки, 1, 3, 5 или 2, 4, 6, а в каждой тройке остатки при делении на 3 разные ⇒ c₁, c₂, c₃ ставим любыми из своих троек, а в c₄ при любых c₁, c₂, c₃ годится ровно одна цифра:

<small>остатки у 1, 3, 5: 1, 0, 2   остатки у 2, 4, 6: 2, 1, 0</small>

<small>c₁, c₂, c₃ = 1, 4, 3 ⇒ сумма 8, остаток 2, в c₄ нечётная ⇒ c₄ = 1, сумма кода 9</small>

<small>c₁, c₂, c₃ = 3, 5, 5 ⇒ сумма 13, остаток 1, в c₄ чётная ⇒ c₄ = 2, сумма кода 15</small>

N(заполнений колёсиков) = 3 · 3 · 3 · 1 = 27

N(одна чётная) = 4 · 27 = 108

**Сборка.**

N = 27 + 108 = 135

**Ответ на задачу:** можно набрать **135 различных кодов**.

**⚠ Ловушки.**

- «Не больше одной» прочитать как «ровно одна» — выйдет 108.
- Забыть выбрать место для чётной цифры — выйдет 54.
- Считать наборы цифр, а не коды: 1155 и 1515 — разные коды, а набор один — выйдет 15.
