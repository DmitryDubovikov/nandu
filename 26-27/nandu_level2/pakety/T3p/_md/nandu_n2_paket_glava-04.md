## 4. Миры по клетке, которая связывает две части (новый)

[← оглавление учебника](index.html)

Если две части доски не связаны между собой ничем, кроме одной клетки, то миры — по числу в этой клетке, а внутри мира число способов для одной части умножается на число способов для другой.

**Условие.** Для пяти площадок детской горки, соединённых лесенками, как на схеме, выбирают высоты по таким правилам:

- высота каждой площадки равна целому числу ступенек от 1 до 6;
- каждая лесенка ведёт вверх: площадка, куда указывает стрелка, выше площадки, откуда стрелка выходит;
- высоты разных площадок могут совпадать.

Сколькими различными способами можно выбрать высоты площадок? Объясни, как ты их считал.

**Способ** — выбор высот c₁, …, c₅ из чисел от 1 до 6, повторы разрешены.

**Идея.** Между левым столбцом c₁, c₄ и правым столбцом c₃, c₅ нет ни одной стрелки: левый и правый столбцы связаны только через среднюю площадку c₂.

**Миры по клетке, которая связывает две части:** разобьём способы на миры по c₂.

**Дано:** *«площадка, куда указывает стрелка, выше площадки, откуда стрелка выходит»* ⇒ по стрелкам схемы высота растёт:

c₄ < c₁ < c₂ < c₃,   c₅ < c₃

| ограничение | откуда |
|---|---|
| c₂ ≥ 3 | 1 ≤ c₄ < c₁ < c₂ |
| c₂ ≤ 5 | c₂ < c₃ ≤ 6 |

**Значит:** у c₂ три возможных значения:

c₂ = 3, 4, 5

N = N(c₂ = 3) + N(c₂ = 4) + N(c₂ = 5)

**1. Мир N(c₂ = 3).**

**Заметим:** c₂ уже выбрана, а левый и правый столбцы между собой не связаны, поэтому любые высоты левого столбца годятся с любыми высотами правого:

N(c₂ = 3) = N(левого столбца) · N(правого столбца)

*Левый столбец, c₁ и c₄:*

c₄ < c₁ < c₂ = 3

N(левого столбца) = 1

<small>c₁ = 2: c₄ = 1</small>

*Правый столбец, c₃ и c₅:*

c₂ = 3 < c₃,   c₅ < c₃

N(правого столбца) = 3 + 4 + 5 = 12

<small>c₃ = 4: c₅ = 1, 2, 3   c₃ = 5: c₅ = 1, 2, 3, 4   c₃ = 6: c₅ = 1, 2, 3, 4, 5</small>

N(c₂ = 3) = 1 · 12 = 12

**2. Миры N(c₂ = 4) и N(c₂ = 5).**

Счёт тот же, меняется только c₂.

:::cols
**N(c₂ = 4)**

*Левый столбец:*

c₄ < c₁ < c₂ = 4

N(левого столбца) = 1 + 2 = 3

<small>c₁ = 2: c₄ = 1   c₁ = 3: c₄ = 1, 2</small>

*Правый столбец:*

c₂ = 4 < c₃,   c₅ < c₃

N(правого столбца) = 4 + 5 = 9

<small>c₃ = 5: c₅ = 1, 2, 3, 4   c₃ = 6: c₅ = 1, 2, 3, 4, 5</small>

N(c₂ = 4) = 3 · 9 = 27
:::col
**N(c₂ = 5)**

*Левый столбец:*

c₄ < c₁ < c₂ = 5

N(левого столбца) = 1 + 2 + 3 = 6

<small>c₁ = 2: c₄ = 1   c₁ = 3: c₄ = 1, 2   c₁ = 4: c₄ = 1, 2, 3</small>

*Правый столбец:*

c₂ = 5 < c₃,   c₅ < c₃

N(правого столбца) = 5

<small>c₃ = 6: c₅ = 1, 2, 3, 4, 5</small>

N(c₂ = 5) = 6 · 5 = 30
:::

**Сборка.**

N = 12 + 27 + 30 = 69

**Ответ на задачу:** высоты площадок можно выбрать **69 способами**.

**⚠ Ловушки.**

- Брать пять разных высот, хотя повторы разрешены: c₅ может равняться c₁, c₂ или c₄ — выйдет 24.
- Сложить N(левого столбца) и N(правого столбца) вместо умножения — выйдет 36.
