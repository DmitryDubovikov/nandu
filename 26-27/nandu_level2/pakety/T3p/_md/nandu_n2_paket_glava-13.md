## 13. Прямоугольник сетки — пара вертикалей и пара горизонталей (новый)

[← оглавление учебника](index.html)

Если считают прямоугольники со сторонами на линиях сетки, то прямоугольник — это пара вертикалей и пара горизонталей, и считается выбор номеров линий.

**Условие.** Окно разделено решёткой на четыре ряда по пять квадратных стёкол, и по четырём стёклам наискосок прошла трещина, как на рисунке:

- линии решётки — это планки и края рамы;
- Лусия считает прямоугольники, все стороны которых лежат на линиях решётки;
- квадраты тоже прямоугольники, их тоже считают;
- прямоугольник годится, только если у него нет ни одной общей точки с трещиной: касаться трещины даже углом нельзя.

Сколько таких прямоугольников насчитает Лусия? Объясни, как ты их считал.

**Способ** — прямоугольник: две вертикали и две горизонтали решётки, на которых лежат его стороны.

**Пронумеруем линии:** номер — сколько стёкол от линии до левого края окна (вертикали 0, 1, …, 5) или до нижнего края (горизонтали 0, 1, …, 4).

**Обозначим:** v₁ и v₂ — номера вертикалей левой и правой сторон прямоугольника, h₁ и h₂ — номера горизонталей нижней и верхней сторон.

**Идея.** **С рисунка:** трещина идёт по диагоналям стёкол через узлы, где пересекаются вертикаль и горизонталь с одним номером: 0 и 0, 1 и 1, …, 4 и 4.

Трещина идёт от левого нижнего угла окна до верхнего края ⇒ она делит окно на две части, и прямоугольник без общих точек с трещиной лежит целиком в одной части: выше трещины или ниже.

N = N(выше трещины) + N(ниже трещины)

**1. N(выше трещины).**

Прямоугольник лежит выше трещины, если выше трещины его правый нижний угол: узел вертикали v₂ и горизонтали h₁.

h₁ не больше 3: выше нижней стороны нужна ещё горизонталь для h₂.

**Выпишем по порядку:** v₂ = 1, потом 2, 3, 4, 5; для каждого — узел, где трещина пересекает вертикаль v₂, потом h₁ выше этого узла, потом все прямоугольники.

| v₂ | трещина пересекает вертикаль v₂ в узле | h₁ выше этого узла и не больше 3 | v₁, v₂, h₁, h₂ |
|---|---|---|---|
| 1 | 1 и 1 | 2 или 3 | 0, 1, 2, 3 |
| 1 | 1 и 1 | 2 или 3 | 0, 1, 2, 4 |
| 1 | 1 и 1 | 2 или 3 | 0, 1, 3, 4 |
| 2 | 2 и 2 | 3 | 0, 2, 3, 4 |
| 2 | 2 и 2 | 3 | 1, 2, 3, 4 |
| 3 | 3 и 3 | такого h₁ нет | прямоугольников нет |
| 4, 5 | трещина уже на верхнем крае окна, в узле 4 и 4 | такого h₁ нет | прямоугольников нет |

<small>h₁ = v₂ не годится: тогда правый нижний угол — узел трещины, а касаться трещины даже углом нельзя</small>

**Как устроен список:**

- в каждой строке h₁ больше v₂ ⇒ номера идут по возрастанию: сначала обе вертикали, потом обе горизонтали;
- все четыре номера разные и взяты из пяти номеров 0, 1, 2, 3, 4: h₂ не больше 4;
- строк пять, в каждой нет одного из пяти номеров: сверху вниз нет 4, нет 3, нет 2, нет 1, нет 0.

v₁ < v₂ < h₁ < h₂

Строка 0, 2, 3, 4 на рисунке: номера вертикалей 0 и 2 стоят левее номеров горизонталей 3 и 4.

**Заметим:** строку задают её четыре номера: какие номера — вертикали, а какие — горизонтали, выбирать не надо, два меньших номера — это v₁ и v₂, два больших — h₁ и h₂.

**Значит:** прямоугольник выше трещины — это только выбор четырёх разных номеров из пяти, переставлять нечего.

N(выше трещины) = C(5, 4) = 5

**2. N(ниже трещины).**

Прямоугольник лежит ниже трещины, если ниже трещины его левый верхний угол: узел вертикали v₁ и горизонтали h₂.

При h₂ = 1: горизонталь 1 трещина пересекает в узле 1 и 1 ⇒ левая сторона правее этого узла: v₁ = 2, 3 или 4.

Так при любом h₂: горизонталь h₂ трещина пересекает на вертикали с тем же номером ⇒ v₁ больше h₂, и номера снова идут по возрастанию — теперь сначала обе горизонтали, потом обе вертикали:

h₁ < h₂ < v₁ < v₂

Строка 0, 2, 3, 5 на рисунке: номера горизонталей 0 и 2 стоят левее номеров вертикалей 3 и 5.

**Заметим:** v₂ может быть 5 — это правый столбец, куда трещина не доходит ⇒ четыре разных номера взяты из шести: 0, 1, 2, 3, 4, 5.

<small>h₁ и h₂ меньше v₂, то есть не больше 4: горизонтали h₁ и h₂ на решётке есть</small>

**Значит:** прямоугольник ниже трещины — это только выбор четырёх разных номеров из шести.

Четыре номера из шести — это шесть номеров без двух.

**Выпишем по порядку** два номера, которых в четвёрке нет: меньший из двух равен 0, потом 1, 2, 3, 4.

| меньший номер, которого нет | больший номер, которого нет | строк |
|---|---|---|
| 0 | 1, 2, 3, 4, 5 | 5 |
| 1 | 2, 3, 4, 5 | 4 |
| 2 | 3, 4, 5 | 3 |
| 3 | 4, 5 | 2 |
| 4 | 5 | 1 |

<small>первая группа, h₁, h₂, v₁, v₂: нет 0 и 1: 2, 3, 4, 5   нет 0 и 2: 1, 3, 4, 5   нет 0 и 3: 1, 2, 4, 5   нет 0 и 4: 1, 2, 3, 5   нет 0 и 5: 1, 2, 3, 4</small>

**Как устроен список:** больший номер, которого нет, стоит только после меньшего ⇒ каждая группа на 1 короче предыдущей.

N(ниже трещины) = C(6, 4) = 5 + 4 + 3 + 2 + 1 = 15

**Сборка.**

N = 5 + 15 = 20

**Ответ на задачу:** Лусия насчитает **20 прямоугольников**, у которых нет ни одной общей точки с трещиной.

**⚠ Ловушки.**

- Считать годным прямоугольник, который касается трещины только углом: выйдет 50.
- Забыть правый столбец, куда трещина не доходит, и ниже трещины тоже взять C(5, 4): выйдет 10.
- Не считать квадраты: выйдет 10.
