## Шаг 1 — страница приёмов (пишешь сам, это единственное, что я читаю)

4. **Какие приёмы:** все приёмы, которые встречаются в решениях корпуса этого типа, не только в образце. Для каждого
   посчитай, в скольких задачах корпуса он работает; порядок на странице — от частых к редким (сначала приёмы записи
   или подсчёта, потом приёмы решения, если тип так делится). **Число задач на страницу не пишется** — оно идёт мне
   в ответ сессии. Новые приёмы (🆕 из этапа В) — тоже на странице, с пометкой «новый» в заголовке приёма: я принимаю
   их, читая страницу.
   **Порядок страницы** (решения родителя 3.11.2026). **Шапка уже заведена** у всех 17 типов — не трогать, дописывать
   под ней:
   1) `# <код> — <название>` и определение одной строкой — из раздела «Названия типов»
   `nandu_n2_tipologia_svodnaya.md`, дословно;
   2) `<small>**Боевые задачи (N):** …</small>` — все задачи корпуса этого типа, одной строкой мелким шрифтом, без ссылок:
   только источник (`нац 2024 I №1`), без сюжета, «(+тип)» у гибрида, «— образец» у образца. Решение родителя:
   связь «тип → его боевые задачи» хранится и здесь; условий на странице нет (правило 1). Перенос задачи между типами
   в CSV — правка этой строки у обоих типов;
   3) `**Образец решения:** [источник: сюжет](../../idealnye_resheniya/fazaN/<страница>.html)`;
   4) приёмы — `## Приёмы …`, каждый приём — заголовок `### N. имя`;
   5) `## Задачи пакета` — ссылки на страницы задач 30/50/70 % и условий на опознание, у задачи — какие приёмы она
   тренирует. **Никакой кухни** (кроме строки 2): ни строки о том, как устроена страница, откуда числа, сколько задач
   в корпусе, «примеры не из задач» — каждая строка учит решать («Ты писал текст просто для того, чтобы написать текст»).
5. **Строка приёма:** «что видно в выписанных примерах → первая формула · имя приёма». Признак описывает устройство
   задачи, а не сюжет. Имя и запись — как в реестре §5 и в решениях. У переборных типов (Т3, Т3′, Т3″, Т3‴, Т1″, Т1‴,
   Т4, Т4′, Т5, Т6) первая строка страницы — «выпиши 3–5 примеров и посмотри, что повторяется». Где строка без примера
   непонятна — пример на числах, **не из корпуса** (правило 1), одной-двумя строками.
6. **Объём** — ориентир А4, не рамка: сколько нужно, чтобы уместить приёмы типа. Без разборов и болтовни: страница
   учится наизусть, на туре ничего не открывается.
7. Файл — `26-27/nandu_level2/pakety/<код>/<код>_stranica.md`.

## Шаг 2 — задачи уменьшенного масштаба (субагенты, по одному на задачу, до 10 параллельно)

8. **Что такое масштаб:** приём тот же, что в боевой задаче корпуса, урезан только объём счёта. 30 % — решается минут
   за 15 без сложных вычислений; 50 % — между; 70 % — почти боевая. Задачи распредели по приёмам страницы: частые
   приёмы — первыми, каждый приём страницы хотя бы в одной задаче или условии на опознание, если хватает числа.
8а. **Разнообразие — как у боевых задач типа** (решение родителя 3.11.2026). Перед раздачей субагентам разложи боевые
   задачи из шапки страницы на группы по устройству (что неизвестно, какого рода данные, какие приёмы работают;
   по решениям корпуса типа) — для себя, без паузы и без показа мне. Задачи 30/50/70 % вместе покрывают **каждую
   группу и каждый приём страницы**; доля группы среди задач пакета — примерно как её доля среди боевых. Если для
   этого числа из роадмапа мало — задач больше, по одной на непокрытую группу; число в роадмапе поправь.
9. **Сюжеты новые:** не из корпуса второго уровня (он бережётся для боя) и не из корпуса первого (ребёнок его решал);
   два элемента пакета с одним сюжетом — дефект.
10. **Бриф субагенту:** полные пути к образцу типа и к решению корпуса с тем же приёмом (с него и уменьшать); приём и
    уровень; пункты 8–9 дословно; CHECKLIST. Решение — **в форме идеального образца типа, копируя его максимально**
    (как пункт 4 промпта этапа В). Номер задачи — `<код>-<уровень>-<№>`: `T1-30-1`, `T1-50-1`, `T1-70-1`.
11. **Проверка:** отдельный агент решает по одному условию; ответ сверяется перебором программой. Расхождение или
    двусмысленность — задача переписывается. Перебор быстрее приёма — задача не годится (выпуклость), заменить.
12. Файлы — `pakety/<код>/_md/<номер>.md` (+ `.vis.json`, `vis/<номер>.py`, если рисунок).
