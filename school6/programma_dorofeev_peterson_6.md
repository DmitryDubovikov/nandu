# Математика. 6 класс. Дорофеев Г.В., Петерсон Л.Г. — программа (оглавление)

Учебник в 3 частях, изд. 2010, курс «Учусь учиться».

⚠ Нумерация глав **сквозная через все три части**: часть 2 продолжает главу 2, часть 3 — главу 3. Делить курс по границам частей = резать главу посередине.

3. Отрицание высказываний о существовании

**§ 2. Переменная**

2. Предложения с переменными

4. Отрицание утверждений с кванторами

**§ 1. Числа и действия с ними**

**§ 2. Проценты**
1. Понятие о проценте

## Структура курса одной строкой

Логика → арифметика (проценты, пропорции) → рациональные числа → уравнения и координаты → геометрия. Логика вынесена в отдельную сквозную линию (отрицания, кванторы, следование), а не разлита по темам.
