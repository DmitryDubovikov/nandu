П10.2. Лента кратных трём

Национал — практика: разборы

Условие. Пепа выписывает подряд, без пробелов, все числа от 1 до 200, которые делятся на 3. Начало ленты выглядит так:

3691215182124…

и заканчивается лента числом 198.

а) Сколько цифр Пепа написала всего?

б) Какая цифра стоит на 120-м месте ленты?

в) Сколько раз в ленте встречается цифра 0? Объясни, почему ты нашёл все нули и почему их не больше.

Шаг 0 — разрезка: как устроена лента.

Один вопрос — одна работа с лентой, и во всех трёх пунктах сначала надо понять её устройство. Лента склеена из чисел разной длины, поэтому режем её на куски по количеству цифр.

💬 «Лента режется на куски по количеству цифр: они не пересекаются и покрывают всё» — это и есть мысль для фразы-объяснения.

Кратные трём от 1 до 200 — это цепочка 3, 6, 9, 12, …, 198 с шагом 3. Всего чисел: (198 − 3) : 3 + 1 = 66.

✅ План готов.

Ответ(а) = N(цифр однозначных) + N(цифр двузначных) + N(цифр трёхзначных)

Ответ(б) = цифра, найденная по таблице кусков

Ответ(в) = N(нулей в единицах) + N(нулей в десятках)

Буквы: N(цифр однозначных) — сколько цифр в куске из однозначных кратных трём; N(цифр двузначных) — то же для двузначных; N(цифр трёхзначных) — для трёхзначных; N(нулей в единицах) — сколько в ленте нулей в разряде единиц; N(нулей в десятках) — сколько нулей в разряде десятков.

Осталось найти: N(цифр однозначных), N(цифр двузначных), N(цифр трёхзначных) (а вместе с ними и накопленный итог, по которому идёт навигация в пункте б), затем N(нулей в единицах) и N(нулей в десятках).

Шаг 1 — считаю длину ленты (пункт a). Нужно число цифр всей ленты — для этого считаю цифры в каждом куске отдельно и складываю:

КусокКакие числаСколько чиселЦифр в кускеНакопленный итог
однозначные3, 6, 933 · 1 = 33
двузначные12, 15, …, 99(99 − 12) : 3 + 1 = 3030 · 2 = 6063
трёхзначные102, 105, …, 198(198 − 102) : 3 + 1 = 3333 · 3 = 99162

Проверка чисел: 3 + 30 + 33 = 66 — ровно столько кратных трём мы и насчитали цепочкой. Значит, ни одно число не потерялось и ни одно не посчитано дважды.

Складываю по формуле плана:

N(цифр однозначных) + N(цифр двузначных) + N(цифр трёхзначных) = 3 + 60 + 99 = 162

Ответ a: 162 цифры.

Шаг 2 — нахожу цифру на 120-м месте (пункт b). Нужна одна цифра — для этого сначала определяю, в каком куске сидит место 120, а потом ныряю внутрь этого куска:

  • смотрим накопленный итог: однозначные и двузначные кончаются на месте 63 → место 120 глубже — оно внутри куска трёхзначных;
  • сколько мест пройдено внутри куска → 120 − 63 = 57;
  • трёхзначные идут порциями по 3 цифры, делим с остатком полной строкой → 57 = 3 · 19 + 0;
  • остаток 0 — это последняя цифра 19-го трёхзначного числа, а не первая цифра двадцатого → ищем 19-е трёхзначное кратное трём;
  • 19-е число цепочки 102, 105, …: первое число — это само 102, до девятнадцатого от него ровно 18 шагов по 3 (на один шаг меньше, чем номер) → 102 + 3 · 18 = 156;
  • берём его последнюю цифру → 6.

Проверка на маленьком месте: место 65. Это 65 − 63 = 2 внутри куска, 2 = 3 · 0 + 2 → вторая цифра первого трёхзначного числа, то есть вторая цифра 102 — ноль. Выпишем стык руками: … 96 99 102 … — места 60, 61 заняты «96», 62, 63 — «99», дальше 64, 65, 66 — «102». На 65-м действительно ноль ✓. Формула работает.

Ответ b: 6.

Шаг 3 — считаю нули (пункт c). Нужно число нулей во всей ленте — для этого считаю их по разрядам, в которых ноль вообще может стоять.

Ноль в ленте берётся только из самих чисел, поэтому считаем не по ленте, а по числам. У кратного трём числа ноль может сидеть в двух разрядах: в единицах или в десятках (в старшем разряде нуля не бывает — с нуля число не начинается).

  • нули в единицах: число кратно 3 и оканчивается на 0, значит кратно 30 → цепочка 30, 60, 90, 120, 150, 180 — шаг 30;
  • сколько их до 200 → (180 − 30) : 30 + 1 = 6, то есть N(нулей в единицах) = 6;
  • нули в десятках: у двузначных десятки — это старший разряд, там нуля нет; значит, ищем только среди трёхзначных вида «1 0 _» и «2 0 _» → у нас трёхзначные идут только до 198, поэтому вид «2 0 _» отпадает целиком;
  • перебираем сотню от 100 до 109 и отбираем кратные трём → 102, 105, 108, то есть N(нулей в десятках) = 3;
  • может ли число попасть в оба списка сразу (два нуля)? → это было бы число вида «_ 0 0», то есть 100 или 200 — ни одно не кратно 3; пересечения нет;
  • складываем по формуле плана → N(нулей в единицах) + N(нулей в десятках) = 6 + 3 = 9 нулей.

Ответ c: 9.

Полнота письменно. Каждый ноль ленты стоит либо в разряде единиц какого-то числа, либо в разряде десятков — третьего места для него нет, потому что старшая цифра числа нулём не бывает. Нули в единицах — это ровно числа, кратные и 3, и 10, то есть кратные 30; их цепочка 30, 60, 90, 120, 150, 180 выписана целиком и следующее, 210, уже больше 200. Нули в десятках у двузначных невозможны (там десятки — старший разряд), а у трёхзначных до 200 они бывают только в числах от 100 до 109; кратные трём среди них — 102, 105, 108, и эта десятка проверена вся. Ни одно число не попало в оба списка, потому что для этого ему пришлось бы кончаться на два нуля, а 100 и 200 на 3 не делятся. Значит, нулей ровно 6 + 3 = 9: ни одного лишнего и ни одного потерянного.

💬 «Это все случаи: они не повторяют друг друга и ни один не потерян» — это и есть мысль для фразы-полноты.

Пересчёт вторым способом. Соберём те же нули не по разрядам, а по числам: ноль есть в записи чисел 30, 60, 90, 102, 105, 108, 120, 150, 180 — девять чисел, и в каждом ровно по одному нулю. 9 ✓.

Ответ. а) 162 цифры. б) 6. в) 9 нулей.

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится.

💬 Фраза-объяснение (в начале)

Separé los casos según la cantidad de cifras: no se superponen y cubren todo, por eso los sumo.

Разрезал на случаи по количеству цифр: они не пересекаются и покрывают всё, поэтому складываю.

Запись

  • N(цифр однозначных), N(цифр двузначных), N(цифр трёхзначных) — цифры в кусках из одно-, дву- и трёхзначных
  • N(нулей в единицах), N(нулей в десятках) — нули в разряде единиц и десятков

✅ План:

Ответ(а) = N(цифр однозначных) + N(цифр двузначных) + N(цифр трёхзначных)
Ответ(в) = N(нулей в единицах) + N(нулей в десятках)
  • чисел в ленте: (198 − 3) : 3 + 1 = 66
  • N(цифр однозначных) = 3 · 1 = 3
  • N(цифр двузначных) = 30 · 2 = 60, где (99 − 12) : 3 + 1 = 30
  • N(цифр трёхзначных) = 33 · 3 = 99, где (198 − 102) : 3 + 1 = 33
Ответ(а) = 3 + 60 + 99 = 162
  • куски кончаются на месте 3 + 60 = 63, дальше 120 − 63 = 57
  • 57 = 3 · 19 + 0 → последняя цифра 19-го трёхзначного
  • 102 + 3 · 18 = 156
Ответ(б) = 6
  • N(нулей в единицах): кратные 30 → 30, 60, 90, 120, 150, 180 → N(нулей в единицах) = 6
  • N(нулей в десятках): трёхзначные от 100 до 109 → 102, 105, 108 → N(нулей в десятках) = 3
  • пересечения нет: 100 и 200 на 3 не делятся
Ответ(в) = 6 + 3 = 9

💬 Фраза в конце — полнота

Estos son todos los casos: no se repiten entre sí y no queda ninguno afuera.

Это все случаи: они не повторяют друг друга и ни один не потерян.

Проверка вторым способом

Полный перебор подтверждает:

  • чисел в ленте 66 — совпало с цепочкой (198 − 3) : 3 + 1;
  • а) длина ленты 162 — совпала с таблицей кусков 3 + 60 + 99;
  • б) на 120-м месте стоит 6 — совпало с ручной навигацией «57 = 3 · 19 + 0 → последняя цифра числа 156»;
  • в) нулей 9, и список чисел с нулём — [30, 60, 90, 102, 105, 108, 120, 150, 180] — ровно тот же, что в ручном разборе по разрядам (6 кратных 30 и 3 числа сотни 100–109).

Дополнительно проверено, что позиция 65 действительно занята нулём — это была проверка формулы на маленьком месте.
