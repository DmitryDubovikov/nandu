П5.1. Ступенька с крышей

Национал — практика: разборы

Условие. Нарисуй прямоугольник ABCH: A — левый низ, B — правый низ, C — правый верх, H — левый верх; сам прямоугольник широкий и низкий.

На стороне HC отметь точку D, на стороне AB — точку G ровно под D; проведи отрезок GD. Он делит прямоугольник ABCH на два прямоугольника: AGDH слева и GBCD справа.

На отрезке HD, как на нижней стороне, построй вверх прямоугольник HDEF: E — над D, F — над H.

На стороне FE построй равнобедренный треугольник FPE с вершиной P (FP = PE), направленный вверх, наружу от фигуры.

Вся фигура — это прямоугольник ABCH вместе с прямоугольником HDEF и треугольником FPE; её контур идёт A → B → C → D → E → P → F → A.

Известно:

  • периметр AGDH = 122 см
  • периметр GBCD = 98 см
  • периметр ABCDEF (контур A → B → C → D → E → F → A, то есть фигура без крыши) = 250 см
  • периметр треугольника FPE = 96 см
  • DE = 5/3 · CD

Вопросы:

а) Чему равен периметр прямоугольника HDEF? б) Чему равен периметр прямоугольника ABCH? в) Чему равен периметр всей фигуры (контур A → B → C → D → E → P → F → A)?

Этап 1 — перевод.

Раскладка: нижний этаж ABCH разрезан вертикалью GD на два прямоугольника; на левом из них стоит верхний прямоугольник HDEF; на нём — крыша FPE. Правая часть — ступенька: над GBCD ничего нет.

Кирпичики: x = AG = HD = FE (ширина левой колонны), y = GB = DC (ширина ступеньки), u = AH = GD = BC (высота нижнего этажа), v = HF = DE (высота верхнего), t = FP = PE (боковая сторона крыши).

Заметь главное

Контур ABCDEF идёт ступенькой, но горизонтальные его куски в сумме дают полную ширину дважды: AB — это x + y, а верхние EF и CD — те же x и y по отдельности. С вертикалями то же самое: BC — это u, DE — это v, а FA идёт сквозь H и стоит u + v. Значит, 250 — это ровно периметр прямоугольника, в который вписана ступенька:

2(x + y) + 2(u + v) = 250
x + y + u + v = 125

И собран этот прямоугольник из тех же кирпичиков, что оба данных этажа, — потому их и можно из него вычесть.

Периметр фигуры буду писать значком P(…): в скобках — имя фигуры или обход контура по буквам. Например, P(FPE) = 96 — это периметр треугольника FPE, а P(ABCDEF) = 250 — длина контура A → B → C → D → E → F → A.

Что даноЧто записываем
P(AGDH) = 122x + u = 61
P(GBCD) = 98y + u = 49
DE = 5/3 · CDv = (5/3)·y
P(ABCDEF) = 250: AB (x + y), BC (u), CD (y), DE (v), EF (x), FA — сквозь H (u + v)x + y + u + v = 125
P(FPE) = 96: основание FE (x) и две боковыеx + 2t = 96

✅ Результат перевода

x + u = 61
y + u = 49
v = (5/3)·y
x + y + u + v = 125
x + 2t = 96

x = AG = HD = FE; y = GB = DC; u = AH = GD = BC; v = HF = DE; t = боковая сторона крыши.

Этап 2 — решение.

Шаг 1 — план: свести систему к одной неизвестной. Все три вопроса — это периметры, а периметр собирается из кирпичиков; значит, вся работа в том, чтобы добыть x, y, u, v и t. Неизвестных пять, перебирать их вместе незачем: два первых уравнения выражают x и y через u, пропорция выражает v через y, а пятое уравнение отдаёт t, как только известно x. Остаётся добыть саму u.

✅ План готов: Ответ = три периметра, собранные из кирпичиков x, y, u, v, t, а все кирпичики — из одной неизвестной u.

Шаг 2 — считаю u. Нужна та единственная неизвестная, с которой пойдёт цепочка, — для этого вычитаю контуры: из четвёртого уравнения вычти первое и второе:

(x + y + u + v) − (x + u) − (y + u) = 125 − 61 − 49 → v − u = 15.

Значит v = u + 15. А из второго уравнения y = 49 − u, и пропорция даёт v = (5/3)(49 − u). Приравниваю:

u + 15 = (5/3)(49 − u) → 3u + 45 = 245 − 5u → 8u = 200 → u = 25.

Шаг 3 — считаю остальные кирпичики. Нужны все размеры, а u уже известна — дальше всё по цепочке, по одному кирпичику на строку:

  • y = 49 − 25 = 24
  • v = 25 + 15 = 40
  • x = 61 − 25 = 36
  • t = (96 − 36) : 2 = 30

Шаг 4 — сборка: три периметра. Кирпичики на руках — остаётся обойти карандашом каждую фигуру из вопросов.

а) P(HDEF) = 2·(x + v) = 2·(36 + 40) = 152 см.

б) ABCH: ширина AB = x + y = 60, высота = u = 25 → P(ABCH) = 2·(60 + 25) = 170 см.

в) Вся фигура: AB (60) + BC (25) + CD (24) + DE (40) + EP (30) + PF (30) + FA (25 + 40 = 65) → P(ABCDEPF) = 274 см.

Ответ. а) 152 см б) 170 см в) 274 см

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится.

Запись

Кирпичики:

  • x = AG = HD = FE
  • y = GB = DC
  • u = AH = GD = BC
  • v = HF = DE
  • t = FP = PE

✅ План:

Ответ(а) = P(HDEF) = 2 · (x + v)
Ответ(б) = P(ABCH) = 2 · (x + y + u)
Ответ(в) = P(ABCDEPF) = (x + y) + u + y + v + 2t + (u + v)
  • P(AGDH) = 122 → x + u = 61
  • P(GBCD) = 98 → y + u = 49
  • P(ABCDEF) = 250 → x + y + u + v = 125
  • DE = 5/3 · CD → v = 5/3 · y
  • P(FPE) = 96 → x + 2t = 96
  • третье минус первое минус второе → v − u = 15
  • u + 15 = 5/3 · (49 − u) → 8u = 200 → u = 25
  • y = 24
  • v = 40
  • x = 36
  • t = 30
P(HDEF) = 2 · (36 + 40) = 152
P(ABCH) = 2 · (60 + 25) = 170
P(ABCDEPF) = 60 + 25 + 24 + 40 + 30 + 30 + 65 = 274

Проверка сложением:

  • 2 · (36 + 25) = 122 ✓
  • 2 · (24 + 25) = 98 ✓
  • 60 + 25 + 24 + 40 + 36 + 65 = 250 ✓
  • 36 + 30 + 30 = 96 ✓

Проверка вторым способом

Подставляю найденные размеры обратно во все данные:

  • P(AGDH) = 2·(36 + 25) = 122 ✓
  • P(GBCD) = 2·(24 + 25) = 98 ✓
  • DE = 5/3 · CD: 5/3 · 24 = 40 ✓
  • P(ABCDEF) = 60 + 25 + 24 + 40 + 36 + 65 = 250 ✓
  • P(FPE) = 36 + 30 + 30 = 96 ✓

Другой путь к тем же числам (без вычитания контуров): из первых двух уравнений x = 61 − u и y = 49 − u, значит x − y = 12; подставляю x, y, v = (5/3)(49 − u) в четвёртое: (61 − u) + (49 − u) + u + (5/3)(49 − u) = 125 → 110 − u + (245 − 5u)/3 = 125 → 330 − 3u + 245 − 5u = 375 → u = 25 — то же самое.

Проверка ответа (в): фигура без крыши даёт 250, крыша заменяет верхнюю сторону FE (36) на две боковые (30 + 30 = 60), то есть периметр растёт на 60 − 36 = 24: 250 + 24 = 274 ✓.

Проверка, что такая крыша вообще рисуется: основание FE = 36, половина основания — 18, а скат 30. Скат длиннее половины основания, значит два ската встречаются над серединой FE и крыша сходится в вершину. Будь скат короче 18, они не дотянулись бы друг до друга.
