П2.2. Английский и португальский

Национал — практика: разборы

Условие

В школе 840 учеников. Три четверти всех учеников изучают английский язык. Две пятых всех учеников изучают португальский язык. Есть ученики, которые изучают оба языка, и есть те, кто не изучает ни одного. Учеников, которые не изучают ни одного из этих двух языков, вдвое меньше, чем тех, кто изучает только португальский.

а) Сколько учеников изучают английский и сколько — португальский?

б) Сколько учеников не изучают ни одного из этих двух языков?

в) Сколько учеников изучают оба языка?

г) Сколько учеников изучают ровно один из двух языков?

Вопросов четыре — подчеркни все.

Шаг 1 — считаю, сколько человек в каждом языке (вопрос а). Нужны два числа изучающих — для этого беру от 840 обе доли:

Язык и доляСколько учеников
английский: три четверти от 840840 · 3/4 = 630
португальский: две пятых от 840840 · 2/5 = 336

Оба числа — это ответ а): английский изучают 630 учеников, португальский — 336.

Оба числа получились целыми — так и должно быть, это ученики, половинок тут не бывает. Вышла бы дробь — я бы вернулся и перечитал, от чего берётся доля.

Шаг 2 — план: полоска из четырёх зон. Оставшиеся три вопроса — про пересечение языков, и чтобы никого не посчитать дважды, нужна картинка, где каждый ученик занимает ровно одно место. Рисую полоску и подписываю на ней четыре зоны: «только английский», «оба», «только португальский», «ни одного». Каждый ученик школы попадает ровно в одну зону — ни в две, ни в ноль. Поэтому четыре зоны в сумме дают 840, и никто не посчитан дважды.

💬 «Кто учит оба языка, попал бы в оба счёта — значит, его считают дважды» — это и есть мысль для фразы-объяснения.

Обозначим n — сколько человек в зоне «ни одного». Тогда в зоне «только португальский» их вдвое больше, то есть 2n. Две оставшиеся зоны теперь тоже выражаются через n — значит, всё держится на одной неизвестной.

Число людей в зоне буду писать значком N(…): в скобках — название зоны, а всё вместе читается «сколько человек в этой зоне». Например, N(ни одного) = n, а N(только португальский) = 2n.

✅ План готов.

Ответ(б) = N(ни одного) = n

Ответ(в) = N(оба) при найденном n

Ответ(г) = N(только английский) + N(только португальский)

Буквы: n — сколько человек в зоне «ни одного»; тогда «только португальский» — это 2n, а две оставшиеся зоны я выражу через n на следующем шаге.

Осталось найти: n — из равенства «четыре зоны дают 840».

Шаг 3 — считаю n (вопрос б). Нужна зона «ни одного» — для этого выражаю через n все четыре зоны и складываю их:

  • португальский = «только португальский» + «оба» → N(оба) = 336 − 2n;
  • английский = «только английский» + «оба» → N(только английский) = 630 − (336 − 2n) = 294 + 2n;
  • все четыре зоны дают школу → (294 + 2n) + (336 − 2n) + 2n + n = 840;
  • привожу подобные → 630 + 3n = 840 → 3n = 210;
  • делю → n = 70.

→ Ни одного языка не изучают 70 учеников.

Шаг 4 — считаю остальные зоны (вопрос в). Нужна зона «оба», а заодно понадобятся и две крайние — подставляю n = 70:

  • N(оба) = 336 − 2 · 70 = 196;
  • N(только португальский) = 2 · 70 = 140;
  • N(только английский) = 630 − 196 = 434.

→ Оба языка изучают 196 учеников.

Шаг 5 — сборка (вопрос г). «Ровно один» — это две зоны полоски: только английский и только португальский. Тех, кто в середине, брать нельзя.

434 + 140 = 574. Ровно один язык изучают 574 ученика.

Ответ. а) Английский — 630, португальский — 336. б) 70. в) 196. г) 574.

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится.

💬 Фраза-объяснение (в начале)

Los que están en los dos grupos los conté dos veces, así que los resto una vez.

Тех, кто попал в обе группы, я посчитал дважды — поэтому вычитаю их один раз.

Запись

  • n — сколько человек в зоне «ни одного»
  • N(…) — сколько человек в названной зоне

✅ План:

Ответ(б) = n
Ответ(в) = N(оба)
Ответ(г) = N(только английский) + N(только португальский)
  • N(английский) = 840 · 3/4 = 630
  • N(португальский) = 840 · 2/5 = 336
  • N(только португальский) = 2n
  • N(оба) = 336 − 2n
  • N(только английский) = 630 − (336 − 2n) = 294 + 2n
  • (294 + 2n) + (336 − 2n) + 2n + n = 840 → 3n = 210 → n = 70
  • N(оба) = 336 − 140 = 196
  • N(только английский) = 630 − 196 = 434
434 + 140 = 574

Проверка:

  • 434 + 196 + 140 + 70 = 840 ✓
  • 840 − 70 − 196 = 574 ✓

Проверка вторым способом

Считал я через уравнение с одной буквой. Проверяю прямым заполнением полоски и вторым, независимым подсчётом «ровно одного»:

ЗонаУчеников
только английский434
оба196
только португальский140
ни одного70
всего434 + 196 + 140 + 70 = 840 ✓

Сверяю с условиями:

  • английский: 434 + 196 = 630 — ровно три четверти от 840 ✓
  • португальский: 140 + 196 = 336 — ровно две пятых ✓
  • «ни одного» 70, «только португальский» 140, и 140 = 2 · 70 ✓

«Ровно один» вторым способом: хотя бы один язык изучают 840 − 70 = 770; из них надо выбросить тех, кто изучает оба: 770 − 196 = 574 ✓ — совпало с суммой двух крайних зон.
