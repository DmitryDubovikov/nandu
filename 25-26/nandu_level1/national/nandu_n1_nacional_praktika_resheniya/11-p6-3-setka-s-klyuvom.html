П6.3. Сетка с клювом

Национал — практика: разборы

Условие. Нарисуй прямоугольник MNPQ: M — левый низ, N — правый низ, P — правый верх, Q — левый верх.

На стороне MN отметь точку R, на стороне QP — точку S ровно над R; проведи отрезок RS. Он делит прямоугольник на левую часть MRSQ и правую часть RNPS.

Левая часть MRSQ разрезана на шесть равных деталей A: два столбца и три строки. Точка V — там, где нижняя горизонтальная линия этой сетки упирается в сторону QM (то есть MV — высота одной детали A).

Правая часть RNPS разрезана горизонтальными отрезками на четыре равные детали B, поставленные стопкой.

K — середина стороны NP. На отрезке KP снаружи прямоугольника построен равнобедренный треугольник KTP (KT = TP), вершина T смотрит вправо. Треугольник — часть фигуры.

Контур всей фигуры идёт M → N → K → T → P → Q → M.

Известно:

  • периметр детали B = 108 см
  • 2 · RN = 3 · MV
  • периметр прямоугольника MNPQ = 296 см
  • периметр треугольника KTP = 96 см

Вопросы:

а) Чему равен периметр детали A? б) Чему равен периметр левой части MRSQ? в) Чему равен периметр всей фигуры (контур M → N → K → T → P → Q → M)?

Этап 1 — перевод.

Раскладка: прямоугольник MNPQ разрезан сквозной вертикалью RS. Слева сетка 2 × 3 из одинаковых деталей A, справа стопка из четырёх одинаковых деталей B. Снаружи, на верхней половине правой стороны, сидит треугольник-клюв KTP.

Кирпичики: a = ширина A, h = высота A (это и есть MV), b = ширина B (это RN), c = высота B, t = боковая сторона клюва.

Заметь главное

Отрезок RS идёт от нижней стороны до верхней насквозь — значит, левая и правая части кончаются на одном уровне и высота у них одна и та же. Слева эту высоту набирают три ряда деталей A, справа — четыре детали B:

3·h = 4·c

Только через это равенство высота детали B и попадает в левую часть фигуры: больше нигде c не стоит рядом с буквами левой сетки. Не заметишь его — периметр детали B так и останется числом про правую часть и ничего не скажет про деталь A.

P(B) = 108: ширина b, высота cb + c + b + c = 108

b + c + b + c = 108
2·b = 3·h
(2a + b) + 3h + (2a + b) + 3h = 296
KP + t + t = 96
KP = (3·h)/2

a = ширина A; h = высота A = MV; b = ширина B = RN; c = высота B; t = боковая сторона клюва.

Этап 2 — решение.

Сначала укорачиваю уравнения, полученные обходом. И деталь B, и прямоугольник MNPQ — прямоугольники, а у прямоугольника обход состоит из двух одинаковых кусков «ширина + высота», поэтому оба уравнения делю пополам:

b + c = 54
2a + b + 3h = 148

Основание клюва KP — половина правой стороны, и его уравнение короче не станет:

KP + 2t = 96
Заметь главное

Посмотри, что известно про высоту A, ширину B и высоту B: 2·b = 3·h и 3·h = 4·c — во сколько раз они друг друга больше, сказано, а сколько это в сантиметрах — нет ни у одной. Такие три размера всегда меряются одной общей меркой: выбери её достаточно мелкой, и каждый из них станет целым числом мерок — дроби из уравнений исчезнут, а неизвестная останется одна, сама мерка. А сантиметры мерке даст единственное данное с настоящим числом — периметр детали B. Какую именно мерку брать — видно из самих уравнений, этим и займусь дальше.

Шаг 1 — план: раздроби кирпичик. Три вопроса — три периметра из кирпичиков a, h, b, c, t. Сначала посмотри, какие дроби вылезут, если всё выражать через высоту детали A: из «2·b = 3·h» ширина B — это полторы высоты A, а из «3·h = 4·c» высота B — три четверти высоты A. Самая мелкая доля здесь четверть, её и беру: пусть k — четверть высоты детали A, то есть h = 4k. Тогда обе дроби превращаются в целые числа долек:

  • из «2·b = 3·h»: b = (3/2)·h = 6k;
  • из «3·h = 4·c»: c = (3/4)·h = 3k.

✅ План готов: Ответ = три периметра, собранные из кирпичиков a, h, b, c, t, а все кирпичики — из одной дольки k.

Шаг 2 — считаю дольку k. Нужна та единственная мерка, через которую записаны все размеры высот и ширин правой части, — для этого подставляю дольки в периметр детали B: 6k + 3k = 54 → 9k = 54 → k = 6.

Шаг 3 — считаю остальные кирпичики. Нужны настоящие размеры в сантиметрах, а долька уже известна — перевожу каждый размер по одному на строку:

  • h = 4k = 24
  • b = 6k = 36
  • c = 3k = 18
  • высота фигуры = 3 · 24 = 72 (проверка по правой части: 4 · 18 = 72 ✓)

Ширины A ещё нет — её отдаёт периметр MNPQ, в который она входит дважды:

2a + 36 + 72 = 148 → 2a = 40 → a = 20.

Тогда вся ширина фигуры:

MN = 2 · 20 + 36 = 76.

Осталась боковая сторона клюва. Его основание KP — половина правой стороны, то есть 72 : 2 = 36:

36 + 2t = 96 → t = 30.

Шаг 4 — сборка: три периметра. Кирпичики на руках — остаётся обойти карандашом каждую фигуру из вопросов.

а) Деталь A = 20 × 24 → P(A) = 2·(20 + 24) = 88 см.

б) MRSQ: ширина 2 · 20 = 40, высота 72 → P(MRSQ) = 2·(40 + 72) = 224 см.

в) Контур: MN (76) + NK (36) + KT (30) + TP (30) + PQ (76) + QM (72) → P(MNKTPQ) = 320 см.

Ответ. а) 88 см б) 224 см в) 320 см

Проверка вторым способом

  • P(B) = 2·(36 + 18) = 108 ✓

Другой путь к ответу (в): возьми P(MNPQ) = 296 и замени верхнюю половину правой стороны (KP = 36) двумя сторонами клюва (30 + 30 = 60): 296 − 36 + 60 = 320 ✓.

Ответ (б) проверяю ещё раз через детали: левая часть — шесть деталей 20 × 24, значит 40 в ширину и 72 в высоту, периметр 224 ✓ (а сумма шести периметров деталей — 6 · 88 = 528 — к делу отношения не имеет: внутренние стыки в контур не входят).

Проверка, что клюв рисуется: основание KP = 36, половина основания — 18, а боковая сторона 30. Боковая длиннее половины основания, значит обе боковые встречаются напротив середины KP и клюв сходится в вершину T.
