5.3 — ответ: 14 способов; наибольшее число на доске 16

Шаг 1 — план счёта. Сумма любых трёх подряд идущих клеток равна 24, а соседние тройки отличаются только клеткой на каждом конце — значит клетка через три равна самой себе. Период 3 работает здесь в обе стороны: по строке 10 столбцов повторяют первые три ещё трижды с хвостом, а по столбцу 4-я строка равна 1-й.

Поэтому вся доска описывается девятью клетками — квадратом 3×3 из первых трёх строк и первых трёх столбцов. Называю клетку по строке и по номеру столбца в тройке: верхняя строка — t₁, t₂, t₃; вторая — m₁, m₂, m₃; третья — n₁, n₂, n₃. Четвёртая строка повторяет первую.

Данные ложатся на эти клетки по остатку номера столбца при делении на 3. Остаток я записываю значком res(…): res(2 : 3) = 2, потому что 2 = 3 · 0 + 2; так же res(4 : 3) = 1 и res(5 : 3) = 2. Само деление по-прежнему пишу полной строкой (ритуал Ч2), а res(…) только называет уже добытый остаток коротко.

Столбец 2 — второй в тройке, столбец 4 — тот же, что 1-й, столбец 5 — тот же, что 2-й. Значит семёрка стоит в t₂, шестёрка — в m₁, восьмёрка — в n₂:

верх: (t₁, 7, t₃)
вторая: (6, m₂, m₃)
третья: (n₁, 8, n₃)

И строки, и столбцы этого квадрата 3×3 — тройки подряд идущих клеток, поэтому каждая обязана дать 24.

✅ План готов: всё через x = t₁:

N(заполнений) = длина диапазона x
max(число на доске) = наибольшее из значений всех клеток на краях диапазона

Шаг 2 — сначала то, что определено однозначно. Нужно уменьшить число неизвестных — беру линию, где известны сразу две клетки. Это средний столбец: в нём стоят 7 и 8.

7 + m₂ + 8 = 24, значит m₂ = 9

Теперь вторая строка знает две свои клетки:

6 + 9 + m₃ = 24, значит m₃ = 9

Шаг 3 — выражаю остальное через x. Зову t₁ = x и иду по линиям, в каждой из которых осталась одна неизвестная. Верхняя строка:

x + 7 + t₃ = 24, значит t₃ = 17 − x

Первый столбец:

x + 6 + n₁ = 24, значит n₁ = 18 − x

Третий столбец:

t₃ + 9 + n₃ = 24, значит n₃ = 15 − t₃ = 15 − (17 − x)

Минус перед скобкой перевернул знаки внутри неё:

n₃ = 15 − 17 + x = x − 2

Проверка: третью строку я ещё ни разу не тратил — она требует суммы 24:

(18 − x) + 8 + (x − 2) = 24 ✓

Система честная.

Шаг 4 — диапазон. Границы дают сами клетки: каждая обязана остаться положительной. Выписываю все клетки, где стоит x, ни одну не пропуская:

  • x ≥ 1 — сама клетка t₁
  • n₃ = x − 2 ≥ 1, значит x ≥ 3
  • t₃ = 17 − x ≥ 1, значит x ≤ 16
  • n₁ = 18 − x ≥ 1, значит x ≤ 17

Снизу самая жадная граница — x ≥ 3 (она перекрывает x ≥ 1), сверху — x ≤ 16. Остальные клетки (7, 6, 8, m₂ = 9, m₃ = 9) — известные положительные числа.

x = 3, …, 16:

N(заполнений) = 14 способов

Шаг 5 — наибольшее число на доске. Нужен максимум одной из клеток, а клетки с x ведут себя по-разному: t₁ = x растёт вместе с x и на верхнем краю даёт 16; n₃ = x − 2 там же даёт 14; t₃ = 17 − x и n₁ = 18 − x, наоборот, падают, и на нижнем краю x = 3 дают 14 и 15. Постоянные клетки не больше 9. Значит рекорд ставит сама клетка t₁ при x = 16:

max(число на доске) = 16

Проверка (Д5): x = 16 → верх 16-7-1, вторая 6-9-9, третья 2-8-14; строки 24, 24, 24 ✓; столбцы 16+6+2 = 24, 7+9+8 = 24, 1+9+14 = 24 ✓.

💬 Фраза-объяснение (в начале)

Elegido t₁, todas las demás casillas quedan obligadas, así que solo pruebo los valores posibles de t₁.

Как только выбрано t₁, все остальные клетки определены, — поэтому перебираю только возможные t₁.

Запись

Период 3 в обе стороны → вся доска это квадрат 3×3: верх (t₁, t₂, t₃), вторая (m₁, m₂, m₃), третья (n₁, n₂, n₃); 4-я строка повторяет 1-ю. Зову x = t₁.

✅ План:

N(заполнений) = длина диапазона x
max(число на доске) = наибольшее значение клеток на краях диапазона
  • данные на полочки: res(2 : 3) = 2 → t₂ = 7; res(4 : 3) = 1 → m₁ = 6; res(5 : 3) = 2 → n₂ = 8
  • средний столбец: 7 + m₂ + 8 = 24 → m₂ = 9; вторая строка: m₃ = 9
  • t₃ = 17 − x; n₁ = 18 − x; n₃ = x − 2
  • все клетки ≥ 1: жадные границы n₃ → x ≥ 3 и t₃ → x ≤ 16
N(заполнений) = 14

💬 Фраза ко второму вопросу:

Más de 16 no se puede, porque t₃ = 17 − x tiene que ser positiva; y con x = 16 se logra, así que el máximo es 16.

Больше 16 быть не может, потому что клетка t₃ = 17 − x обязана быть положительной; а при x = 16 это достигается, — значит максимум равен 16.

max(число на доске) = 16

Проверка третьей строкой: (18 − x) + 8 + (x − 2) = 24 ✓

💬 Фраза в конце — полнота

Probé todos los valores posibles de t₁ y los demás no cumplen que todas las casillas sean positivas, por eso no hay más que estos.

Проверил все возможные значения t₁, остальные не подходят под условие «все клетки положительные», — поэтому других нет.

5.4 — ответ: сумма 20-го столбца 204; сумма всей доски 12403

Шаг 1 — план счёта. Вопроса два, и оба про большие куски доски — считать по клеткам нельзя, надо резать на порции. Порции здесь двух сортов: узор в строке идёт по три, и сами строки идут циклом «с 4», «с 9», «с 2». Первый вопрос — про один столбец, поэтому для него сначала пойму, какой узор идёт по столбцу сверху вниз. Второй вопрос — про всю доску, и его решает счёт каждого числа по типам строк.

✅ План готов:

S(20-го столбца) = сложенные по трём числам узора произведения (число × сколько раз оно стоит в этом столбце)

N(клеток с данным числом) = сложенные по трём типам строк произведения (сколько строк такого типа × сколько раз число стоит в такой строке)

S(доски) = 4 · N(четвёрок) + 9 · N(девяток) + 2 · N(двоек)

где тип строки — с какого числа узора она начинается: «с 4», «с 9» или «с 2»

Осталось найти: узор 20-го столбца и его полочки, а для второго вопроса — сколько строк каждого типа и сколько раз каждое число стоит в строке каждого типа.

Шаг 2 — узор 20-го столбца. Нужно, что стоит в этом столбце сверху вниз. Смотрю первую строку: она идёт 4 9 2 4 9 2 …, и место 20-й клетки в порции даёт остаток (ритуал Ч2): 20 = 3 · 6 + 2, то есть res(20 : 3) = 2 — второе число порции, а это 9. Вторая строка начинается со следующего числа узора, значит и её 20-я клетка сдвинута на одно: 2. Третья — 4, четвёртая снова 9. Значит по столбцу идёт свой узор 9-2-4 с тем же периодом 3.

Шаг 3 — полочки столбца. Строк 40, делю с остатком: 40 = 3 · 13 + 1, то есть res(40 : 3) = 1 — тринадцать полных порций и хвост в одну клетку. В полных порциях каждое из трёх чисел встречается по 13 раз, а хвост добавляет один раз первому числу столбцового узора, то есть девятке: девяток 14, двоек 13, четвёрок 13.

Шаг 4 — сумма 20-го столбца.

S(20-го столбца) = 14·9 + 13·2 + 13·4 = 126 + 26 + 52 = 204

Шаг 5 — что делается в одной строке. Теперь вся доска. Строка из 62 клеток с периодом 3: 62 = 3 · 20 + 2, res(62 : 3) = 2 — двадцать полных порций и хвост в две клетки. Значит первые два числа узора этой строки стоят по 21 разу, третье — 20 раз.

Шаг 6 — сколько строк каждого типа. Строки идут циклом «с 4», «с 9», «с 2»; строк 40 = 3 · 13 + 1 → хвост в одну строку достаётся первому типу: «с 4» — 14 строк, «с 9» — 13, «с 2» — 13.

Шаг 7 — считаю четвёрки и девятки. В строке «с 4» узор 4-9-2: четвёрка первая → 21 раз; в строке «с 9» узор 9-2-4: четвёрка третья → 20; в строке «с 2» узор 2-4-9: четвёрка вторая → 21. Умножаю на число строк каждого типа:

N(четвёрок) = 14·21 + 13·20 + 13·21 = 294 + 260 + 273 = 827

Девятки: в строке «с 4» девятка вторая → 21; в «с 9» первая → 21; в «с 2» третья → 20:

N(девяток) = 14·21 + 13·21 + 13·20 = 294 + 273 + 260 = 827

Двойки добираю остатком — всего клеток 40 · 62 = 2480:

N(двоек) = 2480 − 827 − 827 = 826

Шаг 8 — сумма доски.

S(доски) = 4·827 + 9·827 + 2·826 = 3308 + 7443 + 1652 = 12403

Второй способ (Д5), по строкам: строка «с 4» даёт 4·21 + 9·21 + 2·20 = 84 + 189 + 40 = 313; «с 9»: 9·21 + 2·21 + 4·20 = 189 + 42 + 80 = 311; «с 2»: 2·21 + 4·21 + 9·20 = 42 + 84 + 180 = 306. Итого 14·313 + 13·311 + 13·306 = 4382 + 4043 + 3978 = 12403 ✓.
