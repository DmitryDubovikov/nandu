5.3 — ответ: 19 способов; наименьший угол 3

Шаг 1 — план счёта. По горизонтали период 3: строки (t₁, t₂, 7), (m₁, 9, m₃), (8, b₂, b₃) — данные легли на полочки по остатку номера столбца при делении на 3. Остаток я записываю значком res(…): res(3 : 3) = 0, потому что 3 = 3 · 1 + 0; так же res(5 : 3) = 2 и res(7 : 3) = 1. Само деление по-прежнему пишу полной строкой (ритуал Ч2), а res(…) только называет уже добытый остаток коротко. Столбцы — тройки с суммой 30.

✅ План готов: всё через x = t₁:

N(заполнений) = длина диапазона x
min(угол) = наименьшее значение x

Шаг 2 — выражаю всё через x. Нужен диапазон одной клетки — для этого зову t₁ = x и выражаю через x каждую остальную. Сначала строки, в каждой тройка подряд даёт 30:

t₁ + t₂ = 23, значит t₂ = 23 − x

m₁ + m₃ = 21
b₂ + b₃ = 22

Теперь столбцы — из-за периода разных столбцов всего три, по одному на полочку:

t₁ + m₁ + 8 = 30, значит m₁ = 22 − x

t₂ + 9 + b₂ = 30, значит b₂ = 21 − t₂ = 21 − (23 − x)

Минус перед скобкой перевернул знаки внутри неё:

b₂ = 21 − 23 + x = x − 2

Осталось добрать среднюю и нижнюю клетки правой полочки:

m₃ = 21 − m₁ = 21 − (22 − x) = x − 1

7 + m₃ + b₃ = 30, значит b₃ = 23 − m₃ = 23 − (x − 1) = 24 − x

Проверка: нижнюю строку я ещё ни разу не тратил — она требует b₂ + b₃ = 22:

(x − 2) + (24 − x) = 22 ✓

Система честная.

Шаг 3 — диапазон. Границы дают сами клетки: каждая обязана остаться положительной.

  • b₂ = x − 2 ≥ 1, значит x ≥ 3
  • m₁ = 22 − x ≥ 1, значит x ≤ 21
  • остальные мягче

x = 3, …, 21:

N(заполнений) = 19 способов

Угол — это сама клетка t₁ = x, поэтому

min(угол) = 3

Строки по месту в порции из трёх: верх (t₁, t₂, t₃), середина (m₁, m₂, m₃), низ (b₁, b₂, b₃). Зову x = t₁.

✅ План:

  • по строкам период 3; данные на полочки: res(3 : 3) = 0, res(5 : 3) = 2, res(7 : 3) = 1

💬 Фраза ко второму вопросу:

Menos de 3 no se puede, porque b₂ = x − 2 tiene que ser positiva; y con x = 3 se logra, así que el mínimo es 3.

Меньше 3 быть не может, потому что клетка b₂ = x − 2 обязана быть положительной; а при x = 3 это достигается, — значит минимум равен 3.

min(угол) = 3

Проверка нижней строкой: (x − 2) + (24 − x) = 22 ✓

Проверил все возможные значения t₁, остальные не подходят под условие «все клетки положительные», — поэтому других нет.

5.4 — ответ: чаще всех 2 — 834 раза; сумма 12497

Шаг 1 — план счёта. Одна строка: 50 = 3 · 16 + 2, то есть res(50 : 3) = 2 → первые два числа узора строки по 17 раз, третье 16. Типы строк идут циклом «с 5», «с 2», «с 8»; строк 50 = 3 · 16 + 2 → «с 5» — 17 строк, «с 2» — 17, «с 8» — 16.

✅ План готов:

N(клеток с данным числом) = сложенные по трём типам строк произведения (сколько строк такого типа × сколько раз число стоит в такой строке)

S(доски) = 5 · N(пятёрок) + 2 · N(двоек) + 8 · N(восьмёрок)

тип строки — с какого числа узора она начинается: «с 5», «с 2» или «с 8»

Осталось найти: сколько строк каждого типа и сколько раз каждое число стоит в строке каждого типа.

Шаг 2 — считаю пятёрки. Сначала — сколько пятёрок в одной строке каждого типа: в строке «с 5» пятёрка первая в узоре → 17; в строке «с 2» она третья → 16; в строке «с 8» она вторая → 17. Теперь умножаю каждое на число строк такого типа (их 17, 17 и 16) и складываю: 17 строк · 17 + 17 строк · 16 + 16 строк · 17 = 289 + 272 + 272:

N(пятёрок) = 833

Шаг 3 — двойки и восьмёрки. Двоек в одной строке: «с 5» — 17 (двойка там вторая), «с 2» — 17 (первая), «с 8» — 16 (третья). Умножаю на число строк каждого типа: 17 строк · 17 + 17 строк · 17 + 16 строк · 16 = 289 + 289 + 256:

N(двоек) = 834

Восьмёрки добираю остатком:

N(восьмёрок) = 2500 − 833 − 834 = 833

Чаще всех — 2, 834 раза.

Шаг 4 — сумма. Складываю доску по числам:

S(доски) = 5·833 + 2·834 + 8·833 = 4165 + 1668 + 6664 = 12497 Второй способ (Д5), по строкам: строка «с 5» даёт 5·17 + 2·17 + 8·16 = 247; «с 2»: 2·17 + 8·17 + 5·16 = 250; «с 8»: 8·17 + 5·17 + 2·16 = 253; итого 17·247 + 17·250 + 16·253 = 4199 + 4250 + 4048 = 12497 ✓.
