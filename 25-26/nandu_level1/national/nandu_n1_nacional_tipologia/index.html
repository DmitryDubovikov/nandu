Национальный этап — типология задач 2013–2025

Olimpíada Ñandú · Nivel 1 · Certamen Nacional · Глоссарий типов, разбор корпуса по годам и порядок на двухдневке — файл для родителя

Зачем этот файл. На регионале тип задачи жёстко привязан к номеру: №1 — текстовая, №2 — периметры, №3 — счёт. На провинциале это правило уже трещит (см. 25-26/nandu_level1/provincial/nandu_n1_provincial_tipologia.md). На национале тур вдвое длиннее — два дня по 3 задачи, — и скелет держится по-разному в разных позициях: две позиции гарантированы, одна откровенно нестабильна. Здесь: система обозначений, таблица «год → номер → тип» по всем 66 задачам, ссылка «где это разобрано» для каждого типа, сводка по позициям и выведенный из данных порядок решения на двухдневке.

Корпус. 2013–2025, 13 туров, 66 задач Primer Nivel. С 2017 года тур двухдневный (6 задач); 2013–2016 — один день (3 задачи), эти четыре года используем как дополнительный банк, но в прогнозе по позициям не учитываем. Рабочее окно прогноза — 2019–2025 (7 туров, 42 задачи).
