## 1. 2023 №5 — рамка из пяти прямоугольников *(разминка)*

### Этап 1 — перевод

**Фигура.** Внешний прямоугольник ADEH (A — левый низ, D — правый низ, E — правый верх, H — левый верх). Две вертикали B→G и C→F (B, C на нижней стороне, G, F на верхней) отрезают равные боковые колонны ABGH и CDEF. Полоса между ними разрезана на три этажа: нижняя перемычка BCPM, центральное окно MPRS, верхняя перемычка SRFG — перемычки равны.

**Кирпичики.** `w` = BC, `m` = высота перемычки (равные перемычки → у обеих m), `a` = AB = CD, `v` = высота фигуры (AH).

| Что дано | Что записываем |
|---|---|
| P(BCPM) = 56: ширина w, высота m | w + m + w + m = 56 |
| HG = 2·GS: HG — кусок верхней стороны над колонной (= a), GS — вертикаль от G вниз до S (= m) | a = 2m |
| P(ABGH) = 116: ширина a, высота v | a + v + a + v = 116 |
| P(MPRS) = 112: ширина w, высота окна — это v минус две перемычки | w + (v − 2m) + w + (v − 2m) = 112 |

> ### ✅ Результат перевода
> ```
> w + m + w + m = 56
> a = 2m
> a + v + a + v = 116
> w + (v − 2m) + w + (v − 2m) = 112
> ```
> `w` = BC · `m` = высота перемычки · `a` = AB = CD · `v` = высота фигуры
>
> **На первом проходе задача сделана.**

**Лайфхаки.** Л4 (HG = 2·GS), Л7 (высота окна v − 2m — сквозная вертикаль по этажам), ритуал 4 (пометка «BCPM и SRFG равны» → высоты перемычек равны — без неё система не собирается).

**Ловушка перевода.** HG — не вся верхняя сторона, а её кусок от H до G; GS — вертикаль. Прочитать пропорцию как «две горизонтали» — завал. Вторая мина: высота окна MPRS — это v − 2m, а не v − m.

### Этап 2 — решение (второй проход)

**Шаг 1 — нужны четыре размера: причёсываю систему и свожу её к одной букве.** Сначала привожу подобные и делю каждое уравнение пополам:

w + m = 28

a + v = 58

w + v − 2m = 56

Из (1) выражаю w:

w = 28 − m

Подставляю это в (4) и получаю v тоже через m:

v = 28 + 3m

Теперь в (3) вместо a стоит 2m, вместо v — найденное выражение:

2m + 28 + 3m = 58

**m = 6, w = 22, v = 46, a = 12**

Ширина фигуры:

2a + w = 46

Внешний прямоугольник оказался квадратом.

**Шаг 2 — сборка: считаю спрошенные периметры.**

- **P(ADEH)** = 2(46 + 46) = **184**
- **P(BDEG)** = 2((w + a) + v) = 2(34 + 46) = **160**
- **P(MPFG)** = 2(w + (v − m)) = 2(22 + 40) = **124**
- **P(BCFG)** = 2(w + v) = 2(22 + 46) = **136**

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится.*

Кирпичики: w = BC · m = высота перемычки · a = AB = CD · v = высота фигуры (AH).

> ✅ **План:**
>
> **P(ADEH) = 2·((2a + w) + v)**
>
> **P(BDEG) = 2·((w + a) + v)**
>
> **P(MPFG) = 2·(w + (v − m))**
>
> **P(BCFG) = 2·(w + v)**
>
> Осталось найти w, m, a, v.

- P(BCPM) = 56 → w + m = 28
- HG = 2·GS → a = 2m
- P(ABGH) = 116 → a + v = 58
- P(MPRS) = 112 → w + (v − 2m) = 56
- w = 28 − m, v = 28 + 3m → 2m + 28 + 3m = 58 → **m = 6**
- **w = 22**, **v = 46**, **a = 12**

**P(ADEH) = 2·(46 + 46) = 184**

**P(BDEG) = 2·(34 + 46) = 160**

**P(MPFG) = 2·(22 + 40) = 124**

**P(BCFG) = 2·(22 + 46) = 136**

Проверка сложением: P(BCPM) = 2·(22 + 6) = 56 ✓; P(ABGH) = 2·(12 + 46) = 116 ✓; P(MPRS) = 2·(22 + 34) = 112 ✓

## 2. 2021 №5 — стрела с треугольником

### Этап 1 — перевод

**Фигура.** Справа — прямоугольная часть в два этажа: верхний ряд из A (слева) и B (справа), нижний ряд из пяти равных R подряд. Слева к её левой стороне **целиком** приклеен равнобедренный треугольник T остриём влево; основание T — вся левая сторона, оно внутри фигуры. Буквенных вершин нет вообще — все куски названы по именам деталей.

**Кирпичики.** `x` = горизонтальная сторона A (по условию она же — каждый из равных боков T), `y` = горизонтальная сторона B, `k` = **половина** высоты верхнего ряда (дробь «полторы» → мелкий кирпичик): высота A и B = 2k, высота R = 3k. Обрати внимание: условие «высота R — полторы высоты верхнего ряда» переведено не в уравнение, а прямо в буквы — потому дроби в системе и нет. Если ребёнок вместо этого завёл две высоты и отдельное уравнение между ними, перевод тоже верен, просто система у него на одно уравнение длиннее.

**Заметь главное.** Треугольник приклеен к левой стороне фигуры целиком, и отсюда следуют две разные вещи. Первая: оба бока T идут прямо по контуру фигуры — это буквально одни и те же отрезки, они стоят и в периметре T, и в периметре фигуры. Вторая: основание T — вся левая сторона, оба этажа, 5k, — внутренний стык, в периметр фигуры оно **не** входит; зато правая стена фигуры имеет ровно ту же высоту 5k. То есть тут совпадают не куски, а длины: 5k основания равно 5k правой стены. Этого и достаточно — в двух периметрах стоят одинаковые числа, а откуда они там взялись, вычитанию всё равно:

P(фигуры) = 2(x + y) + (5k + 2x)

P(T) = 5k + 2x

P(фигуры) − P(T) = 2(x + y)

Разность убирает разом и высоту, и обе стороны x, о которых пока ничего не известно. Ребёнку это видно уже на этапе перевода — до всякой алгебры.

| Что дано | Что записываем |
|---|---|
| P(T) = 166: основание — вся левая сторона (2k + 3k), бока по x | (2k + 3k) + x + x = 166 |
| P(фигуры) = 386: верх (x + y), правая стена (2k + 3k), низ (x + y), два бока T | (x + y) + (2k + 3k) + (x + y) + x + x = 386 |
| P(блока «A и B») = 276: ширина x + y, высота 2k | (x + y) + 2k + (x + y) + 2k = 276 |

> ### ✅ Результат перевода
> ```
> (2k + 3k) + x + x = 166
> (x + y) + (2k + 3k) + (x + y) + x + x = 386
> (x + y) + 2k + (x + y) + 2k = 276
> ```
> `x` = горизонталь A (= бок T) · `y` = горизонталь B · `k` = половина высоты верхнего ряда
>
> **На первом проходе задача сделана.**

**Лайфхаки.** Л3 (главный ход: фигура − T), Л2 (прямоугольник «из A и B»), Л4 («полторы» → k), Л5 (пять равных R в ряд → ширина R = (x + y)/5).

**Ловушка перевода.** Основание T — внутренний стык: в периметр фигуры не входит, в периметр T входит. И оно равно **всей** левой стороне (оба этажа, 5k), а не высоте одного ряда.

### Этап 2 — решение (второй проход)

**Шаг 1 — нужны x, y и k: причёсываю систему и вычитаю контуры.** Сначала привожу подобные в каждом уравнении, а третье ещё и делю пополам:

5k + 2x = 166

2(x + y) + 5k + 2x = 386

(x + y) + 2k = 138

Вычитаю (1) из (2) — общий хвост 5k + 2x уходит:

2(x + y) = 220

x + y = 110

Подставляю x + y = 110 в (3):

110 + 2k = 138 → **k = 14**

Возвращаюсь в (1), где 5k = 70:

2x = 166 − 70 → **x = 48**

Отсюда y = 110 − 48 → **y = 62**.

**Шаг 2 — все буквы известны, и размеры деталей читаются прямо из них.**

- высота ряда A/B = 2k = **28**
- высота ряда R = 3k = **42**
- ширина R = 110 : 5 = **22**

**Шаг 3 — сборка: считаю спрошенные периметры.**

- **P(A)** = 2(48 + 28) = **152**
- **P(B)** = 2(62 + 28) = **180**
- **P(R)** = 2(22 + 42) = **128**

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится.*

Кирпичики: x = горизонталь A (= бок T) · y = горизонталь B · k = половина высоты верхнего ряда; высота A и B = 2k, высота R = 3k, ширина R = (x + y) : 5.

> ✅ **План:**
>
> **P(A) = 2·(x + 2k)**
>
> **P(B) = 2·(y + 2k)**
>
> **P(R) = 2·((x + y) : 5 + 3k)**
>
> Осталось найти x, y, k.

- P(фигуры) − P(T) = 386 − 166 → 2·(x + y) = 220 → x + y = 110
- P(блока «A и B») = 276 → 110 + 2k = 138 → **k = 14**
- P(T) = 166, 5k = 70 → 2x = 96 → **x = 48**
- y = 110 − 48 → **y = 62**
- ширина R = 110 : 5 = **22**, высота R = 3k = **42**, высота A и B = 2k = **28**

**P(A) = 2·(48 + 28) = 152**

**P(B) = 2·(62 + 28) = 180**

**P(R) = 2·(22 + 42) = 128**

Проверка сложением: P(T) = 70 + 96 = 166 ✓; P(фигуры) = 220 + 70 + 96 = 386 ✓; P(блока «A и B») = 2·(110 + 28) = 276 ✓

## 3. 2015 №2 — обелиск *(2c-старейшина)*

### Этап 1 — перевод

**Фигура.** Внизу лежит плита ADEH (A, D — на земле, H, E — её верх). Сквозь плиту от земли до самой вершины идёт узкая колонна: B, C — её след на нижней стороне, G, F — верхушка. Колонна набрана чередованием «полка — квадратик — …»: 5 равных полок и 4 равных квадратика, нижняя полка стоит на земле и доходит ровно до уровня H–E. Внутри плиты слева и справа от колонны — два больших равных квадрата. От H и E к верхушке поднимаются скаты HG и EF — гипотенузы двух равных треугольников (горизонтальный катет — верх плиты, вертикальный — стенка колонны выше плиты).

**Кирпичики.** `a` = сторона большого квадрата. Квадраты стоят внутри плиты во всю её высоту — низ на земле, верх на верхней стороне плиты, — поэтому сторона квадрата и есть высота плиты. Нижняя полка колонны стоит заподлицо с плитой, значит и её высота тоже a (полка — это прямоугольник s × a: по ширине колонны, по высоте плиты). Дальше: `s` = сторона квадратика (она же ширина колонны), `t` = скат, `h` = вертикальный катет треугольника (стенка колонны над плитой).

| Что дано | Что записываем |
|---|---|
| P(треугольника) = 132: катеты a и h, скат t | a + h + t = 132 |
| P(CDEF) = 154: C→D (a), D→E (a), E→F (скат t), F→C (вся правая стенка колонны, a + h) | a + a + t + (a + h) = 154 |
| P(ADEFGH) = 174: низ (2a + s), бок a, скат t, верхушка s, скат t, бок a | (2a + s) + a + t + s + t + a = 174 |
| колонна: от земли до верхушки чередуются 5 полок (по a) и 4 квадратика (по s), и та же высота — это плита (a) плюс стенка над ней (h) | 5a + 4s = a + h |

> ### ✅ Результат перевода
> ```
> a + h + t = 132
> a + a + t + (a + h) = 154
> (2a + s) + a + t + s + t + a = 174
> 5a + 4s = a + h
> ```
> `a` = большой квадрат (= высота плиты = высота полки) · `s` = квадратик (= ширина колонны) · `t` = скат · `h` = стенка колонны над плитой
>
> **На первом проходе задача сделана.**

**Лайфхаки.** Л1 (колонна из равных полок), Л3 ((2) − (1) даёт 2a одним вычитанием), Л5 (нижняя полка заподлицо с плитой → её высота = a), Л7 (стенка колонны в CDEF — сквозная, во всю высоту), наклонная из контура (t не вычисляется).

**Ловушка перевода.** В CDEF сторона F→C — **вся** стенка колонны (a + h), а не кусок над плитой. И горизонтальный катет треугольника — это a (ширина большого квадрата), а не половина плиты.

### Этап 2 — решение (второй проход)

**Заметь главное.** В контуре CDEF сидят те же неизвестные, что и в треугольнике: тот же скат t и та же стенка колонны — только в CDEF она взята целиком (a + h), а у треугольника лишь её часть над плитой (h). Сверх этого в CDEF остаются две стороны большого квадрата — низ C→D и правый бок D→E. Одной строкой:

P(CDEF) = P(треугольника) + 2a

154 = 132 + 2a

Разность не требует знать ни скат, ни стенку. Скат в этой задаче вообще не измеряется — он выходит из контуров последним.

**Шаг 1 — два контура отличаются почти ничем: вычитаю их друг из друга.** Сначала привожу подобные в каждом уравнении:

a + h + t = 132

3a + h + t = 154

4a + 2s + 2t = 174

5a + 4s = a + h

Вычитаю (1) из (2) — общий хвост h + t уходит:

2a = 22 → **a = 11**

Возвращаю a = 11 в (1) и в (3):

## 11. 2017 №5 — босс: 6 A + 4 B + 2 C + 2 D

### Этап 1 — перевод

**Фигура.** Прямоугольник MQRU (M — левый низ, Q — правый низ, R — правый верх, U — левый верх). Вертикаль P→S отрезает правую часть PQRS, косая S→Q режет её на два равных треугольника D. В левой части MPSU горизонталь V→Z отрезает верхнюю полосу из **шести** деталей A в ряд; под полосой вертикаль N→X делит низ на стопку из четырёх лежачих B (слева) и пару стоячих C (справа). Буква T на верхней стороне стоит ровно над X и N: граница деталей A₃|A₄, стык блоков B|C и точка N лежат на одной **сквозной** вертикали.
