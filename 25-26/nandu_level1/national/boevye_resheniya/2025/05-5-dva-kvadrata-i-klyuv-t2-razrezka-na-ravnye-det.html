№5 — два квадрата и клюв (Т2′: разрезка на равные детали + доли)

Национальный этап 2025 — боевые решения

Условие

На рисунке ABEF и BCHG — квадраты, DEGH — прямоугольник. M — середина стороны AF. MR = MS = BC, а BR = ES = половине AR. Квадрат BCHG можно разрезать на пять прямоугольников, равных DEGH, если провести отрезки, параллельные BG. Периметр BCDE равен 198 см. Чему равен периметр ACDF? Чему равен периметр MRSF? Чему равен периметр MRCDS?

Как читать рисунок: слева большой квадрат ABEF (A — левый низ, B — правый низ, E — правый верх, F — левый верх). Справа к нему приставлен квадрат поменьше BCHG, а щель между его верхом GH и уровнем E–D закрывает лежачий прямоугольник DEGH. R стоит на нижней стороне AB, S — на верхней стороне FE; косые M→R и M→S похожи на клюв.

🔍 С чего начать. Какие кирпичики? Две стороны — большого квадрата и малого. Но они не независимы: разрезка малого квадрата на 5 равных прямоугольников их связывает. Что делать с косыми MR и MS? Ничего: их длина дана — она равна BC, стороне малого квадрата. Мерить и вычислять косые не нужно.

Заметь главное

Разрезка сравнивает две детали, повёрнутые друг относительно друга. Отрезки разрезки параллельны BG, то есть вертикальны, поэтому полоска малого квадрата стоит: её длинная сторона — вся сторона малого квадрата, а короткая — пятая часть этой стороны. А DEGH лежит: его длинная сторона ED равна BC, то есть тоже стороне малого квадрата, а короткая EG — это то, на сколько большой квадрат выше малого. Длинные стороны равны сами собой, вся работа — в коротких.

Часть 1 — геометрия: что даёт рисунок

Буквы.

  • s — сторона большого квадрата; ей равны AB, BE, EF, FA и правая сторона CD (прямоугольник DEGH доводит правый край до уровня E);
  • q — сторона малого квадрата; ей равны BC, CH, HG, GB, длинная сторона ED прямоугольника DEGH и обе косые MR и MS (по условию);
  • r = AR;
  • t = BR, ему равен ES (по условию).

Уравнения из условия.

Разрезка: короткая сторона стоячей полоски (пятая часть q) равна короткой стороне лежачего DEGH — той, на сколько большой квадрат выше малого.

(1) s − q = q/5
полоска малого квадрата (стоит)      DEGH (лежит)

  G┌──┬──┬──┬──┬──┐H                 E┌──────────────┐D
   │  │  │  │  │  │                  G└──────────────┘H
   │  │  │  │  │  │
  B└──┴──┴──┴──┴──┘C
   ширина q/5, высота q               длина q, высота s − q

Кто сравнит «ширину с шириной», получит бессмыслицу.

Контур BCDE — стоячий прямоугольник: ширина BC — сторона малого квадрата, высота BE — сторона большого.

(2) 2 · (q + s) = 198

R делит нижнюю сторону AB на AR и BR, и BR — половина AR:

(3) r = 2t
(4) r + t = s
Заметь главное

S стоит ровно над R. ES по условию равен BR, поэтому кусок верха SF — это сторона без ES, а кусок низа AR — та же сторона без такого же куска BR. Значит, SF = AR, и S с R на одном расстоянии от левого края. Отсюда два подарка: отрезок R→S — сквозная вертикаль во всю высоту большого квадрата, а верхний кусок DS равен нижнему RC (каждый — сторона малого квадрата плюс кусок t).

SF = s − ES = s − BR = AR = r
RS = s
DS = DE + ES = q + t
RC = BR + BC = t + q

И последний кусок: M — середина стороны AF, поэтому

FM = s/2

Что спрошено. Три периметра — обвожу каждый контур по сторонам.

ACDF — прямоугольник: низ AC — это сторона большого квадрата плюс сторона малого, высота — сторона большого.

MRSF — обхожу от M: косая вниз к R, от R вверх к S, по верху к F и по левой стороне обратно к M.

MRCDS — обхожу от M: косая к R, по низу до C, вверх до D, по верху до S и косой обратно к M.

✅ План готов:

P(ACDF) = 2 · ((s + q) + s)
P(MRSF) = q + s + r + s/2
P(MRCDS) = q + (t + q) + s + (q + t) + q

Осталось найти: s, q, r, t — из системы (1)–(4).

Часть 2 — алгебра: решаем систему

Заметь: в (1) стоит дробь q/5. Чтобы не таскать дробь, беру долю: k — пятая часть стороны малого квадрата. Малый квадрат — пять таких долей, а по (1) большой выше него ещё на одну долю, итого шесть.

(1): q = 5k, s = 6k

(2), подставить:

2 · (5k + 6k) = 198
22k = 198
k = 198 : 22 = 9

→ k = 9, малый квадрат q = 45, большой s = 54

(3) в (4), подставить r = 2t и s = 54: BR — одна часть, AR — две, вся сторона — три части.

2t + t = 54
3t = 54

→ t = 18, r = 36

Сборка. Подставляю s = 54, q = 45, r = 36, t = 18 в формулы плана. Сначала куски контуров:

M — середина AF → MA = MF = 27

SF = r = 36
RS = CD = s = 54
RC = DS = 18 + 45 = 63
P(ACDF) = 2 · ((54 + 45) + 54)
P(ACDF) = 2 · (99 + 54) = 306
P(MRSF) = 45 + 54 + 36 + 27 = 162
P(MRCDS) = 45 + 63 + 54 + 63 + 45 = 270

→ P(ACDF) = 306, P(MRSF) = 162, P(MRCDS) = 270

Проверка для родителя: от M до угла A — 27, от A до R — 36, значит по теореме Пифагора

MR = √(36² + 27²) = 45

— ровно BC, данные условия согласованы: треугольник 27, 36, 45 — это египетский 3, 4, 5, увеличенный в 9 раз ✓.

⚠ Ловушки. (1) Разрезка «с поворотом»: полоска стоит, DEGH лежит — длинное с длинным, короткое с коротким. (2) Отрезок R→S в контуре MRSF — сквозная вертикаль, вся высота 54, а не кусок. (3) Косые MR и MS не измеряются — они даны равенством с BC.

Проверка вторым способом: программа перебрала все целые стороны квадратов и положения R, оставила только те, где выполнены все условия (разрезка на 5 равных DEGH, P(BCDE) = 198, BR = ES = ½ · AR, косые MR и MS равны BC — их длины по теореме Пифагора), и посчитала периметры обходом вершин по координатам — единственный набор 54, 45, 36 и периметры 306, 162, 270.

Ответ на задачу: периметр ACDF — 306 см, периметр MRSF — 162 см, периметр MRCDS — 270 см. (Официальный ключ: 306; 162; 270 — совпадает.)

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.

Запись

Буквы:

  • s — сторона большого квадрата;
  • q — сторона малого, MR = MS = BC = q;
  • r = AR;
  • t = BR = ES.

Уравнения:

(1) разрезка: s − q = q/5
(2) P(BCDE): 2 · (q + s) = 198
(3) r = 2t
(4) r + t = s

ES = BR, поэтому:

  • SF = r, RS = s;
  • DS = RC = q + t;
  • FM = s/2.

✅ План:

P(ACDF) = 2 · ((s + q) + s)
P(MRSF) = q + s + r + s/2
P(MRCDS) = q + (t + q) + s + (q + t) + q

Решение:

  • (1) → q = 5k, s = 6k
  • (2) → 22k = 198 → k = 9 → q = 45, s = 54
  • (3), (4) → 3t = 54 → t = 18, r = 36
  • FM = 27, RC = DS = 18 + 45 = 63
P(ACDF) = 2 · (99 + 54) = 306
P(MRSF) = 45 + 54 + 36 + 27 = 162
P(MRCDS) = 45 + 63 + 54 + 63 + 45 = 270

Проверка: P(BCDE) = 2 · (45 + 54) = 198 ✓; AR + BR = 36 + 18 = 54 ✓
