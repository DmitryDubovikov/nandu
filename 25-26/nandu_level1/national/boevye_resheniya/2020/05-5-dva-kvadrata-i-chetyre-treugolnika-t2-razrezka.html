№5 — два квадрата и четыре треугольника (Т2′: разрезка на равные детали + общий хвост контуров)

Национальный этап 2020 — боевые решения

Условие

Прямоугольник MPQU разрезан на 2 прямоугольника A, 3 прямоугольника B, 1 квадрат C и 4 треугольника D. MNSU — квадрат. Периметр MNZV = 228 см, периметр TUVX = 144 см, периметр MNRU = 324 см, периметр NPQR = 240 см. Чему равен периметр каждого из прямоугольников B? Чему равен периметр каждого из треугольников D? Чему равен периметр MPRU?

Как читать рисунок: M — левый нижний угол, P — правый нижний, Q — правый верхний, U — левый верхний. Левая часть MNSU — квадрат. В нём внизу стоят три одинаковых B (их общий верх — отрезок VZ), над ними слева два одинаковых лежачих A (вместе они образуют прямоугольник TUVX), а справа от A — квадрат C. Правая часть NPQS разрезана на 4 прямоугольных треугольника D. Одна буква на рисунке — одинаковые детали: оба A одинаковы, все три B одинаковы, и все четыре D одинаковы. Косые N→R и R→P идут из точки R на верхней стороне, и из R опущена вертикаль до низа.

🔍 С чего начать. Какие кирпичики? Сторона квадрата MNSU, высота ряда B, ширина блока A, куски верха правой части и косая. Что делать с косыми NR и RP? Не мерить: они входят в данные контуры MNRU и NPQR, и оттуда их можно добыть. Где спрятаны уравнения? В двух квадратах: у квадрата ширина равна высоте.

Буквы: x — сторона квадрата MNSU, v = MV — высота ряда B, t = UT — ширина блока A, g = SR — кусок верха от S до R, d = NR = RP — косая, w = MP — вся ширина фигуры.

Заметь главное

Оба квадрата работают здесь не как фигуры, а как уравнения. MNSU — тем, что его высота и ширина это одна и та же буква x: она сразу и высота всей фигуры, и ширина её левой части. Квадрат C зажат между рядом B снизу и блоком A слева. Его ширина (от T до S) — это сторона x без ширины блока A, а высота (от Z до S) — сторона x без высоты ряда B. У квадрата ширина и высота — одно и то же число:

x − t = x − v
t = v

Половину периметра прямоугольника — одну ширину плюс одну высоту — называют полупериметром. Ширина TUVX — это t, высота — от V до U, то есть x без высоты ряда B. Полупериметр TUVX:

t + (x − v)

А раз t = v, он сворачивается в целую сторону квадрата:

t + (x − v) = v + (x − v) = x

Прямоугольник TUVX сообщает сторону большого квадрата, хотя ни t, ни v ещё не найдены, — на этом и держится вся задача.

Шаг 1 — план. Спрошены три периметра — обвожу каждый по сторонам.

Три B одинаковы и заполняют низ MN = x, поэтому ширина B — треть от x, а высота — v:

P(B) = 2·(x : 3 + v)

Треугольник D — например, SNR. У прямоугольного треугольника две стороны, образующие прямой угол, называются катетами; у SNR прямой угол при S. Верхний катет SR = g, вертикальный катет SN = x, косая NR = d:

P(D) = g + x + d

MPRU обхожу от M: по низу до P (w), косой вверх до R (d), по верху от R до U — через S: сначала кусок RS (g), потом верх квадрата SU (x), — и вниз по левой стороне (x):

P(MPRU) = w + d + (g + x) + x

✅ План готов:

P(B) = 2·(x : 3 + v)
P(D) = g + x + d
P(MPRU) = w + d + (g + x) + x
  • x — сторона квадрата MNSU, v — высота ряда B (= t)
  • g = SR, d — косая NR = RP, w = MP

Ответ = три периметра по этим формулам.

Осталось найти: x, v, g, d, w.

Шаг 2 — x даёт прямоугольник TUVX. Его периметр — это два полупериметра, а полупериметр, как замечено выше, равен x.

2x = 144
x = 144 : 2 = 72

→ x = 72

Шаг 3 — v даёт ряд B. MNZV — ряд B целиком: ширина x, высота v, а x уже известен.

x + v = 228 : 2 = 114
v = 114 − 72 = 42

→ v = 42 (и t = 42)

Шаг 4 — в контурах MNRU и NPQR стоит один и тот же хвост g + d. Чтобы его увидеть, обхожу оба контура по сторонам.

MNRU: M→N (x), N→R (d), R→U — через S: кусок RS (g) и верх квадрата SU (x), — и U→M (x):

x + d + (g + x) + x = 324

NPQR: N→P — низ правой части (вся ширина w без стороны квадрата x), P→Q (x), Q→R, R→N (d). Кусок Q→R — горизонтальный катет треугольника RQP. У всех четырёх D вертикальный катет — вся высота x, а раз треугольники равны, горизонтальные катеты у них тоже равны:

RQ = SR = g

И косые у равных треугольников тоже равны:

RP = NR = d
(w − x) + x + g + d = 240

В обоих обходах косая d и кусок g стоят рядом — это общий хвост. В MNRU, кроме хвоста, три стороны по x, а x уже известен, — значит, хвост считается сразу:

3x + g + d = 324
g + d = 324 − 216 = 108

→ g + d = 108

В NPQR «минус x» у низа и «плюс x» у правой стороны взаимно уничтожаются, и рядом с хвостом остаётся одна-единственная новая буква:

w + g + d = 240
w = 240 − 108 = 132

→ w = 132

Заметь главное

Дальше g и d по отдельности не понадобятся: в обеих оставшихся формулах плана они стоят рядом, и их можно взять одним куском — хвостом, найденным в шаге 4:

g + d = 108

Шаг 5 — сборка. Подставляю числа в формулы плана. Ширина B — треть от 72:

72 : 3 = 24
P(B) = 2·(24 + 42) = 132
P(D) = x + (g + d) = 72 + 108 = 180
P(MPRU) = w + (g + d) + x + x
P(MPRU) = 132 + 108 + 72 + 72 = 384

→ P(B) = 132, P(D) = 180, P(MPRU) = 384

Проверка для родителя. Четыре равных D делят верх правой части SQ пополам, значит:

2g = w − x = 132 − 72 = 60
g = 30
d = 108 − 30 = 78

Треугольник 30-72-78 = 6·(5-12-13) — честный прямоугольный: по теореме Пифагора косая действительно 78 ✓. И все четыре данных периметра сходятся:

  • TUVX: 2·72 = 144 ✓
  • MNZV: 2·114 = 228 ✓
  • MNRU: 216 + 30 + 78 = 324 ✓
  • NPQR: 60 + 72 + 30 + 78 = 240 ✓

⚠ Ключ даёт «D 198 см, MPRU 414 см», это неверно. Периметр D — это сторона квадрата плюс хвост, а оба куска жёстко заданы условием: сторону даёт TUVX, хвост — MNRU. Поэтому другого числа быть не может:

P(D) = 72 + 108 = 180

При 198 не сошёлся бы периметр MNRU. Ответ B = 132 в ключе совпадает с нашим.

⚠ Ловушки. (1) В контурах MNRU и MPRU сторона R→U идёт через S: это кусок RS плюс верх квадрата SU, а не один только верх квадрата. (2) Косые не мерить — они выходят из данных контуров. (3) Квадрат C — не украшение: именно он даёт t = v, без которого TUVX ничего не сообщает.

Проверка вторым способом: программа строила фигуру по координатам (перебор всех целых x, t, v, SR, RQ, косые — по теореме Пифагора), оставляла только варианты, где C — квадрат, четыре D равны и сходятся все четыре данных периметра, — нашёлся единственный: x = 72, t = v = 42, g = 30, d = 78, w = 132, и периметры 132, 180, 384; точное решение линейной системы из пяти уравнений даёт те же числа.

Ответ на задачу: периметр каждого прямоугольника B — 132 см, периметр каждого треугольника D — 180 см, периметр MPRU — 384 см. (Официальный ключ: 132; 198; 414 — в двух последних ответах ключ ошибается, см. выше.)

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и обходы контуров говорят сами за себя.

Запись

x — сторона квадрата MNSU, v = MV (высота B), t = UT, g = SR = RQ, d = NR = RP, w = MP.

Квадрат C: x − t = x − v → t = v.

✅ План:

P(B) = 2·(x : 3 + v)
P(D) = g + x + d
P(MPRU) = w + d + (g + x) + x

Осталось найти x, v, g + d, w.

  • P(TUVX) = 144, полупериметр t + (x − v) = x → 2x = 144 → x = 72
  • P(MNZV) = 228 → x + v = 114 → v = 42
  • P(MNRU) = 324 → 3x + g + d = 324 → g + d = 108
  • P(NPQR) = 240 → w + g + d = 240 → w = 132
  • B = 24 × 42 (ширина 72 : 3 = 24)
P(B) = 2·(24 + 42) = 132
P(D) = 72 + 108 = 180
P(MPRU) = 132 + 108 + 72 + 72 = 384

Проверка: TUVX 2·72 = 144 ✓; MNZV 2·114 = 228 ✓
