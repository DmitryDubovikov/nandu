№5 — два квадрата и четыре треугольника (Т2′: разрезка на равные детали + общий хвост контуров)

Национальный этап 2020 — боевые решения

Условие

Прямоугольник MPQU разрезан на 2 прямоугольника A, 3 прямоугольника B, 1 квадрат C и 4 треугольника D. MNSU — квадрат. Периметр MNZV = 228 см, периметр TUVX = 144 см, периметр MNRU = 324 см, периметр NPQR = 240 см. Чему равен периметр каждого из прямоугольников B? Чему равен периметр каждого из треугольников D? Чему равен периметр MPRU?

Как устроен рисунок. M — левый нижний угол, P — правый нижний, Q — правый верхний, U — левый верхний. Левая часть MNSU — квадрат. В нём внизу стоят три одинаковых B (их общий верх — отрезок VZ), над ними слева два одинаковых лежачих A (вместе они образуют прямоугольник TUVX), а справа от A — квадрат C. Правая часть NPQS разрезана на 4 прямоугольных треугольника D. Одна буква на рисунке — одинаковые детали: оба A одинаковы, все три B одинаковы, и все четыре D одинаковы. Косые N→R и R→P идут из точки R на верхней стороне, и из R опущена вертикаль до низа.

Заметь главное

Оба квадрата работают здесь не как фигуры, а как уравнения: у квадрата ширина равна высоте. Большой квадрат MNSU даёт одну длину сразу и высоте всей фигуры, и ширине её левой части. Квадрат C зажат между рядом B снизу и блоком A слева, и из его равных сторон выходит, что ширина блока A равна высоте ряда B. А тогда у прямоугольника TUVX ширина и высота вместе складываются ровно в сторону большого квадрата — хотя ни ширина, ни высота по отдельности ещё неизвестны. На этом держится вся задача.

Часть 1 — геометрия: что даёт рисунок

Буквы.

  • x — сторона квадрата MNSU: MN = NS = SU = UM = x;
  • v = MV — высота ряда B; ширина каждого B — треть низа MN, то есть x : 3;
  • t = UT — ширина блока A; его высота — от V до U, то есть сторона x без высоты ряда B: x − v;
  • g = SR — кусок верха от S до R;
  • d = NR — косая;
  • w = MP — вся ширина фигуры; низ правой части N→P — это w без стороны квадрата: w − x.

Косые не мерить: они входят в данные контуры, и оттуда их можно добыть.

У прямоугольного треугольника две стороны, образующие прямой угол, называются катетами. У всех четырёх D вертикальный катет — вся высота фигуры x. Треугольники D равны, поэтому равны и их горизонтальные катеты, и их косые:

RQ = SR = g
RP = NR = d

P(X) — периметр контура X: обхожу контур по сторонам и складываю отрезки. Половину периметра прямоугольника — одну ширину плюс одну высоту — называют полупериметром.

Уравнения из условия.

Квадрат C: ширина от T до S — это x без ширины блока A, высота от Z до S — это x без высоты ряда B. У квадрата они равны:

(1) x − t = x − v

Контур TUVX — прямоугольник: ширина t, высота x − v.

(2) 2 · (t + (x − v)) = 144

Контур MNZV — ряд B целиком: ширина x, высота v.

(3) 2 · (x + v) = 228

Контур MNRU: M→N (x), N→R (d), R→U — через S: кусок RS (g) и верх квадрата SU (x), — и U→M (x).

(4) x + d + (g + x) + x = 324

Контур NPQR: N→P (w − x), P→Q (x), Q→R (g — катет треугольника RQP), R→N (d).

(5) (w − x) + x + g + d = 240

Что спрошено.

Прямоугольник B: ширина x : 3, высота v.

Треугольник D — например, SNR, прямой угол при S: верхний катет SR = g, вертикальный катет SN = x, косая NR = d.

Контур MPRU: от M по низу до P (w), косой вверх до R (d), по верху от R до U — через S: сначала кусок RS (g), потом верх квадрата SU (x), — и вниз по левой стороне (x).

✅ План готов:

P(B) = 2 · (x : 3 + v)
P(D) = g + x + d
P(MPRU) = w + d + (g + x) + x

В P(D) и P(MPRU) буквы g и d стоят рядом, поэтому их можно искать одним куском g + d.

Осталось найти: x, v, w и g + d — из системы (1)–(5).

Часть 2 — алгебра: решаем систему

(1): в обеих частях отнимается от одного и того же x, поэтому

t = v

Заметь: прямоугольник TUVX сообщает сторону большого квадрата. В (2) стоит полупериметр, и при t = v он сворачивается:

t + (x − v) = v + (x − v) = x

Значит, (2) — это

2x = 144
x = 72

(3) : 2, подставить x:

x + v = 114
v = 114 − 72 = 42

(4): три стороны по x и хвост g + d:

3x + g + d = 324
(6) g + d = 324 − 216 = 108

(5): «минус x» у низа и «плюс x» у правой стороны взаимно уничтожаются:

w + g + d = 240

Подставить (6):

w = 240 − 108 = 132

Сборка. Ширина B — треть от 72:

72 : 3 = 24

Подставляю в формулы плана; g и d входят одним куском g + d = 108:

  • P(B) = 2 · (24 + 42) = 132
  • P(D) = 72 + 108 = 180
  • P(MPRU) = 132 + 108 + 72 + 72 = 384

Проверка для родителя. Четыре равных D делят верх правой части SQ пополам, значит:

2g = w − x = 132 − 72 = 60
g = 30
d = 108 − 30 = 78

Треугольник 30-72-78 = 6 · (5-12-13) — честный прямоугольный: по теореме Пифагора косая действительно 78 ✓. И все четыре данных периметра сходятся:

  • TUVX: 2 · 72 = 144 ✓
  • MNZV: 2 · 114 = 228 ✓
  • MNRU: 216 + 30 + 78 = 324 ✓
  • NPQR: 60 + 72 + 30 + 78 = 240 ✓

⚠ Ключ даёт «D 198 см, MPRU 414 см», это неверно. Периметр D — это сторона квадрата плюс хвост, а оба куска жёстко заданы условием: сторону даёт TUVX, хвост — MNRU. Поэтому другого числа быть не может:

P(D) = 72 + 108 = 180

При 198 не сошёлся бы периметр MNRU. Ответ B = 132 в ключе совпадает с нашим.

⚠ Ловушки.

  1. 1. В контурах MNRU и MPRU сторона R→U идёт через S: это кусок RS плюс верх квадрата SU, а не один только верх квадрата.
  2. 2. Косые не мерить — они выходят из данных контуров.
  3. 3. Квадрат C — не украшение: именно он даёт t = v, без которого TUVX ничего не сообщает.

Проверка вторым способом: программа строила фигуру по координатам (перебор всех целых x, t, v, SR, RQ, косые — по теореме Пифагора), оставляла только варианты, где C — квадрат, четыре D равны и сходятся все четыре данных периметра, — нашёлся единственный: x = 72, t = 42, v = 42, g = 30, d = 78, w = 132, и периметры 132, 180, 384; точное решение линейной системы из пяти уравнений даёт те же числа.

Ответ на задачу: периметр каждого прямоугольника B — 132 см, периметр каждого треугольника D — 180 см, периметр MPRU — 384 см. (Официальный ключ: 132; 198; 414 — в двух последних ответах ключ ошибается, см. выше.)

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и обходы контуров говорят сами за себя.

Запись

Буквы:

  • x — сторона квадрата MNSU
  • v = MV — высота B
  • t = UT — ширина A
  • g = SR = RQ
  • d = NR = RP
  • w = MP

Уравнения:

(1) квадрат C: x − t = x − v
(2) P(TUVX): 2 · (t + (x − v)) = 144
(3) P(MNZV): 2 · (x + v) = 228
(4) P(MNRU): 3x + g + d = 324
(5) P(NPQR): w + g + d = 240

✅ План:

P(B) = 2 · (x : 3 + v)
P(D) = g + x + d
P(MPRU) = w + d + (g + x) + x

Решение:

  • (1) → t = v
  • (2) → 2x = 144 → x = 72
  • (3) → x + v = 114 → v = 42
  • (4) → g + d = 108
  • (5) → w = 132
  • B: ширина 72 : 3 = 24, высота 42
P(B) = 2 · (24 + 42) = 132
P(D) = 72 + 108 = 180
P(MPRU) = 132 + 108 + 72 + 72 = 384

Проверка:

  • (2): 2 · 72 = 144 ✓
  • (3): 2 · 114 = 228 ✓
