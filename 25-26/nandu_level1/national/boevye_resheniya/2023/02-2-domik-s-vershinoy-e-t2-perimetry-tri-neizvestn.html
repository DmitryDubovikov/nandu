Что пишешь на туре

№2 — домик с вершиной E (Т2: периметры, три неизвестных отрезка из трёх треугольников)

Национальный этап 2023 — боевые решения

Условие

На рисунке ABHG — прямоугольник, BCDI — квадрат. H — середина отрезка BI. EF = GH и FD = EG. Точки E, F и G лежат на одной прямой. Точки B, I и E лежат на одной прямой. Периметр BCDI равен 128 см, периметр ABHG равен 92 см, периметр DEF равен 120 см, периметр DEI равен 96 см, периметр EFI равен 72 см. Каков периметр BCDE? Каков периметр ABIFG? Каков периметр ACDFG? Каков периметр ACDEG?

Как устроен рисунок. Внизу слева лежит прямоугольник ABHG: A и B на земле, G и H — его верх. Справа к нему примыкает квадрат BCDI: C на земле, D — правый верхний угол, I — левый верхний, прямо над B. Прямоугольник вдвое ниже квадрата: его верх GH упирается в середину H стороны BI. Над I стоит вершина E, и от неё идут вниз три отрезка: прямо вниз к I (и дальше до B), вправо вниз к D и влево вниз через F к G. Точка F лежит на продолжении верхней стороны квадрата: по рисунку F, I и D стоят на одной горизонтали.

Три неизвестных отрезка у E. У вершины E есть три отрезка, которые не собрать из сторон квадрата и прямоугольника: IE (стоит вертикально), ED (идёт вкось, как скат крыши) и FI (лежит горизонтально). Каждому даём свою букву и достаём её из уравнений. Дальше эти три отрезка так и зовутся — неизвестные отрезки.

Заметь главное

Три данных треугольника — EFI, DEI и DEF — пересекаются, и каждый неизвестный отрезок входит ровно в два из них:

  • IE — в EFI и DEI;
  • ED — в DEI и DEF;
  • FI — в EFI и DEF.

Поэтому ни один треугольник поодиночке не выдаёт ни одного неизвестного отрезка: в каждом их по два. Зато если сложить все три треугольника разом, каждый неизвестный отрезок встретится в сумме ровно дважды — и сумма всех трёх найдётся одним делением на 2. Это и есть ключ задачи; проверить «каждый ровно в двух» стоит до того, как складывать. Работает он в части 2, а часть 1 только записывает, что даёт рисунок.

Часть 1 — геометрия: что даёт рисунок

Буквы. Кирпичики — так в курсе зовут буквы, через которые выражается каждый отрезок рисунка:

  • s — сторона квадрата BCDI: BC = CD = DI = IB;
  • b — AB, ширина прямоугольника ABHG; верх прямоугольника GH равен низу, а условие EF = GH переносит ту же длину на косой отрезок: AB = GH = EF;
  • p — IE;
  • q — ED;
  • r — FI.

Остальные отрезки, которые понадобятся, собираются из кирпичиков.

H — середина BI, значит высота прямоугольника ABHG — половина стороны квадрата. Левая сторона прямоугольника GA равна правой BH:

GA = BH = s : 2

B, I и E на одной прямой, значит отрезок EB складывается из двух кусков:

EB = EI + IB = p + s

F, I и D на одной прямой, значит FD тоже складывается из двух кусков, а условие FD = EG переносит эту длину на EG:

EG = FD = FI + ID = r + s

E, F и G на одной прямой, значит EG складывается из EF и FG. Кусок FG — это EG без EF:

FG = (r + s) − b

A, B и C на одной прямой, значит AC складывается из двух кусков:

AC = AB + BC = b + s

P(X) — периметр контура X: обхожу контур карандашом по буквам и складываю отрезки.

Уравнения из условия. Каждый данный периметр — обход контура, записанный буквами.

Контур BCDI — квадрат, четыре стороны s:

(1) 4s = 128

Контур ABHG: AB, BH, HG, GA — ширина b дважды и высота s : 2 дважды:

(2) b + s : 2 + b + s : 2 = 92

Контур EFI: EF, FI, IE.

(3) b + r + p = 72

Контур DEI: DE, EI, ID.

(4) q + p + s = 96

Контур DEF: DE, EF, FD. Сторона FD идёт сквозь I, поэтому она r + s, а не одно r.

(5) q + b + (r + s) = 120

Что спрошено. Каждый искомый периметр — тоже обход, записанный буквами.

Контур BCDE: B → C, C → D, D → E, E → B. Сторона E → B идёт сквозь I.

Контур ABIFG: A → B, B → I, I → F, F → G, G → A.

Контур ACDFG: A → C, C → D, D → F — одна сторона через I, F → G, G → A.

Контур ACDEG: A → C, C → D, D → E, E → G — одна сторона через F, G → A.

✅ План готов:

P(BCDE) = s + s + q + (p + s)
P(ABIFG) = b + s + r + ((r + s) − b) + s : 2
P(ACDFG) = (b + s) + s + (r + s) + ((r + s) − b) + s : 2
P(ACDEG) = (b + s) + s + q + (r + s) + s : 2

Осталось найти: s, b, p, q, r — из системы (1)–(5).

Часть 2 — алгебра: решаем систему

(1) : 4:

s = 32

В (2) две половинки s : 2 вместе дают целое s:

2b + s = 92

Подставляю s = 32:

b = (92 − 32) : 2 = 30

Подставляю s = 32 и b = 30 в (3)–(5) и переношу известные числа вправо. В (3) известно одно число (b = 30), в (4) — одно (s = 32), а в (5) — два: b = 30 и s = 32, которое сидит внутри FD:

(6) r + p = 72 − 30 = 42
(7) p + q = 96 − 32 = 64
(8) q + r = 120 − 30 − 32 = 58

Каждый неизвестный отрезок стоит ровно в двух уравнениях из трёх — это наблюдение из «Заметь главное», теперь видное в самих уравнениях: p — в (6) и (7), q — в (7) и (8), r — в (6) и (8). Значит, работает метод сложения: (6) + (7) + (8), левые части с левыми, правые с правыми. Каждый неизвестный отрезок попадает в сумму дважды:

(r + p) + (p + q) + (q + r) = 2 · (p + q + r)
2 · (p + q + r) = 42 + 64 + 58 = 164
(9) p + q + r = 82

Для каждой буквы есть уравнение, где её нет: в (8) нет p, в (6) нет q, в (7) нет r. Метод вычитания — из (9) вычитаю такое уравнение, две буквы уходят:

(9) − (8): p = 82 − 58 = 24

(9) − (6): q = 82 − 42 = 40

(9) − (7): r = 82 − 64 = 18

Сборка. Сначала составные отрезки из части 1:

  • EB = p + s = 24 + 32 = 56
  • EG = FD = r + s = 18 + 32 = 50
  • FG = 50 − 30 = 20
  • AC = b + s = 30 + 32 = 62
  • GA = s : 2 = 16

Подставляю в формулы плана:

  • P(BCDE) = 32 + 32 + 40 + 56 = 160
  • P(ABIFG) = 30 + 32 + 18 + 20 + 16 = 116
  • P(ACDFG) = 62 + 32 + 50 + 20 + 16 = 180
  • P(ACDEG) = 62 + 32 + 40 + 50 + 16 = 200

Проверка подстановкой в (3)–(5):

  • (3): 30 + 18 + 24 = 72 ✓
  • (4): 40 + 24 + 32 = 96 ✓
  • (5): 40 + 30 + 50 = 120 ✓

⚠ Ловушки.

  1. 1. EF идёт вкось, но новой буквы ему не надо: условие EF = GH приравнивает его к горизонтали длины b. Кто этого не заметит, получит в треугольнике EFI три неизвестных.
  2. 2. Левая сторона GA — это половина стороны квадрата (16), а не вся сторона (32).
  3. 3. В контуре ACDEG сторона E → G идёт сквозь F и равна всему EG = 50, а не EF. В контуре ACDFG сторона D → F идёт сквозь I и равна всему FD = 50, а не FI.
  4. 4. Не пытайся найти каждый неизвестный отрезок из «своего» треугольника: в каждом их по два, работает только сложение всех трёх.

Проверка вторым способом: программа перебрала все целые чертежи по координатам (сторона квадрата, ширина прямоугольника, высота E над I, отступ F от I — каждое от 1 до 100) и мерила отрезки настоящими расстояниями, без букв разбора. Она проверяла все пять периметров, равенства EF = GH и FD = EG и то, что E, F, G на одной прямой. Подходит ровно один чертёж — s = 32, b = 30, IE = 24, FI = 18, ED = 40, — и обход его контуров даёт 160, 116, 180, 200. Для родителя: неизвестные отрезки сидят в прямоугольных треугольниках 18-24-30 (EFI), 24-32-40 (EID) и 30-40-50 (EG), все подобны 3-4-5 — чертёж существует на самом деле, данные не противоречат друг другу. Совпадает с официальным ключом.

Ответ на задачу: периметр BCDE равен 160 см, периметр ABIFG — 116 см, периметр ACDFG — 180 см, периметр ACDEG — 200 см. (официальный ключ ✓ по всем четырём)

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.
