## №5 — треугольник с прямоугольником внутри *(Т2: периметры, контур с обходом вместо стороны)*

**Условие.** На рисунке AB = FD, CE = 4CD, DE = EF, AG = BC = CD. DFHI — прямоугольник, треугольники FGH и CDI равны. Периметр DEF равен 144 см, периметр DEFHI равен 168 см, периметр DFHI равен 132 см, периметр CDFG равен 156 см. Чему равен периметр CEG? Чему равен периметр CDFH? Чему равен периметр DEGI? Чему равен периметр ABCEG?

*Как устроен рисунок.* Большой треугольник CEG: E — вершина наверху, G и C — нижние углы, основание GC лежит горизонтально. Точка F лежит на боковой стороне EG, точка D — на боковой стороне EC, и отрезок FD горизонтальный. Из F и D опущены вертикали FH и DI до основания: точки H и I лежат на GC, так что основание идёт G → H → I → C. Под основанием — ещё две точки, A и B: G соединена с A, A с B, B с C, и AB горизонтальный.

**Заметь главное.** Сначала — сколько на рисунке разных длин. Отрезков много, но условие и слово «прямоугольник» склеивают их в группы:

- CD = BC = AG — сказано в условии. А FG = CD, потому что треугольники FGH и CDI равны: у равных треугольников стороны попарно равны, и наклонная сторона FG одного равна наклонной стороне CD другого.
- CE = 4CD, а CE состоит из CD и DE. Значит, DE — это три CD. И EF = DE — тоже три CD.
- FD = AB — сказано в условии, а HI = FD — противоположные стороны прямоугольника.
- FH = DI — тоже противоположные стороны прямоугольника.
- GH = IC — лежачие стороны равных треугольников FGH и CDI (стоячие FH и DI у них и так равны).

Всего четыре разные длины. Назову их буквами:

- a = CD = BC = AG = FG, и тогда DE = EF = 3a;
- b = FD = AB = HI;
- c = FH = DI;
- d = GH = IC.

И второе, главное. Контур DEFHI — это треугольник DEF, у которого сторону FD заменили обходом снизу: F → H → I → D. Нижний отрезок обхода HI равен FD. Значит, DEFHI длиннее DEF ровно на две стоячие стороны FH и DI.

**Шаг 1 — план: записать спрошенные периметры через четыре буквы.**

Буквы a, b, c, d — кирпичики (так в курсе зовут буквы, через которые выражается каждый отрезок рисунка). `P(X)` — периметр контура X: обхожу контур карандашом по буквам и складываю отрезки.

Треугольник CEG. Сторона CE состоит из CD и DE:

CE = a + 3a = 4a

Сторона EG состоит из EF и FG:

EG = 3a + a = 4a

Основание GC идёт через H и I, то есть состоит из GH, HI и IC.

P(CEG) = 4a + 4a + d + b + d

Контур CDFH идёт C → D → F → H → C. Последний его кусок H → C идёт по основанию через точку I, то есть HI и IC:

P(CDFH) = a + b + c + b + d

Контур DEGI идёт D → E → G → I → D. Сторона EG — это 4a, кусок G → I идёт через H, то есть GH и HI:

P(DEGI) = 3a + 4a + d + b + c

Контур ABCEG идёт A → B → C → E → G → A, то есть AB, BC, CE, EG, GA:

P(ABCEG) = b + a + 4a + 4a + a

> ✅ **План готов:**
>
> **P(CEG) = 4a + 4a + d + b + d**
>
> **P(CDFH) = a + b + c + b + d**
>
> **P(DEGI) = 3a + 4a + d + b + c**
>
> **P(ABCEG) = b + a + 4a + 4a + a**
>
> - `a` — длина CD = BC = AG = FG;
> - `b` — длина FD = AB = HI;
> - `c` — длина FH = DI;
> - `d` — длина GH = IC.
>
> Ответ = четыре периметра, расписанные через `a`, `b`, `c`, `d`.
>
> Осталось найти: `a`, `b`, `c`, `d` — из четырёх данных периметров.

**Шаг 2 — четыре данных периметра, записанные буквами.** Каждый контур обхожу карандашом.

Треугольник DEF: DE, EF, FD —

(1) 3a + 3a + b = 144

Контур DEFHI: DE, EF, FH, HI, ID —

(2) 3a + 3a + c + b + c = 168

Прямоугольник DFHI: DF, FH, HI, ID —

(3) b + c + b + c = 132

Контур CDFG: CD, DF, FG и основание G → C через H и I —

(4) a + b + a + d + b + d = 156

**Шаг 3 — контур (2) — это треугольник (1) плюс две стоячие стороны.** В (2) стоят те же 3a, 3a и b, что в (1), и сверх них два раза c. Вычитаю (1) из (2):

(3a + 3a + c + b + c) − (3a + 3a + b) = c + c

c + c = 168 − 144 = 24

**c = 12**

**Шаг 4 — в прямоугольнике (3) неизвестна только буква b.** Две стоячие стороны уже известны:

b + b = 132 − 24 = 108

**b = 54**

**Шаг 5 — в треугольнике (1) неизвестна только буква a.** Основание b уже известно:

6a = 144 − 54 = 90

**a = 15**

**Шаг 6 — в контуре (4) неизвестна только буква d.** Две a дают 30, две b дают 108:

d + d = 156 − 30 − 108 = 18

**d = 9**

**Шаг 7 — сборка.** Подставляю a = 15, b = 54, c = 12, d = 9 в формулы плана. Боковые стороны большого треугольника и его основание:

CE = EG = 4 · 15 = 60

GC = 9 + 54 + 9 = 72

Верхние куски боковых сторон:

DE = EF = 3 · 15 = 45

- **P(CEG)** = 60 + 60 + 72 = **192**
- **P(CDFH)** = 15 + 54 + 12 + 54 + 9 = **144**
- **P(DEGI)** = 45 + 60 + 9 + 54 + 12 = **180**
- **P(ABCEG)** = 54 + 15 + 60 + 60 + 15 = **204**

Проверка по данным условия:

- P(DEF) = 45 + 45 + 54 = 144 ✓
- P(DEFHI) = 45 + 45 + 12 + 54 + 12 = 168 ✓
- P(DFHI) = 54 + 12 + 54 + 12 = 132 ✓
- P(CDFG) = 15 + 54 + 15 + 9 + 54 + 9 = 156 ✓

**⚠ Ловушки.** (1) CE = 4CD — это вся сторона, а не её верхняя часть. Верхняя часть DE — это 3a, а не 4a:

DE = CE − CD = 4a − a = 3a

(2) FG = CD не написано прямо — оно следует из равенства треугольников FGH и CDI; без него FG — пятая неизвестная длина, а данных периметров только четыре, и задача кажется нерешаемой. (3) В контурах CDFH, DEGI и CDFG кусок по основанию проходит через точки H и I, хотя в названии их нет: H → C — это HI и IC, G → I — это GH и HI.

*Проверка вторым способом: полный перебор целых a, b, c, d до 200 по четырём данным периметрам даёт единственное решение (15, 54, 12, 9); независимо фигура построена по координатам (G = (0, 0), C = (72, 0), E = (36, −48), F = (9, −12), D = (63, −12), A = (9, 12), B = (63, 12)) — точки E, F, G и E, D, C лежат на прямых, все равенства условия выполняются точно (треугольники FGH и CDI оба со сторонами 9, 12, 15), а периметры, измеренные программой прямо как длины ломаных, дали 144, 168, 132, 156 для данных и 192, 144, 180, 204 для спрошенных. Отрезки оригинального чертежа, измеренные по PDF, стоят в тех же пропорциях (FD : GC ≈ 0,75 = 54 : 72, FH : GC ≈ 12 : 72).*

**Ответ на задачу:** периметр CEG равен **192 см**, периметр CDFH — **144 см**, периметр DEGI — **180 см**, периметр ABCEG — **204 см**. *(официальный ключ ✓ по всем четырём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики: a = CD = BC = AG = FG (FGH = CDI) · DE = EF = 3a (CE = 4a) · b = FD = AB = HI · c = FH = DI · d = GH = IC.

> ✅ **План:**
>
> **P(CEG) = 4a + 4a + d + b + d**
>
> **P(CDFH) = a + b + c + b + d**
>
> **P(DEGI) = 3a + 4a + d + b + c**
>
> **P(ABCEG) = b + a + 4a + 4a + a**
>
> Осталось найти a, b, c, d из P(DEF), P(DEFHI), P(DFHI), P(CDFG).

- P(DEFHI) − P(DEF) = (6a + b + 2c) − (6a + b) → 2c = 168 − 144 = 24 → **c = 12**
- P(DFHI) = 2b + 2c = 132 → **b = 54**
- P(DEF) = 6a + b = 144 → **a = 15**
- P(CDFG) = 2a + 2b + 2d = 156 → **d = 9**

CE = EG = 4 · 15 = 60

GC = 9 + 54 + 9 = 72

DE = EF = 3 · 15 = 45

**P(CEG) = 60 + 60 + 72 = 192**

**P(CDFH) = 15 + 54 + 12 + 54 + 9 = 144**

**P(DEGI) = 45 + 60 + 9 + 54 + 12 = 180**

**P(ABCEG) = 54 + 15 + 60 + 60 + 15 = 204**

Проверка сложением:

- P(DEF) = 45 + 45 + 54 = 144 ✓
- P(DEFHI) = 45 + 45 + 12 + 54 + 12 = 168 ✓
- P(DFHI) = 54 + 12 + 54 + 12 = 132 ✓
- P(CDFG) = 15 + 54 + 15 + 9 + 54 + 9 = 156 ✓
