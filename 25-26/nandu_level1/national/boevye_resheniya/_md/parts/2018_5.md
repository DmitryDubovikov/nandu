## №5 — треугольник с прямоугольником внутри *(Т2: периметры, контур с обходом вместо стороны)*

**Условие.** На рисунке AB = FD, CE = 4CD, DE = EF, AG = BC = CD. DFHI — прямоугольник, треугольники FGH и CDI равны. Периметр DEF равен 144 см, периметр DEFHI равен 168 см, периметр DFHI равен 132 см, периметр CDFG равен 156 см. Чему равен периметр CEG? Чему равен периметр CDFH? Чему равен периметр DEGI? Чему равен периметр ABCEG?

*Как устроен рисунок.* Большой треугольник CEG: E — вершина наверху, G и C — нижние углы, основание GC лежит горизонтально. Точка F лежит на боковой стороне EG, точка D — на боковой стороне EC, и отрезок FD горизонтальный. Из F и D опущены вертикали FH и DI до основания: точки H и I лежат на GC, так что основание идёт G → H → I → C. Под основанием — ещё две точки, A и B: G соединена с A, A с B, B с C, и AB горизонтальный.

**Заметь главное.** Отрезков на рисунке много, но разных длин среди них всего четыре: условие и слово «прямоугольник» склеивают отрезки в группы. Самое незаметное звено — FG = CD. Прямо в условии этого нет: оно следует из того, что треугольники FGH и CDI равны. У равных треугольников стороны попарно равны, и наклонная сторона FG одного равна наклонной стороне CD другого. Без этого звена FG была бы пятой неизвестной длиной, а данных периметров только четыре.

### Часть 1 — геометрия: что даёт рисунок

**Буквы.** Всего четыре разные длины — по букве на каждую группу равных отрезков:

- a = CD. Ей равны: BC и AG (по условию), FG (треугольники FGH и CDI равны — см. «Заметь главное»);
- b = FD. Ей равны: AB (по условию), HI (противоположные стороны прямоугольника DFHI);
- c = FH. Ей равна DI (противоположные стороны прямоугольника);
- d = GH. Ей равна IC (лежачие стороны равных треугольников FGH и CDI; стоячие FH и DI у них и так равны).

Верхние куски боковых сторон. По условию CE = 4CD, а CE состоит из CD и DE, поэтому DE — это три CD:

DE = CE − CD = 4a − a = 3a

По условию EF = DE, значит, и EF — это 3a. Боковая сторона CE целиком равна 4a по условию, а вторая боковая сторона складывается из двух кусков:

EG = EF + FG = 3a + a = 4a

Основание GC идёт через H и I:

GC = GH + HI + IC = d + b + d

`P(X)` — периметр контура X: обхожу контур карандашом по буквам и складываю отрезки.

**Уравнения из условия.** Каждый данный периметр — обход контура по рисунку.

Контур DEF: DE, EF, FD.

**(1) 3a + 3a + b = 144**

Контур DEFHI: DE, EF, FH, HI, ID.

**(2) 3a + 3a + c + b + c = 168**

Контур DFHI — прямоугольник: DF, FH, HI, ID.

**(3) b + c + b + c = 132**

Контур CDFG: CD, DF, FG и основание G → C через H и I.

**(4) a + b + a + d + b + d = 156**

**Что спрошено.** Каждый искомый периметр — тоже обход.

Контур CEG: две боковые стороны по 4a и основание GC.

Контур CDFH: C → D → F → H → C; последний кусок H → C идёт по основанию через I, то есть HI и IC.

Контур DEGI: D → E → G → I → D; сторона EG — это 4a, кусок G → I идёт через H, то есть GH и HI.

Контур ABCEG: A → B → C → E → G → A, то есть AB, BC, CE, EG, GA.

> ✅ **План готов:**
>
> **P(CEG) = 4a + 4a + d + b + d**
>
> **P(CDFH) = a + b + c + b + d**
>
> **P(DEGI) = 3a + 4a + d + b + c**
>
> **P(ABCEG) = b + a + 4a + 4a + a**
>
> Осталось найти: a, b, c, d — из системы (1)–(4).

### Часть 2 — алгебра: решаем систему

Заметь: в (2) стоят те же 3a, 3a и b, что в (1), и сверх них два раза c. На рисунке это видно так: контур DEFHI — это треугольник DEF, у которого сторону FD заменили обходом снизу F → H → I → D, а нижний кусок обхода HI снова равен b. Метод вычитания, (2) − (1): всё общее уходит, остаются две стоячие стороны.

**c + c = 168 − 144 = 24**

**c = 12**

В (3) теперь неизвестна только b. Подставляю c = 12:

**b + b = 132 − 24 = 108**

**b = 54**

В (1) неизвестна только a. Подставляю b = 54:

**6a = 144 − 54 = 90**

**a = 15**

В (4) неизвестна только d. Две a дают 30, две b дают 108:

**d + d = 156 − 30 − 108 = 18**

**d = 9**

**Сборка.** Сначала длинные отрезки:

- CE = EG = 4 · 15 = **60**
- GC = 9 + 54 + 9 = **72**
- DE = EF = 3 · 15 = **45**

Подставляю в формулы плана:

- **P(CEG)** = 60 + 60 + 72 = **192**
- **P(CDFH)** = 15 + 54 + 12 + 54 + 9 = **144**
- **P(DEGI)** = 45 + 60 + 9 + 54 + 12 = **180**
- **P(ABCEG)** = 54 + 15 + 60 + 60 + 15 = **204**

Проверка подстановкой в (1)–(4):

- (1): 45 + 45 + 54 = 144 ✓
- (2): 45 + 45 + 12 + 54 + 12 = 168 ✓
- (3): 54 + 12 + 54 + 12 = 132 ✓
- (4): 15 + 54 + 15 + 9 + 54 + 9 = 156 ✓

**⚠ Ловушки.**

- CE = 4CD — это вся боковая сторона, а не её верхняя часть. Верхняя часть DE — это 3a, а не 4a.
- FG = CD не написано прямо — оно следует из равенства треугольников FGH и CDI. Без него FG — пятая неизвестная длина, а данных периметров только четыре, и задача кажется нерешаемой.
- В контурах CDFH, DEGI и CDFG кусок по основанию проходит через точки H и I, хотя в названии их нет: H → C — это HI и IC, G → I — это GH и HI.

**Проверка вторым способом.** *Полный перебор целых a, b, c, d до 200 по четырём данным периметрам даёт единственное решение a = 15, b = 54, c = 12, d = 9.*

*Независимо фигура построена по координатам: G = (0, 0), C = (72, 0), E = (36, −48), F = (9, −12), D = (63, −12), A = (9, 12), B = (63, 12). Точки E, F, G и E, D, C лежат на прямых, все равенства условия выполняются точно (треугольники FGH и CDI оба со сторонами 9, 12, 15). Периметры, измеренные программой прямо как длины ломаных, дали 144, 168, 132, 156 для данных и 192, 144, 180, 204 для спрошенных.*

*Отрезки оригинального чертежа, измеренные по PDF, стоят в тех же пропорциях: FD : GC ≈ 0,75 = 54 : 72, FH : GC ≈ 12 : 72.*

**Ответ на задачу:** периметр CEG равен **192 см**, периметр CDFH — **144 см**, периметр DEGI — **180 см**, периметр ABCEG — **204 см**. *(официальный ключ ✓ по всем четырём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Буквы:

- a = CD = BC = AG = FG (FGH = CDI)
- DE = EF = 3a (CE = 4a)
- b = FD = AB = HI
- c = FH = DI
- d = GH = IC

Уравнения:

**(1) P(DEF): 6a + b = 144**

**(2) P(DEFHI): 6a + b + 2c = 168**

**(3) P(DFHI): 2b + 2c = 132**

**(4) P(CDFG): 2a + 2b + 2d = 156**

> ✅ **План:**
>
> **P(CEG) = 4a + 4a + d + b + d**
>
> **P(CDFH) = a + b + c + b + d**
>
> **P(DEGI) = 3a + 4a + d + b + c**
>
> **P(ABCEG) = b + a + 4a + 4a + a**

Решение:

- (2) − (1): 2c = 24 → **c = 12**
- (3): 2b = 108 → **b = 54**
- (1): 6a = 90 → **a = 15**
- (4): 2d = 156 − 30 − 108 = 18 → **d = 9**

**P(CEG) = 60 + 60 + 72 = 192**

**P(CDFH) = 15 + 54 + 12 + 54 + 9 = 144**

**P(DEGI) = 45 + 60 + 9 + 54 + 12 = 180**

**P(ABCEG) = 54 + 15 + 60 + 60 + 15 = 204**

Проверка сложением:

- (1): 45 + 45 + 54 = 144 ✓
- (2): 45 + 45 + 12 + 54 + 12 = 168 ✓
- (3): 54 + 12 + 54 + 12 = 132 ✓
- (4): 15 + 54 + 15 + 9 + 54 + 9 = 156 ✓
