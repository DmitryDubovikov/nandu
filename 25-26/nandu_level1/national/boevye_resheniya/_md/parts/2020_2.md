## №2 — треугольник и его утроенные стороны *(Т2: периметры, большие отрезки через стороны маленького треугольника)*

**Условие.** На рисунке точки A, F и E лежат на одной прямой, треугольник CDE — равносторонний, CE = 3AF, CF = 3AB, EF = 3BF. Периметр ABF равен 48 см, периметр CDEF равен 180 см, периметр ABCF равен 128 см, периметр BCF равен 120 см. Каков периметр CDE? Каков периметр BCEF? Каков периметр ABCDE?

*Как устроен рисунок.* Сверху треугольник CDE: D наверху, E слева, C справа. Из E вниз идёт длинный косой отрезок к F; F стоит прямо под C, и их соединяет вертикальный отрезок CF. Справа от F — точка B, отрезок FB горизонтальный, и B соединена с C. Под отрезком FB — маленький треугольник ABF с вершиной A внизу. Всего на рисунке девять отрезков: DE, DC, CE, EF, FC, CB, FB, FA, AB.

**Равносторонний треугольник** — треугольник, у которого все три стороны равны. У CDE это значит: CD, DE и CE — одной длины.

**Точки на одной прямой.** A, F и E лежат на одной прямой, и F — между A и E. Значит, путь от E до A идёт через F, и отрезок EA складывается из двух кусков:

EA = EF + FA

**Заметь главное.** Все три равенства условия говорят одно и то же: длинный отрезок равен **утроенной стороне маленького треугольника ABF**. Сторона AF, утроенная, — это CE (а с ним CD и DE, ведь CDE равносторонний). Сторона AB, утроенная, — это CF. Сторона BF, утроенная, — это EF. Поэтому букв нужно всего три на весь рисунок — по одной на каждую сторону ABF:

- a = AF, тогда CE = CD = DE = 3a;
- b = AB, тогда CF = 3b;
- c = BF, тогда EF = 3c.

Только BC ни с чем не связан — через a, b, c его не выразить; ему четвёртая буква d. Четыре буквы и четыре данных периметра: задача сводится к четырём неизвестным.

**Шаг 1 — план: записать спрошенные периметры через четыре буквы.**

`P(X)` — периметр контура X: обхожу контур карандашом по буквам и складываю отрезки. Например, данное условия «периметр ABF равен 48» записывается так:

P(ABF) = AB + BF + FA = 48

Треугольник CDE — три стороны по 3a:

P(CDE) = 3a + 3a + 3a

Контур BCEF идёт B → C → E → F → B, то есть BC, CE, EF и FB. Отрезок CF остаётся внутри, в контур не входит:

P(BCEF) = d + 3a + 3c + c

Контур ABCDE идёт A → B → C → D → E → A, то есть AB, BC, CD, DE и EA. Последний кусок E → A проходит через F, поэтому он равен EF + FA:

P(ABCDE) = b + d + 3a + 3a + 3c + a

> ✅ **План готов:**
>
> **P(CDE) = 3a + 3a + 3a**
>
> **P(BCEF) = d + 3a + 3c + c**
>
> **P(ABCDE) = b + d + 3a + 3a + 3c + a**
>
> - `a` — длина AF;
> - `b` — длина AB;
> - `c` — длина BF;
> - `d` — длина BC.
>
> Ответ = три периметра, расписанные через `a`, `b`, `c`, `d`.
>
> Осталось найти: `a`, `b`, `c`, `d` — из четырёх данных периметров.

**Шаг 2 — четыре данных периметра, записанные буквами.** Каждый контур обхожу карандашом.

Треугольник ABF: AB, BF, FA —

(1) b + c + a = 48

Четырёхугольник CDEF: C → D → E → F → C, то есть CD, DE, EF, FC —

(2) 3a + 3a + 3c + 3b = 180

Четырёхугольник ABCF: A → B → C → F → A, то есть AB, BC, CF, FA (отрезок BF внутри) —

(3) b + d + 3b + a = 128

Треугольник BCF: BC, CF, FB —

(4) d + 3b + c = 120

**Шаг 3 — в контуре CDEF спрятан утроенный треугольник ABF.** В уравнении (2) стоят 3a, 3b и 3c — это три стороны ABF, каждая взятая трижды, — и сверху ещё одно лишнее 3a. Утроенный треугольник ABF весит

3a + 3b + 3c = 3 · 48 = 144

Значит, на лишнее 3a приходится остаток:

3a = 180 − 144 = 36

**a = 12**

**Шаг 4 — в (3) и (4) стоит один и тот же кусок d + 3b.** Контуры ABCF и BCF оба идут B → C → F (это и есть общий кусок BC + CF), а дальше расходятся — каждый по-своему возвращается в B:

ABCF: … → F → A → B, кусок a + b

BCF: … → F → B, кусок c

Вычитаю (4) из (3) — общий кусок уходит, остаётся разница концовок:

(a + b) − c = 128 − 120 = 8

Подставляю a = 12:

12 + b − c = 8

Прибавляю c к обеим частям — «минус c» слева уходит:

12 + b = c + 8

Слева b вместе с двенадцатью, справа c вместе с восьмёркой, и суммы равны. Восьмёрка на 4 меньше двенадцати — значит, c больше b на 12 − 8 = 4:

c − b = 4

**Шаг 5 — в треугольнике ABF теперь известна сумма двух остальных сторон.** Из уравнения (1):

b + c = 48 − 12 = 36

Сумма b и c равна 36, и c больше b на 4. Отнимаю лишние 4 — остаются две одинаковые части по b:

b + b = 36 − 4 = 32

**b = 16**

c = 16 + 4

**c = 20**

**Шаг 6 — в треугольнике BCF неизвестна только сторона BC.** В уравнении (4) CF = 3b = 48 и FB = c = 20 уже известны:

d = 120 − 48 − 20

**d = 52**

**Шаг 7 — сборка.** Подставляю a = 12, b = 16, c = 20, d = 52 в формулы плана. Сначала длинные отрезки: 3a = 36, 3c = 60.

- **P(CDE)** = 36 + 36 + 36 = **108**
- **P(BCEF)** = 52 + 36 + 60 + 20 = **168**
- **P(ABCDE)** = 16 + 52 + 36 + 36 + 60 + 12 = **212**

Проверка по данным условия:

- P(ABF) = 16 + 20 + 12 = 48 ✓
- P(CDEF) = 36 + 36 + 60 + 48 = 180 ✓
- P(ABCF) = 16 + 52 + 48 + 12 = 128 ✓
- P(BCF) = 52 + 48 + 20 = 120 ✓

**⚠ Ловушки.** (1) Последняя сторона контура ABCDE — это EA целиком, от E через F до A:

EA = EF + FA = 60 + 12 = 72

а не только EF = 60. Точка F лежит на этой стороне, и забыть кусок FA — самая частая потеря 12 см. (2) CE = 3AF значит, что CE втрое **длиннее** AF, а не AF втрое длиннее CE: тройка стоит у короткого отрезка. (3) В контурах BCEF и ABCF внутри остаются разные отрезки: в BCEF — CF, в ABCF — BF.

*Проверка вторым способом: полный перебор целых длин (каждый из девяти отрезков своей переменной, AF и AB до 100, BC до 300) под семь равенств условия и четыре данных периметра дал единственное решение AF = 12, AB = 16, BF = 20, BC = 52 и те же три ответа 108, 168, 212. Кроме того, фигура с этими длинами действительно строится: треугольники ABF (12, 16, 20) и CEF (36, 48, 60) — прямоугольные с пропорцией сторон 3 : 4 : 5, BCF (20, 48, 52) — прямоугольный с пропорцией 5 : 12 : 13, что совпадает с оригинальным чертежом (CF вертикален, FB горизонтален, CE горизонтален), и точка F в этих координатах лежит ровно на прямой AE.*

**Ответ на задачу:** периметр CDE равен **108 см**, периметр BCEF — **168 см**, периметр ABCDE — **212 см**. *(официальный ключ ✓ по всем трём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики: a = AF · b = AB · c = BF · d = BC; CE = CD = DE = 3a, CF = 3b, EF = 3c, EA = 3c + a.

> ✅ **План:**
>
> **P(CDE) = 3a + 3a + 3a**
>
> **P(BCEF) = d + 3a + 3c + c**
>
> **P(ABCDE) = b + d + 3a + 3a + 3c + a**
>
> Осталось найти a, b, c, d из P(ABF), P(CDEF), P(ABCF), P(BCF).

- P(CDEF) = 6a + 3b + 3c = 3 · 48 + 3a = 180 → 3a = 36 → **a = 12**
- P(ABCF) − P(BCF) = a + b − c = 128 − 120 = 8 → c − b = 4
- P(ABF): b + c = 48 − 12 = 36 → **b = 16**, **c = 20**
- P(BCF) = d + 3b + c = 120 → **d = 120 − 48 − 20 = 52**

**P(CDE) = 36 + 36 + 36 = 108**

**P(BCEF) = 52 + 36 + 60 + 20 = 168**

**P(ABCDE) = 16 + 52 + 36 + 36 + 72 = 212**

Проверка сложением: P(ABF) = 16 + 20 + 12 = 48 ✓; P(CDEF) = 36 + 36 + 60 + 48 = 180 ✓; P(ABCF) = 16 + 52 + 48 + 12 = 128 ✓; P(BCF) = 52 + 48 + 20 = 120 ✓
