## №2 — треугольник и его утроенные стороны *(Т2: периметры, большие отрезки через стороны маленького треугольника)*

**Условие.** На рисунке точки A, F и E лежат на одной прямой, треугольник CDE — равносторонний, CE = 3AF, CF = 3AB, EF = 3BF. Периметр ABF равен 48 см, периметр CDEF равен 180 см, периметр ABCF равен 128 см, периметр BCF равен 120 см. Каков периметр CDE? Каков периметр BCEF? Каков периметр ABCDE?

*Как устроен рисунок.* Сверху треугольник CDE: D наверху, E слева, C справа. Из E вниз идёт длинный косой отрезок к F; F стоит прямо под C, и их соединяет вертикальный отрезок CF. Справа от F — точка B, отрезок FB горизонтальный, и B соединена с C. Под отрезком FB — маленький треугольник ABF с вершиной A внизу. Всего на рисунке девять отрезков: DE, DC, CE, EF, FC, CB, FB, FA, AB.

**Равносторонний треугольник** — треугольник, у которого все три стороны равны. У CDE это значит: CD, DE и CE — одной длины.

**Точки на одной прямой.** A, F и E лежат на одной прямой, и F — между A и E. Значит, путь от E до A идёт через F, и отрезок EA складывается из двух кусков:

EA = EF + FA

**Заметь главное.** Все три равенства условия говорят одно и то же: длинный отрезок равен **утроенной стороне маленького треугольника ABF**. Сторона AF, утроенная, — это CE (а с ним CD и DE, ведь CDE равносторонний). Сторона AB, утроенная, — это CF. Сторона BF, утроенная, — это EF. Поэтому на весь рисунок хватает трёх букв — по одной на каждую сторону ABF. Только BC ни с чем не связан — через стороны ABF его не выразить, и ему нужна четвёртая буква. Четыре буквы и четыре данных периметра: четыре уравнения на четыре неизвестных.

### Часть 1 — геометрия: что даёт рисунок

**Буквы.** Три стороны маленького треугольника ABF и отрезок BC:

- a = AF; ему втрое равны стороны равностороннего треугольника: CE = CD = DE = 3a;
- b = AB; ему втрое равен CF = 3b;
- c = BF; ему втрое равен EF = 3c;
- d = BC — ни с чем не связан.

F лежит между A и E, поэтому EA складывается из двух кусков:

EA = EF + FA = 3c + a

`P(X)` — периметр контура X: обхожу контур карандашом по буквам и складываю отрезки.

**Уравнения из условия.** Каждый данный периметр — обход контура по рисунку.

Контур ABF: AB, BF, FA.

**(1) b + c + a = 48**

Контур CDEF: CD, DE, EF, FC.

**(2) 3a + 3a + 3c + 3b = 180**

Контур ABCF: AB, BC, CF, FA; отрезок BF остаётся внутри.

**(3) b + d + 3b + a = 128**

Контур BCF: BC, CF, FB.

**(4) d + 3b + c = 120**

**Что спрошено.** Каждый искомый периметр — тоже обход.

Контур CDE: три стороны по 3a.

Контур BCEF: B → C → E → F → B, то есть BC, CE, EF, FB; отрезок CF остаётся внутри.

Контур ABCDE: A → B → C → D → E → A, то есть AB, BC, CD, DE и EA; последняя сторона E → A идёт сквозь F, она равна 3c + a.

> ✅ **План готов:**
>
> **P(CDE) = 3a + 3a + 3a**
>
> **P(BCEF) = d + 3a + 3c + c**
>
> **P(ABCDE) = b + d + 3a + 3a + (3c + a)**
>
> Осталось найти: a, b, c, d — из системы (1)–(4).

### Часть 2 — алгебра: решаем систему

Заметь: в (2) стоят 3a, 3b и 3c — это утроенное (1), — и сверху ещё одно лишнее 3a. Утроенное (1):

3a + 3b + 3c = 3 · 48 = 144

Метод вычитания, (2) − 3 · (1): утроенный треугольник уходит, остаётся лишнее 3a.

**3a = 180 − 144 = 36**

**a = 12**

В (3) и (4) стоят одни и те же d и 3b: оба контура идут B → C → F, а расходятся только концовкой — ABCF возвращается через A (куски a и b), BCF сразу в B (кусок c). Метод вычитания, (3) − (4): d и 3b уходят.

**(5) a + b − c = 8**

Подставляю a = 12:

12 + b − c = 8

Из 12 + b вычли c и получили 8 — значит, c на 12 − 8 = 4 больше, чем b:

**(6) c = b + 4**

(1) с a = 12:

**(7) b + c = 36**

Метод подстановки, (6) в (7):

b + (b + 4) = 36

2b = 32

**b = 16**

**c = 16 + 4 = 20**

(4), подставляю 3b = 48 и c = 20:

**d = 120 − 48 − 20 = 52**

**Сборка.** Сначала длинные отрезки:

- 3a = **36**
- 3c = **60**
- EA = 60 + 12 = **72**

Подставляю в формулы плана:

- **P(CDE)** = 36 + 36 + 36 = **108**
- **P(BCEF)** = 52 + 36 + 60 + 20 = **168**
- **P(ABCDE)** = 16 + 52 + 36 + 36 + 72 = **212**

Проверка подстановкой в (1)–(4):

- (1): 16 + 20 + 12 = 48 ✓
- (2): 36 + 36 + 60 + 48 = 180 ✓
- (3): 16 + 52 + 48 + 12 = 128 ✓
- (4): 52 + 48 + 20 = 120 ✓

**⚠ Ловушки.**

1. Последняя сторона контура ABCDE — это EA целиком, от E через F до A, то есть 60 + 12 = 72, а не только EF = 60. Точка F лежит на этой стороне, и забыть кусок FA — самая частая потеря 12 см.
2. CE = 3AF значит, что CE втрое **длиннее** AF, а не AF втрое длиннее CE: тройка стоит у короткого отрезка.
3. В контурах BCEF и ABCF внутри остаются разные отрезки: в BCEF — CF, в ABCF — BF.

*Проверка вторым способом: полный перебор целых длин (каждый из девяти отрезков своей переменной, AF и AB до 100, BC до 300) под семь равенств условия и четыре данных периметра дал единственное решение AF = 12, AB = 16, BF = 20, BC = 52 и те же три ответа 108, 168, 212. Кроме того, фигура с этими длинами действительно строится: треугольники ABF (12, 16, 20) и CEF (36, 48, 60) — прямоугольные с пропорцией сторон 3 : 4 : 5, BCF (20, 48, 52) — прямоугольный с пропорцией 5 : 12 : 13, что совпадает с оригинальным чертежом (CF вертикален, FB горизонтален, CE горизонтален), и точка F в этих координатах лежит ровно на прямой AE.*

**Ответ на задачу:** периметр CDE равен **108 см**, периметр BCEF — **168 см**, периметр ABCDE — **212 см**. *(официальный ключ ✓ по всем трём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Буквы:

- a = AF, CE = CD = DE = 3a
- b = AB, CF = 3b
- c = BF, EF = 3c
- d = BC
- EA = 3c + a

Уравнения:

**(1) P(ABF): b + c + a = 48**

**(2) P(CDEF): 6a + 3b + 3c = 180**

**(3) P(ABCF): b + d + 3b + a = 128**

**(4) P(BCF): d + 3b + c = 120**

> ✅ **План:**
>
> **P(CDE) = 3a + 3a + 3a**
>
> **P(BCEF) = d + 3a + 3c + c**
>
> **P(ABCDE) = b + d + 3a + 3a + (3c + a)**

Решение:

- (2) − 3 · (1): 3a = 180 − 144 = 36 → **a = 12**
- (3) − (4): (5) a + b − c = 8 → (6) c = b + 4
- (1): (7) b + c = 36
- (6) в (7): 2b = 32 → **b = 16**, **c = 20**
- (4): d = 120 − 48 − 20 → **d = 52**

**P(CDE) = 36 + 36 + 36 = 108**

**P(BCEF) = 52 + 36 + 60 + 20 = 168**

**P(ABCDE) = 16 + 52 + 36 + 36 + 72 = 212**

Проверка сложением:

- (1): 16 + 20 + 12 = 48 ✓
- (2): 36 + 36 + 60 + 48 = 180 ✓
- (3): 16 + 52 + 48 + 12 = 128 ✓
- (4): 52 + 48 + 20 = 120 ✓
