## №1 — четверо друзей и подарок за $2100 *(Т1′: доля от остальных — у Альдо и Бето уравнение с одной буквой)*

**Условие.** Четверо друзей — Альдо, Бето, Карлос и Дани — покупают подарок за $2100. Альдо платит половину суммы, которую заплатили трое остальных. Бето платит третью часть суммы, которую заплатили трое остальных. Карлос платит четвёртую часть суммы, которую заплатили Альдо и Дани. Сколько платит каждый из четырёх друзей?

**Заметь главное.** «Остальные трое» — это все четверо без самого Альдо, то есть весь подарок минус то, что заплатил Альдо. Если назвать `a` то, что заплатил Альдо, то

остальные для Альдо = 2100 − a

Поэтому фраза «Альдо платит половину того, что остальные» содержит **одну** неизвестную — самого Альдо, и решается отдельно, без системы. То же с Бето. У Карлоса иначе: его доля взята не от всех остальных, а только от двоих — Альдо и Дани, и в этой фразе сидят две неизвестные, он сам и Дани. А про Дани в условии нет никакой фразы вовсе — значит, Дани — это то, что осталось от $2100 после остальных троих.

*💬 «Называю буквами то, чего не знаю, и каждое данное записываю равенством» — это и есть мысль для фразы-объяснения: каждая фраза условия становится равенством, а «остальные» записываются как весь подарок минус сам человек.*

**Шаг 1 — план.** Каждого назовём первой буквой имени: `a` — Альдо, `b` — Бето, `c` — Карлос, `d` — Дани (в долларах).

Фраза про Альдо: «остальные» — это 2100 без Альдо, а Альдо платит половину этого.

a = (2100 − a) / 2

Фраза про Бето — так же, только доля третья.

b = (2100 − b) / 3

Про Дани фразы нет — он остаток: весь подарок минус трое других.

d = 2100 − a − b − c

Фраза про Карлоса: четверть от того, что заплатили Альдо и Дани вместе.

c = (a + d) / 4

Сразу эту строчку не решить — в ней две неизвестные, `c` и `d`. Поэтому строчки решаются сверху вниз: первые две — сами по себе, третья выразит Дани через Карлоса, и тогда в четвёртой останется одна буква.

> ✅ **План готов:**
>
> a = (2100 − a) / 2
>
> b = (2100 − b) / 3
>
> d = 2100 − a − b − c
>
> c = (a + d) / 4
>
> - `a` — сколько заплатил Альдо ($);
> - `b` — сколько заплатил Бето ($);
> - `c` — сколько заплатил Карлос ($);
> - `d` — сколько заплатил Дани ($).
>
> Ответ = a, b, c, d
>
> Осталось найти:
>
> - `a` — из первой строчки, сама по себе;
> - `b` — из второй строчки, сама по себе;
> - `d` — сначала только через `c`, из третьей строчки;
> - `c` — из четвёртой, когда в ней останется одна буква; затем `d` числом.

**Шаг 2 — считаю `a`.** Нужен Альдо, а про него сказано «доля от остальных» — значит, он находится сам, из первой строчки плана. Мешает дробь — умножаю обе части на 2:

2 · a = 2100 − a

Слева и справа есть `a`. Прибавляю `a` к обеим частям: слева станет три `a`, справа минус `a` пропадёт.

2 · a + a = 2100 − a + a

3 · a = 2100

→ **a = 700**

**Шаг 3 — считаю `b`.** Нужен Бето — у него та же фраза «доля от остальных», значит, та же работа со второй строчкой: умножаю обе части на 3:

3 · b = 2100 − b

Так же, как с Альдо, прибавляю `b` к обеим частям:

4 · b = 2100

→ **b = 525**

**Шаг 4 — выражаю `d` через `c`.** Чтобы в четвёртой строчке осталась одна буква, Дани надо записать через Карлоса. Подставляю найденные `a` и `b` в третью строчку:

d = 2100 − 700 − 525 − c

d = 875 − c

**Шаг 5 — считаю `c`.** Нужен Карлос — он в четвёртой строчке. Подставляю в неё `a = 700`, а вместо `d` — только что полученное выражение; букв остаётся одна:

c = (700 + 875 − c) / 4

Умножаю обе части на 4:

4 · c = 1575 − c

Так же прибавляю `c` к обеим частям:

5 · c = 1575

→ **c = 315**

**Шаг 6 — сборка.** Карлос теперь число — возвращаюсь к третьей строчке плана, где Дани был выражен через него:

d = 875 − 315 = 560

Проверка по каждой фразе условия:

- всего: 700 + 525 + 315 + 560 = 2100 ✓
- остальные для Альдо: 525 + 315 + 560 = 1400, половина — 700 ✓
- остальные для Бето: 700 + 315 + 560 = 1575, третья часть — 525 ✓
- Альдо и Дани: 700 + 560 = 1260, четвёртая часть — 315 ✓

⚠ **Ловушка 1.** Прочитать «половину того, что заплатили остальные» как «половину всего подарка» и получить Альдо $1050. Сам Альдо в «остальных» не участвует: его доля берётся от того, что заплатили трое других, а не от всех 2100.

⚠ **Ловушка 2.** У Карлоса доля взята не от «остальных трёх», а только от Альдо и Дани. Кто решит его строчку так же, как у Альдо и Бето, запишет неверное уравнение

c = (2100 − c) / 4

и получит $420 — а четверть от суммы Альдо и Дани не сойдётся.

Проверка вторым способом: перебор по целым долларам (для каждой пары Альдо–Бето сначала проверяются первые два условия, и только для прошедших перебираются все суммы Карлоса, Дани — остаток) и прямая подстановка в каждую фразу условия дают единственное решение 700, 525, 315, 560; метод исключения неизвестных в системе из четырёх уравнений даёт то же; совпадает с официальным ключом.

**Ответ на задачу:** Альдо платит $700, Бето — $525, Карлос — $315, Дани — $560.

#### 💬 Фраза-объяснение (в начале)

**Llamo a, b, c, d a lo que no sé y escribo cada dato como una igualdad.**

*Называю буквами то, чего не знаю, и каждое данное записываю равенством.*

#### Запись

`a` — Альдо, `b` — Бето, `c` — Карлос, `d` — Дани ($).

> ✅ **План:**
>
> **Ответ = a, b, c, d**

- `a = (2100 − a) / 2` → `3 · a = 2100` → `a = 700`
- `b = (2100 − b) / 3` → `4 · b = 2100` → `b = 525`
- `d = 2100 − 700 − 525 − c` → `d = 875 − c`
- `4 · c = 700 + 875 − c` → `5 · c = 1575` → `c = 315`
- `d = 875 − 315 = 560`

Проверка: `700 + 525 + 315 + 560 = 2100` ✓; `(700 + 560) : 4 = 315` ✓
