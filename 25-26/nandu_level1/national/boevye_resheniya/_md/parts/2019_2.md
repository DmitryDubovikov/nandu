## №2 — квадрат с двумя полосками справа *(Т2: всё меряется стороной квадрата, дробная пропорция → доля)*

**Условие.** На рисунке ABGH — квадрат; KLMI, IMGH, BCFG и CDEF — прямоугольники. AB = 3·BC, BC = 3·CD, HI = ½·IK, IK = ½·KA. Периметр KLMI равен 324 см. Чему равен периметр IMGH? Чему равен периметр BCFG? Чему равен периметр BDEG? Чему равен периметр ACFH?

**Как устроен рисунок.** Слева квадрат ABGH: A — левый низ, B — правый низ, G — правый верх, H — левый верх. Его левая сторона AH и правая сторона BG разрезаны двумя горизонталями: верхняя идёт от I к M, нижняя — от K к L. Так квадрат делится на три этажа: сверху узкая полоска IMGH, в середине полоска KLMI, внизу всё остальное. Справа к квадрату приставлены две вертикальные полоски во всю его высоту: сначала BCFG, за ней ещё более узкая CDEF. Нижний край A, B, C, D и верхний край H, G, F, E — прямые линии.

**Кирпичики.** Неизвестных отрезков четыре, каждому — буква:

- k — отрезок HI;
- a — сторона квадрата ABGH (AB = BG = GH = HA);
- b — отрезок BC;
- c — отрезок CD.

`P(X)` — периметр фигуры X; например, P(KLMI) = 324 — данное условия.

**Заметь главное. Весь рисунок меряется одной стороной квадрата.** Посмотри, куда ни глянь:

- горизонтали IM и KL идут через весь квадрат — их длина a;
- полоски BCFG и CDEF стоят во всю высоту квадрата — их высота тоже a;
- BC и CD по условию — доли от AB, то есть опять от a.

А узнать a можно только через левую сторону AH: её точки I и K режут на куски, и пропорции условия эти куски сравнивают. Слово «квадрат» — это мост: сторона AH вертикальная, AB горизонтальная, но они равны. Поэтому всё, что узнаем про вертикальные куски на AH, сразу переходит в горизонтальную ширину квадрата.

**Шаг 1 — план: обойти четыре спрошенных контура и назвать стороны буквами.** Нужны четыре периметра — для этого обхожу каждый прямоугольник и называю ширину и высоту через k, a, b, c.

IMGH — верхний этаж квадрата. Ширина IM идёт через весь квадрат, это a; высота HI — это k:

P(IMGH) = 2·(a + k)

BCFG — первая полоска справа. Ширина BC — это b; высота BG — сторона квадрата, a:

P(BCFG) = 2·(b + a)

BDEG — обе полоски вместе. Ширина BD — это BC и CD подряд; высота DE равна высоте полоски CDEF, а она стоит во всю высоту квадрата:

P(BDEG) = 2·((b + c) + a)

ACFH — квадрат вместе с первой полоской. Ширина AC — это AB и BC подряд; высота AH — сторона квадрата:

P(ACFH) = 2·((a + b) + a)

> ✅ **План готов:**
>
> **P(IMGH) = 2·(a + k)**
>
> **P(BCFG) = 2·(b + a)**
>
> **P(BDEG) = 2·((b + c) + a)**
>
> **P(ACFH) = 2·((a + b) + a)**
>
> - k — отрезок HI;
> - a — сторона квадрата;
> - b — отрезок BC;
> - c — отрезок CD.
>
> Ответ = четыре периметра по этим формулам.
>
> Осталось найти k, a, b, c.

**Шаг 2 — сторона AH разрезана на три куска, и пропорции сравнивают их по очереди.** Первая пропорция говорит, что HI — половина IK, то есть HI вдвое **короче** IK. Вторая — что IK половина KA, то есть IK вдвое короче KA. Дробь ½ — сигнал взять за долю самый маленький кусок, тогда дробей не будет. Самый маленький — HI, это и есть k:

HI = k

IK = 2k

KA = 4k

Вся сторона AH — три куска подряд:

AH = k + 2k + 4k = 7k

ABGH — квадрат, поэтому ширина AB равна высоте AH (ритуал 4: пометка «квадрат» — это уравнение):

→ **a = 7k**

**Шаг 3 — периметр KLMI дан, а обе его стороны уже выражены через k.** Средний этаж KLMI: ширина KL идёт через весь квадрат — это сторона квадрата, 7k; высота — отрезок IK, 2k. Обвожу контур:

7k + 2k + 7k + 2k = 324

18k = 324

→ **k = 18**

Отсюда сторона квадрата:

a = 7 · 18 = 126

→ **a = 126**

**Шаг 4 — нижний край справа от A идёт кусками, и каждый следующий втрое короче предыдущего.** По условию AB втрое длиннее BC, а BC втрое длиннее CD. AB — это сторона квадрата, значит, BC — треть стороны, а CD — треть BC:

b = 126 : 3 = 42

c = 42 : 3 = 14

→ **b = 42**, **c = 14**

**Шаг 5 — сборка: подставляю k = 18, a = 126, b = 42, c = 14 в формулы плана.**

Сначала две ширины, составленные из кусков:

b + c = 42 + 14 = 56

a + b = 126 + 42 = 168

- **P(IMGH)** = 2·(126 + 18) = **288**
- **P(BCFG)** = 2·(42 + 126) = **336**
- **P(BDEG)** = 2·(56 + 126) = **364**
- **P(ACFH)** = 2·(168 + 126) = **588**

**⚠ Ловушки.** (1) Пропорцию про HI и IK легко прочесть задом наперёд. HI — половина IK, значит, HI **короче**: подставь HI = 1, получится IK = 2. (2) KA — это не 2k, а 4k: KA вдвое длиннее IK, а IK уже 2k. (3) Высота полосок BCFG и CDEF — не BC и не CD, а сторона квадрата: полоски стоят во всю его высоту. (4) Ширина KLMI — вся сторона квадрата a, а не какой-то новый отрезок: точки L и M лежат на BG.

Проверка вторым способом: программа перебрала целые длины HI, IK, KA до 800 и оставила только те, что буквально выполняют обе пропорции условия про HI, IK и KA; построила квадрат со стороной HI + IK + KA по координатам, приставила полоски по двум пропорциям нижнего края и нашла периметры как длину обхода вершин. Условию P(KLMI) = 324 отвечает единственный набор HI = 18, IK = 36, KA = 72, и он даёт те же 288, 336, 364 и 588.

**Ответ на задачу:** периметр IMGH равен 288 см, периметр BCFG — 336 см, периметр BDEG — 364 см, периметр ACFH — 588 см. *(официальный ключ ✓ по всем четырём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и деление говорят сами за себя.*

#### Запись

Кирпичики: k = HI · a = сторона квадрата · b = BC · c = CD. HI = k, IK = 2k, KA = 4k → AH = 7k = a.

> ✅ **План:**
>
> **P(IMGH) = 2·(a + k)**
>
> **P(BCFG) = 2·(b + a)**
>
> **P(BDEG) = 2·((b + c) + a)**
>
> **P(ACFH) = 2·((a + b) + a)**
>
> Осталось найти k, a, b, c.

- P(KLMI) = 324 → 7k + 2k + 7k + 2k = 324 → 18k = 324 → **k = 18**
- a = 7 · 18 → **a = 126**
- AB = 3·BC → b = 126 : 3 → **b = 42**
- BC = 3·CD → c = 42 : 3 → **c = 14**

**P(IMGH) = 2·(126 + 18) = 288**

**P(BCFG) = 2·(42 + 126) = 336**

**P(BDEG) = 2·(56 + 126) = 364**

**P(ACFH) = 2·(168 + 126) = 588**

Проверка сложением: HI + IK + KA = 18 + 36 + 72 = 126 = AB ✓; P(KLMI) = 2·(126 + 36) = 324 ✓
