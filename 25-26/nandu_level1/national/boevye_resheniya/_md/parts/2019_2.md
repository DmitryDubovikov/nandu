## №2 — квадрат с двумя полосками справа *(Т2: всё меряется стороной квадрата, дробная пропорция → доля)*

**Условие.** На рисунке ABGH — квадрат; KLMI, IMGH, BCFG и CDEF — прямоугольники. AB = 3 · BC, BC = 3 · CD, HI = ½ · IK, IK = ½ · KA. Периметр KLMI равен 324 см. Чему равен периметр IMGH? Чему равен периметр BCFG? Чему равен периметр BDEG? Чему равен периметр ACFH?

**Как устроен рисунок.** Слева квадрат ABGH: A — левый низ, B — правый низ, G — правый верх, H — левый верх. Его левая сторона AH и правая сторона BG разрезаны двумя горизонталями: верхняя идёт от I к M, нижняя — от K к L. Так квадрат делится на три этажа: сверху узкая полоска IMGH, в середине полоска KLMI, внизу всё остальное. Справа к квадрату приставлены две вертикальные полоски во всю его высоту: сначала BCFG, за ней ещё более узкая CDEF. Нижний край A, B, C, D и верхний край H, G, F, E — прямые линии.

**Заметь главное. Весь рисунок меряется одной стороной квадрата.** Посмотри, куда ни глянь:

- горизонтали IM и KL идут через весь квадрат — их длина равна стороне квадрата;
- полоски BCFG и CDEF стоят во всю высоту квадрата — их высота тоже равна стороне квадрата;
- BC и CD по условию — доли от AB, то есть опять от стороны квадрата.

А узнать сторону квадрата можно только через левую сторону AH: её точки I и K режут на куски, и пропорции условия эти куски сравнивают. Слово «квадрат» — это мост: сторона AH вертикальная, AB горизонтальная, но они равны. Поэтому всё, что узнаем про вертикальные куски на AH, сразу переходит в горизонтальную ширину квадрата.

### Часть 1 — геометрия: что даёт рисунок

**Буквы.** `P(X)` — периметр фигуры X; например, P(KLMI) = 324 — данное условия.

Левая сторона AH разрезана на три куска, и пропорции сравнивают их по очереди. Первая говорит, что HI — половина IK, то есть HI вдвое **короче** IK. Вторая — что IK половина KA, то есть IK вдвое короче KA. Дробь ½ — сигнал взять за долю самый маленький кусок, тогда дробей не будет. Самый маленький — HI, его и назову буквой:

- k = HI; тогда IK = 2k, а KA = 2 · 2k = 4k (2k значит 2 · k: знак умножения перед буквой обычно пропускают);
- a — сторона квадрата ABGH: ей равны AB, BG, GH, HA, горизонтали IM и KL, высоты полосок CF и DE;
- b = BC, ему равен FG;
- c = CD, ему равен EF.

**Уравнения из условия.**

Квадрат: нижняя сторона AB равна левой стороне AH, а AH — это три куска подряд, HI, IK и KA.

**(1) a = k + 2k + 4k**

Контур KLMI: ширины KL и MI идут через весь квадрат, это a; высоты LM и IK — по 2k.

**(2) a + 2k + a + 2k = 324**

Равенство AB = 3 · BC: AB — сторона квадрата.

**(3) a = 3b**

Равенство BC = 3 · CD.

**(4) b = 3c**

**Что спрошено.** Каждый спрошенный периметр — тоже обход, и все четыре контура — прямоугольники.

IMGH — верхний этаж квадрата: ширина IM идёт через весь квадрат, это a; высота HI — это k.

BCFG — первая полоска справа: ширина BC — это b; высота BG — сторона квадрата, a.

BDEG — обе полоски вместе: ширина BD — это BC и CD подряд; высота DE равна высоте полоски CDEF, а она стоит во всю высоту квадрата.

ACFH — квадрат вместе с первой полоской: ширина AC — это AB и BC подряд; высота AH — сторона квадрата.

> ✅ **План готов:**
>
> **P(IMGH) = 2 · (a + k)**
>
> **P(BCFG) = 2 · (b + a)**
>
> **P(BDEG) = 2 · ((b + c) + a)**
>
> **P(ACFH) = 2 · ((a + b) + a)**
>
> Осталось найти: k, a, b, c — из системы (1)–(4).

### Часть 2 — алгебра: решаем систему

Система треугольная: в (1) и (2) стоят только a и k, дальше (3) даёт b через a, (4) — c через b. Решаю методом подстановки.

(1) — складываю куски:

**a = 7k**

подставить a = 7k в (2):

7k + 2k + 7k + 2k = 324

18k = 324, **k = 18**

снова (1): a = 7 · 18, **a = 126**

(3): b = 126 : 3, **b = 42**

(4): c = 42 : 3, **c = 14**

**Сборка: подставляю k = 18, a = 126, b = 42, c = 14 в формулы плана.**

Сначала две ширины, составленные из кусков:

b + c = 42 + 14 = 56

a + b = 126 + 42 = 168

- **P(IMGH)** = 2 · (126 + 18) = **288**
- **P(BCFG)** = 2 · (42 + 126) = **336**
- **P(BDEG)** = 2 · (56 + 126) = **364**
- **P(ACFH)** = 2 · (168 + 126) = **588**

**⚠ Ловушки.**

- Пропорцию про HI и IK легко прочесть задом наперёд. HI — половина IK, значит, HI **короче**: подставь HI = 1, получится IK = 2.
- KA — это не 2k, а 4k: KA вдвое длиннее IK, а IK уже 2k.
- Высота полосок BCFG и CDEF — не BC и не CD, а сторона квадрата: полоски стоят во всю его высоту.
- Ширина KLMI — вся сторона квадрата a, а не какой-то новый отрезок: точки L и M лежат на BG.

Проверка вторым способом: программа перебрала целые длины HI, IK, KA до 800 и оставила только те, что буквально выполняют обе пропорции условия про HI, IK и KA; построила по координатам квадрат, сторона которого — эти три куска вместе,, приставила полоски по двум пропорциям нижнего края и нашла периметры как длину обхода вершин. Условию P(KLMI) = 324 отвечает единственный набор HI = 18, IK = 36, KA = 72, и он даёт те же 288, 336, 364 и 588.

**Ответ на задачу:** периметр IMGH равен 288 см, периметр BCFG — 336 см, периметр BDEG — 364 см, периметр ACFH — 588 см. *(официальный ключ ✓ по всем четырём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и деление говорят сами за себя.*

#### Запись

Буквы:

- k = HI, тогда IK = 2k, KA = 4k;
- a — сторона квадрата;
- b = BC;
- c = CD.

Уравнения:

**(1) квадрат: a = k + 2k + 4k = 7k**

**(2) P(KLMI): a + 2k + a + 2k = 324**

**(3) a = 3b**

**(4) b = 3c**

> ✅ **План:**
>
> **P(IMGH) = 2 · (a + k)**
>
> **P(BCFG) = 2 · (b + a)**
>
> **P(BDEG) = 2 · ((b + c) + a)**
>
> **P(ACFH) = 2 · ((a + b) + a)**

Решение:

- (1) в (2) → 18k = 324 → **k = 18**
- (1) → a = 7 · 18 → **a = 126**
- (3) → b = 126 : 3 → **b = 42**
- (4) → c = 42 : 3 → **c = 14**

**P(IMGH) = 2 · (126 + 18) = 288**

**P(BCFG) = 2 · (42 + 126) = 336**

**P(BDEG) = 2 · (56 + 126) = 364**

**P(ACFH) = 2 · (168 + 126) = 588**

Проверка сложением:

- HI + IK + KA = 18 + 36 + 72 = 126 = AB ✓
- P(KLMI) = 2 · (126 + 36) = 324 ✓
