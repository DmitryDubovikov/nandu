## №2 — веер из трёх равных треугольников *(Т2: периметры, внутренние стороны в сумме посчитаны дважды)*

**Условие.** На рисунке AC = AD, AE = DE, BC = CD + 9 см. Треугольники ABC, ACD и ADE имеют одинаковый периметр. Периметр ABC равен 268 см, периметр ABCDE равен 372 см. AF = 4/3·EF и EF + AE = 2·AF. Чему равен периметр ACDE? Чему равен периметр ABCDEF? Чему равен периметр ADEF?

**Как устроен рисунок.** Шестиугольник ABCDEF, и из вершины A веером выходят три отрезка внутрь: AC, AD и AE. Они режут фигуру на четыре треугольника, которые идут по кругу: ABC, ACD, ADE и внизу слева AEF.

**Кирпичики.** По ритуалу 2 равные по условию отрезки получают одну букву:

- d — AC и AD (AC = AD);
- c — CD;
- e — AE и DE (AE = DE);
- k — мелкий кирпичик для треугольника AEF.

Откуда k. Условие про AF дробное: AF составляет 4/3 от EF. Дробь в соотношении — сигнал раздробить кирпичик на знаменатель. Беру за кирпичик третью часть EF:

EF = 3k

AF = 4k

Дробь исчезла: 4/3 от трёх кирпичиков — ровно четыре кирпичика.

AB и BC своих букв пока не получают: в спрошенные контуры они по отдельности не входят (это станет видно в шаге 1), а вместе они сидят внутри P(ABCDE), который дан.

`P(X)` — периметр контура X; например, P(ABC) = 268 — данное условия.

**Заметь главное. Три треугольника вместе — это пятиугольник ABCDE, только внутренние стороны посчитаны дважды.** Треугольники ABC, ACD и ADE прилегают друг к другу и вместе закрывают пятиугольник ABCDE. Сложу их периметры и посмотрю, какая сторона сколько раз попала в сумму:

- наружные стороны AB, BC, CD, DE, EA — каждая ровно в одном треугольнике, то есть по разу: это и есть P(ABCDE);
- внутренняя сторона AC — в двух треугольниках, ABC и ACD;
- внутренняя сторона AD — тоже в двух, ACD и ADE.

Значит:

P(ABC) + P(ACD) + P(ADE) = P(ABCDE) + 2·AC + 2·AD

Это та же формула склейки, что в лайфхаке 5 регионального учебника («периметр сборки = сумма периметров деталей − 2 × каждый спрятанный стык»), только прочитанная в обратную сторону. Здесь в ней известно всё, кроме стыков, а оба стыка равны d, — и d выходит одним уравнением.

**Шаг 1 — план: обвести три спрошенных контура и записать стороны буквами.** Нужны три периметра — для этого веду карандаш по каждому контуру (ритуал 1) и называю каждую сторону.

Контур ACDE: A→C это d, C→D это c, D→E это e, E→A это снова e. Отрезок AD лежит внутри и в контур не входит:

P(ACDE) = d + c + 2e

Контур ABCDEF идёт так же, как ABCDE, — A→B→C→D→E, — и расходится с ним только в самом конце: ABCDE возвращается из E в A напрямую, по стороне EA, а ABCDEF — в обход, через F. Значит, из P(ABCDE) убираю сторону EA и добавляю ломаную E→F→A:

P(ABCDEF) = P(ABCDE) − e + 3k + 4k

P(ABCDEF) = 372 − e + 7k

Контур ADEF: A→D это d, D→E это e, E→F это 3k, F→A это 4k. Отрезок AE теперь внутри:

P(ADEF) = d + e + 7k

> ✅ **План готов:**
>
> **P(ACDE) = d + c + 2e**
>
> **P(ABCDEF) = 372 − e + 7k**
>
> **P(ADEF) = d + e + 7k**
>
> - d — AC и AD;
> - c — CD;
> - e — AE и DE;
> - k — мелкий кирпичик: EF = 3k, AF = 4k.
>
> Ответ = три периметра по этим формулам.
>
> Осталось найти d, c, e, k.

**Шаг 2 — d: в сумме трёх треугольников неизвестны только два равных стыка.** По условию все три треугольника имеют периметр 268, P(ABCDE) = 372, а AC = AD = d. Подставляю в формулу из «Заметь главное»:

268 + 268 + 268 = 372 + 2d + 2d

804 = 372 + 4d

4d = 804 − 372

4d = 432

→ **d = 108**

**Шаг 3 — c и e: в треугольнике ACD неизвестна только c, в ADE — только e.** Обхожу треугольник ACD: A→C это d, C→D это c, D→A это снова d:

d + c + d = 268

c = 268 − 216

→ **c = 52**

Обхожу треугольник ADE: A→D это d, D→E это e, E→A это снова e:

d + e + e = 268

2e = 268 − 108

2e = 160

→ **e = 80**

**Шаг 4 — k: во втором условии про F неизвестен только k.** Это условие:

EF + AE = 2·AF

Переписываю его кирпичиками — EF = 3k, AF = 4k, AE = 80:

3k + 80 = 2·4k

3k + 80 = 8k

Слева и справа убираю по 3k:

80 = 5k

→ **k = 16**

Значит, EF = 48 и AF = 64, а вся ломаная E→F→A:

7k = 112

**Шаг 5 — сборка: подставляю d = 108, c = 52, e = 80, k = 16 в формулы плана.**

- **P(ACDE)** = 108 + 52 + 160 = **320**
- **P(ABCDEF)** = 372 − 80 + 112 = **404**
- **P(ADEF)** = 108 + 80 + 112 = **300**

**А где BC = CD + 9?** Ритуал 3 требует перевести каждое данное — переводим:

BC = 52 + 9 = 61

и тогда из треугольника ABC

AB = 268 − 108 − 61 = 99

Подписать на рисунке можно, но в спрошенные контуры AB и BC по отдельности не входят, поэтому ответам это данное не понадобилось. Лишнее данное на олимпиаде бывает — это не ошибка в решении.

**⚠ Ловушки.** (1) Отрезки AC и AD лежат внутри пятиугольника: в P(ABCDE) их нет, а в сумму трёх треугольников каждый входит дважды — не «один раз» и не «трижды». (2) В контуре ABCDEF нет стороны EA: вместо неё обход идёт через F. (3) В контуре ACDE нет AD, в контуре ADEF нет AE — внутренние отрезки в периметр не входят. (4) Дробь 4/3 в условии про AF — не повод решать с дробями: мелкий кирпичик k делает все длины целыми.

Проверка вторым способом: программа перебрала все целые длины AB, BC, CD, AC = AD, AE = DE, EF, AF с учётом всех данных условия (включая BC = CD + 9) — подходит единственный набор AB = 99, BC = 61, CD = 52, AC = AD = 108, AE = DE = 80, EF = 48, AF = 64, и по нему периметры 320, 404, 300; кроме того, рисунок оригинала начерчен в масштабе, и длины, снятые с него линейкой (в масштабе AC = 108), совпадают с найденными с точностью до 1–2 см.

**Ответ на задачу:** периметр ACDE равен 320 см, периметр ABCDEF — 404 см, периметр ADEF — 300 см. *(официальный ключ ✓ по всем трём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики: d = AC = AD · c = CD · e = AE = DE · EF = 3k, AF = 4k.

> ✅ **План:**
>
> **P(ACDE) = d + c + 2e**
>
> **P(ABCDEF) = 372 − e + 7k**
>
> **P(ADEF) = d + e + 7k**
>
> Осталось найти d, c, e, k.

- P(ABC) + P(ACD) + P(ADE) = P(ABCDE) + 2·AC + 2·AD
- 3·268 = 372 + 4d → 4d = 432 → **d = 108**
- P(ACD): 2d + c = 268 → **c = 52**
- P(ADE): d + 2e = 268 → **e = 80**
- EF + AE = 2·AF: 3k + 80 = 8k → **k = 16** (EF = 48, AF = 64)

**P(ACDE) = 108 + 52 + 160 = 320**

**P(ABCDEF) = 372 − 80 + 112 = 404**

**P(ADEF) = 108 + 80 + 112 = 300**

Проверка сложением: P(ACD) + P(ADE) − 2·AD = 536 − 216 = 320 ✓; P(ADE) − AE + EF + AF = 268 − 80 + 112 = 300 ✓; AF = 64 = 4/3·48 ✓, EF + AE = 128 = 2·64 ✓
