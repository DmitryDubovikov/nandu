## №2 — веер из трёх равных треугольников *(Т2: периметры, внутренние стороны в сумме посчитаны дважды)*

**Условие.** На рисунке AC = AD, AE = DE, BC = CD + 9 см. Треугольники ABC, ACD и ADE имеют одинаковый периметр. Периметр ABC равен 268 см, периметр ABCDE равен 372 см. AF = 4/3 · EF и EF + AE = 2 · AF. Чему равен периметр ACDE? Чему равен периметр ABCDEF? Чему равен периметр ADEF?

**Как устроен рисунок.** Шестиугольник ABCDEF, и из вершины A веером выходят три отрезка внутрь: AC, AD и AE. Они режут фигуру на четыре треугольника, которые идут по кругу: ABC, ACD, ADE и внизу слева AEF.

**Заметь главное.** Все три данных треугольника — ABC, ACD и ADE — прилегают друг к другу и вместе закрывают пятиугольник ABCDE. Если сложить их периметры, в сумму попадут:

- наружные стороны AB, BC, CD, DE, EA — каждая ровно в одном треугольнике, то есть по разу: это и есть P(ABCDE);
- внутренняя сторона AC — в двух треугольниках, ABC и ACD;
- внутренняя сторона AD — тоже в двух, ACD и ADE.

Сумма трёх треугольников больше периметра пятиугольника ровно на два стыка, и каждый стык посчитан дважды. Периметры треугольников и пятиугольника даны, а оба стыка равны по условию (AC = AD), — поэтому длина стыка найдётся из одного уравнения. Здесь и начнётся алгебра.

### Часть 1 — геометрия: что даёт рисунок

**Буквы.** Равные по условию отрезки получают одну букву — так сразу видно, сколько на самом деле неизвестных.

- a = AB;
- b = BC;
- c = CD;
- d = AC, ей равен AD (по условию AC = AD);
- e = AE, ей равен DE (по условию AE = DE);
- k — мелкий кирпичик для EF и AF: EF = 3k, AF = 4k.

Откуда k. Условие про AF дробное: AF составляет 4/3 от EF. Дробь в соотношении — сигнал раздробить кирпичик на знаменатель. Беру за кирпичик третью часть EF:

EF = 3k

AF = 4k

Дробь исчезла: 4/3 от трёх кирпичиков — ровно четыре кирпичика. Это данное условия уже вошло в буквы, отдельного уравнения оно не даёт.

`P(X)` — периметр контура X: обхожу контур карандашом по буквам и складываю стороны; например, P(ABC) = 268 — данное условия.

**Уравнения из условия.** Каждый данный периметр — обход контура по рисунку. Три треугольника имеют одинаковый периметр, значит, каждый из них равен 268.

Контур ABC: AB, BC, CA.

**(1) a + b + d = 268**

Контур ACD: AC, CD, DA; обе боковые стороны равны d.

**(2) d + c + d = 268**

Контур ADE: AD, DE, EA; DE и EA равны e.

**(3) d + e + e = 268**

Контур ABCDE: AB, BC, CD, DE, EA; отрезки AC и AD остаются внутри.

**(4) a + b + c + e + e = 372**

Данное «BC на 9 см длиннее CD»:

**(5) b = c + 9**

Данное «EF + AE = 2 · AF», переписанное кирпичиками:

**(6) 3k + e = 2 · 4k**

**Что спрошено.** Каждый искомый периметр — тоже обход.

Контур ACDE: A→C это d, C→D это c, D→E это e, E→A это снова e. Отрезок AD лежит внутри и в контур не входит.

Контур ABCDEF идёт так же, как ABCDE, — A→B→C→D→E, — и расходится с ним только в самом конце: ABCDE возвращается из E в A напрямую, по стороне EA, а ABCDEF — в обход, через F. Значит, из P(ABCDE) = 372 убираю сторону EA и добавляю ломаную E→F→A, то есть 3k и 4k.

Контур ADEF: A→D это d, D→E это e, E→F это 3k, F→A это 4k. Отрезок AE теперь внутри.

> ✅ **План готов:**
>
> **P(ACDE) = d + c + 2e**
>
> **P(ABCDEF) = 372 − e + 7k**
>
> **P(ADEF) = d + e + 7k**
>
> Осталось найти: d, c, e, k — из системы (1)–(6).

### Часть 2 — алгебра: решаем систему

Заметь: в (1), (2) и (3) вместе стоят все стороны пятиугольника из (4) — это и есть «Заметь главное», — и сверху ещё четыре d. Метод сложения/вычитания, (1) + (2) + (3) − (4): a, b, c и оба e уходят, остаются два стыка, каждый дважды.

268 + 268 + 268 − 372 = 804 − 372 = 432

**4d = 432**

**d = 108**

(2), подставить d:

c = 268 − 216

**c = 52**

(3), подставить d:

2e = 268 − 108 = 160

**e = 80**

(6), подставить e: справа 2 · 4k = 8k, слева и справа убираю по 3k.

3k + 80 = 8k

80 = 5k

**k = 16**

Значит, EF = 48 и AF = 64, а вся ломаная E→F→A:

7k = 112

**Сборка: подставляю d = 108, c = 52, e = 80, k = 16 в формулы плана.**

- **P(ACDE)** = 108 + 52 + 160 = **320**
- **P(ABCDEF)** = 372 − 80 + 112 = **404**
- **P(ADEF)** = 108 + 80 + 112 = **300**

**А где (5)?** Каждое данное условия переведено в уравнение, но в плане a и b не стоят: в спрошенные контуры AB и BC по отдельности не входят. Поэтому (5) ответам не понадобилось. Досчитать a и b всё же полезно — это проверка всей системы.

(5), подставить c:

b = 52 + 9 = 61

(1), подставить d и b:

a = 268 − 108 − 61 = 99

(4), проверка:

99 + 61 + 52 + 80 + 80 = 372 ✓

Лишнее данное на олимпиаде бывает — это не ошибка в решении.

**⚠ Ловушки.**

- Отрезки AC и AD лежат внутри пятиугольника: в P(ABCDE) их нет, а в сумму трёх треугольников каждый входит дважды — не «один раз» и не «трижды».
- В контуре ABCDEF нет стороны EA: вместо неё обход идёт через F.
- В контуре ACDE нет AD, в контуре ADEF нет AE — внутренние отрезки в периметр не входят.
- Дробь 4/3 в условии про AF — не повод решать с дробями: мелкий кирпичик k делает все длины целыми.

**Проверка вторым способом.** Программа перебрала все целые длины AB, BC, CD, AC = AD, AE = DE, EF, AF с учётом всех данных условия (включая условие «BC на 9 см длиннее CD»). Подходит единственный набор:

- AB = 99, BC = 61, CD = 52;
- AC = AD = 108, AE = DE = 80;
- EF = 48, AF = 64.

По нему периметры 320, 404, 300. Кроме того, рисунок оригинала начерчен в масштабе, и длины, снятые с него линейкой (в масштабе AC = 108), совпадают с найденными с точностью до 1–2 см.

**Ответ на задачу:** периметр ACDE равен 320 см, периметр ABCDEF — 404 см, периметр ADEF — 300 см. *(официальный ключ ✓ по всем трём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Буквы:

- a = AB, b = BC, c = CD;
- d = AC = AD;
- e = AE = DE;
- EF = 3k, AF = 4k.

Уравнения:

**(1) P(ABC): a + b + d = 268**

**(2) P(ACD): 2d + c = 268**

**(3) P(ADE): d + 2e = 268**

**(4) P(ABCDE): a + b + c + 2e = 372**

**(6) EF + AE = 2 · AF: 3k + e = 8k**

> ✅ **План:**
>
> **P(ACDE) = d + c + 2e**
>
> **P(ABCDEF) = 372 − e + 7k**
>
> **P(ADEF) = d + e + 7k**

Решение:

- (1) + (2) + (3) − (4): 4d = 804 − 372 = 432 → **d = 108**
- (2) → c = 268 − 216 → **c = 52**
- (3) → 2e = 160 → **e = 80**
- (6) → 5k = 80 → **k = 16**; 7k = 112

**P(ACDE) = 108 + 52 + 160 = 320**

**P(ABCDEF) = 372 − 80 + 112 = 404**

**P(ADEF) = 108 + 80 + 112 = 300**

Проверка:

- b = 52 + 9 = 61, a = 268 − 108 − 61 = 99
- P(ABCDE) = 99 + 61 + 52 + 160 = 372 ✓
- AF = 64 = 4/3 · 48 ✓
- EF + AE = 48 + 80 = 128 = 2 · 64 ✓
