## №5 — прямоугольник с крышей и клином *(Т2: периметры, данный контур содержит целый треугольник)*

**Условие.** На рисунке ABCE — прямоугольник, BC = CF = FE, CD = DE = AO, BO = DF. Периметр AOBCE равен 162 см, периметр CFE равен 100 см, периметр CDE равен 128 см, периметр DEF равен 88 см. Каков периметр ABCFE? Каков периметр ABCDE? Каков периметр закрашенной части? Каков периметр AOBCFE?

*Как устроен рисунок.* Прямоугольник ABCE стоит так: E и C — верхние углы, A и B — нижние. Над стороной EC — треугольник CDE с вершиной D наверху. Внутри него точка F, и из неё идут три отрезка — к D, к E и к C; отрезок DF вертикальный. Под стороной AB — треугольник AOB с вершиной O внизу. Закрашены два треугольника — DFC и EFC; треугольник DEF между ними не закрашен.

**Заметь главное.** У прямоугольника противоположные стороны равны, поэтому к трём равенствам условия добавляются ещё два: AE = BC и AB = CE. Тогда отрезков рисунка много, а разных длин всего четыре:

- a = BC = CF = FE = AE;
- b = CD = DE = AO;
- c = BO = DF;
- d = CE = AB.

И второе, главное. Контур AOBCE обходит отрезки AO, OB, BC, CE, EA, то есть b, c, a, d, a. А в нём стоит полный набор сторон треугольника DEF — одно a, одно b и одно c, — хотя сам треугольник DEF нарисован совсем в другом месте. Значит, из данного 162 можно целиком вычесть данное 88.

**Шаг 1 — план: записать спрошенные периметры через четыре буквы.**

Буквы a, b, c, d — кирпичики (так в курсе зовут буквы, через которые выражается каждый отрезок рисунка). `P(X)` — периметр контура X: обхожу контур карандашом по буквам и складываю отрезки.

Контур ABCFE идёт A → B → C → F → E → A, то есть AB, BC, CF, FE, EA:

P(ABCFE) = d + a + a + a + a

Контур ABCDE идёт A → B → C → D → E → A, то есть AB, BC, CD, DE, EA:

P(ABCDE) = d + a + b + b + a

Закрашенная часть — это треугольник CDE без треугольника DEF. Её граница идёт D → C → E → F → D, то есть DC, CE, EF, FD. Отрезок FC в границу не входит: с обеих его сторон закрашено, он внутри части. А EF и FD входят: по другую их сторону лежит незакрашенный DEF.

P(закрашенной) = b + d + a + c

Контур AOBCFE идёт A → O → B → C → F → E → A, то есть AO, OB, BC, CF, FE, EA:

P(AOBCFE) = b + c + a + a + a + a

> ✅ **План готов:**
>
> **P(ABCFE) = d + a + a + a + a**
>
> **P(ABCDE) = d + a + b + b + a**
>
> **P(закрашенной) = b + d + a + c**
>
> **P(AOBCFE) = b + c + a + a + a + a**
>
> - `a` — длина BC = CF = FE = AE;
> - `b` — длина CD = DE = AO;
> - `c` — длина BO = DF;
> - `d` — длина CE = AB.
>
> Ответ = четыре периметра, расписанные через `a`, `b`, `c`, `d`.
>
> Осталось найти: `a`, `b`, `c`, `d` — из четырёх данных периметров.

**Шаг 2 — четыре данных периметра, записанные буквами.** Каждый контур обхожу карандашом.

Контур AOBCE: AO, OB, BC, CE, EA —

(1) b + c + a + d + a = 162

Треугольник CFE: CF, FE, EC —

(2) a + a + d = 100

Треугольник CDE: CD, DE, EC —

(3) b + b + d = 128

Треугольник DEF: DE, EF, FD —

(4) b + a + c = 88

**Шаг 3 — в контуре (1) стоят все три стороны треугольника DEF.** В (1) есть b, c и одно из a — ровно левая часть (4). Вычитаю (4) из (1): b и c уходят, а из двух a остаётся одно:

(b + c + a + d + a) − (b + a + c) = a + d

a + d = 162 − 88 = 74

**Шаг 4 — треугольник CFE длиннее этой суммы ровно на одно a.** В (2) буква a стоит дважды, а d — один раз; в только что найденной сумме обе буквы стоят по разу. Вычитаю одно из другого — d уходит, остаётся лишнее a:

(a + a + d) − (a + d) = a

a = 100 − 74

**a = 26**

И тогда из a + d = 74:

d = 74 − 26

**d = 48**

**Шаг 5 — в треугольнике CDE неизвестна только буква b.** В (3) основание d уже известно, а две боковые стороны одинаковые:

b + b = 128 − 48 = 80

**b = 40**

**Шаг 6 — в треугольнике DEF неизвестна только буква c.** В (4) a и b уже известны:

c = 88 − 40 − 26

**c = 22**

**Шаг 7 — сборка.** Подставляю a = 26, b = 40, c = 22, d = 48 в формулы плана:

- **P(ABCFE)** = 48 + 26 + 26 + 26 + 26 = **152**
- **P(ABCDE)** = 48 + 26 + 40 + 40 + 26 = **180**
- **P(закрашенной)** = 40 + 48 + 26 + 22 = **136**
- **P(AOBCFE)** = 40 + 22 + 26 + 26 + 26 + 26 = **166**

Проверка по данным условия:

- P(AOBCE) = 40 + 22 + 26 + 48 + 26 = 162 ✓
- P(CFE) = 26 + 26 + 48 = 100 ✓
- P(CDE) = 40 + 40 + 48 = 128 ✓
- P(DEF) = 40 + 26 + 22 = 88 ✓

**⚠ Ловушки.** (1) AE = BC и AB = CE в условии не написаны — они следуют из слова «прямоугольник». Без них букв получается шесть, и задача кажется нерешаемой. (2) В границу закрашенной части не входит FC — он внутри неё; зато входят EF и FD, по которым она граничит с белым треугольником DEF. (3) Контур AOBCE идёт от A вниз к O, поэтому стороны AB в нём нет.

*Проверка вторым способом: полный перебор целых a, b, c, d до 200 по четырём данным периметрам даёт единственное решение (26, 40, 22, 48); независимо фигура построена по координатам (E = (0, 0), C = (48, 0), D = (24, −32), F = (24, −10), O найдена по AO = 40 и BO = 22) — все равенства условия выполняются точно (например, EF получается ровно 26), а периметры, измеренные программой прямо как длины ломаных, дали 162, 100, 128, 88 для данных и 152, 180, 136, 166 для спрошенных. Отрезки оригинального чертежа, измеренные по PDF, стоят в тех же пропорциях 26 : 40 : 22 : 48.*

**Ответ на задачу:** периметр ABCFE равен **152 см**, периметр ABCDE — **180 см**, периметр закрашенной части — **136 см**, периметр AOBCFE — **166 см**. *(официальный ключ ✓ по всем четырём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики: a = BC = CF = FE = AE · b = CD = DE = AO · c = BO = DF · d = CE = AB (ABCE прямоугольник).

> ✅ **План:**
>
> **P(ABCFE) = d + a + a + a + a**
>
> **P(ABCDE) = d + a + b + b + a**
>
> **P(закрашенной) = DC + CE + EF + FD = b + d + a + c**
>
> **P(AOBCFE) = b + c + a + a + a + a**
>
> Осталось найти a, b, c, d из P(AOBCE), P(DEF), P(CFE), P(CDE).

- P(AOBCE) − P(DEF) = (2a + b + c + d) − (a + b + c) → a + d = 162 − 88 = 74
- P(CFE) = 2a + d = 100 → **a = 100 − 74 = 26** → **d = 48**
- P(CDE) = 2b + d = 128 → **b = 40**
- P(DEF) = a + b + c = 88 → **c = 22**

**P(ABCFE) = 48 + 26 + 26 + 26 + 26 = 152**

**P(ABCDE) = 48 + 26 + 40 + 40 + 26 = 180**

**P(закрашенной) = 40 + 48 + 26 + 22 = 136**

**P(AOBCFE) = 40 + 22 + 26 + 26 + 26 + 26 = 166**

Проверка сложением: P(AOBCE) = 40 + 22 + 26 + 48 + 26 = 162 ✓; P(CFE) = 26 + 26 + 48 = 100 ✓; P(CDE) = 40 + 40 + 48 = 128 ✓; P(DEF) = 40 + 26 + 22 = 88 ✓
