## №2 — восьмиугольник со столбиком P, Q, R *(Т2: периметры, склейка трёх деталей с известными периметрами)*

**Условие.** Фигура ABCDEFGH разрезана на два равных четырёхугольника ABGH и CDEF, прямоугольник P, квадрат Q и прямоугольник R. Косые стороны ABGH равны стороне квадрата Q. Периметр BCLI равен 128 см. Периметр BCFG равен 172 см. Периметр ABCDEFGH равен 200 см. Периметр ABGH равен 150 см. Чему равен периметр FGJK? Чему равен периметр BCDEFG?

**Как устроен рисунок.** Посередине стоит высокий столбик BCFG: внизу B и C, наверху G и F. Два горизонтальных отрезка IL и JK режут его на три этажа: сверху прямоугольник P (это GFLI), в середине квадрат Q (это ILKJ), снизу прямоугольник R (это JKCB). Точки G, I, J, B лежат на одной прямой — это левая сторона столбика, а F, L, K, C — правая. К левой стороне столбика приставлен четырёхугольник ABGH: две его стороны косые (AB внизу и GH наверху), а сторона HA стоит вертикально. Справа точно такой же четырёхугольник CDEF с косыми CD и EF и вертикальной DE.

**Кирпичики.** Равные отрезки получают одну букву.

- s — сторона квадрата Q. Ей равны и косые стороны: AB и GH — по условию, а CD и EF — потому что CDEF равен ABGH. Кроме того, у всех трёх этажей столбика одна и та же ширина — сторона квадрата, поэтому BC, JK, IL и GF — тоже s.
- c — вся высота столбика: c = BG = CF.
- r — высота нижнего этажа R: r = BJ = CK.
- h — вертикальная сторона четырёхугольника: h = HA, и в равном ему CDEF тоже DE = h.

Косых сторон четыре, а буква у них одна и та же, что и у ширины столбика. Такой отрезок, как GJ, отдельной буквы не получает: он состоит из верхнего этажа и квадрата, а это вся высота столбика без нижнего этажа:

GJ = c − r

`P(X)` — периметр контура X; например, P(ABGH) = 150 — данное условия.

**Заметь главное. Восьмиугольник ABCDEFGH склеен из трёх деталей — ABGH, BCFG и CDEF, — и периметр каждой из них известен.** P(ABGH) = 150 и P(BCFG) = 172 даны прямо, а CDEF равен ABGH, значит, у него тот же периметр 150. Сложу три периметра и посмотрю, какая сторона сколько раз попала в сумму:

- наружные стороны восьмиугольника — каждая ровно в одной детали, то есть по разу: это и есть P(ABCDEFGH);
- стык BG — в двух деталях, ABGH и BCFG;
- стык CF — тоже в двух, BCFG и CDEF.

Значит:

P(ABGH) + P(BCFG) + P(CDEF) = P(ABCDEFGH) + 2·BG + 2·CF

Это формула склейки из лайфхака 5 регионального учебника («периметр сборки = сумма периметров деталей − 2 × каждый спрятанный стык»), прочитанная в обратную сторону. В ней известно всё, кроме стыков, а оба стыка — это высота столбика c. Значит, c выйдет одним уравнением, раньше всех остальных букв.

**Шаг 1 — план: обвести два спрошенных контура и записать стороны буквами.** Нужны два периметра — для этого веду карандаш по каждому контуру (ритуал 1) и называю каждую сторону.

Контур FGJK — это верхний этаж P вместе с квадратом Q. F→G это s, G→J это c − r, J→K это s, K→F снова c − r. Отрезок IL лежит внутри и в контур не входит:

P(FGJK) = 2s + 2·(c − r)

Контур BCDEFG — столбик вместе с правым четырёхугольником. B→C это s, C→D это s, D→E это h, E→F это s, F→G это s, а G→B — вся левая сторона столбика c. Стык CF лежит внутри и в контур не входит:

P(BCDEFG) = 4s + h + c

> ✅ **План готов:**
>
> **P(FGJK) = 2s + 2·(c − r)**
>
> **P(BCDEFG) = 4s + h + c**
>
> - s — сторона квадрата Q, она же ширина столбика и каждая косая сторона;
> - c — высота столбика BG = CF;
> - r — высота нижнего этажа R;
> - h — вертикальная сторона HA = DE.
>
> Ответ = два периметра по этим формулам.
>
> Осталось найти s, c, r, h.

**Шаг 2 — c: в формуле склейки из «Заметь главное» неизвестны только стыки, а оба они равны c.** Подставляю данные:

150 + 172 + 150 = 200 + 2c + 2c

472 = 200 + 4c

4c = 472 − 200

4c = 272

→ **c = 68**

**Шаг 3 — s: в P(BCFG) теперь неизвестна только ширина s.** Обхожу столбик: B→C это s, C→F это c, F→G это s, G→B это c:

2s + 2·68 = 172

2s = 172 − 136

2s = 36

→ **s = 18**

**Шаг 4 — r: в P(BCLI) теперь неизвестна только высота нижнего этажа r.** Контур BCLI — это нижний этаж R вместе с квадратом Q. B→C это s, C→L это r + s, L→I это s, I→B снова r + s:

2s + 2·(r + s) = 128

4s + 2r = 128

72 + 2r = 128

2r = 56

→ **r = 28**

**Шаг 5 — h: в P(ABGH) теперь неизвестна только вертикальная сторона h.** Обхожу четырёхугольник: A→B это s, B→G это c, G→H это s, H→A это h:

2s + c + h = 150

36 + 68 + h = 150

h = 150 − 104

→ **h = 46**

**Шаг 6 — сборка: подставляю s = 18, c = 68, r = 28, h = 46 в формулы плана.** Сначала отрезок GJ:

GJ = 68 − 28 = 40

- **P(FGJK)** = 2·18 + 2·40 = 36 + 80 = **116**
- **P(BCDEFG)** = 4·18 + 46 + 68 = 72 + 46 + 68 = **186**

**А где периметр ABCDEFGH = 200 в остальных шагах?** Он уже сработал в шаге 2 — внутри формулы склейки. Проверю его ещё и прямым обходом: четыре косые, BC и GF дают шесть раз по s, и две вертикали h:

6·18 + 2·46 = 108 + 92 = 200 ✓

**⚠ Ловушки.** (1) Стороны BC и GF — это не новые неизвестные: у всех этажей столбика ширина одна, сторона квадрата, и она же равна косым. (2) CDEF в условии не имеет своего периметра, но он равен ABGH — значит, P(CDEF) = 150, и без этого третьей детали в склейке не будет. (3) В контуре BCDEFG левая сторона G→B — вся высота столбика c, а стык CF внутри. (4) Сторона GJ контура FGJK — это верхний этаж и квадрат вместе, c − r, а не высота одного P.

Проверка вторым способом: тоже склейкой, но другой — контур BCDEFG собран из столбика BCFG и детали CDEF со спрятанным стыком CF:

**Ответ на задачу:** периметр FGJK равен 116 см, периметр BCDEFG — 186 см. *(официальный ключ ✓ по обоим)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики:

- s = сторона Q = BC = GF = AB = GH = CD = EF
- c = BG = CF
- r = BJ
- h = HA = DE
- GJ = c − r
- P(CDEF) = P(ABGH) = 150

> ✅ **План:**
>
> **P(FGJK) = 2s + 2·(c − r)**
>
> **P(BCDEFG) = 4s + h + c**
>
> Осталось найти s, c, r, h.

- склейка: 150 + 172 + 150 = 200 + 4c → 4c = 272 → **c = 68**
- P(BCFG): 2s + 136 = 172 → **s = 18**
- P(BCLI): 4s + 2r = 128 → 72 + 2r = 128 → **r = 28**
- P(ABGH): 2s + c + h = 150 → 104 + h = 150 → **h = 46**
- GJ = 68 − 28 = 40

**P(FGJK) = 36 + 80 = 116**

**P(BCDEFG) = 72 + 46 + 68 = 186**

Проверка:

P(ABCDEFGH) = 6·18 + 2·46 = 200 ✓

P(BCLI) = 2·18 + 2·(28 + 18) = 36 + 92 = 128 ✓

P(BCFG) + P(CDEF) − 2·CF = 172 + 150 − 136 = 186 ✓
