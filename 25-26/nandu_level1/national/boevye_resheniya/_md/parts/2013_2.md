## №2 — восьмиугольник из рамки и уголков *(Т2: периметры, равные стороны и равные треугольники дают три буквы)*

**Условие.** У фигуры ABCDEFGH все восемь сторон равны. Четыре треугольника T равны между собой. R1, R2, R3 и R4 — прямоугольники. Периметр T равен 84 см. Периметр ADEH равен 252 см. Периметр BCFG равен 224 см. Чему равен периметр R2? Чему равен периметр CDEF? Чему равен периметр ADEFGH?

**Как устроен рисунок.** Две горизонтальные линии — H–E наверху и A–D внизу — и две вертикальные — через G и B слева, через F и C справа — режут восьмиугольник на девять кусков. В середине пустой четырёхугольник без имени. Слева от него R4 (его левая сторона — HA), справа R2 (правая сторона — DE), снизу R1 (нижняя сторона — BC), сверху R3 (верхняя сторона — GF). В четырёх углах — треугольники T; у каждого один угол прямой, а наклонная сторона — это сторона восьмиугольника: GH, EF, AB или CD.

**Заметь главное.** Двух пометок условия хватает, чтобы вся фигура записалась **тремя** буквами.

*Первая пометка — восемь равных сторон.* Назову сторону восьмиугольника s. Сторона HA — это левый бок R4, значит высота R4 равна s. Сторона GF — верх R3, значит ширина R3 равна s. Середина стоит под R3 и рядом с R4, поэтому она тоже s в ширину и s в высоту — это квадрат. И у каждого T наклонная сторона равна s.

*Вторая пометка — четыре равных треугольника.* У прямоугольного треугольника две стороны, образующие прямой угол, называются **катетами**. У каждого T один катет горизонтальный, другой вертикальный. У T при H горизонтальный катет — это ширина R4, вертикальный — высота R3; у T при E горизонтальный — ширина R2, вертикальный — та же высота R3. Треугольники равны, вертикальный катет у них одинаковый — значит, одинаковы и горизонтальные: R2 такой же ширины, как R4. Так же, сравнив T при H и T при A, получаю: R1 такой же высоты, как R3.

Назову ширину R4 и R2 буквой a, высоту R1 и R3 — буквой h. Теперь каждый отрезок рисунка — это s, a, h или их сумма. `P(X)` — периметр контура X; например, P(T) = 84 — данное условия.

**Шаг 1 — план: обойти три спрошенных контура и записать стороны буквами.** Нужны три периметра — для этого веду карандаш по каждому контуру и называю каждую сторону.

R2 — прямоугольник шириной a и высотой DE, то есть s:

P(R2) = 2·(a + s)

CDEF: C→D, D→E и E→F — три стороны восьмиугольника, по s каждая. F→C — вертикаль сквозь всю фигуру: высота R3, потом квадрат, потом высота R1.

FC = h + s + h

P(CDEF) = s + s + s + (h + s + h)

P(CDEF) = 4s + 2h

ADEFGH: низ A→D составлен из ширины R4, квадрата и ширины R2; дальше пять сторон восьмиугольника D→E, E→F, F→G, G→H, H→A.

AD = a + s + a

P(ADEFGH) = (a + s + a) + 5s

P(ADEFGH) = 2a + 6s

> ✅ **План готов:**
>
> **P(R2) = 2·(a + s)**
>
> **P(CDEF) = 4s + 2h**
>
> **P(ADEFGH) = 2a + 6s**
>
> - s — сторона восьмиугольника (и сторона квадрата в середине);
> - a — ширина R4 и R2;
> - h — высота R1 и R3.
>
> Ответ = три периметра по этим формулам.
>
> Осталось найти:
>
> - a + s — из P(ADEH);
> - h + s — из P(BCFG);
> - s, a и h по отдельности — из P(T).

**Шаг 2 — a + s из P(ADEH): кроме a и s, в этом контуре ничего нет.** ADEH — прямоугольник: низ AD — тот же, что в шаге 1, бок AH равен s.

P(ADEH) = 2·(a + s + a) + 2s

P(ADEH) = 4a + 4s = 252

Четыре раза по (a + s) — это 252, поэтому делю на 4:

a + s = 252 : 4

→ **a + s = 63**

**Шаг 3 — h + s из P(BCFG): кроме h и s, в этом контуре ничего нет.** BCFG — прямоугольник: низ BC равен s, бок CF — та же вертикаль FC, что в шаге 1.

P(BCFG) = 2s + 2·(h + s + h)

P(BCFG) = 4h + 4s = 224

h + s = 224 : 4

→ **h + s = 56**

**Шаг 4 — в двух найденных суммах вместе стоят все три стороны T и ещё одно s.** Складываю результаты шагов 2 и 3:

(a + s) + (h + s) = 63 + 56 = 119

Слева стоят катеты a и h и наклонная сторона s — это как раз периметр T, — и сверх него ещё одно s:

P(T) + s = 119

84 + s = 119

→ **s = 35**

Теперь a и h выходят вычитанием:

a = 63 − 35

→ **a = 28**

h = 56 − 35

→ **h = 21**

**Шаг 5 — сборка: подставляю s = 35, a = 28, h = 21 в формулы плана.**

- **P(R2)** = 2·(28 + 35) = **126**
- **P(CDEF)** = 4·35 + 2·21 = 140 + 42 = **182**
- **P(ADEFGH)** = 2·28 + 6·35 = 56 + 210 = **266**

Для P(R2) числа a и s по отдельности даже не нужны: в его формуле стоит только сумма из шага 2, так что 126 известно уже после шага 2.

**⚠ Ловушки.** (1) FC — не сторона восьмиугольника, а вертикаль сквозь всю фигуру: высота R3, квадрат и высота R1. (2) AD — тоже не одна сторона: ширина R4, квадрат и ширина R2. (3) Наклонные стороны GH, EF, AB, CD — это s, их не надо складывать из катетов: два катета вместе длиннее наклонной стороны (49 против 35).

Проверка вторым способом: программа перебрала все целые ширины R4 и R2, высоты R1 и R3 и сторону восьмиугольника до 200, **не** предполагая заранее, что ширины R4 и R2 (и высоты R1 и R3) равны, — трём данным периметрам и равенству четырёх треугольников отвечает единственный набор s = 35, a = 28, h = 21. По координатам вершин она заново обошла контуры: все восемь сторон ABCDEFGH вышли по 35 (наклонные — тройка 21-28-35, то есть чертёж с такими числами существует), данные 84, 252, 224 и искомые 126, 182, 266 совпали.

**Ответ на задачу:** периметр R2 равен 126 см, периметр CDEF — 182 см, периметр ADEFGH — 266 см. *(официальный ключ ✓ по всем трём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики: s = сторона восьмиугольника (= сторона квадрата в середине) · a = ширина R4 = ширина R2 · h = высота R1 = высота R3. T равны → у всех T катеты a и h.

P(T) = a + h + s

FC = h + s + h

AD = a + s + a

> ✅ **План:**
>
> **P(R2) = 2·(a + s)**
>
> **P(CDEF) = 4s + 2h**
>
> **P(ADEFGH) = 2a + 6s**
>
> Осталось найти a + s, h + s, s, a, h.

- P(ADEH) = 4a + 4s = 252 → **a + s = 63**
- P(BCFG) = 4h + 4s = 224 → **h + s = 56**
- 63 + 56 = 119 = P(T) + s = 84 + s → **s = 35**
- a = 63 − 35 → **a = 28**
- h = 56 − 35 → **h = 21**

**P(R2) = 2·63 = 126**

**P(CDEF) = 140 + 42 = 182**

**P(ADEFGH) = 56 + 210 = 266**

Проверка сложением:

P(T) = 28 + 21 + 35 = 84 ✓

P(ADEH) = 2·(28 + 35 + 28 + 35) = 2·126 = 252 ✓

P(BCFG) = 2·(35 + 21 + 35 + 21) = 2·112 = 224 ✓
