## №5 — треугольник-скрепка *(Т2: периметры, одна буква на пять отрезков)*

**Условие.** На рисунке AF = BF = ED, BC = CF, AE = FD, а CDF — равносторонний треугольник. Периметр ABF равен 96 см, периметр BCF равен 108 см, периметр AFDE равен 138 см. Каков периметр BCDF? Каков периметр ABCF? Каков периметр ABCDE?

*Как устроен рисунок.* Пятиугольник ABCDE: A и B внизу, C справа, D наверху, E слева. Внутри точка F, и из неё идут четыре отрезка — к A, B, C и D. Всего на рисунке девять отрезков: пять сторон пятиугольника и четыре отрезка из F.

**Равносторонний треугольник** — треугольник, у которого все три стороны равны. У CDF это значит: CD, DF и FC — одной длины.

**Заметь главное.** Равносторонний треугольник CDF сцепляет между собой два равенства условия, которые сами по себе ни о чём друг с другом не говорят. Иду по цепочке от BC:

- BC = CF — дано;
- CF = CD = DF — стороны равностороннего треугольника;
- DF = AE — дано.

Выходит, что пять отрезков — BC, CF, CD, DF и AE — имеют одну и ту же длину. Им хватает одной буквы. Ещё три отрезка — AF, BF и ED — равны по условию, это вторая буква. Остаётся AB, ни с чем не связанный, — третья. Девять отрезков, три буквы, три данных периметра: задача сводится к трём неизвестным.

**Шаг 1 — план: записать спрошенные периметры через три буквы.**

Кирпичики (так в курсе зовут буквы, через которые выражается каждый отрезок рисунка):

- c = BC = CF = CD = DF = AE;
- a = AF = BF = ED;
- b = AB.

`P(X)` — периметр контура X: обхожу контур карандашом по буквам и складываю отрезки. Например, данное условия «периметр ABF равен 96» записывается так:

P(ABF) = AB + BF + FA = 96

Контур BCDF идёт B → C → D → F → B, то есть BC, CD, DF и FB:

P(BCDF) = c + c + c + a

Контур ABCF идёт A → B → C → F → A, то есть AB, BC, CF и FA:

P(ABCF) = b + c + c + a

Контур ABCDE — это обход пятиугольника снаружи: AB, BC, CD, DE, EA. Отрезки из F внутри, в этот контур они не входят:

P(ABCDE) = b + c + c + a + c

> ✅ **План готов:**
>
> **P(BCDF) = c + c + c + a**
>
> **P(ABCF) = b + c + c + a**
>
> **P(ABCDE) = b + c + c + a + c**
>
> - `a` — длина AF = BF = ED;
> - `b` — длина AB;
> - `c` — длина BC = CF = CD = DF = AE.
>
> Ответ = три периметра, расписанные через `a`, `b`, `c`.
>
> Осталось найти: `a`, `b`, `c` — из трёх данных периметров.

**Шаг 2 — три данных периметра, записанные буквами.** Каждый контур обхожу карандашом.

Треугольник ABF: AB, BF, FA —

(1) b + a + a = 96

Треугольник BCF: BC, CF, FB —

(2) c + c + a = 108

Четырёхугольник AFDE: A → F → D → E → A, то есть AF, FD, DE, EA —

(3) a + c + a + c = 138

**Шаг 3 — в контуре AFDE каждая буква стоит дважды.** Значит, 138 — это два одинаковых полупериметра, и половина сразу даёт сумму двух букв:

a + c = 138 : 2 = 69

**Шаг 4 — контур BCF длиннее половины AFDE ровно на один отрезок c.** В уравнении (2) буква c стоит дважды, а a — один раз; в только что найденной сумме обе буквы стоят по разу. Вычитаю одно из другого — a уходит, остаётся лишнее c:

(a + c + c) − (a + c) = c

c = 108 − 69

**c = 39**

И тогда из a + c = 69:

a = 69 − 39

**a = 30**

**Шаг 5 — в треугольнике ABF неизвестна только сторона AB.** В уравнении (1) обе боковые стороны уже известны:

b = 96 − 30 − 30

**b = 36**

**Шаг 6 — сборка.** Подставляю a = 30, b = 36, c = 39 в формулы плана:

- **P(BCDF)** = 39 + 39 + 39 + 30 = **147**
- **P(ABCF)** = 36 + 39 + 39 + 30 = **144**
- **P(ABCDE)** = 36 + 39 + 39 + 30 + 39 = **183**

Проверка по данным условия:

- P(ABF) = 36 + 30 + 30 = 96 ✓
- P(BCF) = 39 + 39 + 30 = 108 ✓
- P(AFDE) = 30 + 39 + 30 + 39 = 138 ✓

**⚠ Ловушки.** (1) В контуре AFDE отрезок F → D — сторона равностороннего треугольника, то есть c, а не a: буква a стоит у соседнего DE. (2) Контур ABCDE обходит пятиугольник снаружи, отрезков из F в нём нет.

*Проверка вторым способом: система из девяти отрезков рисунка (шесть равенств условия и треугольника + три данных периметра) решена программой точной арифметикой без ручной склейки букв — все девять длин совпали с разбором (a = 30, b = 36, c = 39); полный перебор целых a, b, c до 200 даёт единственное решение; отрезки оригинального чертежа, измеренные по PDF, стоят в тех же пропорциях 30 : 36 : 39. Дополнительно: P(ABCDE) − P(ABCF) = 183 − 144 = 39 = c, как и должно быть — у контуров общий кусок A → B → C, а дальше ABCF возвращается путём C → F → A (c и a), ABCDE — путём C → D → E → A (c, a и ещё одно c).*

**Ответ на задачу:** периметр BCDF равен **147 см**, периметр ABCF — **144 см**, периметр ABCDE — **183 см**. *(официальный ключ ✓ по всем трём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики: a = AF = BF = ED · b = AB · c = BC = CF = CD = DF = AE (CDF равносторонний).

> ✅ **План:**
>
> **P(BCDF) = c + c + c + a**
>
> **P(ABCF) = b + c + c + a**
>
> **P(ABCDE) = b + c + c + a + c**
>
> Осталось найти a, b, c из P(AFDE), P(BCF), P(ABF).

- P(AFDE) = 2a + 2c = 138 → a + c = 69
- P(BCF) = a + 2c = 108 → **c = 108 − 69 = 39** → **a = 30**
- P(ABF) = b + 2a = 96 → **b = 36**

**P(BCDF) = 39 + 39 + 39 + 30 = 147**

**P(ABCF) = 36 + 39 + 39 + 30 = 144**

**P(ABCDE) = 36 + 39 + 39 + 30 + 39 = 183**

Проверка сложением: P(ABF) = 36 + 30 + 30 = 96 ✓; P(BCF) = 39 + 39 + 30 = 108 ✓; P(AFDE) = 30 + 39 + 30 + 39 = 138 ✓
