## №3 — последняя цифра равна среднему трёх первых *(Т3″: признак делимости на 3 + полочка кратных трём)*

**Условие.** Пабло хочет выписать список всех четырёхзначных чисел, у которых последняя цифра равна среднему арифметическому трёх остальных цифр. Пояснение: среднее чисел 3; 7 и 8 — это их сумма 18, делённая на 3, то есть 6; среднее чисел 2; 8 и 8 — это их сумма 18, делённая на 3, то есть тоже 6. Сколько чисел придётся написать Пабло? Сколько из этих чисел нечётных? Объясни, как ты их считал.

**Жанр ответа (ритуал Д6).** Дважды спрашивают «сколько» и один раз «объясни, как считал» — значит, нужны **два числа с объяснением**, а не сам список Пабло. Объяснение — это фраза в начале (почему так можно считать) и фраза про полноту (ритуал Ч5).

Ритуал Ч1 «цифры или числа?»: условие говорит о **цифрах** одного числа, а спрашивает, сколько **чисел**. Цифры четырёхзначного числа назову буквами: a — тысячи, b — сотни, c — десятки, d — единицы. Само число пишу **abcd** — это не произведение, а запись цифрами: например, при a = 3, b = 7, c = 8, d = 6 это 3786. Первая цифра a не ноль, иначе число не четырёхзначное.

Среднее трёх первых цифр — их сумма, делённая на 3. Поэтому условие Пабло — одно равенство:

d = (a + b + c) : 3

или, что то же самое,

a + b + c = 3 · d

**Заметь главное.** Последнюю цифру Пабло **не выбирает** — она вычисляется из трёх первых. Выбрал начало abc — и d уже определена, ровно одна. Значит, число из списка целиком задаётся своими первыми тремя цифрами, а разные начала дают разные числа. Весь вопрос переезжает с четырёхзначных чисел на трёхзначные начала abc: **какие начала годятся?** Годится то, у которого сумма трёх первых цифр делится на 3, — тогда частное и есть d. А цифрой это частное выходит всегда: сумма трёх цифр самое большее

9 + 9 + 9 = 27

а 27 : 3 = 9 — ещё цифра.

**Шаг 1 — план.** `N(…)` — сколько объектов подходит под то, что стоит в скобках; например, N(цифр у числа Пабло) = 4.

Первый вопрос — сколько чисел в списке. Каждому числу — своё годное начало, каждому годному началу — своё число, поэтому считаю начала:

**N(чисел Пабло) = N(годных начал abc)**

Второй вопрос — сколько из них нечётных. Чётность числа решает его последняя цифра, то есть d. Нечётная d — это 1, 3, 5, 7 или 9, и при каждой из них сумма начала своя:

- d = 1 → a + b + c = 3
- d = 3 → a + b + c = 9
- d = 5 → a + b + c = 15
- d = 7 → a + b + c = 21
- d = 9 → a + b + c = 27

Режу нечётные числа на миры по последней цифре: у каждого числа d ровно одна, поэтому миры не пересекаются и покрывают всё, — их складываю. В каждом мире число задано началом с нужной суммой цифр, значит, мир — это начала с этой суммой:

**N(нечётных) = N(с суммой 3) + N(с суммой 9) + N(с суммой 15) + N(с суммой 21) + N(с суммой 27)**

*💬 «Разрезал на случаи по последней цифре: они не пересекаются и покрывают всё, поэтому складываю» — это мысль для фразы ко второму вопросу.*

> ✅ **План готов:**
>
> **N(чисел Пабло) = N(годных начал abc)**
>
> **N(нечётных) = N(с суммой 3) + N(с суммой 9) + N(с суммой 15) + N(с суммой 21) + N(с суммой 27)**
>
> - годное начало — трёхзначное abc, у которого сумма цифр делится на 3
> - N(с суммой s) — сколько трёхзначных чисел abc, у которых сумма цифр равна s
>
> Осталось найти: N(годных начал abc) и пять слагаемых N(с суммой …).

**Заметь главное.** Годность начала — это делимость **суммы его цифр** на 3. А признак делимости на 3 говорит: число делится на 3 ровно тогда, когда на 3 делится сумма его цифр. Значит, годное начало — это просто **трёхзначное число, кратное 3**. Проверка на начале из пояснения, 378. Сумма его цифр

3 + 7 + 8 = 18

делится на 3 — и само 378 = 3 · 126 делится на 3 ✓. Условие о цифрах превратилось в вопрос попроще: сколько трёхзначных чисел кратны 3?

*💬 «Список выписывать не нужно: каждое abc, кратное 3, даёт ровно одно число из списка, а разные abc дают разные числа, — поэтому счёт точен» — это мысль для фразы-объяснения: она соединяет обе находки — последняя цифра вычисляется, а годное начало — это число, кратное 3.*

**Шаг 2 — считаем N(годных начал abc).** Годные начала — трёхзначные числа, кратные 3. Они идут цепочкой с шагом 3: каждое следующее на 3 больше предыдущего. Чтобы их сосчитать, не выписывая, нужны три приметы цепочки: первое число, шаг и последнее.

Первое: 100 кратно ли 3? Пишу деление целиком (ритуал Ч2):

100 = 3 · 33 + 1

Остаток 1, значит, 100 не годится; 101 даёт остаток 2; следующее, 102, уже кратно 3 (102 = 3 · 34). Первое — **102**.

Последнее: 999 = 3 · 333 — кратно 3, а следующее кратное, 1002, уже четырёхзначное. Последнее — **999**.

Сначала считаю прыжки: от 102 до 999 цепочка идёт прыжками по 3, и их

(999 − 102) : 3 = 897 : 3 = 299

Чисел на одно больше, чем прыжков: первое число, 102, стоит ещё до первого прыжка, а каждый прыжок приносит одно новое. Это **формула цепочки** — «прыжки плюс один»:

N(годных начал abc) = 299 + 1

→ **N(годных начал abc) = 300**

*💬 «Шёл по цепочке до последнего, который влезает: следующий уже выходит за 999, — значит ни одного не пропустил и лишнего не посчитал» — это мысль для фразы про полноту.*

**Заметь главное.** Все пять слагаемых второго вопроса считаются одним и тем же ходом. Первая цифра a выбирается от 1 до 9, а две другие, b и c, обязаны добрать до суммы s то, что осталось:

b + c = s − a

Этот остаток назову t. Сколько пар цифр (b, c) дают в сумме t? Перебираю b, а c дополняет его до t и обязано быть цифрой от 0 до 9:

- если t не больше 9, то b берётся любое от 0 до t, и c выходит цифрой само — пар на одну больше, чем t (например, при t = 2 это b = 0, 1, 2 — три пары);
- если t больше 9, давит потолок: c не больше 9, поэтому маленькие b не годятся. Например, при t = 14 и b = 4 пришлось бы взять c = 10 — не цифра; годятся b от 5 до 9, пар 5;
- если t больше 18, пар нет вовсе: даже 9 + 9 = 18.

Сколько пар при t больше 9 в общем случае? Самое маленькое годное b то, при котором c = 9, то есть

b = t − 9

От этого значения b идёт до 9. Это цепочка с шагом 1, и по формуле цепочки чисел в ней на одно больше, чем прыжков:

9 − (t − 9) + 1 = 19 − t

Коротко, обе ветки:

N(пар с суммой t) = t + 1, если t ≤ 9

N(пар с суммой t) = 19 − t, если t ≥ 9

Проверка на маленьком (ритуал Ч3): t = 2 — пары (0, 2), (1, 1), (2, 0), их 3 = 2 + 1 ✓; t = 14 — пары (5, 9), (6, 8), (7, 7), (8, 6), (9, 5), их 5 = 19 − 14 ✓; при t = 9 обе строки дают 10 ✓.

Разные a дают разные начала, поэтому по a складываю:

N(с суммой s) = N(пар с суммой s − 1) + N(пар с суммой s − 2) + … + N(пар с суммой s − 9)

**Шаг 3 — считаем N(с суммой 3).** Первая цифра не больше 3, иначе сумма перевалит за 3:

- a = 1 → t = 2 → 3 пары
- a = 2 → t = 1 → 2 пары
- a = 3 → t = 0 → 1 пара

**N(с суммой 3) = 3 + 2 + 1 = 6**

Проверка списком (Ч3): начала 102, 111, 120, 201, 210, 300 — шесть, и числа Пабло 1021, 1111, 1201, 2011, 2101, 3001. У 1201 среднее трёх первых

(1 + 2 + 0) : 3 = 1

— это и есть последняя цифра ✓.

→ **N(с суммой 3) = 6**

**Шаг 4 — считаем N(с суммой 9).** Здесь a от 1 до 9, а остаток

t = 9 − a

идёт от 8 до 0 — всюду не больше 9, потолок не давит, пар на одну больше, чем остаток:

- a = 1, 2, 3, …, 9 → пар 9, 8, 7, …, 1

Складываю с краёв:

**N(с суммой 9) = (9 + 1) + (8 + 2) + (7 + 3) + (6 + 4) + 5 = 45**

→ **N(с суммой 9) = 45**

**Шаг 5 — считаем N(с суммой 15).** Здесь a от 1 до 9, а остаток

t = 15 − a

идёт от 14 до 6 — и переходит через 9, так что при маленьких a давит потолок:

| a | t = 15 − a | пар | как считаю |
|---|---|---|---|
| 1 | 14 | 5 | 19 − 14 |
| 2 | 13 | 6 | 19 − 13 |
| 3 | 12 | 7 | 19 − 12 |
| 4 | 11 | 8 | 19 − 11 |
| 5 | 10 | 9 | 19 − 10 |
| 6 | 9 | 10 | 9 + 1 |
| 7 | 8 | 9 | 8 + 1 |
| 8 | 7 | 8 | 7 + 1 |
| 9 | 6 | 7 | 6 + 1 |

**N(с суммой 15) = (5 + 6 + 7 + 8 + 9 + 10) + (9 + 8 + 7) = 45 + 24 = 69**

→ **N(с суммой 15) = 69**

**Шаг 6 — считаем N(с суммой 21).** Если a = 1 или a = 2, двум другим цифрам пришлось бы набрать 20 или 19, а больше 9 + 9 = 18 они не дают — пар нет. При a от 3 до 9 остаток

t = 21 − a

идёт от 18 до 12 — всюду больше 9, давит потолок, пары считаю по второй строке:

- a = 3, 4, 5, 6, 7, 8, 9 → t = 18, 17, 16, 15, 14, 13, 12 → пар 1, 2, 3, 4, 5, 6, 7

**N(с суммой 21) = 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28**

→ **N(с суммой 21) = 28**

**Шаг 7 — считаем N(с суммой 27).** Сумма 27 — это наибольшая сумма трёх цифр, она набирается только тремя девятками: начало 999, число Пабло 9999.

→ **N(с суммой 27) = 1**

**Шаг 8 — сборка.** Подставляю всё найденное в формулы плана:

**N(чисел Пабло) = 300**

**N(нечётных) = 6 + 45 + 69 + 28 + 1 = 149**

**Проверка сцепкой двух ответов.** Чётные числа Пабло — это d = 2, 4, 6, 8, то есть суммы начала 6, 12, 18, 24 (d = 0 не бывает: сумма 0 требует a = 0). Тем же ходом:

- N(с суммой 6): a от 1 до 6, пар 6, 5, 4, 3, 2, 1 → **21**
- N(с суммой 12): a от 1 до 9, t от 11 до 3, пар 8, 9, 10, 9, 8, 7, 6, 5, 4 → **66**
- N(с суммой 18): a от 1 до 9, t от 17 до 9, пар 2, 3, 4, 5, 6, 7, 8, 9, 10 → **54**
- N(с суммой 24): a от 6 до 9, t от 18 до 15, пар 1, 2, 3, 4 → **10**

N(чётных) = 21 + 66 + 54 + 10 = 151

N(нечётных) + N(чётных) = 149 + 151 = 300

Сошлось с первым ответом, а он получен совсем другим ходом — цепочкой кратных трём ✓.

**⚠ Ловушки.** (1) Пустить первую цифру с нуля — тогда кратных 3 от 0 до 999 выйдет 334, а «0000», «0031» и прочие не четырёхзначные. (2) Считать пары без потолка, всегда «на одну больше, чем t», — при сумме 15 и a = 1 выйдет 15 пар вместо 5. (3) Решить, что нечётных «примерно половина», и написать 150: половины здесь нет, миры по d неравные. (4) Искать нечётность по сумме трёх первых цифр или по началу abc: нечётность числа abcd решает только его последняя цифра d.

Проверка вторым способом: полный компьютерный перебор всех четырёхзначных чисел от 1000 до 9999 (условие: утроенная последняя цифра равна сумме трёх первых) даёт ровно 300 чисел, из них 149 нечётных; по последней цифре 6, 21, 45, 66, 69, 54, 28, 10, 1 при d = 1…9 — те же числа, что и в разборе; совпадает с официальным ключом.

**Ответ на задачу:** Пабло придётся написать **300 чисел**, из них **149 нечётных**. Считали так: последняя цифра вычисляется из трёх первых, поэтому чисел столько же, сколько трёхзначных начал abc с суммой цифр, кратной 3, — а по признаку делимости это трёхзначные числа, кратные 3, от 102 до 999, их 300; нечётные — это d = 1, 3, 5, 7, 9, то есть суммы начала 3, 9, 15, 21, 27, и таких начал 149.

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Фразы входят в образец наравне с числами.*

#### 💬 Фраза-объяснение (в начале)

**No hace falta escribir la lista: cada abc múltiplo de 3 da exactamente un número de la lista, y abc distintos dan números distintos, por eso el conteo es exacto.**

*Список выписывать не нужно: каждое abc, кратное 3, даёт ровно одно число из списка, а разные abc дают разные числа, — поэтому счёт точен.*

#### Запись

abcd — цифры числа; N(с суммой s) — сколько трёхзначных abc с суммой цифр s.

d = (a + b + c) : 3 → a + b + c = 3 · d

признак делимости: abc кратно 3 ровно тогда, когда его сумма цифр кратна 3

> ✅ **План:**
>
> **N(чисел) = N(трёхзначных, кратных 3)**
>
> **N(нечётных) = N(с суммой 3) + N(с суммой 9) + N(с суммой 15) + N(с суммой 21) + N(с суммой 27)**

- 100 = 3 · 33 + 1 → первое 102; последнее 999 = 3 · 333

**N(чисел) = (999 − 102) : 3 + 1 = 300**

#### 💬 Фраза в конце — полнота

**Seguí la cadena hasta el último que entra: el siguiente ya se pasa de 999, así que no me salté ninguno ni conté de más.**

*Шёл по цепочке до последнего, который влезает: следующий уже выходит за 999, — значит ни одного не пропустил и лишнего не посчитал.*

#### 💬 Фраза ко второму вопросу

**Separé los casos según la última cifra: no se superponen y cubren todo, por eso los sumo.**

*Разрезал на случаи по последней цифре: они не пересекаются и покрывают всё, поэтому складываю.*

Пар (b, c) с суммой t:

t ≤ 9 → t + 1

t ≥ 9 → 19 − t

- d = 1, сумма 3: a = 1…3 → 3 + 2 + 1 = **6**
- d = 3, сумма 9: a = 1…9 → 9 + 8 + … + 1 = **45**
- d = 5, сумма 15: a = 1…9 → 5 + 6 + 7 + 8 + 9 + 10 + 9 + 8 + 7 = **69**
- d = 7, сумма 21: a = 3…9 → 1 + 2 + … + 7 = **28**
- d = 9, сумма 27: только 999 → **1**

**N(нечётных) = 6 + 45 + 69 + 28 + 1 = 149**
