## №2 — шоколадка с двумя треугольниками *(Т2′: сетка равных деталей, блоки по именам)*

**Условие.** Фигура разбита на 16 прямоугольников — 4 равных A, 4 равных B, 4 равных C и 4 равных D — и 2 треугольника: E равносторонний, а T равнобедренный, и его неравная сторона горизонтальна. Наклонные стороны T равны длинной стороне прямоугольника, составленного из A, C и A. Периметр треугольника E равен 207 см. Периметр прямоугольника, составленного из A, B и A, равен 192 см. Периметр прямоугольника, составленного из B, A и B, равен 198 см. Прямоугольники B, A, B, D, C и D образуют квадрат. Чему равен периметр прямоугольника A? Чему равен периметр прямоугольника D? Чему равен периметр прямоугольника, составленного из A, B, C, D, A и B? Чему равен периметр фигуры, составленной из C, D, C, D и T?

**Как устроен рисунок.** Прямоугольники стоят сеткой 4 × 4. Ряды сверху вниз: «A B A B», «C D C D», снова «A B A B», снова «C D C D». Значит, детали стоят и колонками: в первой и третьей колонке чередуются A и C, во второй и четвёртой — B и D. Треугольник E стоит сверху, но не на всей верхней стороне: его основание начинается у левого края второй колонки и закрывает три детали «B, A, B». Треугольник T подпирает снизу всю нижнюю сторону, остриём вниз.

**Кирпичики.** По ритуалу 2 у каждой детали два размера. Детали стоят колонками, поэтому хватает четырёх букв на всю сетку:

- a — ширина A (и C: они в одной колонке);
- b — ширина B (и D);
- p — высота ряда с A и B;
- q — высота ряда с C и D.

`P(X)` — периметр фигуры X; например, P(E) = 207 — данное условия. Блок по ритуалу 3 называю по составу: блок «A, B, A» — прямоугольник из трёх деталей первого ряда.

**Заметь главное. Одна и та же ширина стоит в условии трижды.** Основание E закрывает детали «B, A, B», то есть его длина — это ширина полосы из трёх колонок:

основание E = b + a + b = a + 2b

Та же полоса — длинная сторона блока «B, A, B» из первого ряда. И тот же отрезок — ширина квадрата «B, A, B, D, C, D»: этот квадрат стоит на трёх правых колонках в первых двух рядах. Треугольник E равносторонний, поэтому его периметр сообщает эту ширину сразу, делением на 3 — без уравнений. А дальше готовое число встаёт в периметр блока «B, A, B» (оттуда выйдет p) и в сторону квадрата (оттуда выйдет q).

**Шаг 1 — план: обойти четыре спрошенных контура и записать стороны буквами.** Нужны четыре периметра — для этого обхожу каждый контур и называю каждую сторону через a, b, p, q.

A — одна деталь: ширина a, высота p.

P(A) = 2·(a + p)

D — одна деталь: ширина b, высота q.

P(D) = 2·(b + q)

Блок «A, B, C, D, A, B» — две левые колонки, три верхних ряда (A, B над C, D над A, B). Ширина — одна A и одна B, высота — ряды p, q, p:

P(блока «A, B, C, D, A, B») = 2·((a + b) + (2p + q))

Фигура «C, D, C, D, T» — нижний ряд вместе с T. Верх — ширина всей сетки, две a и две b. Бока ряда — по q. Основание T прилегает к ряду изнутри и в контур не входит; остаются две наклонные стороны T. По условию каждая равна длинной стороне прямоугольника «A, C, A». Это колонка из трёх верхних рядов — с A, с C и снова с A, — и её длинная сторона складывается из их высот:

наклонная сторона T = 2p + q

P(фигуры «C, D, C, D, T») = (2a + 2b) + 2q + 2·(2p + q)

> ✅ **План готов:**
>
> **P(A) = 2·(a + p)**
>
> **P(D) = 2·(b + q)**
>
> **P(блока «A, B, C, D, A, B») = 2·((a + b) + (2p + q))**
>
> **P(фигуры «C, D, C, D, T») = (2a + 2b) + 2q + 2·(2p + q)**
>
> - a — ширина A и C;
> - b — ширина B и D;
> - p — высота ряда «A B A B»;
> - q — высота ряда «C D C D».
>
> Ответ = четыре периметра по этим формулам.
>
> Осталось найти a, b, p, q.

**Шаг 2 — у E все три стороны равны, а основание — полоса «B, A, B».** Периметр E — это три одинаковые стороны, каждая равна ширине полосы (см. «Заметь главное»):

(a + 2b) + (a + 2b) + (a + 2b) = 207

a + 2b = 207 : 3

→ **a + 2b = 69**

**Шаг 3 — в периметре блока «B, A, B» стоит тот же кусок.** Блок «B, A, B» — три детали первого ряда: длинная сторона — та самая полоса, короткая — высота ряда p. Обхожу контур:

(a + 2b) + p + (a + 2b) + p = 198

Контур дважды проходит одно и то же, поэтому делю пополам:

(a + 2b) + p = 99

Кусок в скобках уже известен из шага 2:

69 + p = 99

→ **p = 30**

**Шаг 4 — блок «A, B, A» устроен так же, только a и b в нём поменялись ролями.** Длинная сторона — две A и одна B, короткая — снова p:

(2a + b) + p + (2a + b) + p = 192

Пополам:

2a + b + p = 96

2a + b = 96 − 30

2a + b = 66

Теперь рядом два уравнения, в которых a и b стоят крест-накрест:

2a + b = 66

a + 2b = 69

Вычитаю первое из второго — это **метод вычитания**: одно уравнение отнимаю от другого целиком, левую часть от левой, правую от правой. Одна a и одна b уходят:

b − a = 69 − 66

b − a = 3

Значит, b на 3 больше a:

b = a + 3

Подставляю это в первое уравнение вместо b (**метод подстановки**):

2a + (a + 3) = 66

3a = 63

→ **a = 21**, отсюда **b = 24**

**Шаг 5 — «B, A, B, D, C, D образуют квадрат»: ширина равна высоте.** По ритуалу 4 пометка «образуют квадрат» — уравнение. Ширина квадрата — та же полоса «B, A, B», высота — два ряда, p и q:

p + q = a + 2b

30 + q = 69

→ **q = 39**

**Шаг 6 — сборка: подставляю a = 21, b = 24, p = 30, q = 39 в формулы плана.** Два куска повторяются, считаю их один раз:

a + b = 21 + 24 = 45

2a + 2b = 2·45 = 90

2p + q = 60 + 39 = 99

Проверка: высота колонки «A, C, A» равна 99, это больше её ширины 21 — значит, длинная сторона колонки и правда высота, а не ширина.

- **P(A)** = 2·(21 + 30) = **102**
- **P(D)** = 2·(24 + 39) = **126**
- **P(блока «A, B, C, D, A, B»)** = 2·(45 + 99) = **288**
- **P(фигуры «C, D, C, D, T»)** = (2a + 2b) + 2q + 2·(2p + q) = 90 + 2·39 + 2·99 = 90 + 78 + 198 = **366**

**⚠ Ловушки.** (1) Основание E — не вся верхняя сторона фигуры (она 90), а только полоса «B, A, B» (69): смотри, где начинается треугольник на рисунке. (2) Квадрат «B, A, B, D, C, D» стоит на трёх колонках, а не на четырёх: его ширина — полоса «B, A, B», а не вся верхняя сторона. (3) Наклонная сторона T равна колонке «A, C, A» — трём рядам, а не двум. (4) Основание T в контур «C, D, C, D, T» не входит: оно общее с нижним рядом и ушло внутрь.

Проверка вторым способом: программа перебрала все целые a, b, p, q до 200 — условиям на E, два блока и квадрат отвечает единственный набор a = 21, b = 24, p = 30, q = 39; затем она построила фигуру по координатам (E на полосе «B, A, B», T с боком, равным колонке «A, C, A»), нашла периметры как длину внешней границы, где общие стороны деталей сокращаются, заново получила три данных (207, 192, 198) и четыре искомых (102, 126, 288, 366).

**Ответ на задачу:** периметр прямоугольника A равен 102 см, периметр прямоугольника D — 126 см, периметр прямоугольника из A, B, C, D, A и B — 288 см, периметр фигуры из C, D, C, D и T — 366 см. *(официальный ключ ✓ по всем четырём)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики:

- a — ширина A и C;
- b — ширина B и D;
- p — высота ряда «A B A B»;
- q — высота ряда «C D C D».

Основание E (полоса «B, A, B»):

основание E = a + 2b

Бок T (колонка «A, C, A»):

бок T = 2p + q

> ✅ **План:**
>
> **P(A) = 2·(a + p)**
>
> **P(D) = 2·(b + q)**
>
> **P(блока «A, B, C, D, A, B») = 2·((a + b) + (2p + q))**
>
> **P(фигуры «C, D, C, D, T») = (2a + 2b) + 2q + 2·(2p + q)**
>
> Осталось найти a, b, p, q.

- P(E) = 207 → 3·(a + 2b) = 207 → **a + 2b = 69**
- P(блока «B, A, B») = 198 → a + 2b + p = 99 → **p = 30**
- P(блока «A, B, A») = 192 → 2a + b + p = 96 → 2a + b = 66
- вычитаю: b − a = 3 → b = a + 3
- подставляю: 2a + (a + 3) = 66 → **a = 21**, **b = 24**
- квадрат «B, A, B, D, C, D» → p + q = 69 → **q = 39**
- бок T = 2p + q = **99**

**P(A) = 2·(21 + 30) = 102**

**P(D) = 2·(24 + 39) = 126**

**P(блока «A, B, C, D, A, B») = 2·(45 + 99) = 288**

2a + 2b = 2·45 = 90

**P(фигуры «C, D, C, D, T») = (2a + 2b) + 2q + 2·(2p + q) = 90 + 78 + 198 = 366**

Проверка подстановкой:

- P(E) = 3·69 = 207 ✓
- P(блока «A, B, A») = 2·(66 + 30) = 192 ✓
- P(блока «B, A, B») = 2·(69 + 30) = 198 ✓
- квадрат: ширина 69, высота 30 + 39 = 69 ✓
