## №3 — шестиугольник с центром, суммы по 24 *(Т4′: вершины через одну равны + миры по центру)*

**Условие.** В каждый кружок фигуры вписывают целое положительное число так, чтобы сумма трёх чисел, стоящих в вершинах каждого из шести треугольников фигуры, всегда была равна 24. Фигура — шестиугольник: по кружку в каждой из его шести вершин и ещё один кружок в центре; центр соединён со всеми вершинами, так что шестиугольник разбит на шесть треугольников. Сколькими различными способами это можно сделать? Объясни, как ты их сосчитал. Какое наибольшее значение может иметь сумма семи записанных чисел?

Сначала жанр ответа: до всякого счёта решаю, **что** от меня ждут — число, список, «да или нет», наибольшее значение. Вопросов два, и жанры у них разные. Первый ждёт **число** способов и отдельно — объяснение, почему посчитано всё и ничего не посчитано дважды: это и есть «Explica cómo las contaste». Второй, «какое наибольшее?», ждёт **оценку плюс пример**: доказать, что больше нельзя, и показать заполнение, на котором наибольшее получается.

Имена. Центральный кружок — **c** (от *centro*). Кружки-вершины обхожу по часовой стрелке, начиная с верхнего левого: **a₁, a₂, a₃, a₄, a₅, a₆**. Каждый треугольник — это центр и две соседние вершины: c, a₁, a₂; потом c, a₂, a₃; и так далее по кругу до c, a₆, a₁.

**Заметь главное.** Два соседних треугольника делят общую сторону. У треугольников c, a₁, a₂ и c, a₂, a₃ это сторона от центра до a₂: в их суммах два слагаемых из трёх одни и те же, а итог у обоих 24.

**c + a₁ + a₂ = 24**

**c + a₂ + a₃ = 24**

Вычитаю второе равенство из первого: слева уходят c и a₂, справа уходит 24.

**a₁ − a₃ = 0**

**a₃ = a₁**

Третьи числа соседних треугольников обязаны совпасть. Та же пара рассуждений работает на каждой стороне от центра, и, обходя круг, получаю: **вершины через одну равны**. На кольце всего два разных числа — одно стоит в a₁, a₃, a₅, другое в a₂, a₄, a₆, — а центр входит во все шесть треугольников сразу.

**Шаг 1 — план.** Нужно число заполнений и наибольшая сумма. Заполнение — семь чисел, но свободы в них гораздо меньше. Первый треугольник называет сумму двух соседних вершин через центр:

**a₁ + a₂ = 24 − c**

По «Заметь главное» кольцо чередуется: нечётные вершины равны a₁, чётные равны a₂.

**a₁ = a₃ = a₅**

**a₂ = a₄ = a₆ = 24 − c − a₁**

Обратно тоже верно. Пусть в центре c, а кольцо чередуется так. В каждом треугольнике стоят центр, одна нечётная вершина и одна чётная, поэтому сумма у всех шести одна и та же:

**c + a₁ + (24 − c − a₁) = 24**

Значит, заполнение — это просто выбор двух чисел: центра c и вершины a₁, а остальные пять досчитываются сами. Центр сидит во всех треугольниках, поэтому режу заполнения на **миры** по числу в центре: при выбранном c сумма пары соседних вершин известна, и внутри мира всё висит на одной клетке a₁.

*💬 «Разрезал на случаи по числу в центральном кружке: они не пересекаются и покрывают всё, поэтому складываю» — мысль для фразы-объяснения: у каждого заполнения ровно одно число в центре, значит, оно лежит ровно в одном мире.*

Обозначения. `N(…)` — сколько объектов подходит под то, что стоит в скобках; например, N(треугольников) = 6. `S(…)` — сумма чисел; S(семи чисел) — сумма всех семи кружков. **Диапазон** — полный список годных значений клетки; обычно это все целые числа от какого-то и до какого-то.

> ✅ **План готов:**
>
> **N(заполнений) = N(значений a₁ при c = 1) + N(значений a₁ при c = 2) + …**
>
> **max(S(семи чисел)) = наибольшее S(семи чисел) среди всех заполнений (всех пар c, a₁)**
>
> - N(значений a₁ при c = 1) — сколько чисел можно поставить в a₁, когда в центре 1; все заполнения с одним и тем же c — один мир, миры не пересекаются, поэтому их складывают;
> - max(S(семи чисел)) — наибольшая сумма семи чисел.
>
> Ответ = N(заполнений) и max(S(семи чисел)). Осталось найти:
>
> - докуда идёт c;
> - N(значений a₁ при данном c);
> - S(семи чисел) через c и a₁.

**Шаг 2 — докуда идёт c.** Границу называет сама пара соседних вершин:

**a₁ + a₂ = 24 − c**

Слева два целых положительных числа, значит, слева не меньше 1 + 1 = 2. Справа записано то же самое число — значит, и оно не меньше двойки. Проверяю на краю:

- c = 22 → справа 2, вершины берут по единице ✓
- c = 23 → справа 1, двумя положительными числами единицу не набрать ✗; при c больше 23 справа ещё меньше — тоже ✗

Снизу c — целое положительное, то есть от 1. Диапазон центра — от 1 до 22:

**c = 1, 2, …, 22 → N(миров) = 22**

Граница найдена, и многоточие в плане получает конец:

> ✅ **План уточнён:**
>
> **N(заполнений) = N(значений a₁ при c = 1) + N(значений a₁ при c = 2) + … + N(значений a₁ при c = 22)**
>
> Слагаемых 22, и устроены они одинаково — поэтому считаю одно слагаемое сразу для любого c, а потом складываю.

**Шаг 3 — считаю N(значений a₁ при данном c).** Сразу назову, что здесь считается. a₁ и a₂ — **разные места** фигуры: заполнение «a₁ = 5, a₂ = 15» и заполнение «a₁ = 15, a₂ = 5» — два разных способа. Второе выглядит как первое, повёрнутое на одну вершину, но кружки стоят на своих местах, и в кружке a₁ у них разные числа. Поэтому пары вершин считаю с порядком, пополам ничего не делю.

Считаю на живом мире — возьму c = 4, тогда сумма пары соседних вершин равна 20. Гоню a₁ по порядку:

- a₁ = 1 → a₂ = 19 ✓
- a₁ = 2 → a₂ = 18 ✓
- … пока a₁ растёт, a₂ убывает и остаётся положительным …
- a₁ = 19 → a₂ = 1 ✓ — последнее годное
- a₁ = 20 → a₂ = 0 ✗ ноль не положителен, дальше только минус

Значит, a₁ идёт подряд от 1 до 19 — на единицу меньше суммы пары, — и заполнений в этом мире 19. Тот же ход буквами: верхнее значение a₁ на единицу меньше суммы пары, а чисел подряд от 1 до K ровно K.

**N(значений a₁ при данном c) = (24 − c) − 1 = 23 − c**

Сверяю с перебором: c = 4 → 23 − 4 = 19 ✓.

→ **N(значений a₁ при данном c) = 23 − c**

**Шаг 4 — складываю миры.** Подставляю формулу шага 3 в уточнённый план, c от 1 до 22:

**N(заполнений) = (23 − 1) + (23 − 2) + … + (23 − 22)**

**N(заполнений) = 22 + 21 + … + 1**

Слагаемые убывают каждый раз на одно и то же — на 1; такую цепочку зову **лесенкой**. Двадцать два слагаемых подряд складывать долго, и каждое сложение — шанс ошибиться. Складываю с краёв: первое с последним, второе с предпоследним. У всех таких пар сумма одна и та же, потому что слева убавилось ровно столько, сколько справа прибавилось:

- 22 + 1 = 23
- 21 + 2 = 23
- …
- 12 + 11 = 23

Пар вдвое меньше, чем слагаемых: 22 : 2 = 11.

**N(заполнений) = 11 × 23 = 253**

**Шаг 5 — S(семи чисел) через c и a₁.** Сумма нужна формулой — сразу при любом заполнении. Шесть вершин разбиваются на три пары соседних: a₁ и a₂, a₃ и a₄, a₅ и a₆. Каждая пара даёт сумму из шага 1, центр входит один раз:

**S(семи чисел) = c + 3 · (24 − c)**

**S(семи чисел) = c + 72 − 3 · c = 72 − 2 · c**

Буква a₁ из суммы ушла: сумма зависит только от центра. Перед c стоит минус — центр тянет сумму вниз. Каждая лишняя единица в центре добавляет к сумме 1, но отнимает по единице у каждой из трёх пар вершин. Значит, максимум — на нижнем краю диапазона, при c = 1:

**max(S(семи чисел)) = 72 − 2 · 1 = 70**

Больше 70 не бывает: в любом заполнении центр не меньше 1. Пример, где 70 получается: c = 1, a₁ = 1, тогда кольцо — 1, 22, 1, 22, 1, 22. Проверяю пример:

- каждый треугольник — центр 1 и вершины 1 и 22, сумма 24 ✓
- сумма семи чисел — центр 1, три единицы и три числа 22:

**1 + 3 · 1 + 3 · 22 = 1 + 3 + 66 = 70 ✓**

*💬 «Больше 70 быть не может: сумма зависит только от центра и падает с его ростом, а центр не меньше 1; а при центре 1 она достигается» — мысль для фразы ко второму вопросу: это оценка плюс пример.*

**Шаг 6 — сборка.** Подставляю найденное в формулы плана:

**N(заполнений) = 22 + 21 + … + 1 = 253**

**max(S(семи чисел)) = 72 − 2 · 1 = 70**

**Других нет, потому что** каждое заполнение однозначно называет свою пару чисел — центр c и вершину a₁, а остальные пять кружков по ним досчитываются. Центр перебран по порядку от 1 до 22 — при 23 паре вершин не хватает даже по единице. При каждом c значения a₁ перебраны все подряд, от 1 до последнего, при котором a₂ ещё положительно. Ни одно заполнение не попало сразу в два мира: миры различаются числом в центре.

*💬 «Это все случаи: они не повторяют друг друга и ни один не потерян» — мысль для фразы про полноту.*

**⚠ Ловушки.**

- Решить, что шесть вершин заполняются независимо, и перебирать их деревом: на деле на кольце всего два разных числа, вершины через одну равны.
- Считать пару вершин без порядка — «5 и 15» то же, что «15 и 5», — и получить примерно вдвое меньше: это разные заполнения, в кружке a₁ разные числа.
- Подумать, что для большой суммы центр надо брать побольше: центр входит в сумму один раз, а у трёх пар вершин отнимает трижды, поэтому сумма семи чисел с ростом центра падает — на 2 за каждую единицу.
- Складывать лесенку 22 + 21 + … + 1 подряд: двадцать одно сложение, и одна ошибка губит верный ход.

**Проверка вторым способом.** Компьютерный перебор всех семёрок целых положительных чисел (каждое от 1 до 22 — больше не бывает, два других числа треугольника хотя бы по 1) с проверкой всех шести треугольников даёт:

- ровно 253 заполнения, по мирам 22, 21, …, 1 — как в шагах 3–4;
- наибольшую сумму 70, и достигается она только при центре 1 (22 заполнения).

Совпадает с официальным ключом (253 maneras; mayor suma 70, centro 1).

**Ответ на задачу:** заполнить кружки можно **253 способами**. Считали так: вершины через одну равны, поэтому заполнение задают число в центре и число в одной вершине; при центре 1 годятся 22 заполнения, при центре 2 — 21, и так далее до центра 22 с единственным заполнением; миры по центру не пересекаются, и лесенка с краёв даёт 11 пар по 23. Наибольшая сумма семи чисел — **70**: в центре 1, а вершины через одну — 1 и 22.

#### 💬 Фраза-объяснение (в начале)

**Separé los casos según el número del círculo del centro: no se superponen y cubren todo, por eso los sumo.**

*Разрезал на случаи по числу в центральном кружке: они не пересекаются и покрывают всё, поэтому складываю.*

#### Запись

c — центр, a₁ … a₆ — вершины по часовой стрелке.

- c + a₁ + a₂ = 24
- c + a₂ + a₃ = 24
- a₃ = a₁ → вершины через одну равны
- a₁ + a₂ = 24 − c
- a₁ + a₂ не меньше 2 → c = 1, …, 22

> ✅ **План уточнён:**
>
> **N(заполнений) = N(значений a₁ при c = 1) + N(значений a₁ при c = 2) + … + N(значений a₁ при c = 22)**

- N(значений a₁ при данном c) = 23 − c, порядок считается (места разные)
- S(семи чисел) = c + 3 · (24 − c) = 72 − 2 · c

**N(заполнений) = 22 + 21 + … + 1 = 11 × 23 = 253**

**💬 Фраза ко второму вопросу:**

**Más de 70 no se puede, porque la suma vale 72 − 2 · c y c es al menos 1; y con c = 1 se logra, así que el máximo es 70.**

*Больше 70 быть не может, потому что сумма равна 72 − 2 · c, а c не меньше 1; а при c = 1 она достигается, — значит максимум равен 70.*

**max(S(семи чисел)) = 72 − 2 · 1 = 70**

Проверка: c = 1, кольцо 1, 22, 1, 22, 1, 22.

- каждый треугольник: 1 + 1 + 22 = 24 ✓
- сумма семи: 1 + 3 · 1 + 3 · 22 = 70 ✓

#### 💬 Фраза в конце — полнота

**Estos son todos los casos: no se repiten entre sí y no queda ninguno afuera.**

*Это все случаи: они не повторяют друг друга и ни один не потерян.*
