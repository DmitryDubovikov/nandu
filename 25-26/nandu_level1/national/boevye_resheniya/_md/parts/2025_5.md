## №5 — два квадрата и клюв *(Т2′: разрезка на равные детали + доли)*

**Условие.** На рисунке ABEF и BCHG — квадраты, DEGH — прямоугольник. M — середина стороны AF. MR = MS = BC, а BR = ES = половине AR. Квадрат BCHG можно разрезать на пять прямоугольников, равных DEGH, если провести отрезки, параллельные BG. Периметр BCDE равен 198 см. Чему равен периметр ACDF? Чему равен периметр MRSF? Чему равен периметр MRCDS?

Как читать рисунок: слева большой квадрат ABEF (A — левый низ, B — правый низ, E — правый верх, F — левый верх). Справа к нему приставлен квадрат поменьше BCHG, а щель между его верхом GH и уровнем E–D закрывает лежачий прямоугольник DEGH. R стоит на нижней стороне AB, S — на верхней стороне FE; косые M→R и M→S похожи на клюв.

**🔍 С чего начать.** **Какие кирпичики?** Две стороны — большого квадрата и малого. Но они не независимы: разрезка малого квадрата на 5 равных прямоугольников их связывает. **Что делать с косыми MR и MS?** Ничего: их длина **дана** — она равна BC, стороне малого квадрата. Мерить и вычислять косые не нужно.

**Заметь главное.** Разрезка сравнивает две детали, повёрнутые друг относительно друга. Отрезки разрезки параллельны BG, то есть вертикальны, поэтому полоска малого квадрата **стоит**: её длинная сторона — вся сторона малого квадрата, а короткая — пятая часть этой стороны. А DEGH **лежит**: его длинная сторона ED равна BC, то есть тоже стороне малого квадрата, а короткая EG — это то, на сколько большой квадрат выше малого. Длинные стороны равны сами собой, вся работа — в коротких.

Пусть s — сторона большого квадрата, q — сторона малого. Короткая сторона полоски равна короткой стороне DEGH:

s − q = q/5

```
полоска малого квадрата (стоит)      DEGH (лежит)

  G┌──┬──┬──┬──┬──┐H                 E┌──────────────┐D
   │  │  │  │  │  │                  G└──────────────┘H
   │  │  │  │  │  │
  B└──┴──┴──┴──┴──┘C
   ширина q/5, высота q               длина q, высота s − q
```

Кто сравнит «ширину с шириной», получит бессмыслицу. Дробь q/5 здесь не единственная (ещё будет «половина AR»), поэтому сразу беру долю: `k` — пятая часть стороны малого квадрата. Малый квадрат — пять таких долей, а большой выше него ещё на одну долю, итого шесть.

q = 5k

s = 6k

**Шаг 1 — план.** Спрошены три периметра — обвожу каждый контур по сторонам.

ACDF — прямоугольник: низ AC — это сторона большого квадрата плюс сторона малого, высота — сторона большого.

P(ACDF) = 2·((s + q) + s)

MRSF — обхожу четырёхугольник от M: косая вниз к R, от R к S, по верху к F и по левой стороне обратно к M.

P(MRSF) = MR + RS + SF + FM

MRCDS — обхожу от M: косая к R, по низу до C, вверх до D, по верху до S и косой обратно к M.

P(MRCDS) = MR + RC + CD + DS + SM

Косые известны сразу — по условию они равны стороне малого квадрата:

MR = MS = BC = q

Всё остальное в контурах — куски сторон квадратов, а куски низа и верха зависят от того, где стоят R и S, то есть от AR.

> ✅ **План готов:**
>
> **P(ACDF) = 2·((s + q) + s)**
>
> **P(MRSF) = MR + RS + SF + FM**
>
> **P(MRCDS) = MR + RC + CD + DS + SM**
>
> - `s` — сторона большого квадрата, `q` — сторона малого; MR = MS = q
> - `k` — пятая часть q: q = 5k, s = 6k
> - `r` = AR
>
> Ответ = три периметра по этим формулам.
>
> Осталось найти: долю `k` (из P(BCDE)) и `r` (из BR = ½·AR).

**Шаг 2 — нужна доля k.** Её даёт единственное число условия: BCDE — стоячий прямоугольник. Его ширина — сторона малого квадрата, высота — сторона большого:

BC = 5k

BE = 6k

P(BCDE) = 2·(5k + 6k) = 198

22k = 198

k = 198 : 22 = 9

→ **k = 9**, малый квадрат **q = 45**, большой **s = 54**

**Шаг 3 — нужно r = AR.** R делит нижнюю сторону AB = 54 на два отрезка, и BR — половина AR. Назову **частью** половину AR (это не доля k — часть крупнее). Тогда AR — две части, BR — одна, вся сторона — три части.

54 : 3 = 18 — одна часть

r = 2 · 18 = 36

→ **r = AR = 36**, BR = ES = **18**

**Заметь главное.** S стоит ровно над R. ES по условию равен BR, поэтому кусок верха SF — это сторона без ES, а кусок низа AR — та же сторона без такого же куска BR. Значит, SF = AR, и S с R на одном расстоянии от левого края. Отсюда два подарка: отрезок R→S — сквозная вертикаль во всю высоту большого квадрата, а верхний кусок DS равен нижнему RC (каждый — сторона малого квадрата плюс кусок 18).

SF = s − ES = s − BR = AR

RS = s

DS = DE + ES = BC + BR = RC

**Шаг 4 — сборка.** Подставляю числа в формулы плана. Сначала недостающие отрезки контуров. Левый кусок FM — половина стороны AF:

M — середина AF → MA = MF = 27

Верхний отрезок SF равен AR, отрезок RS и правая сторона CD — сторона большого квадрата:

SF = AR = 36

RS = 54

CD = 54

Нижний отрезок RC (и равный ему DS) складывается из двух:

RC = BR + BC = 18 + 45 = 63

DS = 63

P(ACDF) = 2·((54 + 45) + 54)

P(ACDF) = 2·(99 + 54) = 306

P(MRSF) = 45 + 54 + 36 + 27 = 162

P(MRCDS) = 45 + 63 + 54 + 63 + 45 = 270

→ **P(ACDF) = 306**, **P(MRSF) = 162**, **P(MRCDS) = 270**

Проверка для родителя: от M до угла A — 27, от A до R — 36, значит по теореме Пифагора

MR = √(36² + 27²) = 45

— ровно BC, данные условия согласованы: треугольник 27, 36, 45 — это египетский 3, 4, 5, увеличенный в 9 раз ✓.

**⚠ Ловушки.** (1) Разрезка «с поворотом»: полоска стоит, DEGH лежит — длинное с длинным, короткое с коротким. (2) Отрезок R→S в контуре MRSF — сквозная вертикаль, вся высота 54, а не кусок. (3) Косые MR и MS не измеряются — они даны равенством с BC.

Проверка вторым способом: программа перебрала все целые стороны квадратов и положения R, оставила только те, где выполнены все условия (разрезка на 5 равных DEGH, P(BCDE) = 198, BR = ES = ½·AR, MR = MS = BC — длины косых по теореме Пифагора), и посчитала периметры обходом вершин по координатам — единственный набор 54, 45, 36 и периметры 306, 162, 270.

**Ответ на задачу:** периметр ACDF — 306 см, периметр MRSF — 162 см, периметр MRCDS — 270 см. *(Официальный ключ: 306; 162; 270 — совпадает.)*

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*
