## №1 — доска-крест с цифрами 3–9 *(Т4: миры по парам строк + пара для столбца)*

**Условие.** Доска имеет форму креста: центральный столбец из четырёх клеток, а через его вторую и третью клетки проходят две строки по три клетки. В левой клетке верхней строки уже стоит 1, в правой клетке нижней строки уже стоит 2, остальные шесть клеток пустые. Федя должен вписать в каждую пустую клетку цифру от 3 до 9, без повторов, так, чтобы сумма трёх чисел в клетках строки, которая начинается с 1, была равна 12; сумма трёх чисел в клетках строки, которая кончается на 2, была равна 15; а сумма четырёх чисел в клетках центрального столбца была равна 24. Сколькими способами он может это сделать? Приведи все возможности.

Сначала жанр ответа (ритуал Д6). Вопросов два, и они разного жанра: «сколькими способами» ждёт **число**, «приведи все возможности» — **полный список**. Значит, нужны оба, а список соберётся по ходу счёта. Способ здесь — готовая доска: две доски различаются, если хоть в одной клетке у них разные цифры.

Назову пустые клетки буквами: столбец сверху вниз — **a, b, c, d**; справа от b — **x**, слева от c — **y**. Тогда строка с единицей — это 1, b, x, строка с двойкой — это y, c, 2.

Вписанные 1 и 2 входят в суммы строк: в условии сказано «сумма **трёх** чисел строки», а единица и двойка — два из этих шести чисел. Записываю три данных равенствами и сразу убираю известные числа:

Строка с единицей:

1 + b + x = 12

**b + x = 11**

Строка с двойкой:

y + c + 2 = 15

**y + c = 13**

Столбец:

**a + b + c + d = 24**

Цифр от 3 до 9 семь, а пустых клеток шесть — одна цифра останется лишней.

**Заметь главное.** Строки и столбец пересекаются только в двух клетках — b и c. Поэтому строки можно заполнять, не думая о столбце, а столбцу от них достаётся одно-единственное требование: верх и низ вместе должны добрать то, чего не хватает до 24. И второе: верх a и низ d не входят ни в одну строку. Поменяй их местами — ни одна сумма этого не заметит, а доска получится другая.

**Шаг 1 — план.** Нужно число досок. `N(…)` — сколько объектов подходит под то, что стоит в скобках; например, N(пустых клеток) = 6.

Каждая доска складывается из двух частей: четыре клетки строк b, x, c, y и две клетки столбца вне строк, a и d. Четвёрку b, x, c, y назову **раскладкой строк**. Столбец требует от a и d одного — добрать сумму:

**a + d = 24 − b − c**

Значит, раскладка строк годится, только если среди оставшихся цифр найдётся пара с такой суммой. Нашлась — её можно поставить двумя способами: меньшую цифру наверх или вниз. По «Заметь главное» оба способа подходят, и доски у них разные — поэтому умножаю на 2 (что пара всегда одна, проверим в шаге 4):

> ✅ **План готов:**
>
> **N(досок) = N(годных раскладок строк) × 2**
>
> - N(годных раскладок строк) — сколькими способами заполнить b, x, c, y так, чтобы к ним нашлась пара для a и d;
> - 2 — порядок пары в столбце: какая её цифра сверху.
>
> Ответ = N(досок) и список всех досок. Осталось найти: N(годных раскладок строк) — и выписать сами раскладки.

**Шаг 2 — в каждой строке две пустые клетки и известная сумма: выписываю меню пар.** Меню — полный список пар разных цифр от 3 до 9 с нужной суммой. Перебираю по меньшей цифре пары — тогда ни одна пара не потеряется и ни одна не повторится.

Строка с единицей, b + x = 11:

- меньшая 3 → **{3, 8}** ✓
- меньшая 4 → **{4, 7}** ✓
- меньшая 5 → **{5, 6}** ✓
- меньшая 6 → напарником была бы 5, она меньше шестёрки — это уже названная пара {5, 6}. Стоп.

Строка с двойкой, y + c = 13:

- меньшая 3 → напарником была бы 10, это не цифра ✗
- меньшая 4 → **{4, 9}** ✓
- меньшая 5 → **{5, 8}** ✓
- меньшая 6 → **{6, 7}** ✓
- меньшая 7 → напарником была бы 6 — это уже названная пара {6, 7}. Стоп.

→ **по три пары на каждую строку.**

**Шаг 3 — цифры не повторяются, значит пары двух строк не могут делить цифру.** Сочетаю каждую пару строки с единицей с каждой парой строки с двойкой — таких сочетаний 3 × 3 = 9 — и вычёркиваю те, где цифра общая:

| строка с 1 ↓ / строка с 2 → | {4, 9} | {5, 8} | {6, 7} |
|---|---|---|---|
| {3, 8} | ✓ | ✗ общая 8 | ✓ |
| {4, 7} | ✗ общая 4 | ✓ | ✗ общая 7 |
| {5, 6} | ✓ | ✗ общая 5 | ✗ общая 6 |

Сочетание «пара строки с единицей + пара строки с двойкой» назову **миром**. Остаются **четыре мира**: {3, 8} и {4, 9}; {3, 8} и {6, 7}; {4, 7} и {5, 8}; {5, 6} и {4, 9}. У каждой раскладки строк пары строк свои, поэтому она лежит ровно в одном мире: миры не пересекаются и покрывают всё — их числа складываются.

*💬 «Разрезал на случаи по тому, какая пара цифр стоит в каждой строке: они не пересекаются и покрывают всё, поэтому складываю» — это и есть мысль для фразы-объяснения.*

**Шаг 4 — в каждом мире остаются ровно три цифры, и пару для a и d столбец берёт из них.** Строки забрали четыре цифры из семи, осталось три. У трёх цифр всего три пары, и суммы у них разные: две пары тройки делят одну цифру, а вторые цифры у них разные. Значит, для каждой раскладки строк подходящая пара для a и d находится **не больше одной**. Значит, годная раскладка даёт ровно две доски — одна пара и два её порядка, и формула плана N(годных раскладок) × 2 не теряет ни одной доски.

Внутри мира раскладок четыре: в строку с единицей любая цифра её пары может встать в центр (в b), и в строку с двойкой — тоже любая (в c). Для каждой раскладки считаю, сколько не хватает столбцу, и ищу эту сумму среди пар тройки.

*Мир {3, 8} и {4, 9}.* Осталось 5, 6, 7; пары тройки: 5 + 6 = 11, 5 + 7 = 12, 6 + 7 = 13.

- b = 3, c = 4 → a + d = 17 — такой пары нет ✗
- b = 3, c = 9 → a + d = 12 → **{5, 7}** ✓
- b = 8, c = 4 → a + d = 12 → **{5, 7}** ✓
- b = 8, c = 9 → a + d = 7 — такой пары нет ✗

*Мир {3, 8} и {6, 7}.* Осталось 4, 5, 9; пары тройки: 4 + 5 = 9, 4 + 9 = 13, 5 + 9 = 14.

- b = 3, c = 6 → a + d = 15 ✗
- b = 3, c = 7 → a + d = 14 → **{5, 9}** ✓
- b = 8, c = 6 → a + d = 10 ✗
- b = 8, c = 7 → a + d = 9 → **{4, 5}** ✓

*Мир {4, 7} и {5, 8}.* Осталось 3, 6, 9; пары тройки: 3 + 6 = 9, 3 + 9 = 12, 6 + 9 = 15.

- b = 4, c = 5 → a + d = 15 → **{6, 9}** ✓
- b = 4, c = 8 → a + d = 12 → **{3, 9}** ✓
- b = 7, c = 5 → a + d = 12 → **{3, 9}** ✓
- b = 7, c = 8 → a + d = 9 → **{3, 6}** ✓

*Мир {5, 6} и {4, 9}.* Осталось 3, 7, 8; пары тройки: 3 + 7 = 10, 3 + 8 = 11, 7 + 8 = 15.

- b = 5, c = 4 → a + d = 15 → **{7, 8}** ✓
- b = 5, c = 9 → a + d = 10 → **{3, 7}** ✓
- b = 6, c = 4 → a + d = 14 ✗
- b = 6, c = 9 → a + d = 9 ✗

Складываю миры:

**N(годных раскладок строк) = 2 + 2 + 4 + 2 = 10**

*💬 «Проверил все возможные случаи, остальные не подходят под правила (цифры разные и сумма 24 в столбце), — поэтому других нет» — это мысль для фразы про полноту.*

**Шаг 5 — сборка.** Подставляю в формулу плана:

**N(досок) = N(годных раскладок строк) × 2 = 10 × 2 = 20**

Список получается из шага 4: каждая годная раскладка строк даёт две доски — пара столбца ставится в a и d в одном порядке и в другом. Доска записана по строкам креста сверху вниз: верх a; строка 1, b, x; строка y, c, 2; низ d.

Проверка вторым способом: полный компьютерный перебор всех расстановок шести разных цифр из 3–9 по шести клеткам (5040 вариантов) даёт ровно 20 досок, и они совпадают с таблицей шага 5 одна в одну; по мирам 2 + 2 + 4 + 2 годных раскладок строк — тоже совпало; совпадает с официальным ключом (20 maneras).

**Ответ на задачу:** **20 способов**; все двадцать досок — в таблице выше. Считал так: разрезал доски на миры по тому, какие пары цифр стоят в двух строках, — годных миров четыре, они не пересекаются; в каждом мире проверил все четыре раскладки строк, и у десяти раскладок нашлась пара для верха и низа столбца, ровно одна; верх и низ меняются местами, поэтому каждая такая раскладка даёт две доски.

(4) Выписать только одну раскладку на мир: в центр строки может встать любая цифра её пары, и это разные доски.
