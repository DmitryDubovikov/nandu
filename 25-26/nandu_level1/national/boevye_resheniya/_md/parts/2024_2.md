## №2 — квадрат на плите и два треугольника *(Т2: сквозная стена + пропорция 3/2)*

**Условие.** На рисунке GHIJ — квадрат; ACDH и DEJI — прямоугольники; ABC и EFG — равные треугольники. Известно: CE = EJ и AH = BC; периметр DEJI равен 100 см, периметр ACDH равен 128 см; сторона AB составляет 3/2 от CE. а) Чему равен периметр DEGH? б) Сколько сантиметров в каждой стороне треугольника ABC? в) Чему равен периметр ABCDH? г) Чему равен периметр DEFGH?

**Фигура.** Посередине лежит плита ACDH: A — левый нижний угол, C — правый нижний, D — правый верхний, H — левый верхний. Над ней второй этаж от H до D: слева квадрат GHIJ, справа прямоугольник DEJI, E стоит над D. Снизу к плите приставлен треугольник ABC (B — под плитой, ближе к C), сверху на линию G–J–E поставлен равный ему треугольник EFG (F — над этажом, ближе к G). Правая стена C–D–E — одна прямая, D на ней только точка.

**Кирпичики.** Три буквы задают всю фигуру:

- `c` = AC — ширина плиты;
- `v` = AH — высота плиты;
- `s` — сторона квадрата GHIJ.

Через них выражается любой отрезок этажей:

- HI и GJ — ширина квадрата, s;
- ID и JE — остаток ширины плиты, c − s;
- DE — высота этажа, та же s: этаж высотой в квадрат;
- правая стена CE проходит оба этажа насквозь.

**Заметь главное. Этаж над плитой поделён на две части:** квадрат GHIJ шириной s и прямоугольник DEJI шириной c − s, — вместе они дают всю ширину плиты c. Высоту этажа задаёт тот же квадрат, она тоже s.

*Полупериметр* — половина периметра прямоугольника, то есть ширина плюс высота. У DEJI периметр 100, значит полупериметр 100 : 2 = 50. А через буквы он такой:

полупериметр DEJI = (c − s) + s = c

Буква s вычитается и тут же прибавляется: полупериметр DEJI сообщает ширину плиты и ничего не говорит про s. Один данный периметр — и c = 50 сразу, без системы. Работает это только потому, что квадрат стоит на том же этаже: будь высота DEJI другой, s не ушла бы.

**Шаг 1 — план: расписать все четыре ответа через c, v, s.** `P(X)` — периметр контура X; например, `P(DEJI) = 100` — данное условия.

DEGH — это квадрат вместе с DEJI, прямоугольник шириной c и высотой s:

P(DEGH) = 2·(c + s)

Треугольник ABC. Сторона AC — общая с плитой, значит AC = c. Сторона BC по пометке условия равна AH, то есть v. Сторону AB даёт пропорция от CE, а CE — сквозная стена через оба этажа:

CE = v + s

AB = (3/2)·CE

Контур ABCDH карандашом: A→B→C→D→H→A. Отрезок AC остаётся внутри фигуры и в периметр не входит:

P(ABCDH) = AB + BC + v + c + v

Контур DEFGH: D→E→F→G→H→D. Отрезок GE внутри. Стороны E→F и F→G — две стороны треугольника EFG, но какая сторона EFG равна какой стороне ABC, условие прямо не говорит; выручает третья сторона — она складывается из верха квадрата и верха DEJI:

GE = s + (c − s) = c

Это ровно AC. Значит, EF и FG — это AB и BC в каком-то порядке, а периметру нужна только их сумма:

P(DEFGH) = s + (AB + BC) + s + c

> ✅ **План готов:**
>
> **P(DEGH) = 2·(c + s)**
>
> **P(ABCDH) = AB + BC + v + c + v**
>
> **P(DEFGH) = s + (AB + BC) + s + c**
>
> - `c` — ширина плиты (= AC);
> - `v` — высота плиты (= AH = BC);
> - `s` — сторона квадрата;
> - AB = (3/2)·CE, где CE = v + s.
>
> Ответ = три периметра по этим формулам и стороны ABC: AB, BC = v, AC = c.
>
> Осталось найти: c, v, s, затем CE и AB.

**Шаг 2 — в полупериметре DEJI буква s уходит сама: остаётся c.** Как в «Заметь главное»:

(c − s) + s = 100 : 2

**c = 50**

**Шаг 3 — в периметре плиты ACDH неизвестна только v.** Плита — прямоугольник шириной c и высотой v, её полупериметр 128 : 2 = 64:

c + v = 64

v = 64 − 50

**v = 14**

**Шаг 4 — равенство CE = EJ сравнивает сквозную стену с верхом DEJI: из него s.** CE — сквозная стена, в неё входят оба этажа: v снизу и s сверху. EJ — верх прямоугольника DEJI, его ширина c − s. Равенство сравнивает вертикаль с горизонталью:

v + s = c − s

Подставляю v = 14 и c = 50:

14 + s = 50 − s

Справа s стоит с минусом. Прибавляю s к обеим частям — равенство не нарушится:

14 + 2s = 50

2s = 36

**s = 18**

**Шаг 5 — стороны ABC (вопрос б): сначала CE, потом пропорция и пометка AH = BC.** Сквозная стена:

CE = v + s = 14 + 18 = 32

«3/2 от CE» — это половина CE, взятая три раза: 32 : 2 = 16, и 16 · 3 = 48.

- AB = (3/2)·32 = **48**
- BC = AH = v = **14**
- AC = c = **50**

**Шаг 6 — сборка: подставляю числа в формулы плана.**

- **P(DEGH)** = 2·(50 + 18) = **136**
- **P(ABCDH)** = 48 + 14 + 14 + 50 + 14 = **140**
- **P(DEFGH)** = 18 + (48 + 14) + 18 + 50 = **148**

**⚠ Ловушки.** (1) CE — вся стена C–D–E, оба этажа, 32 см, а не только верхний кусок DE и не только высота плиты: D на прямой — точка, не угол.

(2) Условие не обещает, что буквы у равных треугольников идут в одном порядке. Из данных следует только GE = AC. По чертежу FG короткая (14), EF длинная (48), но доказать это нельзя — и не нужно: периметру DEFGH нужна лишь сумма двух оставшихся сторон, а она не зависит от того, какая сторона какая:

EF + FG = 48 + 14 = 62

(3) AC в ABCDH и GE в DEFGH лежат внутри фигуры — в периметр их не добавлять.

Проверка вторым способом: полный перебор целых c, v, s до 200 с периметрами, посчитанными по координатам вершин, даёт единственную тройку c = 50, v = 14, s = 18; обход контуров по координатам (B и F поставлены по сторонам 48, 14, 50) даёт 136, 140, 148. Для родителя: 14-48-50 — прямоугольный треугольник (14² + 48² = 50²), прямой угол в B — чертёж согласован.

**Ответ на задачу:** а) периметр DEGH = 136 см; б) стороны треугольника ABC: AB = 48 см, BC = 14 см, AC = 50 см; в) периметр ABCDH = 140 см; г) периметр DEFGH = 148 см. *(официальный ключ ✓ по всем четырём вопросам)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Периметры фразы-объяснения не требуют: буквы, равенства и вычитание говорят сами за себя.*

#### Запись

Кирпичики: c = AC (ширина плиты) · v = AH = BC (высота плиты) · s = сторона квадрата GHIJ.

> ✅ **План:**
>
> **P(DEGH) = 2·(c + s)**
>
> **P(ABCDH) = AB + BC + v + c + v**
>
> **P(DEFGH) = s + (AB + BC) + s + c**
>
> Осталось найти c, v, s, затем CE и AB.

- P(DEJI) = 100 → (c − s) + s = 50 → **c = 50**
- P(ACDH) = 128 → c + v = 64 → **v = 14**
- CE = EJ → v + s = c − s → 14 + 2s = 50 → **s = 18**
- CE = 14 + 18 = 32 → AB = (3/2)·32 = **48**
- BC = AH = **14**; AC = c = **50**

**P(DEGH) = 2·(50 + 18) = 136**

**P(ABCDH) = 48 + 14 + 14 + 50 + 14 = 140**

**P(DEFGH) = 18 + 62 + 18 + 50 = 148**

Проверка сложением: P(DEJI) = 2·(32 + 18) = 100 ✓; P(ACDH) = 2·(50 + 14) = 128 ✓; CE = 32 = EJ ✓
