разбиение на абзацы (строки склеиваются, тяжело читать) и точки-разделители, похожие на знак умножения;
в геометрии разделить решение на **геометрическую часть** (какие уравнения даёт рисунок) и **алгебраическую**

где они что-то поясняют. Частичное улучшение лучше, чем ничего: делай задачу целиком, потом следующую.

## Механические дефекты

- **Абзацы.** Каждая формула — отдельный абзац с пустыми строками вокруг (правило 10). Не бывает двух непустых
  строк подряд вне списка, таблицы и цитаты: markdown склеит их в одну строку. Длинный абзац, в котором
  перемешаны рассуждение и выкладка, режется: фраза-цель → формула отдельной строкой → вывод.
- **Точка «·».** Только знак умножения между множителями. Как разделитель («строка с 1 ↓ · строка с 2 →»,
  «а · б» в смысле перечисления) — заменить на «;», «,», «/» или разнести по пунктам.
  Слитное `2·HJ` — разрядить до `2 · HJ`.
- **Заголовки «Шаг N — нуж…»** — по правилу 14: законны только если величина названа в плане или условии,
  иначе заголовок = наблюдение, которое делает шаг возможным.

## Формат геометрической задачи (Т2) — новый, обязательный

Цель: геометрию читают **одним куском**, алгебру — **коротко**, связь между ними — номера уравнений.

```
**Условие.** …                                  (правило 13, не меняется)
[SVG рисунка условия — статичный]
*Как устроен рисунок.* …                        (если есть — сохранить)
определения (равносторонний и т. п.)            (если есть)

**Заметь главное.** …                           (правило 9)

### Часть 1 — геометрия: что даёт рисунок

**Буквы.** a = AF, b = AB, … — списком, у каждой откуда она (какие отрезки ей равны).

**Уравнения из условия.** Каждый данный периметр — обход контура одной строкой-подписью, затем
пронумерованное уравнение отдельным абзацем:

Контур ABF: AB, BF, FA.

**(1) a + b + c = 48**

Контур CDEF: CD, DE, EF, FC; CDE равносторонний, поэтому CD = DE = 3a.

**(2) 6a + 3b + 3c = 180**

**Что спрошено.** Каждый искомый периметр — тоже обход и формула через буквы (это план правила 8):

> ✅ **План готов:**
> P(CDE) = 9a;  …   (каждая формула — своей строкой)
> Осталось найти: a, b, c, d — из системы (1)–(4).

### Часть 2 — алгебра: решаем систему

Коротко: одна строка-операция над номерами → результат. Метод называется (метод сложения/вычитания,
подстановки — правило 5), номера новых уравнений продолжают нумерацию:

(2) − 3 · (1): **3a = 36**, **a = 12**

(3) − (4), затем подставить a: **(5) …**

Никакой геометрии в этой части: если для шага нужна новая геометрическая мысль — это новое уравнение,
и его место в части 1.

**Сборка** — подстановка в формулы плана → **Ответ на задачу** (отвечает на все вопросы условия).

**Проверка вторым способом** — сохранить, если была (можно сократить до подстановки в (1)–(n)).
```

- Правила 8, 13, 14 действуют внутри частей: «Заметь главное» остаётся, цель шага не выдумывается.
  Но скелет «Шаг 1 — план / Шаг 2 … / Шаг N — сборка» в Т2 заменяется двумя частями.
- Если «Заметь главное» — это ключевая алгебраическая комбинация (утроенный треугольник спрятан в (2)),
  её место — в начале части 2 («Заметь: в (2) стоят 3a, 3b, 3c — утроенное (1)»), а не в геометрии.
- **✍ «Что достаточно написать на туре»** — той же структуры: сначала пронумерованные уравнения, потом
  короткая строчка решения. Т2 фраз-объяснений не получает (правило 11).
- **SVG для Т2 обязателен**: рисунок условия с подписанными буквами точек. Длины через буквы (a, 3a …) —
  второй рисунок в начале части 1 или анимация, где обходимый контур подсвечивается по номерам уравнений
  (это и есть «переход»: какой контур даёт какое уравнение). Прорисовку рисунка условия не анимировать.

## Не-геометрия

Структуру «план → шаги → сборка» не ломать. Только механика + полировка + иллюстрации там, где есть
перебор, таблица, доска или процесс, которые без картинки читаются тяжело.
