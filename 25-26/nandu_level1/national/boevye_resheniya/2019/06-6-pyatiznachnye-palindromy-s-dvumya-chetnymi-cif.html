№6 — пятизначные палиндромы с двумя чётными цифрами (Т3: зеркало цифр + миры и «И»)

Национальный этап 2019 — боевые решения

Условие

Феде составляет список всех пятизначных чисел, которые выполняют три условия: в каждом числе ровно две чётные цифры; каждое число читается одинаково слева направо и справа налево; в каждом числе не может быть больше двух цифр, равных 1. Замечание из условия: помни, что 0 — чётное число. Сколько чисел в списке Феде? Объясни, как ты их считал.

Число, которое читается одинаково слева направо и справа налево, называется палиндромом (по-испански capicúa). Например, 40504: справа налево — снова 40504. А 40540 — не палиндром: наоборот выходит 04504.

Ритуал Ч1 «цифры или числа?»: все три условия — про цифры числа, а не про само число. Значит, работаем с местами цифр.

Назову цифры числа по местам слева направо: a, b, c, d, e. Условие палиндрома говорит, что последняя цифра равна первой, а четвёртая — второй:

e = a
d = b

Значит, каждое число списка выглядит так:

a b c b a

Первая цифра a — не ноль: число пятизначное.

Заметь главное

В палиндроме цифры a и b стоят по два раза, а цифра c — только один раз, посередине. Поэтому и чётные цифры приходят парами: если a чётная, это сразу две чётные цифры числа; если b чётная — тоже две; чётная c даёт одну. Переберу, какие из a, b, c чётные, и сосчитаю чётные цифры числа:

  • чётные обе, a и b, — уже четыре чётные цифры, много;
  • ни a, ни b не чётная — чётных цифр ноль (c нечётная) или одна (c чётная), мало;
  • чётная ровно одна из a и b и чётная c — три, много;
  • чётная ровно одна из a и b, а c нечётная — ровно две.

Значит, ровно две чётные цифры получаются только одним способом: чётная ровно одна из цифр a и b, а c нечётная. С единицами то же самое: единица на месте a или b — это сразу две единицы.

💬 «Разрезал на случаи по тому, какая из повторяющихся цифр чётная: они не пересекаются и покрывают всё, поэтому складываю» — это мысль для фразы-объяснения: случаев ровно два, и наблюдение выше показывает, что третьего нет.

Шаг 1 — план. Нужно число палиндромов в списке. Каждое такое число целиком задаётся тройкой первых цифр a, b, c: остальные две — их зеркало. Разные тройки дают разные числа. Значит, считать надо тройки, а выписывать сами числа не нужно.

Из наблюдения выше тройки делятся на два мира: либо чётная a, либо чётная b. Одновременно это не бывает — ровно одна из них чётная. Разные миры никогда не встречаются: ни одно число не попадёт в оба. Когда случаи идут через «ИЛИ» и не пересекаются, их количества складываются.

✅ План готов:

Ответ = N(a чётная) + N(b чётная)
  • N(a чётная) — сколько чисел списка, где чётная первая цифра, а b и c нечётные;
  • N(b чётная) — сколько чисел списка, где чётная вторая цифра, а a и c нечётные.

Ответ = сколько всего чисел в списке Феде.

Осталось найти: N(a чётная) и N(b чётная).

Шаг 2 — считаю N(a чётная). Здесь три выбора: a, затем b, затем c.

  • a чётная и не ноль (первая цифра): 2, 4, 6, 8 — 4 варианта;
  • b нечётная: 1, 3, 5, 7, 9 — 5 вариантов;
  • c нечётная: тоже 5 вариантов.

Какие цифры можно поставить на места b и c, не зависит от того, какую a взяли, — это закон «И»: выборы идут друг за другом и не мешают друг другу, поэтому числа вариантов перемножаются. Но пару b и c сначала надо проверить на единицы. Единица может стоять только на месте b (тогда в числе две единицы) и на месте c (одна). Две единицы разрешены, три — уже нет. Три получаются ровно тогда, когда b = 1 и c = 1. Из всех пар b, c выкидываю эту одну:

N(пар b, c) = 5 · 5 − 1 = 24

Любая из 4 чётных a сочетается с любой из 24 пар, закон «И»:

N(a чётная) = 4 · 24 = 96

→ N(a чётная) = 96

Шаг 3 — считаю N(b чётная). Снова три выбора.

  • b чётная: 0, 2, 4, 6, 8 — 5 вариантов. Здесь ноль разрешён: b стоит не первой, число 10301 — пятизначное;
  • a нечётная: 5 вариантов (нечётная цифра нулём не бывает, так что запрет на ноль впереди соблюдён сам);
  • c нечётная: 5 вариантов.

Теперь единица может стоять на месте a (две единицы) и на месте c (одна). Лишняя, третья, единица появляется ровно при a = 1 и c = 1 — эту пару выкидываю:

N(пар a, c) = 5 · 5 − 1 = 24

Любая из 5 чётных b сочетается с любой из 24 пар, закон «И»:

N(b чётная) = 5 · 24 = 120

→ N(b чётная) = 120

💬 «Это все случаи: они не повторяют друг друга и ни один не потерян» — это мысль для фразы про полноту: два мира не пересекаются, а внутри каждого каждая тройка цифр даёт ровно одно число.

Шаг 4 — сборка. Подставляю в формулу плана:

Ответ = 96 + 120 = 216

Проверка на примере — по числу из каждого мира и одно выброшенное:

  • 21712 — чётные только две двойки, единиц две ✓;
  • 30703 — чётные только два нуля, единиц нет ✓;
  • 21112 выброшено в шаге 2: единиц в нём три.

⚠ Ловушки.

  • Забыть, что 0 чётный: тогда во втором мире у b четыре варианта вместо пяти, и выходит 96 + 96 = 192.
  • Поставить 0 на первое место: 02320 — не пятизначное число.
  • Думать, что единица на месте b — это одна единица: в числе она стоит дважды, 41714.
  • Разрешить чётную c: одна чётная посередине плюс пара чётных по краям — уже три чётные цифры.

Проверка вторым способом: полный компьютерный перебор всех пятизначных чисел — ровно 216 проходят три условия, из них 96 с чётной первой цифрой и 120 с чётной второй, общих нет; без условия про единицы их 225, и отсеянные девять — ровно те, что выброшены в шагах 2 и 3 (4 + 5).

Ответ на задачу: в списке Феде 216 чисел: 96 с чётной первой (и последней) цифрой и 120 с чётной второй (и четвёртой). (официальный ключ ✓)

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Фразы входят в образец наравне с числами.

💬 Фраза-объяснение (в начале)

Разрезал на случаи по тому, какая из повторяющихся цифр чётная: они не пересекаются и покрывают всё, поэтому складываю.

Запись

Число a b c b a: a и b — по 2 раза, c — 1 раз → чётная ровно одна из a, b; c нечётная.

✅ План:

Ответ = N(a чётная) + N(b чётная)
  • a чётная: a ∈ {2, 4, 6, 8}
  • b, c нечётные, кроме b = c = 1 (три единицы) → 5 · 5 − 1 = 24
  • N(a чётная) = 4 · 24 = 96
  • b чётная: b ∈ {0, 2, 4, 6, 8}
  • a, c нечётные, кроме a = c = 1 → 5 · 5 − 1 = 24
  • N(b чётная) = 5 · 24 = 120
96 + 120 = 216 чисел

Проверка:

  • 21712 ✓
  • 30703 ✓
  • 21112 ✗ (три единицы)
