9. 2022 №2 — шоколадка с двумя треугольниками

Сетка равных деталей — Ключ к практикум-маршруту

Этап 1 — перевод

Фигура. Сетка 4 × 4 из деталей: колонки шириной a, b, a, b. Строки сверху вниз: первая «A B A B», вторая «C D C D», третья снова «A B A B», четвёртая снова «C D C D» (строки с A — высота p, строки с C — высота q). Сверху сидит равносторонний треугольник E, снизу — равнобедренный T остриём вниз: его основание — вся нижняя сторона (внутри фигуры), бока равны длинной стороне колонны «A, C, A» (детали первой колонки, три верхних этажа).

Кирпичики. a = ширина A (= ширина C), b = ширина B (= D), p = высота A-строки, q = высота C-строки.

Что даноЧто записываем
P(блока «A, B и A») = 192: ширина 2a + b, высота p(2a + b) + p + (2a + b) + p = 192
P(блока «B, A и B») = 198: ширина a + 2b, высота p(a + 2b) + p + (a + 2b) + p = 198
P(E) = 207: E равносторонний, значит каждая его сторона — это 207 : 3 = 69, и столько же его основание, кусок верхней стороны фигуры. Ширину 69 в верхнем ряду даёт полоса «B, A, B» (вся верхняя сторона длиннее), поэтому основание = a + 2b, и все три стороны по a + 2b(a + 2b) + (a + 2b) + (a + 2b) = 207
«B, A, B, D, C и D образуют квадрат»: ширина a + 2b, высота p + qa + 2b = p + q

✅ Результат перевода

(2a + b) + p + (2a + b) + p = 192
(a + 2b) + p + (a + 2b) + p = 198
(a + 2b) + (a + 2b) + (a + 2b) = 207
a + 2b = p + q

a = ширина A и C · b = ширина B и D · p = высота A-строк · q = высота C-строк

На первом проходе задача сделана.

Лайфхаки. Л2 (вся задача — блоки по именам), Л3 ((2) − (1): b − a = 3), Л1, ритуал 4 (квадрат из блоков: ширина = высота).

Ловушка перевода. Рисунок схематичен: основание E нарисовано во всю ширину фигуры (90), но равносторонний треугольник сам сообщает свою ширину периметром — 207/3 = 69, это полоса «B, A, B». Верь числу, а не толщине линий. И основание T в контур «C, D, C, D, T» не входит.

Этап 2 — решение (второй проход)

Шаг 1 — третье уравнение целиком стоит куском внутри второго. Первые два уравнения делю пополам, третье — на 3:

2a + b + p = 96
a + 2b + p = 99
a + 2b = 69
p + q = 69

Во втором уравнении стоит кусок a + 2b, а третье говорит, что он равен 69:

69 + p = 99 → p = 30

Шаг 2 — нужны ширины и вторая высота: вычитаю два почти одинаковых уравнения. Вычитаю (1) из (2) — буква p уходит:

(a + 2b) − (2a + b) = 99 − 96 → b − a = 3

Из (1) при p = 30:

2a + b = 66

Подставляю b = a + 3:

3a + 3 = 66 → a = 21, отсюда b = 24

Из (4): q = 69 − 30 = 39

Шаг 3 — у T бок собран из трёх этажей. Бок T — это колонна «A, C, A», то есть две A-строки и одна C-строка:

бок T = 2p + q = 60 + 39 = 99

Шаг 4 — сборка: подставляю числа в формулы плана.

  • P(A) = 2(21 + 30) = 102
  • P(D) = 2(24 + 39) = 126
  • P(блока «A, B, C, D, A, B») (две колонки × три строки) = 2((a + b) + (2p + q)) = 2(45 + 99) = 288
  • P(фигуры «C, D, C, D, T») = верх 90 + бока 39 + 39 + скаты 99 + 99 = 366

✍ Что достаточно написать на туре

Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится.

Кирпичики: a = ширина A и C · b = ширина B и D · p = высота A-строк · q = высота C-строк; бок T = колонна «A, C, A» = 2p + q.

✅ План:

P(A) = 2·(a + p)
P(D) = 2·(b + q)
P(блока «A, B, C, D, A, B») = 2·((a + b) + (2p + q))
P(фигуры «C, D, C, D, T») = (2a + 2b) + 2q + 2·(2p + q)

Осталось найти a, b, p, q.

  • P(блока «A, B, A») = 192 → 2a + b + p = 96
  • P(блока «B, A, B») = 198 → a + 2b + p = 99
  • P(E) = 207, E равносторонний → сторона 69 = полоса «B, A, B» → a + 2b = 69, значит p = 30
  • разность уравнений: b − a = 3; из первого 2a + b = 66 → a = 21, b = 24
  • квадрат «B, A, B, D, C, D» → p + q = 69 → q = 39
  • бок T = 2p + q = 60 + 39 = 99
P(A) = 2·(21 + 30) = 102
P(D) = 2·(24 + 39) = 126
P(блока «A, B, C, D, A, B») = 2·(45 + 99) = 288
P(фигуры «C, D, C, D, T») = 90 + 39 + 39 + 99 + 99 = 366

Проверка сложением: P(блока «A, B, A») = 2·(66 + 30) = 192 ✓; P(блока «B, A, B») = 2·(69 + 30) = 198 ✓; a + 2b = 69 ✓; p + q = 69 ✓
