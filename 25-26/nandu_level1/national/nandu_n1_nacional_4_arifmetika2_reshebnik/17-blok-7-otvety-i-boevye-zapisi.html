7.3 — ответ: 5 коробок + 14 подносов, 9400 песо

Шаг 1 — план. Спрашивают самую дешёвую покупку, а выбирать можно только из выписанного (ритуал 4). Обозначу a — сколько коробок по 8 маффинов, b — сколько подносов по 30. Условие «ровно 460» даёт одну строчку:

8a + 30b = 460

Букв две, а уравнение одно — значит, попаданий несколько, и нужен их полный список. Цена любой покупки из списка считается одинаково:

pre = 200 · a + 600 · b

Самая маленькая цена по всему списку пишется min(pre) — «наименьшее значение, какое pre может принять»; будь в списке только 11200 и 10600, было бы min(pre) = 10600.

✅ План готов:

Ответ = та пара из списка, у которой pre = min(pre)
pre = 200 · a + 600 · b

a — сколько коробок по 8 маффинов (шт.); b — сколько подносов по 30 маффинов (шт.); список — все пары целых a ≥ 0, b ≥ 0, для которых 8a + 30b = 460.

Осталось найти: сам список, потом цену каждой его пары.

Заметь главное

В 8a + 30b = 460 все три числа чётные, поэтому уравнение можно поделить на 2 целиком: 4a + 15b = 230. Решения при этом не теряются и не добавляются — это то же самое уравнение, только числа меньше и остатки считать легче. Обратная сторона того же факта: если бы у левой части общий делитель был, а правое число на него не делилось, решений не было бы вовсе.

Шаг 2 — кандидаты по остаткам. Нужно сузить перебор. Сначала уменьшаю числа делением пополам:

4a + 15b = 230

Теперь смотрю остатки при делении на 4: у 230 остаток 2, а у 15b при b = 0, 1, 2, 3 остатки идут 0, 3, 2, 1 и дальше повторяются по кругу. Подходит b = 2, и дальше каждый четвёртый. Граница:

15b ≤ 230 → b ≤ 15

Кандидаты: b ∈ {2, 6, 10, 14} — следующий, 18, уже за границей.

Шаг 3 — полный список. У каждого кандидата свой напарник a = (230 − 15b)/4: решения (50, 2), (35, 6), (20, 10), (5, 14).

Шаг 4 — сборка: считаю цену каждой пары. Заранее видно, куда идти: маффин на подносе стоит 600 : 30 = 20 песо, а в коробке 200 : 8 = 25 — поднос выгоднее. Но это подсказка, а не доказательство, поэтому считаю весь список: цены 11200, 10600, 10000, 9400.

min(pre) = 9400

7.4 — ответ: 9 банок + 2 ведра, 1780 песо

Шаг 1 — план. Та же машина: сначала полный список способов набрать ровно 41 л, потом цена каждого. Обозначу a — сколько банок по 3 л, b — сколько вёдер по 7 л.

✅ План готов:

Ответ = та пара из списка, у которой pre = min(pre)
pre = 120 · a + 350 · b

a — сколько банок по 3 л (шт.); b — сколько вёдер по 7 л (шт.); список — все пары целых a ≥ 0, b ≥ 0, для которых 3a + 7b = 41.

Осталось найти: сам список, потом цену каждой его пары.

Шаг 2 — кандидаты по остаткам. Смотрю на 3a + 7b = 41 через остатки при делении на 3: слагаемое 3a в остаток не приносит ничего, значит, весь остаток даёт 7b. У 41 остаток 2, у 7b при b = 0, 1, 2 остатки 0, 1, 2 и дальше по кругу → подходит b = 2 и каждый третий после него. Граница:

7b ≤ 41 → b ≤ 5

Кандидаты: b ∈ {2, 5}.

Шаг 3 — полный список. Решения (9, 2) и (2, 5).

Шаг 4 — сборка: считаю цену каждой пары. Здесь, наоборот, дешевле банка: литр из банки стоит 120 : 3 = 40 песо, а из ведра 350 : 7 = 50. Считаю обе пары:

120 · 9 + 350 · 2 = 1080 + 700 = 1780
120 · 2 + 350 · 5 = 240 + 1750 = 1990
min(pre) = 1780

7.5 — ответ: а) нельзя; б) 5 пачек по 6 + 15 по 15 — всего 20 пачек

Шаг 1 — план. Вопроса два, и они разной природы. В а) спрашивают, возможно ли вообще, — это проверка делимости, перебор не нужен: и 6, и 15 делятся на 3, значит, любая покупка даёт число, кратное 3, и остаётся спросить про 250: делится — «можно», не делится — «нельзя». В б) число другое, и уравнение своё:

6a + 15b = 255

Там нужна покупка с наименьшим числом пачек, причём обоих видов — значит, a не меньше единицы.

✅ План готов:

Ответ а) = «можно», если res(250 : 3) = 0
Ответ б) = пара (a; b), у которой a + b = min(a + b) при a ≥ 1 и b ≥ 1

a — сколько пачек по 6 конфет (шт.); b — сколько пачек по 15 конфет (шт.).

Осталось найти: res(250 : 3); годные b; наименьшее a + b.

Шаг 2 — а) проверка делимости. Сумма цифр 250 равна 2 + 5 + 0 = 7, а 7 на 3 не делится — значит, и 250 не делится. Кратным трём число 6a + 15b быть обязано, поэтому нельзя.

Заметь главное

В 2a + 5b = 85 слева 2a — всегда чётное, а справа 85 — нечётное. Значит, нечётным обязано быть 5b, а это бывает только при нечётном b. Одна проверка на чётность выбрасывает половину кандидатов сразу: годятся b = 1, 3, 5, … Это тот же ход «смотрю на остатки», только делитель здесь 2.

Шаг 3 — б) какие b бывают. Все три числа делятся на 3, поэтому уменьшаю уравнение втрое целиком:

6a + 15b = 255
2a + 5b = 85

По наблюдению выше годятся только нечётные b.

Шаг 4 — сборка: наименьшее число пачек. Нужно понять, куда двигаться по списку, — для этого выражаю число пачек через одну букву. Из уравнения a = (85 − 5b) : 2, значит:

a + b = (85 − 5b) : 2 + b = (85 − 3b) : 2

Справа b стоит с минусом — значит, чем больше b, тем меньше пачек всего. Осталась верхняя граница: пачек по 6 нужна хотя бы одна, то есть a ≥ 1:

85 − 5b ≥ 2
b ≤ 16

Но b нечётно, поэтому наибольшее годное — b = 15, и тогда a = (85 − 75) : 2 = 5. Проверка по формуле: a + b = (85 − 45) : 2 = 20 пачек, то есть min(a + b) = 20.
