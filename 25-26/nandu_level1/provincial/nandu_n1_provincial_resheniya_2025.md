## №2 — прямоугольник BCDF, точки A и E *(Т2: вычитание периметров, кирпичик)*

*Расположение (по рисунку).* A, B, C — на одной прямой (A — продолжение за B); E — «крыша» над стороной DF.

**🔍 С чего начать.** **Какие кирпичики?** «B — середина AC» → a = BC = AB; вертикаль h = CD; равенства DE = EF = h/3 и AF = CF новых букв не требуют. **С какого периметра начать?** С того, где неизвестных меньше всего: ACF записывается одними a и CF (потому что AF = CF) → даёт a + CF разом; затем BCF добавляет ровно одну новую букву h; контур BCDEF добирает a. Каждый следующий периметр вводит одну новую величину — цепочка раскручивается без систем.

**Решение.** Кирпичики: a = BC = AB (B — середина) и h = CD (вертикаль). Наклонная CF через a и h не выражается — это третья неизвестная, и AF = CF по условию, так что буква нужна одна: **c = CF = AF**.

**Шаг 1 — план: свести три периметра к трём буквам.** BCDF = 2 · (a + h), CDEF = CD + DE + EF + FC, ACDEF = AC + CD + DE + EF + FA — в них входят только a, h, c и производные от них (AC = 2a, CD = h, DE = EF = h/3, FA = c). Значит, считать надо a, h и c, а периметры даны так, что каждый следующий вводит ровно одну новую величину.

> ✅ **План готов:** Ответ = BCDF = 2 · (a + h), CDEF = h + 2h/3 + c, ACDEF = 2a + h + 2h/3 + c. Осталось найти a, h и c по цепочке ACF → BCF → контур BCDEF.

**Шаг 2 — нужна первая связь, и самая дешёвая — сумма a + c.** ACF: AC + CF + FA. Тут AC = AB + BC = a + a = 2a, а FA = CF = c, значит периметр = 2a + 2c = 2 · (a + c) = 144, делим пополам → **a + c = 72**.

**Шаг 3 — нужна вертикаль h.** BCF: BC + CF + FB. BC = a, CF = c; FB — сторона прямоугольника, противоположная CD, поэтому FB = h. Получается a + c + h, а сумму a + c мы уже знаем — это 72 → 72 + h = 120 → **h = 48**.

**Шаг 4 — нужны DE и EF.** DE = 1/3 · DC, а DC — это наша вертикаль h = 48; EF равно DE по условию → **DE = EF = 48 : 3 = 16**.

**Шаг 5 — нужны a и c по отдельности.** Их разделяет третий данный контур BCDEF: BC + CD + DE + EF + FB = a + 48 + 16 + 16 + 48, то есть a + 128 = 148 → **a = 20**, и тогда c = 72 − 20 = **52**.

**Шаг 6 — сборка.** Подставляю a = 20, h = 48, c = 52 в три периметра плана:

- BCDF = 2 · (a + h) = 2 · (20 + 48) = **136**;
- CDEF = h + 2h/3 + c = 48 + 16 + 16 + 52 = **132**;
- ACDEF = 2a + h + 2h/3 + c = 40 + 48 + 16 + 16 + 52 = **172**.

Проверка сложением: BCF: 20 + 52 + 48 = 120 ✓; ACF: 40 + 52 + 52 = 144 ✓; BCDEF: 20 + 48 + 16 + 16 + 48 = 148 ✓.

**Ответ: 136; 132; 172.** *(официальный ключ ✓ по всем трём; и снова спрятан треугольник 20–48–52)*

## №3 — фишки 1×2 по строкам *(Доски, гл. 3 «строка за строкой»)*

**🔍 С чего начать.** Первый вопрос: **что здесь один способ?** По фишке в каждой строке → способ = четвёрка позиций фишек. Второй: **что связывает условие?** Только **соседние** строки → на доску целиком не смотрим, идём строка за строкой (ритуал Д4). Третий: **продолжений поровну или по-разному?** По-разному: у крайних позиций «друзей» меньше, чем у средних → таблица этажей, а перед ней — разбор, какие позиции соседних строк дружат, то есть какие пары фишек можно поставить одну под другой.

*💬 «Условие связывает только соседние строки» — это и есть мысль для фразы-объяснения.*

**Решение.** В строке из 5 клеток у домино четыре позиции: 1–2, 2–3, 3–4, 4–5. Позицию удобно называть по её левой клетке: 1–2 — это позиция 1, 2–3 — позиция 2, 3–4 — позиция 3, 4–5 — позиция 4. Дальше везде говорим просто «позиция 1», «позиция 4».

**Шаг 1 — план.** Условие связывает только соседние строки, поэтому расклад собирается сверху вниз, строка за строкой. Но продолжений у разных позиций поровну не будет — просто перемножить нельзя, и приходится хранить своё число для каждой позиции.

Заведу для этого таблицу этажей: **Т(n; p)** — сколькими способами можно заполнить первые n строк так, чтобы фишка n-й строки стояла на позиции p.

Первый этаж известен даром: первую строку ничто не ограничивает, любая её позиция даёт ровно один способ заполнить «первую одну» строку. Дальше в позицию p на этаже n можно прийти из любой позиции q этажом выше, которая с p дружит, и разные q дают разные способы — значит, складываем. А любой способ заполнить всю доску кончается какой-то позицией четвёртой строки, и ровно одной, — поэтому в конце последний этаж достаточно сложить.

> ✅ **План готов:**
>
> **Т(1; p) = 1** для каждой из четырёх позиций
>
> **Т(n; p) = сумма всех Т(n − 1; q) по позициям q, дружащим с p**
>
> **Ответ = Т(4; 1) + Т(4; 2) + Т(4; 3) + Т(4; 4)**
>
> где
> - **p, q** — позиции фишки в строке из 5 клеток: 1 — это клетки 1–2, 2 — клетки 2–3, 3 — клетки 3–4, 4 — клетки 4–5;
> - **Т(n; p)** — сколькими способами можно заполнить первые n строк так, чтобы фишка n-й строки стояла на позиции p.
>
> Осталось найти: **правило дружбы** (какие q дружат с p), а по нему — **все Т(n; p) этаж за этажом**.

**Шаг 2 — считаем правило дружбы:** какие позиции соседних строк можно ставить одну под другую. Что значит «две клетки одного столбца»? Возьми один столбец и две соседние строки — клеток в нём на эти две строки всего две, верхняя и нижняя. Значит «накрыть две клетки одного столбца» можно только так: обе фишки попали в один и тот же столбец — верхняя закрыла верхнюю клетку, нижняя нижнюю. То есть **фишки соседних строк обязаны перекрываться хотя бы одним столбцом.**

Нарисуй четыре позиции, а потом две фишки одну под другой:

```
   поз.1 ▓▓░░░    поз.2 ░▓▓░░    поз.3 ░░▓▓░    поз.4 ░░░▓▓

   сдвиг 1 — общий столбец есть:      сдвиг 2 — общего столбца нет:
      ░▓▓░░                              ▓▓░░░
      ░░▓▓░                              ░░▓▓░
```

Перекрытие есть тогда и только тогда, когда позиции совпадают или стоят рядом, то есть номера позиций отличаются не больше чем на 1. Проверь на числах: позиции 2 и 3 — верхняя фишка занимает столбцы 2 и 3, нижняя 3 и 4, общий столбец 3 есть, так можно. А позиции 1 и 3 — верхняя занимает столбцы 1 и 2, нижняя 3 и 4, общего столбца нет, так нельзя. Чем дальше позиции друг от друга, тем хуже, поэтому годятся ровно те пары, где номера отличаются на 0 или на 1.

**Шаг 3 — считаем все Т(n; p).** Первый этаж — это первая строка, в ней фишку можно поставить на любую из четырёх позиций, и каждый такой вариант — пока ровно один способ: пишем 1, 1, 1, 1. Дальше работает формула плана:

| Этаж n | Т(n; 1) | Т(n; 2) | Т(n; 3) | Т(n; 4) |
|---|---|---|---|---|
| 1 | 1 | 1 | 1 | 1 |
| 2 | 2 | 3 | 3 | 2 |
| 3 | 5 | 8 | 8 | 5 |
| 4 | 13 | 21 | 21 | 13 |

(в клетку Т(n; p) приходит сумма тех клеток этажом выше, из которых сюда разрешено спуститься: это та же позиция и её соседи слева и справа. Например Т(3; 2) = 8 — это 2 + 3 + 3: сверху позиции 1, 2 и 3. У позиции 1 соседа слева нет, у позиции 4 — справа, поэтому крайние столбцы всегда меньше средних. Левая и правая половины таблицы получаются зеркальными, потому что доска симметрична: если зеркальность где-то сломалась — ищи ошибку в сложении.)

**Шаг 4 — сборка.** Каждый способ разложить все четыре фишки заканчивается фишкой на какой-то одной из четырёх позиций четвёртой строки, и ни один способ не попадает сразу в две клетки. Значит все способы разложились по четырём клеткам последнего этажа без потерь и без повторов, и остаётся их сложить: Ответ = Т(4; 1) + Т(4; 2) + Т(4; 3) + Т(4; 4) = 13 + 21 + 21 + 13 = **68**.

**Ответ: 68.** *(официальный ключ ✓; компьютерный перебор по настоящей доске 4×5 ✓)*

## №1 (отложенная) — три возраста *(Т1: сценарии + перебор случаев, блок 1c)*

**🔍 С чего начать.** Вопрос: **какое условие переводится в уравнение сразу?** «Через 15 лет один будет равен сумме сегодняшних двух других»: сумма всех сегодня известна (109), поэтому «двое других» — это 109 − a, и в уравнении остаётся одна неизвестная — возраст a находится немедленно. Второй вопрос — читаем внимательно: «разность каких-то двух — 14», а **между кем** — не сказано → это конечное меню случаев, и «дать все возможности» требует перебрать его целиком.

**Решение.**

**Шаг 1 — план.** Условие «через 15 лет он будет равен сумме сегодняшних двух других» переводится в уравнение сразу: сумма двоих других сегодня — это 109 без него самого. Про самих двоих остальных известно только одно — их общая сумма. А «разность каких-то двух равна 14» не говорит, между кем именно она стоит: случаев несколько, а просят все возможности — значит, их придётся выписать полным списком и пройти каждый.

> ✅ **План готов:**
>
> **a + 15 = 109 − a**
>
> **x + y = 109 − a**
>
> **Ответ = все тройки (a, x, y), у которых разность 14 стоит в одном из мест списка**
>
> где
> - **a** — возраст того, про кого сказано «через 15 лет»;
> - **x, y** — двое остальных (между собой их не различаем).
>
> Осталось найти: **a**; потом **список случаев**; потом **x и y** в каждом случае.

**Шаг 2 — считаем a.** Двое других сегодня дают в сумме 109 − a, и условие говорит a + 15 = 109 − a → 2a = 94 → **a = 47**; тогда **x + y = 62**.

**🗺 Шаг 3 — выписываем случаи.** Нужен полный список мест, где может стоять разность 14. Список надо не *придумать*, а **сгенерировать механически**: выписать все места подряд и вычеркнуть повторы — тогда случай нельзя потерять, а именно за полноту тут и ставят балл.

Пар в тройке ровно три: (a, x), (a, y), (x, y). В каждой паре разность может стоять в две стороны — кто из двоих больше. Итого шесть вариантов.

**Заметь главное.** x и y — это просто «двое остальных», между собой мы их не различаем. Поэтому «a − y = 14» — это тот же вариант, что «a − x = 14», только та же буква приклеена к другому человеку; и «y − x = 14» — это «x − y = 14» после переименования. Переименование убирает ровно половину списка.

```
a − x = 14          a − y = 14   ← то же самое, переименование
x − a = 14          y − a = 14   ← то же самое, переименование
x − y = 14          y − x = 14   ← то же самое, переименование
```

Остаётся три случая, и четвёртому взяться неоткуда. А два из трёх можно превратить в число прямо сейчас, не таща букву дальше: если разность задевает сорокасемилетнего, то второй участник этой разности либо на 14 младше, либо на 14 старше.

```
[a − x = 14 → x = 47 − 14 = 33] ─ИЛИ─ [x − a = 14 → x = 47 + 14 = 61] ─ИЛИ─ [x − y = 14]
```

*💬 Это и есть мысль для фразы-объяснения.*

**Шаг 4 — считаем x и y по каждому случаю.** В каждом случае известна сумма x + y = 62 и что-то ещё — этого хватает, чтобы найти обоих.

**Случай 1 — x = 33** (сорокасемилетний старше на 14).

**y = 62 − 33 = 29**

→ тройка **47, 33, 29** (проверка: 47 + 33 + 29 = 109 ✓, 47 + 15 = 62 = 33 + 29 ✓, 47 − 33 = 14 ✓)

**Случай 2 — x = 61** (сорокасемилетний младше на 14).

**y = 62 − 61 = 1**

→ тройка **47, 61, 1** (проверка: 47 + 61 + 1 = 109 ✓, 47 + 15 = 62 = 61 + 1 ✓, 61 − 47 = 14 ✓)

**Случай 3 — разность между «другими»:** x + y = 62 и x − y = 14; больший — это половина суммы плюс половина разности.

**x = (62 + 14) : 2 = 38**

**y = 62 − 38 = 24**

→ тройка **47, 38, 24** (проверка: 47 + 38 + 24 = 109 ✓, 47 + 15 = 62 = 38 + 24 ✓, 38 − 24 = 14 ✓)

**Шаг 5 — сборка.** Три случая дали три тройки: 47, 33, 29; 47, 61, 1; 47, 38, 24 — и вот тут расхождение с ключом.

⚠ **Официальный ключ приводит только две тройки: 47, 38, 24 и 47, 33, 29.** Но тройка 47, 61, 1 формально удовлетворяет всем условиям (сумма 109 ✓; 47 + 15 = 62 = 61 + 1 ✓; 61 − 47 = 14 ✓) — подтверждено полным перебором. Видимо, составители сочли годовалого участника не «persona» с возрастом. На туре надёжнее выписать все три и приписать ко второй комментарий — за полноту перебора баллы не снимают, за потерю случая 1 или 3 — снимут.

**Ответ: 47, 38, 24 и 47, 33, 29 (официально); формально есть и 47, 61, 1.**

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Просят «все возможности», поэтому список случаев и проверка каждой тройки пишутся обязательно — это и есть доказательство полноты.*

#### 💬 Фраза-объяснение (в начале)

**El enunciado no dice entre quiénes está la diferencia y los otros dos no se distinguen: hay tres casos.**

*В условии не сказано, между кем разница, а двое остальных неразличимы — значит случаев три.*

#### Запись

a — возраст того, про кого сказано «через 15 лет»; x и y — двое остальных (между собой не различаем).

> ✅ **План:**
>
> **a + 15 = 109 − a**
>
> **x + y = 109 − a**
>
> Ответ = все тройки (a, x, y), где разность 14 стоит в одном из мест списка.

- a + 15 = 109 − a → 2a = 94 → **a = 47**, и тогда x + y = 62
- пар три: (a, x), (a, y), (x, y); разность в каждой — в две стороны, итого шесть. Но x и y не различаем, поэтому половина — переименования:

```
a − x = 14          a − y = 14   ← переименование
x − a = 14          y − a = 14   ← переименование
x − y = 14          y − x = 14   ← переименование

[a − x = 14 → x = 47 − 14 = 33] ─ИЛИ─ [x − a = 14 → x = 47 + 14 = 61] ─ИЛИ─ [x − y = 14]
```

- случай 1: x = 33, y = 62 − 33 = 29 → **47, 33, 29**
  - проверка: 47 + 33 + 29 = 109 ✓
  - 47 + 15 = 62 = 33 + 29 ✓
  - 47 − 33 = 14 ✓
- случай 2: x = 61, y = 62 − 61 = 1 → **47, 61, 1**
  - проверка: 47 + 61 + 1 = 109 ✓
  - 47 + 15 = 62 = 61 + 1 ✓
  - 61 − 47 = 14 ✓
- случай 3: x = (62 + 14) : 2 = 38, y = 24 → **47, 38, 24**
  - проверка: 47 + 38 + 24 = 109 ✓
  - 47 + 15 = 62 = 38 + 24 ✓
  - 38 − 24 = 14 ✓

**Ответ: 47, 33, 29; 47, 61, 1; 47, 38, 24 — вторая годится формально, выписать с оговоркой.**

#### 💬 Фраза в конце — полнота

**Escribí los seis pares con diferencia posible y taché los tres repetidos, porque los otros dos no se distinguen. No puede quedar ningún caso afuera.**

*Выписал все шесть пар с возможной разностью и вычеркнул три повтора, потому что двое остальных неразличимы. Ни один случай не мог остаться в стороне.*
