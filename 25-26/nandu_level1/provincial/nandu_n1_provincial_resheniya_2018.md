## №2 — прямоугольник ABDF, точки C и E *(Т2: кирпичик + вычитание периметров)*

*Расположение (восстановлено по условию, все три ответа сошлись с ключом).* Прямоугольник ABDF: A и B внизу, D над B, F над A. C — продолжение AB за B (B — середина AC). E — «крыша» над верхней стороной DF: треугольник DEF стоит на DF снаружи. Отсюда видно, из чего сложены нужные контуры. ABDEF — прямоугольник с крышей: обходим A → B → D → E → F → A, и сторона DF внутрь обхода не попадает, она осталась внутри фигуры. ADEF — обход A → D → E → F → A, где AD уже не сторона прямоугольника, а его диагональ. ACD — треугольник со сторонами AC, CD и DA.

**🔍 С чего начать.** **Какие кирпичики?** Стороны прямоугольника: **a = AB** (= DF) и **b = AF** (= BD); равенство AF = 3·FE значит FE = b/3 — новой буквы не нужно. Диагональ AD через стороны не выражается — это третья неизвестная, **c = AD**, и CD = c по условию. Итого неизвестных три: a, b, c. **Где вычитать?** Периметр ABD — это a + b + c, а a + b — полупериметр прямоугольника: диагональ c выскакивает одним вычитанием. Потом периметр DEF (в нём DF = a и FE = b/3) вместе с полупериметром даст сами a и b.

**Решение.**

**Шаг 1 — план: свести три периметра к трём буквам.** Все три искомых контура — это суммы отрезков, и каждый отрезок выражается через a, b, c (BD = b, DF = a, EF = b/3, AC = 2a, CD = c); DE = 12 дано.

> ✅ **План готов:** Ответ = ABDEF = a + b + 12 + b/3 + b, ADEF = c + 12 + b/3 + b, ACD = 2a + c + c. Осталось: полупериметр → c → a и b.

**Шаг 2 — нужен полупериметр прямоугольника** (он войдёт и в c, и в разность с DEF). Обход ABDF — это a + b + a + b, то есть 136 состоит из двух одинаковых кусков a + b → 136 : 2 = 68, **a + b = 68**.

**Шаг 3 — нужна диагональ c.** Периметр ABD — это AB + BD + DA = a + b + c, то есть полупериметр плюс c → 68 + c = 120, **c = 52**.

**Шаг 4 — нужны сами a и b** (через них выражаются все оставшиеся отрезки). Треугольник DEF даёт вторую связь: DE + EF + FD = 48, где DE = 12, FD = a, EF = b/3 → **a + b/3 = 36**. Из полупериметра (a + b = 68) вычитаю эту строку: a есть и там, и там, он уходит, остаётся b без своей трети: b − b/3 = 68 − 36 = 32. Две трети b равны 32, значит одна треть = 16, весь **b = 48**. Дальше **a = 68 − 48 = 20**, и FE = b : 3 = **16**. Проверка треугольника DEF: 12 + 16 + 20 = 48 ✓ (это 3–4–5, увеличенный в 4 раза).

**Шаг 5 — сборка.** Подставляю a = 20, b = 48, c = 52 в три суммы плана:

- ABDEF = a + b + 12 + b/3 + b = 20 + 48 + 12 + 16 + 48 = **144**;
- ADEF = c + 12 + b/3 + b = 52 + 12 + 16 + 48 = **128**;
- ACD = 2a + c + c = 40 + 52 + 52 = **144** (B — середина AC, поэтому AC = 2a; CD = DA = c).

Проверка сложением: ABDF: 2·(20 + 48) = 136 ✓; ABD: 20 + 48 + 52 = 120 ✓; DEF: 12 + 16 + 20 = 48 ✓.

**Ответ: ABDEF = 144, ADEF = 128, ACD = 144.** *(официальный ключ ✓ по всем трём; и снова семейство 20–48–52, то есть 5–12–13 × 4)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится.*

Кирпичики: a = AB = DF, b = AF = BD, c = AD = CD; FE = b/3, DE = 12.

> ✅ **План:**
>
> **ABDEF = a + b + 12 + b/3 + b**
>
> **ADEF = c + 12 + b/3 + b**
>
> **ACD = 2a + c + c**
>
> Осталось найти a, b и c.

- П(ABDF) = 2 · (a + b) = 136 → a + b = 68
- П(ABD) = a + b + c = 120 → **c = 52**
- П(DEF) = 12 + b/3 + a = 48 → a + b/3 = 36
- вычитаю из a + b = 68: 2b/3 = 32 → **b = 48**, **a = 20**, FE = 16

**ABDEF = 20 + 48 + 12 + 16 + 48 = 144**

**ADEF = 52 + 12 + 16 + 48 = 128**

**ACD = 40 + 52 + 52 = 144**

Проверка: 2 · (20 + 48) = 136 ✓; 20 + 48 + 52 = 120 ✓; 12 + 16 + 20 = 48 ✓

## №1 — фишки трёх цветов *(Т1: доли + одно уравнение, блок 1c)*

**🔍 С чего начать.** Вопрос: **что здесь повторяется?** Нарисуй коробку кусками:

```
   ┌──────── 100 ────────┬── 20 ──┬── 20 ──┬─ … ─┬── 20 ──┐
   │  92 кр.    5 чёрн.  │ 13 кр. │ 13 кр. │     │ 13 кр. │
   │             3 бел.  │  5 чёр.│  5 чёр.│     │  5 чёр.│
   │                     │  2 бел.│  2 бел.│     │  2 бел.│
   └─────────────────────┴────────┴────────┴─────┴────────┘
        первая сотня          Д одинаковых двадцаток
```

Неполного хвоста в конце быть не может: про **каждую** следующую двадцатку сказано, что в ней 13 красных и 5 чёрных, — значит коробка кончилась ровно на границе двадцатки. Первая сотня особая, дальше куски одинаковые, и сколько их — не сказано: весь состав описывается **одним неизвестным числом Д**, а условие «красные — это 7/10 всего» даст на него **одно уравнение**.

*💬 Это и есть мысль для фразы-объяснения.*

**Решение.**

**Шаг 1 — план.** Коробка кончилась ровно на границе двадцатки, значит вся она — первая сотня плюс сколько-то целых двадцаток; сколько именно, назову Д. Каждый цвет собирается по тем же кускам: сколько было в первой сотне плюс столько же раз по двадцатке. Белые ни в одном куске не названы — зато они остаток от всей коробки.

> ✅ **План готов:**
>
> **Всего = 100 + 20 · Д**
>
> **Кр = 92 + 13 · Д**
>
> **Чр = 5 + 5 · Д**
>
> **Бл = Всего − Кр − Чр**
>
> где
> - **Д** — сколько двадцаток вынули после первой сотни;
> - **Всего** — сколько фишек было в коробке;
> - **Кр, Чр, Бл** — красные, чёрные и белые во всей коробке.
>
> Ответ = **Кр**, **Чр**, **Бл**. Осталось найти: **Д**.

**Шаг 2 — считаем Д.** Условие «красные — это 7/10 всего» превращается в уравнение: слева красные, справа семь десятых коробки.

**92 + 13 · Д = 7/10 · (100 + 20 · Д)**

Справа беру семь десятых от каждого слагаемого: 7/10 · 100 = 70, 7/10 · 20 = 14.

**92 + 13 · Д = 70 + 14 · Д**

Вычитаю из обеих частей 13 · Д и 70:

**Д = 92 − 70 = 22**

Уравнение первой степени даёт ровно один корень — значит, других вариантов нет и проверять больше нечего. То же самое в уме, если считать по кускам: первая сотня дала 92 красных вместо положенных 70 — запас 22; каждая двадцатка даёт 13 вместо 14 — съедает по одной. Значит двадцаток 22.

**Шаг 3 — сборка.** Подставляю Д = 22 в формулы плана:

- **Всего = 100 + 20 · 22 = 540**;
- **Кр = 92 + 13 · 22 = 378** (проверка: 7/10 · 540 = 378 ✓);
- **Чр = 5 + 5 · 22 = 115**;
- **Бл = 540 − 378 − 115 = 47** (проверка по кускам: в первой сотне белых 100 − 92 − 5 = 3, в каждой двадцатке 20 − 13 − 5 = 2, итого 3 + 22 · 2 = 47 ✓).

**Ответ: 378 красных, 115 чёрных, 47 белых.** *(официальный ключ ✓)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Фраза-объяснение входит в образец наравне с числами: её сверяют так же, как ответ.*

#### 💬 Фраза-объяснение (в начале)

**Después de las primeras 100 fichas todas las tandas de 20 son iguales, y la caja terminó justo al final de una tanda: por eso todo depende de una sola incógnita, D, la cantidad de tandas.**

*После первых 100 фишек все двадцатки одинаковые, и коробка кончилась ровно на границе двадцатки: поэтому всё зависит от одной неизвестной — Д, количества двадцаток.*

#### Запись

Коробка = первая сотня + Д одинаковых двадцаток (неполной двадцатки быть не может).

> ✅ **План:**
>
> **Всего = 100 + 20 · Д**
>
> **Кр = 92 + 13 · Д**
>
> **Чр = 5 + 5 · Д**
>
> **Бл = Всего − Кр − Чр**
>
> Ответ = **Кр**, **Чр**, **Бл**. Осталось найти Д.

- красные — 7/10 всего: 92 + 13 · Д = 7/10 · (100 + 20 · Д) = 70 + 14 · Д → **Д = 22**
- Всего = 100 + 440 = **540**
- Кр = 92 + 286 = **378**
  - проверка: 7/10 · 540 = 378 ✓
- Чр = 5 + 110 = **115**
- Бл = 540 − 378 − 115 = **47**
  - проверка по кускам: 3 + 22 · 2 = 47 ✓

**Ответ: 378 красных, 115 чёрных, 47 белых.**

## №3 — 6 фишек на доске 3×3 *(Счёт: группа + «минус»; Доски: строки и столбцы)*

**🔍 С чего начать.** Первый вопрос: **что здесь один способ?** Фишки одинаковые → способ = выбор шести клеток из девяти. Второй: **какое условие мешает?** «Ни строка, ни столбец не пусты» — редкий запрет, значит «всё минус плохие». Третий — обязательная проверка: **бывает ли плохое дважды?**

**Заметь главное.** Считать удобнее с изнанки: выбрать шесть занятых клеток из девяти — то же самое, что выбрать **три пустые**. Какие три оставил пустыми, такие шесть и занял, и наоборот; наборов поровну. Нарисуй доску, отмечая фишку ● и пустую клетку ○:

```
   годится:        плохо — пуста строка:    плохо — пуст столбец:
   ● ○ ●                 ○ ○ ○                    ● ○ ●
   ○ ● ●                 ● ● ●                    ● ○ ●
   ● ● ○                 ● ● ●                    ● ○ ●
```

А в пустых клетках запрет читается сразу: пустых всего три, поэтому строка пуста ровно тогда, когда все три выстроились в одну строку, — со столбцом так же. И плохое дважды не бывает: строке нужны все три в одной горизонтали, столбцу — в одной вертикали, разом не выйдет. Значит, вычитаем честно.

*💬 Обе эти мысли — «изнанка: выбираем пустые» и «плохое дважды не бывает» — и пойдут во фразу-объяснение.*

**🗺 Шаг 1 — план счёта.**

```
[все способы выбрать 3 пустые из 9] ─минус─ [пустая строка] ─минус─ [пустой столбец]
```

Один способ — это выбор трёх пустых клеток из девяти, поэтому первым делом нужны все такие тройки, без оглядки на запреты. Запрет же «ни одна строка и ни один столбец не пусты» бьёт по редким случаям, и одна тройка не может опустошить строку и столбец сразу, — значит, вычитаем честно, без возвратов. Количества пишу буквой **N**, а в скобках — чего именно.

> ✅ **План готов:**
>
> **Ответ = N(всех троек пустых) − N(троек с пустой строкой) − N(троек с пустым столбцом)**
>
> где
> - **N(всех троек пустых)** — все выборы трёх пустых клеток из девяти, без запретов;
> - **N(троек с пустой строкой)** — те, что оставляют пустой целую строку;
> - **N(троек с пустым столбцом)** — те, что оставляют пустым целый столбец.
>
> Плохое дважды не бывает — вычитаем без возвратов. Осталось найти эти три числа.

**Шаг 2 — считаю все тройки пустых.** Три пустые клетки из девяти берутся без порядка — это группа, сочетания:

**C(9, 3) = 9 · 8 · 7 : 6 = 84** — делим на 6, потому что каждую тройку девять-восемь-семь насчитали шесть раз, по числу порядков внутри тройки.

Проверка вторым ходом — перебор по младшей клетке: пронумеруем клетки 1–9, в любой тройке есть самая младшая, а две оставшиеся — пара из клеток старше неё. Младшая 1 → пара из восьми, 28; младшая 2 → пара из семи, 21; дальше 15, 10, 6, 3, 1; с младшими 8 и 9 пары старше уже не набрать. 28 + 21 + 15 + 10 + 6 + 3 + 1 = 84 ✓.

→ **N(всех троек пустых) = 84**

**Шаг 3 — считаю плохие тройки.** Пустая строка означает, что все три пустые клетки лежат в одной строке. Но выбрал строку — и выбирать больше нечего: пустыми оказываются ровно её три клетки. Значит, на каждую строку приходится ровно одна плохая тройка, а строк три. Со столбцами всё то же самое.

→ **N(троек с пустой строкой) = 3**, **N(троек с пустым столбцом) = 3**

**Шаг 4 — сборка.** Подставляю три числа в план: Ответ = 84 − 3 − 3 = **78**.

**Ответ: 78.** *(официальный ключ ✓; компьютерный перебор ✓)*

### ✍ Что достаточно написать на туре

*Образец записи для сравнения с работой ребёнка: разбор выше объясняет, почему так можно считать, — на бумагу это не выносится. Фраза-объяснение и фраза про полноту входят в образец наравне с числами.*

#### 💬 Фраза-объяснение (в начале)

**Las fichas son iguales: elegir las 6 ocupadas es lo mismo que elegir las 3 vacías. Con solo 3 vacías, una fila y una columna no pueden quedar vacías a la vez: resto sin devolver nada.**

*Фишки одинаковые: выбрать 6 занятых — то же самое, что выбрать 3 пустые. А с тремя пустыми строка и столбец разом пустыми не бывают: вычитаю без возвратов.*

#### Запись

Фишки одинаковые, поэтому выбрать 6 занятых клеток из 9 — то же самое, что выбрать 3 пустые.
Пустая строка означает, что все три пустые клетки легли в одну строку; со столбцом так же; обе беды разом невозможны, поэтому вычитаю без возвратов.

> ✅ **План:**
>
> **Ответ = N(всех троек пустых) − N(троек с пустой строкой) − N(троек с пустым столбцом)**

- N(всех троек пустых) = C(9, 3) = 9 · 8 · 7 : 6 = **84**
- N(троек с пустой строкой) = **3** (на каждую строку ровно одна тройка)
- N(троек с пустым столбцом) = **3**

**Ответ = 84 − 3 − 3 = 78.**

#### 💬 Фраза в конце — полнота

**Conté todas las ternas de casillas vacías y resté las malas; los dos tipos de malas no se superponen, así que ninguna quedó restada dos veces.**

*Посчитал все тройки пустых клеток и вычел плохие; два вида плохих не пересекаются, поэтому ни одна не вычтена дважды.*
