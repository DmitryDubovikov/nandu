# Провинциальный этап — тренировочные двойники
## Olimpíada Ñandú · Nivel 1 · 12 задач «как боевые» с разборами

> Здесь 12 задач, придуманных по образцу провинциальных туров 2018–2025: на каждый тип задач этих лет — по одной, на самые частые — по две-три. Настоящие задачи туров здесь не используются: они ждут тебя в боевой фазе.
>
> **Как тренироваться.** Прочитай условие и честно попробуй пару минут — не решить, а назвать тип задачи и первый ход. Потом прочитай разбор целиком и разберись в каждом шаге. Закрой файл — и восстанови решение на бумаге: план, числа, проверку. Открой и сверь. Разошлось — найди место расхождения, снова закрой и повтори.
>
> Разбор здесь читать не стыдно: он для того и написан. Вся работа — в восстановлении. Поэтому правило одно: **разбор никогда не заканчивается чтением, только записанным по памяти решением.**
>
> **💬 Одна фраза словами.** Выкладки показывают, **что** ты посчитал; балл за объяснение ставят за **почему так вообще можно считать**. Поэтому у каждой задачи (кроме периметров — там всё видно из записи) есть **фраза-объяснение**: одно-два предложения по-испански, которые пишутся до выкладок. У счётных задач в конце добавляется вторая фраза — про полноту: все случаи проверены, других нет. Фразы короткие нарочно: длинный текст съест время, которого не хватит на решение. Их учат наизусть вместе с записью — они собраны в памятке, в разделе «Что писать словами».
>
> **Последний тренировочный день — боевой:** три задачи подряд, в порядке тура, на часах, разборы не открываешь до конца. Это репетиция настоящих туров, которые пойдут дальше.
>
> Порядок задач — как порядок на туре: сначала периметры (№2), потом текстовые (№1), потом счёт (№3); в конце — доска-головоломка, которую на туре откладывают на самый конец.

# Периметры

## Задача 1 — прямоугольник с полоской и «крышей» *(Т2: кирпичик + вычитание контуров)*

**Условие.** KLMN — прямоугольник (K и L — внизу, M и N — наверху). Вертикальная линия PQ делит его на два **равных** прямоугольника KPQN и PLMQ. Точки S (на стороне KN) и R (на стороне LM) отрезают нижнюю полоску KLRS; KN = 3 · KS. Снаружи справа отмечены точки D (ниже L) и F (выше M), причём LD = MF = KS; точка E — ещё правее, DE = EF, и D, E, F образуют треугольник. Периметры: контур KLDEFMN = 260, треугольник DEF = 140, полоска KLRS = 144. Найди периметры прямоугольника PLMQ, полоски SRMN и контура PLDEFMQ.

**🔍 С чего начать.** **Какие кирпичики?** s = KS — тогда KN = 3s — это высота; W = KL — ширина. Раз KPQN и PLMQ равные, P стоит посередине KL: PL = W : 2. Всё остальное выражается через них: LD = MF = s, а сторона треугольника FD идёт по вертикали от D (на s ниже L) до F (на s выше M): FD = s + 3s + s = 5s. А наклонные DE и EF через кирпичики не выражаются вовсе — это отдельная неизвестная; по условию они равны, значит буква нужна одна: **d = DE = EF**. Итого неизвестных три: W, s, d. **Где вычитать?** Контур KLDEFMN и треугольник DEF оба содержат обе наклонные, то есть 2d, а вертикальные куски взаимно сокращаются: у контура их LD + FM + NK = s + s + 3s = 5s, у треугольника — FD = 5s. Разность оставит чистое 2W.

**Решение.**

**Шаг 1 — план.** Все три спрашиваемых периметра собираются из одних и тех же величин: ширины W = KL, полоски s = KS (высота KN = 3s) и наклонной d (d = DE = EF). Значит, считать контуры по отдельности рано — сначала нужно добыть W, s и d.

> ✅ **План готов:** Ответ = три периметра, собранные из W, s и d:
> - PLMQ = 2 · (W : 2 + 3s);
> - SRMN = 2 · (W + (3s − s));
> - PLDEFMQ = W : 2 + s + 2d + s + W : 2 + 3s.
>
> Осталось найти W, s и d.

**Шаг 2 — считаем W (ширину).** Ширина прямо не дана — зато её можно выделить вычитанием контуров: у KLDEFMN и у треугольника DEF есть общий кусок 2d, а вертикали взаимно сокращаются. Записываю оба периметра через кирпичики:

- контур KLDEFMN: W + s + d + d + s + W + 3s → 2W + 5s + 2d = 260;
- треугольник DEF: d + d + FD, где FD = 5s → 2d + 5s = 140.

Вычитаю из контура треугольник — 2d и все s исчезают разом: 2W = 260 − 140 = 120 → **W = 60**.

**Шаг 3 — считаем s (полоску) и высоту.** Нужна вторая мерка — её держит периметр полоски KLRS, где ширина уже известна:

- 2 · (W + s) = 144 → W + s = 144 : 2 = 72;
- s = 72 − 60 = **12**; высота KN = 3 · 12 = **36**.

**Шаг 4 — считаем d (наклонную).** Для контура PLDEFMQ нужны наклонные стороны — их отдаёт периметр DEF, в котором вертикаль 5s теперь известна: 2d = 140 − 5 · 12 = 80 → **d = 40**.

**Шаг 5 — сборка.** Подставляю W = 60, s = 12 и d = 40 в три формулы плана.

Правая половина: PQ делит ширину пополам (W : 2 = 30), высота вся (3s = 36).

**PLMQ = 2 · (W : 2 + 3s) = 2 · (30 + 36) = 132**

Верхняя полоска: ширина вся, высота — вся высота без нижней полоски (3s − s = 24).

**SRMN = 2 · (W + (3s − s)) = 2 · (60 + 24) = 168**

Контур с крышей — по обходу PL, LD, DE, EF, FM, MQ, QP:

**PLDEFMQ = W : 2 + s + 2d + s + W : 2 + 3s = 30 + 12 + 80 + 12 + 30 + 36 = 200**

Проверка сложением: DEF: 40 + 40 + 60 = 140 ✓; KLRS: 2 · (60 + 12) = 144 ✓; KLDEFMN: 60 + 12 + 40 + 40 + 12 + 60 + 36 = 260 ✓.

**Ответ: PLMQ = 132, SRMN = 168, PLDEFMQ = 200.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре.*

Кирпичики: W = KL (ширина), s = KS (высота KN = 3s), d = DE = EF.
Тогда LD = MF = s, вертикаль FD = s + 3s + s = 5s, а PL = W : 2.

> ✅ **План:**
>
> **PLMQ = 2 · (W : 2 + 3s)**
>
> **SRMN = 2 · (W + (3s − s))**
>
> **PLDEFMQ = W : 2 + s + 2d + s + W : 2 + 3s**
>
> Осталось найти W, s и d.

- KLDEFMN: 2W + 5s + 2d = 260
- DEF: 2d + 5s = 140
- вычитаю: 2W = 260 − 140 = 120 → **W = 60**
- KLRS: 2 · (W + s) = 144 → W + s = 72 → **s = 12**, высота 3s = 36
- DEF: 2d = 140 − 5 · 12 = 80 → **d = 40**

**PLMQ = 2 · (30 + 36) = 132**

**SRMN = 2 · (60 + 24) = 168**

**PLDEFMQ = 30 + 12 + 80 + 12 + 30 + 36 = 200**

Проверка: 40 + 40 + 60 = 140 ✓; 2 · (60 + 12) = 144 ✓; 60 + 12 + 40 + 40 + 12 + 60 + 36 = 260 ✓

## Задача 2 — фигура из трёх прямоугольников и двух треугольников *(Т2′: кирпичик + склейка)*

**Условие.** Фигура разрезана на прямоугольники F, G, H, треугольник M и равносторонний треугольник D. F и G лежат стопкой (F сверху, G снизу) и имеют общую ширину; вертикальная сторона G вдвое длиннее вертикальной стороны F. H приставлен слева во всю высоту стопки. Треугольник M стоит на всей верхней стороне получившегося прямоугольника, а равносторонний D приклеен к правой стороне M — вместе M и D образуют четырёхугольник. Периметры: P(F) = 84, P(F+G) = 120, P(H) = 96, P(M) = 124, P(M+D) = 150 — здесь **P(X) означает «периметр фигуры X»**, чтобы имя фигуры и её периметр не путались. Найди P(D), P(G), P(F+G+H) и периметр всей фигуры.

**🔍 С чего начать.** **Какие кирпичики?** F и G стопкой — ширина одна (назовём a); вертикаль F назовём p, тогда вертикаль G = 2p — единственная связь размеров, данная словами. **Что дано?** Одни периметры → удобнее **полупериметры**: полупериметр прямоугольника — это просто «ширина + высота», потому что в периметре каждая из них учтена дважды. **Где фигуры склеены?** M с D и вся фигура с четырёхугольником M+D.

**Заметь главное — формула склейки.** **P(X+Y) = P(X) + P(Y) − 2 · (общий отрезок).** Отрезок склейки один, а вычитается дважды: в периметре каждой части он посчитан по разу, а у соединённой фигуры его нет вовсе — он ушёл внутрь.

**Решение.**

**Шаг 1 — план.** Спрашивают четыре периметра, и все они стоят на двух кирпичиках стопки: ширине a и вертикали F, которую назову p (вертикаль G = 2p). P(G) и P(F+G+H) соберутся прямо из них, а P(D) и периметр всей фигуры — из формулы склейки.

> ✅ **План готов:** Ответ = четыре периметра: P(G) и P(F+G+H) — из кирпичиков a и p (для H нужна ещё его ширина c), P(D) — из склейки M и D, периметр всей фигуры — из склейки прямоугольника F+G+H с четырёхугольником M+D.

**Шаг 2 — считаем кирпичики a и p.** Нужны обе мерки стопки, а даны только периметры — перехожу к полупериметрам, тогда записи у «F» и у «стопки F+G» будут отличаться ровно на 2p:

- F: a + p = 84 : 2 = 42;
- стопка F+G: a + 3p = 120 : 2 = 60.

Вычитаю: 2p = 18 → **p = 9**, **a = 33**, вертикаль G = 2 · 9 = **18**.

**Шаг 3 — считаем P(G).** Обе стороны G теперь известны: P(G) = 2 · (33 + 18) = **102**.

**Шаг 4 — считаем ширину H.** Для прямоугольника F+G+H нужна ширина H — её даёт полупериметр H, ведь по высоте H равен всей стопке: 9 + 18 = 27, значит c + 27 = 96 : 2 = 48 → **c = 21**.

**Шаг 5 — считаем P(F+G+H).** Складываю ширины (a + c = 33 + 21 = 54) и беру высоту стопки (3p = 27).

**P(F+G+H) = 2 · ((a + c) + 3p) = 2 · (54 + 27) = 162**

**Шаг 6 — считаем P(D) (склейка).** D приклеен к M целой своей стороной, а у равностороннего треугольника все три стороны одинаковые → общий отрезок = P(D) : 3. По формуле склейки:

P(M+D) = P(M) + P(D) − 2 · (P(D) : 3), то есть 150 = 124 + P(D) − 2 · (P(D) : 3).

Из P(D) убрали две трети — осталась треть:

150 = 124 + P(D) : 3 → P(D) : 3 = 150 − 124 = 26 → **P(D) = 78**.

**Шаг 7 — сборка: вся фигура.** Четырёхугольник M+D стоит на всей верхней стороне прямоугольника, то есть общий отрезок — это a + c = 54. Снова склейка:

**P(фигуры) = P(F+G+H) + P(M+D) − 2 · (a + c) = 162 + 150 − 108 = 204**

Проверка сложением: P(F) = 2 · (33 + 9) = 84 ✓; стопка: 2 · (33 + 27) = 120 ✓; P(H) = 2 · (21 + 27) = 96 ✓; P(M+D) = 124 + 78 − 2 · 26 = 150 ✓.

**Ответ: P(D) = 78, P(G) = 102, P(F+G+H) = 162, периметр всей фигуры = 204.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре.*

Кирпичики: a — ширина стопки F+G, p — вертикаль F (вертикаль G = 2p), c — ширина H.
Склейка: **P(X+Y) = P(X) + P(Y) − 2 · (общий отрезок)**.

> ✅ **План:**
>
> **P(G) = 2 · (a + 2p)**
>
> **P(F+G+H) = 2 · ((a + c) + 3p)**
>
> **P(D)** — из склейки M с D
>
> **периметр всей фигуры** — из склейки прямоугольника F+G+H с четырёхугольником M+D
>
> Осталось найти a, p и c.

- полупериметр F: a + p = 84 : 2 = 42
- полупериметр стопки F+G: a + 3p = 120 : 2 = 60
- вычитаю: 2p = 18 → **p = 9**, **a = 33**, вертикаль G = 18
- высота стопки 9 + 18 = 27, поэтому H: c + 27 = 96 : 2 = 48 → **c = 21**
- D равносторонний, общий отрезок с M равен P(D) : 3, значит 150 = 124 + P(D) : 3 → **P(D) = 78**

**P(G) = 2 · (33 + 18) = 102**

**P(F+G+H) = 2 · (54 + 27) = 162**

**Вся фигура = 162 + 150 − 2 · 54 = 204**

Проверка: 2 · (33 + 9) = 84 ✓; 2 · (33 + 27) = 120 ✓; 2 · (21 + 27) = 96 ✓; 124 + 78 − 2 · 26 = 150 ✓

# Текстовые задачи

## Задача 3 — полки и горшки *(Т1′: доли + система 2×2)*

**Условие.** В цветочном магазине полки на 3, 5, 8 и 12 горшков; всего 130 полок и 640 горшков. Четверть всех горшков стоит на полках по 8. Полок по 12 вдвое меньше, чем полок по 8. Сколько горшков на полках по 12? Сколько полок по 3? По 5?

**🔍 С чего начать.** Вопрос: **какое данное самое зажатое — что вычисляется сразу, без предположений?** Найди такое данное и тяни за цепочку: за первым сортом обычно сразу считается второй. А когда неизвестных сортов останется ровно два при двух известных итогах — это система из двух уравнений, и дальше работает обычное исключение.

*💬 Это и есть мысль для фразы-объяснения.*

**Решение.**

**Шаг 1 — план.** Сортов полок четыре, но один из них считается сразу, без всяких предположений: «четверть всех горшков — на полках по 8», а сколько всего горшков, сказано. За этим сортом по цепочке тянется второй: «полок по 12 вдвое меньше, чем полок по 8». Когда оба сорта уйдут из итогов, останутся только полки по 3 и по 5, и про них известны сразу оба итога — сколько таких полок всего и сколько на них горшков; это система с двумя неизвестными.

> ✅ **План готов:**
>
> **Г8 = 640 : 4**
>
> **П8 = Г8 : 8**
>
> **П12 = П8 : 2**
>
> **Г12 = 12 · П12**
>
> **1 · П3 + 1 · П5 = 130 − П8 − П12**
>
> **3 · П3 + 5 · П5 = 640 − Г8 − Г12**
>
> где
> - **П8, П12, П3, П5** — сколько полок каждого сорта;
> - **Г8, Г12** — сколько горшков стоит на полках по 8 и по 12.
>
> Ответ = **Г12**, **П3**, **П5**. Осталось найти: **Г8**, **П8**, **П12**, потом решить систему на **П3** и **П5**.

**Шаг 2 — считаем Г8 и П8.** Иду по первым двум строкам плана:

- **Г8 = 640 : 4 = 160** горшков;
- **П8 = 160 : 8 = 20** полок.

**Шаг 3 — считаем П12 и Г12.** Следующие две строки плана:

- **П12 = 20 : 2 = 10** полок;
- **Г12 = 12 · 10 = 120** горшков — первое из трёх спрошенных чисел готово.

**Шаг 4 — считаем правые части двух последних строк.** Оба итога — и полки, и горшки — уменьшаются на одно и то же: на два уже посчитанных сорта. Вычитаю их столбиком:

```
                        полок   горшков
   всего                 130      640
   по 8                −  20    − 160
   по 12               −  10    − 120
   ─────────────────────────────────────
   осталось на 3 и 5     100      360
```

- **1 · П3 + 1 · П5 = 130 − 20 − 10 = 100**;
- **3 · П3 + 5 · П5 = 640 − 160 − 120 = 360**.

Два итога на две неизвестные — это и есть система.

**Шаг 5 — считаем П3 и П5.** Осталась система из двух уравнений. Коэффициенты при П3 нигде не совпадают, поэтому домножаю первое уравнение на 3 и вычитаю:

```
3 · П3 + 3 · П5 = 300
3 · П3 + 5 · П5 = 360
```

**2 · П5 = 60 → П5 = 30**

**П3 = 100 − 30 = 70**

**Шаг 6 — сборка.** Собираю ответ: **Г12 = 120**, **П3 = 70**, **П5 = 30**.

Проверка: 70·3 + 30·5 + 20·8 + 10·12 = 210 + 150 + 160 + 120 = 640 ✓.

**Ответ: 120 горшков; 70 полок по 3; 30 полок по 5.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре.*

#### 💬 Фраза-объяснение (в начале)

**Los estantes de 8 y de 12 salen en cadena de los totales; al sacarlos quedan solo dos tipos con dos totales, y eso ya es un sistema de dos ecuaciones.**

*Полки по 8 и по 12 считаются по цепочке из итогов; когда убрал их, остаются ровно два сорта при двух итогах — а это уже система из двух уравнений.*

#### Запись

П8, П12, П3, П5 — сколько полок каждого сорта; Г8, Г12 — сколько горшков на полках по 8 и по 12.

> ✅ **План:**
>
> **Г8 = 640 : 4**
>
> **П8 = Г8 : 8**
>
> **П12 = П8 : 2**
>
> **Г12 = 12 · П12**
>
> **П3 + П5 = 130 − П8 − П12**
>
> **3 · П3 + 5 · П5 = 640 − Г8 − Г12**
>
> Ответ = **Г12**, **П3**, **П5**.

- Г8 = 640 : 4 = **160**, П8 = 160 : 8 = **20**
- П12 = 20 : 2 = **10**, Г12 = 12 · 10 = **120**
- осталось на полки по 3 и 5: полок 130 − 20 − 10 = **100**, горшков 640 − 160 − 120 = **360**
- умножаю первое уравнение на 3: 3 · П3 + 3 · П5 = 300
- вычитаю его из второго: 2 · П5 = 60 → **П5 = 30**, **П3 = 100 − 30 = 70**

Проверка: 70 · 3 + 30 · 5 + 20 · 8 + 10 · 12 = 640 ✓

**Ответ: 120 горшков; 70 полок по 3; 30 полок по 5.**

## Задача 4 — бусины порциями *(Т1′: доля от итога + одно уравнение)*

**Условие.** У Valen мешок с красными, синими и зелёными бусинами. Среди первых 100 вынутых бусин — 82 красные и 11 синих. Дальше он вынимал бусины по двадцать штук, и в каждой такой двадцатке было 14 красных и 4 синие; последняя двадцатка вышла полной — на ней мешок и опустел. Оказалось, что красные — это 3/4 всех бусин. Сколько бусин каждого цвета было в мешке?

**🔍 С чего начать.** Вопрос: **что здесь повторяется?** Нарисуй мешок кусками:

```
   ┌──────── 100 ────────┬── 20 ──┬── 20 ──┬─ … ─┬── 20 ──┐
   │  82 кр.   11 син.   │ 14 кр. │ 14 кр. │     │ 14 кр. │
   │            7 зел.   │  4 син.│  4 син.│     │  4 син.│
   │                     │  2 зел.│  2 зел.│     │  2 зел.│
   └─────────────────────┴────────┴────────┴─────┴────────┘
        первая сотня          Д одинаковых двадцаток
```

Первая сотня особая, а дальше идут одинаковые куски, и сколько их — не сказано. Значит, весь мешок описывается **одним неизвестным числом Д**, а условие «красные — это 3/4 всего» даст на него **одно уравнение**.

*💬 Это и есть мысль для фразы-объяснения.*

**Решение.**

**Шаг 1 — план.** Мешок состоит из первой сотни и нескольких одинаковых двадцаток, а сколько их — не сказано; назову это число Д. Тогда весь мешок записывается сразу, и каждый цвет тоже — «сколько было в первой сотне плюс столько же раз по двадцатке». Про зелёные в условии прямо не сказано ни слова, зато они остаток: всё, что не красное и не синее. Значит, весь ответ упирается в одно-единственное число Д.

> ✅ **План готов:**
>
> **Всего = 100 + 20 · Д**
>
> **Кр = 82 + 14 · Д**
>
> **Си = 11 + 4 · Д**
>
> **Зл = Всего − Кр − Си**
>
> где
> - **Д** — сколько двадцаток он вынул после первой сотни;
> - **Всего** — сколько бусин было в мешке;
> - **Кр, Си, Зл** — красные, синие и зелёные во всём мешке.
>
> Ответ = **Кр**, **Си**, **Зл**. Осталось найти: **Д**.

**Шаг 2 — считаем Д.** Условие «красные — это 3/4 всего» превращается в уравнение: слева красные, справа три четверти мешка.

**82 + 14 · Д = 3/4 · (100 + 20 · Д)**

Справа беру три четверти от каждого слагаемого: 3/4 · 100 = 75, 3/4 · 20 = 15.

**82 + 14 · Д = 75 + 15 · Д**

Вычитаю из обеих частей 14 · Д и 75:

**Д = 82 − 75 = 7**

То же самое в уме, если считать по кускам: первая сотня дала 82 красных вместо положенных 75 — запас 7; каждая двадцатка даёт 14 вместо 15 — съедает по одной. Значит двадцаток 7. Это те же два вычитания, что и в уравнении.

**Шаг 3 — сборка.** Подставляю Д = 7 в формулы плана:

- **Всего = 100 + 20 · 7 = 240**;
- **Кр = 82 + 14 · 7 = 180** (проверка: 3/4 · 240 = 180 ✓);
- **Си = 11 + 4 · 7 = 39**;
- **Зл = 240 − 180 − 39 = 21** (проверка по кускам: 7 + 7 · 2 = 21 ✓).

**Ответ: 180 красных, 39 синих, 21 зелёная.**

## Задача 5 — пуговицы по дням, вперёд *(Т1″: процесс по дням + доли в конце)*

**Условие.** У Bruno в коробке жёлтые и зелёные пуговицы. Три дня подряд — в понедельник, вторник и среду — он пересчитывает жёлтые и докладывает в коробку столько же и ещё две. Зелёные он вынимает: в понедельник 4, а каждый следующий день — на 3 больше, чем накануне. После среды в коробке 141 пуговица, и жёлтых вдвое больше, чем зелёных. Сколько жёлтых и сколько зелёных пуговиц было вначале?

**🔍 С чего начать.** Задача-процесс, значит, вопрос один: **где в процессе точка, известная точно?** Нарисуй процесс лентой — по дорожке на цвет, по стрелке на день, а на стрелке то, что в этот день сделали:

```
                  пн          вт          ср
   жёлтые   Жн ──×2+2──> ? ──×2+2──> ? ──×2+2──> Ж
   зелёные  Зн ───−4───> ? ───−7───> ? ──−10───> Зл

            ищем ←──── разматываем назад ────── Ж + Зл = 141, Ж = 2 · Зл
```

Видно сразу две вещи. Точка, известная точно, — правый край: про начало не сказано ничего, а про конец сказано и сколько всего, и как цвета соотносятся. И дорожки нигде не пересекаются: ни одно условие не связывает жёлтые с зелёными, значит, это два независимых процесса и каждый разматывается назад сам по себе.

*💬 Это и есть мысль для фразы-объяснения.*

**Решение.**

**Шаг 1 — план.** Спрашивают начало, а точно известен только конец — то, что стало после среды. Значит, сначала конец надо получить в числах: пуговиц 141, жёлтых вдвое больше зелёных, то есть зелёные — одна доля из трёх. Дальше цвета друг с другом никак не связаны и разматываются назад по отдельности: зелёных только вынимали — вернуть надо всё вынутое, 4, 7 и 10; жёлтых каждый день делали «столько же и ещё две» — такой день придётся разворачивать, и трижды.

> ✅ **План готов:**
>
> **Зл = 141 : 3**
>
> **Ж = 2 · Зл**
>
> **Зн = Зл + 4 + 7 + 10**
>
> **Жн = развернуть три дня назад, начиная с Ж**
>
> где
> - **Ж, Зл** — жёлтые и зелёные после среды;
> - **Жн, Зн** — жёлтые и зелёные вначале («н» — начало).
>
> Ответ = **Жн**, **Зн**. Осталось найти: **Ж**, **Зл** и правило разворота одного дня.

**Шаг 2 — считаем Ж и Зл (конец процесса).** Разматывать не от чего, пока конец не в числах. «Жёлтых вдвое больше» — значит, зелёные это одна доля, а жёлтые две такие же:

```
   зелёные  ▓▓▓▓▓▓▓
   жёлтые   ▓▓▓▓▓▓▓ ▓▓▓▓▓▓▓        всего 3 доли = 141
```

После среды зелёные — 1 доля, жёлтые — 2 доли, всего 3 доли:

- **Зл = 141 : 3 = 47**;
- **Ж = 2 · 47 = 94**.

**Шаг 3 — считаем Зн.** Зелёных только вынимали, значит, вернуть надо всё вынутое: 4, 7, 10 (каждый день на 3 больше):

- **Зн = 47 + 4 + 7 + 10 = 68**.

**Шаг 4 — считаем Жн.** Жёлтых каждый день удваивали «и ещё две»: было x — стало x + x + 2. Разворачиваю: после − 2 — это дважды «перед», значит **перед днём = (после − 2) : 2** — минус две, потом пополам. Иду с конца три раза:

| День (с конца) | После | Перед |
|---|---|---|
| среда | 94 | (94 − 2) : 2 = 46 |
| вторник | 46 | (46 − 2) : 2 = 22 |
| понедельник | 22 | (22 − 2) : 2 = **10** |

Три дня развёрнуты → **Жн = 10**.

**Шаг 5 — сборка.** Вначале жёлтых **Жн = 10**, зелёных **Зн = 68**.

Проверка прямым ходом: жёлтые 10 → 22 → 46 → 94; зелёные 68 − 4 − 7 − 10 = 47; жёлтых вдвое больше (94 = 2·47 ✓); всего 94 + 47 = 141 ✓.

**Ответ: вначале 10 жёлтых и 68 зелёных.**

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре.*

#### 💬 Фраза-объяснение (в начале)

**Del final sé todo: 141 en total y el doble de amarillos. Durante los días los colores no se mezclan, así que voy hacia atrás con cada color por separado.**

*Про конец известно всё: 141 всего и жёлтых вдвое больше. А внутри дней цвета не связаны — поэтому разматываю назад каждый цвет по отдельности.*

#### Запись

> ✅ **План:**
>

>
> **Ж = 2 · Зл**

>

Проверка прямым ходом: 10 → 22 → 46 → 94; 68 − 4 − 7 − 10 = 47; 94 = 2 · 47 ✓; 94 + 47 = 141 ✓

**Ответ: вначале 10 жёлтых и 68 зелёных.**

## Задача 6 — наклейки «половина плюс три», назад *(Т1″: работа с конца)*

**Условие.** Каждое утро Sofía раздаёт половину наклеек из пачки и ещё три. Начала в понедельник; после раздачи в четверг пачка опустела. Сколько наклеек она раздала в четверг? Сколько было в пачке вначале?

**🔍 С чего начать.** Вопрос задач-процессов: **где в процессе точка, известная точно?** Не в начале (сколько было — и спрашивают), а в конце: после четверга пусто, 0. Значит, идём **с конца**, разворачивая последнее действие первым; шаг «раздала половину и ещё три» назад — это «плюс три, потом удвоить». И ответ не принят без прогона прямым ходом.

*💬 «Конец известен точно, поэтому иду с конца» — это и есть мысль для фразы-объяснения.*

**Решение.**

**Шаг 1 — план.** В четверг пачка опустела — значит, в тот день она раздала ровно всё, что было в пачке утром четверга. Начало неизвестно, зато конец известен точно: после четверга ноль. Поэтому иду с конца, разворачивая по одному дню; от четверга до понедельника таких дней четыре. Само правило разворота — как из «после» получить «перед» — из условия прямо не читается, его придётся вывести.

> ✅ **План готов:**
>
> **Р = Нчт**
>
> **Нпн = развернуть четыре дня назад, начиная с нуля**
>
> где
> - **Нчт** — сколько наклеек было в пачке перед четвергом;
> - **Нпн** — сколько было перед понедельником, то есть вначале;
> - **Р** — сколько раздала в четверг.
>
> Ответ = **Р**, **Нпн**. Осталось найти: **правило разворота одного дня**, а по нему — **Нчт** и **Нпн**.

**Шаг 2 — выводим правило разворота дня.** Чтобы шагать назад, нужно развернуть один день. Если перед днём было x, то раздала она x : 2 + 3, а осталось x : 2 − 3. Разворачиваю: после = x : 2 − 3, значит x : 2 = после + 3, и **перед днём = (после + 3) × 2**. А раздала за день = перед − после.

**Шаг 3 — считаем Нчт и Нпн: разворачиваю четыре дня.**

| День (с конца) | После | Перед | Раздала |
|---|---|---|---|
| четверг | 0 | (0+3)·2 = 6 | 6 |
| среда | 6 | (6+3)·2 = 18 | 12 |
| вторник | 18 | (18+3)·2 = 42 | 24 |
| понедельник | 42 | (42+3)·2 = 90 | 48 |

Раздала считаю как перед − после: 6 − 0 = 6, 18 − 6 = 12, 42 − 18 = 24, 90 − 42 = 48. Первая строка даёт **Нчт = 6** (и **Р = 6**), последняя — **Нпн = 90**.

**Шаг 4 — проверка прямым ходом.** 90 → раздала 48, осталось 42 → раздала 24, осталось 18 → 12, 6 → 6, 0 ✓ (и сумма розданного 48 + 24 + 12 + 6 = 90 ✓).

**Ответ: в четверг 6 наклеек; было 90.**

**El final se conoce: después del jueves el paquete quedó vacío, así que voy hacia atrás deshaciendo cada día.**

## Задача 7 — три возраста *(Т1‴: уравнение + перебор случаев, все возможности)*

**Условие.** Сумма возрастов троих друзей сегодня — 92 года. Через 12 лет возраст одного из них будет равен сумме **сегодняшних** возрастов двух остальных. Сегодня разность возрастов каких-то двух из троих — 16 лет. Какие возрасты возможны? Дай все возможности.

**🔍 С чего начать.** Вопрос: **какое условие переводится в уравнение сразу?** «Через 12 лет один будет равен сумме сегодняшних двух других»: сумма всех сегодня известна (92), поэтому «двое других» — это 92 − a, и в уравнении остаётся одна неизвестная — возраст a находится немедленно. Второй вопрос — читаем внимательно: «разность каких-то двух — 16», а **между кем** — не сказано → вариантов немного, и их можно выписать все; а «дай все возможности» требует разобрать каждый.

**Решение.**

**Шаг 1 — план.** Обозначу через **a** возраст того, про кого сказано «через 12 лет», а через **x и y** — двоих остальных. Условие про него переводится в уравнение сразу: сегодня все трое дают в сумме 92, значит, двое остальных дают 92 − a — и это то самое число, до которого он дорастёт через 12 лет.

В этом уравнении одна неизвестная, так что a найдётся немедленно, а про x и y то же условие говорит пока только их сумму. Осталось третье условие — «разность каких-то двух равна 16». Оно не говорит, **между кем** стоит эта разность, а спрашивают все возможности. Значит, придётся разобрать все случаи: где эта разность может стоять. Каждый случай даст свою тройку чисел, но в ответ пойдут не все: возраст не бывает отрицательным, так что годится только тройка, в которой все три числа больше нуля.

> ✅ **План готов:**
>
> **a + 12 = 92 − a**
>
> **x + y = 92 − a**
>
> **Ответ = тройки (a, x, y) из разбора случаев «между кем стоит разность 16», в которых все три числа больше нуля**
>
> где
> - **a** — возраст того, про кого сказано «через 12 лет»;
> - **x, y** — двое остальных (между собой их не различаем).
>
> Осталось найти: **a**; потом список случаев; потом **x и y** в каждом случае.

**Шаг 2 — находим a.** Решаю первое уравнение плана: прибавляю a к обеим частям, 2a + 12 = 92 → 2a = 80 → **a = 40**. Тогда на двоих остальных остаётся 92 − 40 = **52**.

**🗺 Шаг 3 — выписываем случаи.** Нужен полный список: между кем может стоять разность 16.

**Заметь главное.** Пар в тройке всего три: a с x, a с y и x с y. Но x и y — это просто «двое остальных», мы их между собой не различаем, поэтому «разность 16 у a с x» и «разность 16 у a с y» — один и тот же случай, только по-разному записанный. Значит, развилка короткая: разность либо стоит между двумя «другими», либо задевает сорокалетнего.

*💬 Это и есть мысль для фразы-объяснения.*

А если задевает — второго участника этой разности можно назвать числом прямо сейчас: он либо на 16 младше сорокалетнего (40 − 16 = **24**), либо на 16 старше (40 + 16 = **56**). Пусть это будет x. Итого случаев ровно три.

```
[x − y = 16] ─ИЛИ─ [x = 24] ─ИЛИ─ [x = 56]
```

**Шаг 4 — считаем x и y по каждому случаю.** В каждом случае известна сумма x + y = 52 и что-то ещё — этого хватает, чтобы найти обоих. Ни один случай не бросаем на полпути: в каждом досчитываем обоих и смотрим на условие из плана — все ли три числа больше нуля.

**Случай 1 — разность между «другими»:** x + y = 52 и x − y = 16.

**x = (52 + 16) : 2 = 34**

**y = 52 − 34 = 18**

→ тройка **40, 34, 18**

**Случай 2 — x = 24** (сорокалетний старше на 16).

**y = 52 − 24 = 28**

→ тройка **40, 28, 24**

**Случай 3 — x = 56** (сорокалетний младше на 16).

**y = 52 − 56 = −4**

→ третьему остался бы возраст −4 года, а такого возраста не бывает. Случай отпадает.

**Шаг 5 — сборка.** Из трёх случаев два дали тройки возрастов: **40, 34, 18** и **40, 28, 24**.

Проверка обеих троек: 40 + 34 + 18 = 92 ✓, 40 + 12 = 52 = 34 + 18 ✓, 34 − 18 = 16 ✓; 40 + 28 + 24 = 92 ✓, 52 = 28 + 24 ✓, 40 − 24 = 16 ✓.

Третий случай в ответ не идёт, но из решения его не выбрасывай: написанное «третий случай проверен и невозможен, потому что возраст вышел отрицательным» — это и есть доказательство, что других возможностей нет, и за него ставят балл.

**Ответ: 40, 34, 18 и 40, 28, 24.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре. Просят «все возможности», поэтому список случаев и разбор отпавшего пишутся обязательно — это и есть доказательство полноты.*

*Не сказано, между кем стоит разность 16, а двое остальных между собой не различаются — поэтому случаев ровно три.*

#### Запись

a — возраст того, про кого сказано «через 12 лет»; x и y — двое остальных (между собой не различаем).

## Задача 8 — треугольники по точкам на трёх прямых *(Т3: группа-лесенка + закон «И» + миры)*

**Условие.** Нарисованы три параллельные прямые. На первой отмечено 3 точки, на второй — 4, на третьей — 6. Рисуют треугольники: две вершины на одной прямой, третья — на другой. Сколько разных треугольников можно нарисовать? Объясни, как считал.

**🔍 С чего начать.** Первый вопрос: **что здесь один способ?** Нарисуй три прямые с точками и назови их буквами — так их будет удобно различать:

```
   ·   ★   ·                 ← прямая a: 3 точки
   ·   ★   ★   ·             ← прямая b: 4 точки
   ·   ·   ·   ·   ·   ·     ← прямая c: 6 точек
```

Соедини на своём рисунке три звёздочки — вот один способ, один треугольник. Две его вершины лежат на прямой `b`, третья на прямой `a`.

Чтобы такие треугольники было удобно считать, договоримся сначала не о самих точках, а о том, **на какой прямой лежит пара вершин, а на какой одиночка**. Это ещё не треугольник, а только его сорт.

Второй вопрос: **режется ли задача?** Режется — как раз по сортам. Разложим все треугольники по кучкам: в одной лежат те, у кого пара вершин на прямой `b`, а одиночка на прямой `a`, — такую кучку запишем **(b; a)**. Первая буква всегда про прямую с парой, вторая — про прямую с одиночкой. Такие кучки мы весь курс зовём **мирами**. Миров шесть: (a; b), (a; c), (b; a), (b; c), (c; a), (c; b) — прямую для пары выбираем из трёх, прямую для одиночки из двух оставшихся, 3 · 2 = 6.

**Заметь главное.** Каждый треугольник попадает ровно в один мир, а не в два сразу. Почему: прямая, на которой лежат две его вершины, у него ровно одна — третья вершина на ней не лежит, иначе треугольника не выйдет. Значит, миры не пересекаются, и их числа можно просто сложить.

*💬 Это и есть мысль для фразы-объяснения.*

**🗺 Шаг 1 — план счёта.** Раз миры не пересекаются, ответ уже можно записать, хотя ни одного числа мы ещё не знаем. Любое количество буду записывать буквой **N**, а в скобках — чего именно: N(a; b) значит «сколько треугольников в мире (a; b)». Ответ тогда просто сумма шести таких чисел.

> ✅ **План готов:**
>
> **Ответ = N(a; b) + N(a; c) + N(b; a) + N(b; c) + N(c; a) + N(c; b)**,
> где **N(…)** — количество того, что стоит в скобках, а мир записан парой «прямая с парой вершин; прямая с одиночкой».
>
> Осталось научиться считать N для одного любого мира.

**Шаг 2 — раскрываю N.** Возьму любой мир и обозначу его прямые: **X** — прямая, на которой лежит пара вершин, **Y** — прямая с одиночкой (каждая из них — это `a`, `b` или `c`). Прямые в мире уже выбраны, остаётся выбрать сами точки — две на X и одну на Y. Эти два выбора делаются вместе, значит, количества вариантов перемножаются:

```
N(X; Y) = [какие две точки на прямой X] ─И─ [какая точка на прямой Y]
```

Оба множителя — тоже количества, значит, и они пишутся через N, а в скобках — чего именно:

→ **N(X; Y) = N(пар на X) · N(точек на Y)**

Например, N(b; a) = N(пар на b) · N(точек на a): пары берём на прямой `b`, одиночку — на прямой `a`.

**Шаг 3 — считаю оба множителя.** В формуле два числа, но добывать надо только одно.

Первое, N(точек на прямой), прямо написано в условии:

**N(точек на a) = 3, N(точек на b) = 4, N(точек на c) = 6.**

Второе, N(пар на прямой), придётся посчитать. Из точек прямой берут две, и порядок внутри пары ничего не значит: «точки 1 и 3» и «точки 3 и 1» — одна и та же пара вершин. Это **группа, то есть сочетания**, и для пар работает готовая формула:

**C(n, 2) = n · (n − 1) : 2** — каждая из n точек образует пару с (n − 1) остальными, но так каждая пара сосчитана дважды, с двух своих концов, поэтому делим на 2.

| Прямая | a (3 точки) | b (4 точки) | c (6 точек) |
|---|---|---|---|
| N(пар на прямой) | C(3, 2) = 3 · 2 : 2 = **3** | C(4, 2) = 4 · 3 : 2 = **6** | C(6, 2) = 6 · 5 : 2 = **15** |

Точек тут мало, поэтому те же числа можно добыть и лесенкой — а заодно проверить формулу. На прямой `b` пронумерую точки 1, 2, 3, 4 и выпишу пары: сначала все пары с точкой 1, потом новые пары с точкой 2, и так далее:

```
1–2, 1–3, 1–4     3 пары
2–3, 2–4          2 пары   (пара 2–1 уже сосчитана)
3–4               1 пара
```

3 + 2 + 1 = 6 ✓ — сошлось с C(4, 2).

**Шаг 4 — считаю шесть миров.** Теперь у каждого мира считаю своё N по формуле N(X; Y) = N(пар на X) · N(точек на Y):

| Мир (X; Y) | (a; b) | (a; c) | (b; a) | (b; c) | (c; a) | (c; b) |
|---|---|---|---|---|---|---|
| N(пар на X) | 3 | 3 | 6 | 6 | 15 | 15 |
| N(точек на Y) | 4 | 6 | 3 | 6 | 3 | 4 |
| N(X; Y) | 3·4 = 12 | 3·6 = 18 | 6·3 = 18 | 6·6 = 36 | 15·3 = 45 | 15·4 = 60 |

**Шаг 5 — сборка.** Подставляю шесть чисел в план: Ответ = 12 + 18 + 18 + 36 + 45 + 60 = **189**.

**Пересчёт вторым способом.** Всего точек 3 + 4 + 6 = 13. Любая тройка точек — одного из трёх сортов: все три на одной прямой, две на одной и третья на другой (это наши треугольники), все три на разных прямых. Считаю все тройки и убираю не наши:

- все тройки из 13 точек: 13 · 12 · 11 : 6 = 286 (делим на 6, потому что каждую тройку так насчитали шесть раз — столько у трёх точек порядков);
- тройки на одной прямой (треугольника не дают): на `a` тройка одна, на `b` — 4, на `c` — 6 · 5 · 4 : 6 = 20, всего 1 + 4 + 20 = 25;
- тройки «по одной точке на каждой прямой» (это треугольники, но не наши: у них нет двух вершин на общей прямой): 3 · 4 · 6 = 72.

Остаются ровно наши: 286 − 25 − 72 = 189 ✓ — сошлось.

**Ответ: 189.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре.*

#### 💬 Фраза-объяснение (в начале)

**Cada triángulo tiene exactamente una recta con dos de sus vértices, así que los seis casos no se superponen y se suman.**

*У каждого треугольника ровно одна прямая несёт две его вершины — поэтому шесть миров не пересекаются и складываются.*

#### Запись

Мир — пара «прямая с парой вершин; прямая с одиночкой». У готового треугольника такая прямая одна, значит миры не пересекаются и складываются.

> ✅ **План:**
>
> **Ответ = N(a; b) + N(a; c) + N(b; a) + N(b; c) + N(c; a) + N(c; b)**
>
> **N(X; Y) = N(пар на X) · N(точек на Y)**

- N(точек на прямой): на a — 3, на b — 4, на c — 6
- N(пар на прямой) = C(n, 2) = n · (n − 1) : 2: на a — 3, на b — 6, на c — 15
- N(a; b) = 3 · 4 = 12, N(a; c) = 3 · 6 = 18
- N(b; a) = 6 · 3 = 18, N(b; c) = 6 · 6 = 36
- N(c; a) = 15 · 3 = 45, N(c; b) = 15 · 4 = 60

**Ответ = 12 + 18 + 18 + 36 + 45 + 60 = 189.**

Пересчёт вторым способом:

- все тройки из 13 точек: 13 · 12 · 11 : 6 = 286
- минус тройки на одной прямой: 1 + 4 + 20 = 25
- минус тройки по одной точке на каждой прямой: 3 · 4 · 6 = 72
- 286 − 25 − 72 = 189 ✓

#### 💬 Фраза в конце — полнота

**Los seis casos cubren todos los triángulos que pide el problema y ninguno se cuenta dos veces; lo verifiqué contando de otra manera.**

*Шесть миров покрывают все треугольники, которые просит задача, и ни один не посчитан дважды; проверил, посчитав другим способом.*

## Задача 9 — полоска 1×9: 4 жёлтые + 5 зелёных *(Т3′: островки + миры)*

**Условие.** Полоску из 9 клеток красят: 4 клетки жёлтым и 5 зелёным, причём нигде нет трёх подряд клеток одного цвета. Сколькими способами это можно сделать? Объясни, как считал.

**🔍 С чего начать.** Первый вопрос: **что здесь один способ?** Одна раскраска всех девяти клеток. Второй: **какое условие самое жёсткое?** «Нет трёх подряд одного цвета» — значит, полоска распадается на одноцветные **островки** длины 1 или 2. Нарисуй одну подходящую раскраску и обведи островки:

```
   [Ж Ж][З][Ж][З З][Ж][З З]
```

Проверь по рисунку: жёлтых клеток 2 + 1 + 1 = 4, зелёных 1 + 2 + 2 = 5, трёх подряд одного цвета нигде нет ✓.

Третий вопрос: **режется ли задача?** Да: миры — по паре «сколько жёлтых островков и сколько зелёных» (складываем); внутри мира формы островков каждого цвета выбираются независимо (перемножаем).

**🗺 Шаг 1 — план счёта.**

```
[сколько островков у жёлтого и у зелёного — миры, складываем]
внутри мира: [форма жёлтых островков] ─И─ [форма зелёных] ─И─ [с какого цвета начать]
```

Мир задаётся парой «сколько островков у жёлтого и сколько у зелёного» — назову эти числа a и b. Две раскраски из разных миров совпасть не могут, значит, миры складываем.

Внутри мира надо ответить на три вопроса вместе, и ответы друг от друга не зависят: какой формы жёлтые островки, какой формы зелёные и с какого цвета полоска начинается. Что этих трёх ответов и правда хватает, чтобы восстановить всю полоску до последней клетки, проверю сразу после шага 2. Количества, как обычно, пишу буквой **N**, а в скобках — чего именно.

> ✅ **План готов:**
>
> **N(a; b) = N(жёлтых на a островков) · N(зелёных на b островков) · N(стартов в мире (a; b))**
>
> **Ответ = сумма всех N(a; b)**
>
> где
> - **a** — сколько островков у жёлтого цвета, **b** — сколько у зелёного; пара (a; b) и задаёт мир;
> - **N(a; b)** — сколько раскрасок в мире (a; b);
> - **N(жёлтых на a островков)** — сколькими формами четыре жёлтые клетки режутся на a островков;
> - **N(зелёных на b островков)** — то же для пяти зелёных клеток;
> - **N(стартов в мире (a; b))** — сколько у мира вариантов старта, то есть каким цветом начинается полоска.
>
> Осталось найти: эти три числа для каждого мира и сам **список миров (a; b)**.

**Шаг 2 — считаю формы островков.** Мир задаётся числом островков у каждого цвета, поэтому сначала нужно знать, на какие островки вообще режутся четыре жёлтые и пять зелёных клеток.

Островок бывает длины 1 или 2, поэтому разбиения отличаются только тем, сколько в них двоек: у четырёх жёлтых клеток двоек может быть две, одна или ни одной, у пяти зелёных — тоже. Других разбиений нет.

**Форма** — это длины островков **по порядку**, слева направо. Островки стоят в ряд, поэтому 2 + 1 + 1 и 1 + 2 + 1 — разные формы: полоски получаются разные. Отсюда и правило счёта: если все слагаемые одинаковы, форма одна; если ровно одно слагаемое отличается от остальных, форм столько, сколько у него мест.

| Жёлтые: разбиение | островков a | форм | почему |
|---|---|---|---|
| 2 + 2 | 2 | **1** | оба островка двойки, менять нечего |
| 2 + 1 + 1 | 3 | **3** | двойка стоит на одном из 3 мест |
| 1 + 1 + 1 + 1 | 4 | **1** | все островки одиночки |

| Зелёные: разбиение | островков b | форм | почему |
|---|---|---|---|
| 2 + 2 + 1 | 3 | **3** | одиночка стоит на одном из 3 мест |
| 2 + 1 + 1 + 1 | 4 | **4** | двойка стоит на одном из 4 мест |
| 1 + 1 + 1 + 1 + 1 | 5 | **1** | все островки одиночки |

**Заметь главное.** Два соседних островка всегда разного цвета — будь они одного, они бы слились в один островок. Значит, цвета островков идут строго через один: жёлтый, зелёный, жёлтый, зелёный… И тогда полоска восстанавливается целиком из трёх вещей: формы жёлтых островков, формы зелёных и цвета самого первого островка. Дальше в строчках вида `Ж З Ж З` буквы означают уже не клетки, а целые островки.

*💬 Это и есть мысль для фразы-объяснения.*

Вот эта сборка на числах. Беру жёлтую форму 2 + 1 + 1, зелёную 2 + 2 + 1 и старт жёлтым — и просто выкладываю островки по очереди, беря их то из одной формы, то из другой:

```
   островки:  Ж=2   З=2   Ж=1  З=2   Ж=1  З=1
   полоска:  [Ж Ж][З З][Ж][З З][Ж][З]
```

Клеток вышло 2 + 1 + 1 = 4 жёлтых и 2 + 2 + 1 = 5 зелёных ✓. Больше выбирать было нечего: три выбора задали раскраску однозначно. Поэтому третий множитель в плане — это и есть выбор стартового цвета.

**Шаг 3 — считаю старты и нахожу список миров.** Нужно понять, какие пары (a; b) вообще существуют и сколько у мира вариантов старта. И то и другое следует из чередования.

*Какие пары (a; b) бывают.* Между двумя соседними жёлтыми островками всегда стоит ровно один зелёный:

```
   Ж З Ж З Ж
    └┬┘ └┬┘     ← между жёлтыми — по одному зелёному
```

Значит, если жёлтых островков a, то зелёных не меньше, чем a − 1; и точно так же наоборот. Отличаться на 2 и больше количества не могут: **разница между a и b — не больше 1**.

*Сколько стартов.* Старт — это цвет первого островка, вариантов у него всего два: Ж или З. Вопрос только в том, оба ли годятся в этом мире. Проверяю каждый отдельно.

Пусть старт жёлтый. Дальше выбирать нечего — цвета чередуются сами, и весь вопрос в том, каким цветом цепочка кончится:

```
   Ж З Ж З      кончилась зелёным  → жёлтых и зелёных поровну
   Ж З Ж З Ж    кончилась жёлтым   → жёлтых на один больше
```

Третьего не дано. Значит, **старт жёлтым бывает только при a = b или a = b + 1** — а если зелёных больше, жёлтым начать нельзя вовсе. Со стартом зелёным всё то же самое наоборот: он бывает только при b = a или b = a + 1. Складываю оба вывода:

| в мире | старт Ж | старт З | стартов |
|---|---|---|---|
| a = b + 1 (жёлтых больше) | ✓ | ✗ | **1** |
| b = a + 1 (зелёных больше) | ✗ | ✓ | **1** |
| a = b (поровну) | ✓ | ✓ | **2** |

В случае «поровну» две полоски действительно разные, а не одна и та же. Проверю на мире (3; 3) с теми же формами 2 + 1 + 1 и 2 + 2 + 1:

```
   старт Ж:  [Ж Ж][З З][Ж][З З][Ж][З]
   старт З:  [З З][Ж Ж][З З][Ж][З][Ж]
```

Уже первая клетка разного цвета — раскраски разные. Так что при a = b одна и та же пара форм даёт две раскраски.

*Список миров.* По шагу 2 у жёлтого островков бывает a = 2, 3 или 4, у зелёного b = 3, 4 или 5. Выписываю все девять пар и оставляю те, где разница не больше 1:

| a \ b | 3 | 4 | 5 |
|---|---|---|---|
| **2** | стартов 1 (с зелёного) | ✗ разница 2 | ✗ разница 3 |
| **3** | стартов 2 | стартов 1 (с зелёного) | ✗ разница 2 |
| **4** | стартов 1 (с жёлтого) | стартов 2 | стартов 1 (с зелёного) |

Миров шесть: (2; 3), (3; 3), (3; 4), (4; 3), (4; 4), (4; 5). Строки a = 5 в таблице нет — четыре жёлтые клетки на пять островков не режутся.

| Мир (a; b) | форм жёлтых · форм зелёных | стартов | N(a; b) |

**Шаг 5 — сборка.** Подставляю шесть чисел в план: Ответ = 3 + 18 + 12 + 3 + 8 + 1 = **45**.

**Ответ: 45.**

**Como no hay tres seguidos iguales, cada isla mide 1 o 2 y las islas alternan de color: la tira queda definida por las formas de cada color y el color de la primera.**

Островки длины 1 или 2, цвета островков идут строго через один.

> ✅ **План:**
>
> **N(a; b) = N(жёлтых на a островков) · N(зелёных на b островков) · N(стартов в мире (a; b))**

> где a и b — числа островков у жёлтого и у зелёного.

## Задача 10 — раскраска доски из квадратных и прямоугольных клеток *(Т3′: раскраски + «всё минус плохие»)*

**Условие.** Доска из 2 строк и 7 столбцов, но столбцы разной ширины: крайние (первый и седьмой) узкие — их клетки **квадратные**, две вертикальные пары; каждый из пяти средних широких столбцов — одна высокая **прямоугольная** клетка. Доску красят в 3 цвета (синий, оранжевый, белый): каждая клетка одним цветом; среди **прямоугольных** клеток есть все три цвета; квадратные клетки с общей стороной — **одного цвета**. Сколькими способами? Объясни, как считал.

```
   ┌───┬─────┬─────┬─────┬─────┬─────┬───┐
   │ □ │     │     │     │     │     │ □ │
   ├───┤  ▯  │  ▯  │  ▯  │  ▯  │  ▯  ├───┤
   │ □ │     │     │     │     │     │ □ │
   └───┴─────┴─────┴─────┴─────┴─────┴───┘
     ↑         пять прямоугольных          ↑
   пара квадратных                   пара квадратных
```

**🔍 С чего начать.** Первый вопрос: **что здесь один способ?** Одна раскраска всех девяти клеток целиком. Второй: **режется ли задача?** Да: ни одно условие не связывает квадратные клетки с прямоугольными → два независимых куска, красятся вместе, в одной картинке (перемножаем).

В квадратном куске «клетки с общей стороной одного цвета» — склейка: каждая пара красится как один объект. В прямоугольном куске «есть все три цвета» — это вычитание: всё минус плохие, а плохая — та, в которой какого-то цвета не хватает.

Перед вычитанием обязательная проверка: **может ли одна плохая раскраска быть плохой сразу по двум причинам?** Может: если все пять клеток синие, то в ней нет ни оранжевого, ни белого, и, вычитая «нет оранжевого» и «нет белого», мы вычтем её дважды. Поэтому плохие считаем не по «какого цвета не хватает», а раскладываем на непересекающиеся миры: «в раскраске ровно один цвет» и «ровно два цвета».

**🗺 Шаг 1 — план счёта.**

```
[две склеенные пары квадратных: цвет каждой] ─И─ [5 прямоугольных: есть все три цвета]
```

Квадратные клетки и прямоугольные не связаны ни одним условием, но красятся в одной картинке — значит, количества раскрасок перемножаются. Количества пишу буквой **N**, а в скобках — чего именно.

Прямоугольные с условием «есть все три цвета» напрямую не посчитать. Считаем «всё минус плохие», разложив плохие на два непересекающихся мира — «ровно один цвет» и «ровно два».

*💬 Обе эти мысли — «куски не связаны» и «плохие разложены, чтобы не вычесть дважды» — и пойдут во фразу-объяснение.*

> ✅ **План готов:**
>
> **Ответ = N(квадратных) · N(прямоугольных)**
>
> **N(прямоугольных) = N(всех раскрасок пяти) − N(плохих с одним цветом) − N(плохих с двумя цветами)**
>
> где
> - **N(квадратных)** — сколькими способами красятся квадратные клетки (две склеенные пары);
> - **N(прямоугольных)** — сколькими способами красятся пять прямоугольных так, чтобы были все три цвета;
> - **N(всех раскрасок пяти)** — раскраски пяти прямоугольных без всяких условий;
> - **N(плохих с одним цветом)** и **N(плохих с двумя цветами)** — два непересекающихся мира плохих.
>
> Осталось найти эти четыре числа.

**Шаг 2 — считаю квадратные.** В паре с общей стороной оба цвета одинаковы → каждая пара красится целиком: 3 цвета × 3 цвета → **N(квадратных) = 9**.

**Шаг 3 — считаю прямоугольные.** Нужны три числа из формулы «всё минус плохие»:

- все раскраски: 3⁵ → **N(всех раскрасок пяти) = 243**;
- плохие с одним цветом — все пять клеток одного цвета → **N(плохих с одним цветом) = 3**;
- плохие с двумя цветами — выбираем пару цветов (пар три) × раскраски пяти клеток только этими двумя (2⁵ = 32), но выбрасываем две одноцветные, они уже посчитаны строкой выше: 32 − 2 = 30 → **N(плохих с двумя цветами) = 3 · 30 = 90**.

Подставляю: **N(прямоугольных) = 243 − 3 − 90 = 150**.

**Шаг 4 — сборка.** Подставляю два числа в план: Ответ = 9 · 150 = **1350**.

**Ответ: 1350.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре.*

#### 💬 Фраза-объяснение (в начале)

**Nada une las cuadradas con las rectangulares, así que multiplico. Separo las coloraciones malas por cuántos colores usan, uno o dos, para no restar ninguna dos veces.**

*Ничто не связывает квадратные клетки с прямоугольными, поэтому перемножаю. Плохие раскраски раскладываю по числу цветов — один или два, — чтобы ни одну не вычесть дважды.*

#### Запись

Квадратные и прямоугольные клетки не связаны ни одним условием, поэтому числа перемножаю. Плохие раскладываю на два непересекающихся мира — по числу цветов, — поэтому вычитаю без возвратов.

> ✅ **План:**
>
> **Ответ = N(квадратных) · N(прямоугольных)**
>
> **N(прямоугольных) = N(всех раскрасок пяти) − N(плохих с одним цветом) − N(плохих с двумя цветами)**

- N(квадратных) = 3 · 3 = **9** (пара с общей стороной красится целиком)
- N(всех раскрасок пяти) = 3⁵ = **243**
- N(плохих с одним цветом) = **3**
- N(плохих с двумя цветами) = 3 пары цветов · (2⁵ − 2) = 3 · 30 = **90**
- N(прямоугольных) = 243 − 3 − 90 = **150**

**Ответ = 9 · 150 = 1350.**

#### 💬 Фраза в конце — полнота

**Toda coloración es buena o mala, y resté todas las malas sin repetir ninguna: por eso lo que queda son exactamente las que tienen los tres colores.**

*Каждая раскраска либо хорошая, либо плохая; вычел все плохие и ни одну дважды — значит, осталось ровно то, где есть все три цвета.*

## Задача 11 — фишки 1×2 по строкам *(Т3′: строка за строкой + таблица этажей)*

**Условие.** Доска из 5 строк и 4 столбцов. В каждую строку кладут одну прямоугольную фишку 1×2 (домино). Если две фишки стоят в соседних строках, то хотя бы в одном столбце они должны закрывать **обе** клетки — и верхнюю, и нижнюю. Сколькими способами? Объясни, как считал.

**🔍 С чего начать.** Первый вопрос: **что здесь один способ?** По фишке в каждой строке → способ = пятёрка позиций фишек. Второй: **что связывает условие?** Только **соседние** строки → на доску целиком не смотрим, идём строка за строкой. Третий: **продолжений поровну или по-разному?** По-разному: у крайних позиций разрешённых продолжений меньше, чем у средней → таблица этажей, а перед ней — карта, кто с кем уживается.

**Решение.** Фишка в строке из 4 клеток стоит одним из трёх способов; назову их **Л** (клетки 1–2), **Ц** (клетки 2–3), **П** (клетки 3–4):

```
   Л  Ф Ф ○ ○      Ц  ○ Ф Ф ○      П  ○ ○ Ф Ф
```

**Шаг 1 — план.** Нужно понять, из чего состоит один способ, — тогда будет видно, что перебирать. В каждой строке лежит одна фишка, значит способ — это пятёрка позиций, по одной на строку: **одна строка = один выбор**. Условие связывает только соседние строки, поэтому иду сверху вниз, строка за строкой.

Но продолжений у разных позиций поровну не будет: у крайних меньше, чем у средней, — одним умножением не обойтись. Тогда веду **таблицу этажей**: по три числа на строку доски, и в каждой клетке стоит одно и то же — **сколько способов застроить доску от верхней строки до этой включительно, если в самой этой строке фишка стоит на указанной позиции.** Числа последней строки я обозначу Л₅, Ц₅, П₅.

Верхнюю строку ничто не ограничивает, поэтому первая строчка таблицы даром: 1, 1, 1. А любая застройка всей доски кончается фишкой в пятой строке, и ровно на одной позиции, — значит эти три числа делят все способы без потерь и без повторов, и в конце их достаточно сложить.

> ✅ **План готов:**
>
> **Ответ = Л₅ + Ц₅ + П₅** — три числа последней, пятой строки таблицы этажей
>
> Осталось: построить **карту — кто с кем уживается**, а по ней вести таблицу строчка за строчкой.

**Шаг 2 — нужна карта: из какой позиции в какую разрешено приходить.** Чтобы её построить, переведу условие в геометрию. Фишка лежит в строке плашмя, поэтому в каждом столбце она закрывает не больше одной клетки — верхнюю или нижнюю. Значит, «обе клетки столбца закрыты» бывает только так: обе соседние фишки попали в этот столбец, одна закрыла верхнюю клетку, другая нижнюю. То есть **фишки соседних строк обязаны перекрываться хотя бы одним столбцом**. (На туре это же условие могут написать словами «накрывают хотя бы две клетки одного столбца» — это одно и то же.)

Теперь кладу пары позиций одну под другую и ищу общий столбец:

```
   Л  Ф Ф ○ ○         Ц  ○ Ф Ф ○         Л  Ф Ф ○ ○
   Ц  ○ Ф Ф ○         П  ○ ○ Ф Ф         П  ○ ○ Ф Ф
   общий: 2           общий: 3           общих нет
```

Одинаковые позиции перекрываются целиком, значит «Л под Л», «Ц под Ц», «П под П» разрешены. Из разных пар запрещена ровно одна — Л и П: Л занимает столбцы 1 и 2, П — 3 и 4, пересечься им негде.

> ✅ **Карта готова:** Л уживается с Л и Ц; Ц — с Л, Ц и П; П — с Ц и П.

**Шаг 3 — нужны первые числа таблицы; беру их с дерева.** Рисую, пока помещается: две верхние строки. Читаю дерево слева направо, как повёрнутую набок доску; ветки растут по карте.

```
 стр.1   стр.2   конец

         ┌── Л   ЛЛ
 ┌── Л ──┤
 │       └── Ц   ЛЦ
 │
 │       ┌── Л   ЦЛ
 ●── Ц ──┼── Ц   ЦЦ
 │       └── П   ЦП
 │
 │       ┌── Ц   ПЦ
 └── П ──┤
         └── П   ПП
```

Веток 7; кончились на Л — 2 (ЛЛ, ЦЛ), на Ц — 3 (ЛЦ, ЦЦ, ПЦ), на П — 2 (ЦП, ПП). Это и есть вторая строчка таблицы → **2, 3, 2**.

**Заметь главное.** Дальше рисовать не нужно, и вот почему: продолжение ветки зависит только от того, **чем она кончилась**. Нижней фишке всё равно, что стояло двумя строками выше, — ей важна только позиция прямо над ней. Значит, ветки с одинаковым концом можно не различать: сложить в кучку и запомнить лишь её размер. Дерево не пропадает, а сворачивается в три числа на строку.

*💬 Это и есть мысль для фразы-объяснения.*

**Шаг 4 — бросаю рисовать, продолжаю числами.** Правило одно на каждую клетку: **число под позицией X = сумма чисел под теми позициями, которые условие разрешает поставить над X.** Складываю, а не умножаю, потому что над клеткой стоит что-то одно: либо Л, либо Ц, либо П — это «ИЛИ». Число сверху беру как есть: свою фишку я подкладываю ровно одним способом.

Строчка 3: под Л = 2 + 3 = 5; под Ц = 2 + 3 + 2 = 7; под П = 3 + 2 = 5. Дальше так же, каждый раз из чисел предыдущей строчки.

| Строка доски | фишка на Л | фишка на Ц | фишка на П |
|---|---|---|---|
| 1 (верхняя) | 1 | 1 | 1 |
| 2 | 2 | 3 | 2 |
| 3 | 5 | 7 | 5 |
| 4 | 12 | 17 | 12 |
| 5 (нижняя) | 29 | 41 | 29 |

Проверка счёта: доска зеркальна, левое и правое в ней равноправны, поэтому числа под Л и под П в каждой строчке обязаны совпадать: 1 и 1, 2 и 2, 5 и 5, 12 и 12, 29 и 29 ✓ — нигде не сбился. Дерева на пять строк уже не нарисуешь, а эта проверка работает и здесь.

**Шаг 5 — сборка.** Ответ = Л₅ + Ц₅ + П₅ = 29 + 41 + 29 = **99**.

**Ответ: 99.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре.*

#### 💬 Фраза-объяснение (в начале)

**La condición solo relaciona filas vecinas, así que lo que puede ir abajo depende únicamente de la posición de la fila anterior. Por eso voy fila por fila sumando.**

*Условие связывает только соседние строки, поэтому то, что можно поставить ниже, зависит только от позиции в предыдущей строке. Поэтому иду строка за строкой, складывая.*

#### Запись

Позиции фишки в строке из 4 клеток: **Л** — клетки 1–2, **Ц** — клетки 2–3, **П** — клетки 3–4.
Соседние строки обязаны перекрываться столбцом, поэтому уживаются: Л — с Л и Ц; Ц — со всеми тремя; П — с Ц и П.

> ✅ **План:** Ответ = Л₅ + Ц₅ + П₅ — три числа последней строки таблицы этажей.
>
> В клетке таблицы — сколько способов застроить доску до этой строки, если фишка в ней стоит на этой позиции. Число под X = сумма чисел под теми позициями, которые разрешено поставить над X.

| Строка доски | фишка на Л | фишка на Ц | фишка на П |
|---|---|---|---|
| 1 (верхняя) | 1 | 1 | 1 |
| 2 | 2 | 3 | 2 |
| 3 | 5 | 7 | 5 |
| 4 | 12 | 17 | 12 |
| 5 (нижняя) | 29 | 41 | 29 |

Проверка: доска зеркальна, поэтому числа под Л и под П в каждой строчке совпадают ✓

**Ответ = 29 + 41 + 29 = 99.**

#### 💬 Фраза в конце — полнота

**Cada forma de llenar el tablero termina en una sola posición de la última fila, así que los tres casos finales cubren todo y no se repiten.**

*Любая застройка доски кончается ровно на одной позиции последней строки — поэтому три последних случая покрывают всё и не повторяются.*

## Задача 12 — доска 2×3 с суммами *(Т4: перебор с отсечением, все возможности)*

**Условие.** В доску 2×3 впиши шесть **разных** цифр так, чтобы сумма верхней строки была 13, нижней — 9, а суммы столбцов слева направо — 5, 8 и 9. Дай все возможности.

**🔍 С чего начать.** Первый вопрос: **что здесь один способ?** Одна заполненная доска целиком; просят «дай все возможности» — значит, перебор обязан идти в строгом порядке, чтобы никого не потерять и не повторить. Второй — якорь: **сходятся ли суммы строк и столбцов?** Третий: **какая клетка тянет за собой всю доску?** Любая клетка верха: нижняя строка вычисляется из столбцов, поэтому перебираем только верх.

*💬 Это и есть мысль для фразы-объяснения.*

**Решение.** Назову клетки по строкам: верхняя a, b, c; нижняя d, e, f — и нарисую доску с суммами:

```
   ┌───┬───┬───┐
   │ a │ b │ c │ → 13
   ├───┼───┼───┤
   │ d │ e │ f │ → 9
   └───┴───┴───┘
     ↓   ↓   ↓
     5   8   9
```

Прежде чем решать — якорь: строки 13 + 9 = 22; столбцы 5 + 8 + 9 = 22 ✓. Условие не врёт, работать можно.

**Шаг 1 — план.** Шесть клеток сразу не перебрать — но нижняя строка и не свободна: каждую её клетку задаёт сумма своего столбца.

```
   d = 5 − a      e = 8 − b      f = 9 − c
```

Значит, вся доска тянется за верхней тройкой. А сама верхняя тройка связана суммой своей строки, поэтому свободны в ней только две клетки — c досчитывается:

```
   c = 13 − a − b
```

Подставлю это в f = 9 − c и запишу всю доску через две свободные клетки:

```
   f = 9 − (13 − a − b) = a + b − 4
```

> ✅ **План готов:** Ответ = все пары (a, b), при которых доска
>
> ```
>    ┌────────┬───────┬────────────┐
>    │   a    │   b   │ 13 − a − b │
>    ├────────┼───────┼────────────┤
>    │ 5 − a  │ 8 − b │  a + b − 4 │
>    └────────┴───────┴────────────┘
> ```
>
> состоит из шести **разных** цифр.
>
> Осталось найти: **границы перебора по a и b**, потом **отсечь, что видно из формул**, потом **пройти оставшиеся ветки по порядку**.

**Новый приём: перебор с отсечением.** «Дай все возможности» означает, что перебор обязан быть полным, — но полный не значит «пощупать руками каждую доску». Перебор идёт в строгом порядке (сначала по a, внутри каждой ветки — по b), а **отсечение** — это когда целую ветку хоронят рассуждением, ни разу в неё не заглянув: показал, что в ней ни одна доска не годится, — и вычеркнул её всю разом. Отсечение не урезает ответ, оно урезает работу: вычеркнутая ветка проверена так же честно, как пройденная, — потому за неё и ставят балл.

**Шаг 2 — границы перебора.** Чтобы перебор был конечным и ничего не потерял, нужны рамки: низ не должен уйти в минус → a ≤ 5, b ≤ 8, c ≤ 9. Всё, что снаружи этих рамок, отсечено сразу — там доска ломается по построению.

Последняя рамка, c ≤ 9, — это запрет на **маленькое** b: c = 13 − a − b, и чем меньше b, тем c больше. Записываю её сразу как нижнюю границу ветки:

```
   13 − a − b ≤ 9   →   b ≥ 4 − a
```

Значит, ветка a = 0 стартует с b = 4, ветка a = 1 — с b = 3, ветка a = 2 — с b = 2, ветка a = 3 — с b = 1, а дальше нижней границы нет вовсе.

**Шаг 3 — отсекаю до перебора.** Прежде чем считать доски по одной, стоит поискать запреты, которые видны прямо в формулах: каждый такой запрет убивает не доску, а сразу пачку. Смотрю на столбцы — в них цифры тоже обязаны быть разными, а обе клетки столбца у меня уже выражены через одну букву:

- средний столбец: b и e = 8 − b. Они совпадут ровно при b = 4 → **b ≠ 4**, и это во всех ветках сразу;
- левый столбец: a и d = 5 − a. Совпали бы при 2a = 5 — такой цифры нет, проверка ничего не даёт;
- правый столбец: c и f, а их сумма 9 — число нечётное, пополам не делится, значит совпасть они не могут никогда.

Теперь то же самое, но по строкам — и тут отсекаются целые ветки:

- при a = 4 верх даёт c = 13 − 4 − b = 9 − b, а тогда f = 9 − c = b — правая нижняя цифра всегда повторяет b. **Ветка a = 4 мертва целиком**;
- при a = 5 верх даёт c = 13 − 5 − b = 8 − b, а тогда e = 8 − b = c — средняя нижняя цифра всегда повторяет c. **Ветка a = 5 мертва целиком**.

Вот оно, настоящее отсечение: две ветки похоронены рассуждением, без единой проверки по b, и в каждой оставшейся я не пишу строку b = 4.

**Шаг 4 — иду по выжившим веткам.** Осталось четыре ветки: a = 0, 1, 2, 3. В каждой строке считаю c = 13 − a − b, потом низ: d = 5 − a, e = 8 − b, f = 9 − c — и смотрю, все ли шесть цифр разные.

**Ветка a = 0** (значит d = 5), b с 4, но b = 4 отсечено:

| b | c | e | f | Что видим |
|---|---|---|---|---|
| 5 | 8 | 3 | 1 | b = d = 5 — повтор |
| 6 | 7 | 2 | 2 | e = f = 2 — повтор |
| 7 | 6 | 1 | 3 | 0 7 6 / 5 1 3 — все разные ✓ |
| 8 | 5 | 0 | 4 | c = d = 5 — повтор |

**Ветка a = 1** (d = 4), b с 3:

| b | c | e | f | Что видим |
|---|---|---|---|---|
| 3 | 9 | 5 | 0 | 1 3 9 / 4 5 0 ✓ |
| 5 | 7 | 3 | 2 | 1 5 7 / 4 3 2 ✓ |
| 6 | 6 | 2 | 3 | b = c = 6 — повтор |
| 7 | 5 | 1 | 4 | a = e = 1 — повтор |
| 8 | 4 | 0 | 5 | c = d = 4 — повтор |

**Ветка a = 2** (d = 3), b с 2:

| b | c | e | f | Что видим |
|---|---|---|---|---|
| 2 | 9 | 6 | 0 | a = b = 2 — повтор |
| 3 | 8 | 5 | 1 | b = d = 3 — повтор |
| 5 | 6 | 3 | 3 | e = f = 3 — повтор |
| 6 | 5 | 2 | 4 | a = e = 2 — повтор |
| 7 | 4 | 1 | 5 | 2 7 4 / 3 1 5 ✓ |
| 8 | 3 | 0 | 6 | c = d = 3 — повтор |

**Ветка a = 3** (d = 2), b с 1:

| b | c | e | f | Что видим |
|---|---|---|---|---|
| 1 | 9 | 7 | 0 | 3 1 9 / 2 7 0 ✓ |
| 2 | 8 | 6 | 1 | b = d = 2 — повтор |
| 3 | 7 | 5 | 2 | a = b = 3 — повтор |
| 5 | 5 | 3 | 4 | b = c = 5 — повтор |
| 6 | 4 | 2 | 5 | d = e = 2 — повтор |
| 7 | 3 | 1 | 6 | a = c = 3 — повтор |
| 8 | 2 | 0 | 7 | c = d = 2 — повтор |

**Шаг 5 — сборка.** Собираю всё, что выжило по веткам, — пять досок:

```
   ┌───┬───┬───┐   ┌───┬───┬───┐   ┌───┬───┬───┐
   │ 0 │ 7 │ 6 │   │ 1 │ 3 │ 9 │   │ 1 │ 5 │ 7 │
   ├───┼───┼───┤   ├───┼───┼───┤   ├───┼───┼───┤
   │ 5 │ 1 │ 3 │   │ 4 │ 5 │ 0 │   │ 4 │ 3 │ 2 │
   └───┴───┴───┘   └───┴───┴───┘   └───┴───┴───┘

   ┌───┬───┬───┐   ┌───┬───┬───┐
   │ 2 │ 7 │ 4 │   │ 3 │ 1 │ 9 │
   ├───┼───┼───┤   ├───┼───┼───┤
   │ 3 │ 1 │ 5 │   │ 2 │ 7 │ 0 │
   └───┴───┴───┘   └───┴───┴───┘
```

Ни одна ветка не пропущена: четыре пройдены по строкам, две похоронены рассуждением, — а внутри ветки b шёл по возрастанию. Поэтому «других досок нет» здесь не обещание, а проверенный факт. Так и записывай на туре: за доказанную полноту перебора и ставят балл, и отсечённая ветка засчитывается наравне с пройденной.

**Ответ: 5 способов.**

### ✍ Что пишешь на туре

*Разбор выше объясняет, почему так считать можно; его читают, а не переписывают. По памяти восстанавливай вот эту запись — столько и пишут на туре. **Эта задача — тот редкий случай, когда короткого решения не бывает: перебор и есть решение.** Сократить его нельзя, «выжила b = 7» без вычеркнутых строк — не ответ, а объявление. Поэтому все кандидаты выписываются, каждый со своей причиной смерти: это и есть доказательство полноты, за которое ставят балл. Сокращает работу только отсечение — и оно тоже пишется.*

#### 💬 Фраза-объяснение (в начале)

**Llamo a, b, c a la fila de arriba. Cada casilla de abajo sale de la suma de su columna y c sale de la suma de arriba, así que solo quedan libres a y b.**

*Верхнюю строку называю a, b, c. Каждая нижняя клетка получается из суммы своего столбца, а c — из суммы верхней строки, поэтому свободны только a и b.*

#### Запись

Якорь: строки 13 + 9 = 22, столбцы 5 + 8 + 9 = 22 ✓

Низ тянется за верхом: **d = 5 − a**, **e = 8 − b**, **f = 9 − c**, **c = 13 − a − b**; свободны только a и b.

> ✅ **План:** Ответ = все пары (a, b), при которых доска
>
> | a | b | 13 − a − b |
> |---|---|---|
> | **5 − a** | **8 − b** | **a + b − 4** |
>
> состоит из шести **разных** цифр.

Рамки: a ≤ 5, b ≤ 8, а из c ≤ 9 следует b ≥ 4 − a.

Отсечение до перебора:

- b ≠ e = 8 − b → **b ≠ 4** во всех ветках
- a и d = 5 − a совпасть не могут (2a = 5), c и f тоже (c + f = 9 нечётно) — эти проверки пусты
- a = 4: f = a + b − 4 = b — повтор всегда, **ветка мертва**
- a = 5: c = 8 − b = e — повтор всегда, **ветка мертва**

Остались ветки a = 0, 1, 2, 3; в каждой b идёт от границы вверх, b = 4 пропускаю. Считаю c = 13 − a − b, d = 5 − a, e = 8 − b, f = a + b − 4 и вычёркиваю доски с повторами.

- **a = 0** (d = 5), b с 4:
  - b = 5 → c = 8, e = 3, f = 1: b = d = 5 ✗
  - b = 6 → c = 7, e = 2, f = 2: e = f ✗
  - b = 7 → c = 6, e = 1, f = 3: **0 7 6 / 5 1 3** ✓
  - b = 8 → c = 5, e = 0, f = 4: c = d = 5 ✗
- **a = 1** (d = 4), b с 3:
  - b = 3 → c = 9, e = 5, f = 0: **1 3 9 / 4 5 0** ✓
  - b = 5 → c = 7, e = 3, f = 2: **1 5 7 / 4 3 2** ✓
  - b = 6 → c = 6: b = c ✗
  - b = 7 → c = 5, e = 1, f = 4: a = e = 1 ✗
  - b = 8 → c = 4: c = d = 4 ✗
- **a = 2** (d = 3), b с 2:
  - b = 2: a = b ✗
  - b = 3 → c = 8, e = 5, f = 1: b = d = 3 ✗
  - b = 5 → c = 6, e = 3, f = 3: e = f = d = 3 ✗
  - b = 6 → c = 5, e = 2, f = 4: a = e = 2 ✗
  - b = 7 → c = 4, e = 1, f = 5: **2 7 4 / 3 1 5** ✓
  - b = 8 → c = 3: c = d = 3 ✗
- **a = 3** (d = 2), b с 1:
  - b = 1 → c = 9, e = 7, f = 0: **3 1 9 / 2 7 0** ✓
  - b = 2 → c = 8, e = 6, f = 1: b = d = 2 ✗
  - b = 3: a = b ✗
  - b = 5 → c = 5: b = c ✗
  - b = 6 → c = 4, e = 2, f = 5: d = e = 2 ✗
  - b = 7 → c = 3: a = c = 3 ✗
  - b = 8 → c = 2: c = d = 2 ✗

**Ответ: 5 досок.**

#### 💬 Фраза в конце — полнота

**Recorrí en orden las cuatro ramas que quedaban y salteé b = 4, que siempre repite; las otras dos ramas repiten siempre una cifra. Por eso no hay más tableros.**

*Прошёл по порядку четыре оставшиеся ветки и пропустил b = 4, где повтор всегда; в двух других ветках цифра тоже повторяется всегда. Поэтому других досок нет.*
