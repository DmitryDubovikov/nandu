# Учебные материалы — карта репозитория

Не софт. Это русскоязычные учебные материалы: олимпиада **Olimpíada Matemática Ñandú** (Аргентина),
школьная математика и кружковые темы. «Исходники» — markdown-документы, «данные» — корпус
оригинальных условий в `korpus/`.

Правила авторства и текущий фокус — в `CLAUDE.md`.

## Структура

```
25-26/  26-27/  27-28/     сезоны занятий
korpus/                    оригинальные условия (общие для всех сезонов)
arhiv/                     отменённые и переписанные версии материалов
tools/                     скрипты скачивания и разбора корпуса, venv
```

### Сезон

Сезон — **с конца октября по конец октября**, по календарю Ñandú: национальный тур закрывает
один сезон и открывает следующий. Привязки к русскому учебному году нет.

- `25-26/` — заканчивается национальным туром 20–23 октября 2026. Содержит `nandu_level1/` —
  курс Primer Nivel целиком (регионал, провинциал, зональный, национальный). **Текущая работа.**
- `26-27/` — `nandu_level2/` (Segundo Nivel), `school5/`, `school6/`, `tinkov/`.
- `27-28/` — `nandu_level3/`, `school7/`, `tinkov/`.

Внутри сезона верхний уровень — **курс целиком**, а не этап: `<сезон>/<курс>/<этап>/файлы`.
У каждого курса свой `README.md` — читать его перед тем, как что-то там писать или править.

Два постоянных запрета: папки `tinkov/` — **карман, а не расписание** (никаких дат и ☐-дней
в трекерах), и **никаких брифов и роадмапов в `27-28/`** — либо пишется конкретная пара, либо идея
выбрасывается.

### Пути в документах

Все ссылки на файлы внутри репозитория пишутся **от корня репозитория**
(`korpus/omn_regional/regional_2024.md`, `25-26/nandu_level1/regional/nandu_n1_regional_roadmap.md`),
а не относительно текущего файла. Это единственный работающий вариант, когда один и тот же документ
читают и из корня, и из своей папки.

## Корпус задач — `korpus/`

⚠ **Здесь живут две разные олимпиады, различай их по префиксу папки:**

- **Ñandú = `omn_*`** (Olimpíada Matemática Ñandú) — начальная школа, на неё и нацелен курс.
  По годам `<этап>_<год>.{pdf,md}` в `omn_regional`, `omn_zonal`, `omn_nacional`, `omn_provincial`
  (в каждом `.md` все три nivel'я Ñandú; курс использует Primer Nivel).
  Плюс `historico/*_N1.md` — многолетние компиляции Nivel 1, используются как ключи ответов.
- **OMA = `oma/`** (Olimpíada Matemática Argentina) — **отдельная, более трудная олимпиада средней школы**,
  возможный следующий шаг после Ñandú. Ни один материал курса на неё не нацелен;
  роадмап-мост, который был нацелен, удалён (см. `27-28/tinkov/README.md`).
  `oma/oma_<этап>_<год>.pdf` за 2021–2025 (этапы inter/zonal/regional/nacional; в каждом PDF Primer/Segundo/Tercer Nivel).
  Скачано с oma.org.ar по `oma_index.json`.

⚠ **`korpus/2025/` — это НЕ Ñandú**: все шесть файлов `2025_*_N1.*` — это OMA secundaria 2025
(скачаны до появления папки `oma/`; теперь они есть и там, помеченные правильно).
Настоящие условия Ñandú 2025 лежат в компиляциях `historico/*_N1.md`, раздел «Año 2025».

## Инструменты — `tools/`

`download.sh` — загрузка PDF через gdown (сначала `source tools/venv/bin/activate`).
`oma_index.json`, `oma_page.html`, `enunciados.js`, `zonal_list.txt` — производное от www.oma.org.ar.
В `tools/venv/` стоит инструментарий извлечения PDF (pypdf, pymupdf, pdfplumber), используется
однострочниками и скриптами `python3` для превращения PDF в `.md`.

Сборки печатных PDF из материалов курса **больше нет** (август 2026): скрипт `build_pdf.py` и
слэш-команда `/pdf` удалены. Материалы читаются и печатаются из markdown как есть.

## Архив — `arhiv/`

- `schet_v1/` — первая версия материалов по счёту (uchebnik, reshebnik, spravochnik, opredelitel,
  session_prompt); в курсе не используется. Живой из неё остаётся только методичка
  `arhiv/schet_v1/nandu_n1_regional_schet_session_prompt.md` — поэтапный workflow создания новой пары (hard rule 7).
