# Национал — пост-учебниковая практика

## Olimpíada Ñandú · Nivel 1 · Certamen Nacional

### Заготовка. Набор задач по типам, пропорционально частоте в окне 2019–2025

> **Статус: пустой каркас.** Условия задач не написаны — это ТЗ для отдельной сессии.
>
> **Зачем этот документ.** Четыре пары учебник+решебник покрывают типы неравномерно: Т3″ получает 22 задачи при частоте 4 из 42, Т2 — 3 задачи при частоте 8 из 42. Пары строились по темам, а не по частоте, и это правильно для обучения; но перед туром нужен добор, выравнивающий покрытие по реальной встречаемости.
>
> **Принцип.** Количество задач на тип выводится из трёх факторов: **частота** в окне 2019–2025 (7 туров, 42 задачи), **знакомость** (сколько этого типа ребёнок уже решал — на регионале, провинциале и в четырёх национальных парах; 5 = тип давно в руках, 1 = встречен впервые) и **когнитивная сложность** для 10–11 лет (5 = максимальная). Обе оценки — по пятибалльной шкале.
>
> **Формула:** `Задач = ceil(Частота / 3) + round((Сложность − Знакомость) / 3)`, результат зажимается в пределы 1–3. Частота даёт базу, разность «сложность минус знакомость» сдвигает её на ±1: новый тяжёлый тип получает добор, знакомый лёгкий — минимум.
>
> **Источник частот:** `nandu_n1_nacional_tipologia.md`, раздел «Сводка по окну 2019–2025».
>

1. **Не из корпуса.** Реальные задачи 2013–2025 уже разошлись по маршрутам пар и по симуляциям боевой фазы; дублировать их нельзя. Задачи генерируются как двойники — по образцу `../nandu_n1_provincial_trenirovka.md`.
2. **Не дублировать блоки решебников.** Ни числами, ни сюжетом.
3. **Национальный формат подачи:** 2–4 вопроса в задаче, а не один; в счётных — обязательное «объясни, почему все и почему не больше» (ритуал Ч5).
4. **Уровень — боевой, а не учебный.** Приём не подсказан условием: задача должна начинаться с опознания типа.
5. **Каждый ответ вычислен и независимо перепроверен** (перебор против приёма).
6. Язык — русский, обращение на «ты», без мета-разговоров про курс.
