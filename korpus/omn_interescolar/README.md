# Corpus del Certamen Interescolar — Ñandú

Место этапа: **первый тур сезона** (начало мая) → зональ → провинциал → регионал → национал.

- `interescolar_<год>.pdf` — официальные PDF с oma.org.ar (`/contents/enunciados/pdf/nandu/<год>/`), 2013–2026.
- `interescolar_<год>.md` — транскрипция всех трёх уровней, формат как в `korpus/omn_zonal/`; рисунки — пометками
  `[Figura: …]`, по которым чертёж восстанавливается без PDF.
- 2020 и 2021 — пандемийный формат: по 6 задач на уровень, только ответ, без «Explica».
- Primer Nivel сверен с компиляцией `korpus/historico/Interescolares_N1.md`; в ней исправлены 2022 №3 (сетка 2×7,
  а не 2×6) и 2016 №3 («los contaste»).
- Выборка Segundo Nivel с типологией — `26-27/nandu_level2/interescolar/`.
