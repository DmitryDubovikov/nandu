# Corpus del Certamen Provincial/Metropolitano — Ñandú Nivel 1

Место этапа в лестнице: **зональный → провинциальный (в CABA — Metropolitano) → региональный → национальный**. В 2025: зональный — конец июня, провинциальный — 18–19 августа, региональный — 28 августа.

## Что здесь лежит

- `provincial_<год>.md` — условия Primer Nivel по годам, 2012–2025. Источник текста: компиляция `korpus/historico/Provinciales_N1.md` (проф. W. O. Rosello), **линия Bonaerense–Metropolitano–Córdoba–Santa Fe** (канонический вариант тура — проверено сверкой с официальными PDF 2013–2016).
- `provincial_<год>.pdf` (2013–2016) — официальные PDF с oma.org.ar (`/contents/enunciados/pdf/provinciales/`), в них есть **рисунки** и все три уровня.
- `provincial_<год>_variante_*.pdf/.md` — параллельные варианты того же тура для других регионов: в 2015/2016 те же задачи с другими числами, в 2014 (metro/otras prov) — **другой комплект задач** (бонусный материал, см. `provincial_2014_variante_metro.md`).
- `provincial_<год>_metro_silvia.pdf` (2019, 2022, 2023, 2024, 2025) — оригинальные PDF тура Metropolitano (от Сильвии, июль 2026), со всеми тремя уровнями и **рисунками**. Тексты Primer Nivel дословно совпадают с нашими `provincial_<год>.md`; ценность — исходные фигуры. По ним уточнены/исправлены рисунки в `provincial_2022.md` (раскладка сумм задачи 1), `provincial_2023.md` (2-3-4-5 точек по прямым, задача 3) и `provincial_2025.md` (доска 4×5, фишки 1×2 — прежняя реконструкция «4×6 / 1×3» была неверной, официальный ответ 68 подтверждён перебором). Июль 2026: по этим же PDF переписаны **все** пометки `[Figura: …]` за 2019 и 2022–2025 — теперь каждая описывает настоящий чертёж (взаимное расположение прямоугольников и треугольников в задачах №2, доска 2×4 с узкими крайними столбцами в 2024 №3). Разборы (по годам: `nandu_n1_provincial_resheniya_<год>.md`) сверены с этими чертежами: все 12 ответов 2022–2025 устояли, переписан только ход 2025 №3.

## Чего здесь нет

- **2020, 2021** — этап не проводился (пандемия).
- **2000–2011** — старые годы остаются в `korpus/historico/Provinciales_N1.md`.
- ⚠ **`../2025/` — это НЕ Ñandú.** Все шесть файлов `2025/2025_*_N1.*` (Colegial…Nacional) — старшая олимпиада **OMA** (простые числа, доказательства, биссектрисы), скачаны по ошибке. Настоящий Ñandú-2025 по всем этапам — в компиляциях `korpus/historico/*_N1.md` (раздел «Año 2025»); провинциал-2025 продублирован здесь как `provincial_2025.md`.
- Официальных PDF за 2017–2019 и 2022–2024 в индексе oma.org.ar нет (файлы `URBANA_*` в тех папках — другая олимпиада, «Olimpíada Matemática Urbana», не Ñandú). Для 2019/2022/2023/2024 оригиналы получены отдельно от Сильвии — см. `provincial_<год>_metro_silvia.pdf` выше.

## Ответы

Официальный ключ ответов по всем годам — в конце `korpus/historico/Provinciales_N1.md` (раздел «Respuestas»). В погодовые файлы ответы намеренно не включены (банк для боевой фазы).

## Исправленная ошибка транскрипции

2015 №3: в транскрипции стояло «tablero 1x6», в официальном PDF — **7 клеток** (проверено по рисунку `provincial_2015.pdf`; официальный ответ «100 maneras» подтверждён brute-force перебором; для 6 клеток было бы 56).
