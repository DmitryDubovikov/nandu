---
description: Собрать печатный PDF (2 страницы A5 на альбомном A4, с номерами) из markdown-файлов курса
argument-hint: <файл.md> [ещё файлы.md ...]
allowed-tools: Bash(venv/bin/python3 build_pdf.py:*), Bash(ls:*), Read, Edit
---

Собери печатные PDF из указанных файлов: **$ARGUMENTS**

Как:

1. Если файлы не указаны — спроси, какие; не угадывай и не собирай всё подряд.
2. Запусти `venv/bin/python3 build_pdf.py <файлы>` из корня репозитория.
   Скрипт делает всё сам: markdown → HTML → Chrome headless (страницы A5) →
   раскладка по две страницы на альбомный A4 + номера страниц + линия реза.
   Результат — `<имя>_print.pdf` рядом с исходником.
3. Проверь результат глазами, а не на веру: через PyMuPDF отрендерь 2–3 листа
   в PNG во временную папку и посмотри их (Read). Смотри на: обрывы таблиц и
   врезок, заголовок один внизу страницы, номер задачи, оторванный от своей
   системы, огромные пустые куски (>40% страницы пусто на нескольких подряд).
4. Если что-то из этого есть — правь CSS/препроцессинг в `build_pdf.py`
   (там уже есть правила `section`, `.keep`, `table.long`) и пересобирай.
   Правила вёрстки общие для всего курса — не хардкодь под один документ.
5. В ответе назови файлы, число листов A4 и напомни: печатать в масштабе 100%
   («Actual size»), **без** опции «2 страницы на листе» в диалоге принтера —
   раскладка уже сделана.
