# Corpus del Certamen Provincial/Metropolitano — Ñandú Nivel 1

Место этапа в лестнице: **зональный → провинциальный (в CABA — Metropolitano) → региональный → национальный**. В 2025: зональный — конец июня, провинциальный — 18–19 августа, региональный — 28 августа.

## Что здесь лежит

- `provincial_<год>.md` — условия Primer Nivel по годам, 2012–2025. Источник текста: компиляция `../historico/Provinciales_N1.md` (проф. W. O. Rosello), **линия Bonaerense–Metropolitano–Córdoba–Santa Fe** (канонический вариант тура — проверено сверкой с официальными PDF 2013–2016).
- `provincial_<год>.pdf` (2013–2016) — официальные PDF с oma.org.ar (`/contents/enunciados/pdf/provinciales/`), в них есть **рисунки** и все три уровня.
- `provincial_<год>_variante_*.pdf/.md` — параллельные варианты того же тура для других регионов: в 2015/2016 те же задачи с другими числами, в 2014 (metro/otras prov) — **другой комплект задач** (бонусный материал, см. `provincial_2014_variante_metro.md`).

## Чего здесь нет

- **2020, 2021** — этап не проводился (пандемия).
- **2000–2011** — старые годы остаются в `../historico/Provinciales_N1.md`.
- ⚠ **`../2025/` — это НЕ Ñandú.** Все шесть файлов `2025/2025_*_N1.*` (Colegial…Nacional) — старшая олимпиада **OMA** (простые числа, доказательства, биссектрисы), скачаны по ошибке. Настоящий Ñandú-2025 по всем этапам — в компиляциях `../historico/*_N1.md` (раздел «Año 2025»); провинциал-2025 продублирован здесь как `provincial_2025.md`.
- Официальных PDF за 2017–2019 и 2022–2024 в индексе oma.org.ar нет (файлы `URBANA_*` в тех папках — другая олимпиада, «Olimpíada Matemática Urbana», не Ñandú).

## Ответы

Официальный ключ ответов по всем годам — в конце `../historico/Provinciales_N1.md` (раздел «Respuestas»). В погодовые файлы ответы намеренно не включены (банк для боевой фазы).

## Исправленная ошибка транскрипции

2015 №3: в транскрипции стояло «tablero 1x6», в официальном PDF — **7 клеток** (проверено по рисунку `provincial_2015.pdf`; официальный ответ «100 maneras» подтверждён brute-force перебором; для 6 клеток было бы 56).
